## 核验链路（四类结论怎么得出）

**第 1 步 抽取（代码，`numbers.py::extract_figures`）**：逐行扫正文与 Markdown 表格；先按掩码表（行内代码、链接、脚注引用、SEC accession `\d{10}-\d{2}-\d{6}`、连字符编号、ISO/中文/短横线日期、财报表单号、实体 id、期间 token、结构计数"第 N 节/3 个支柱"）把非数字 span 替换为空格，再用 `_NUMBER_RE` 抽数字（符号/括号负数、币种、量级词含 billion/million、单位 %/bp/x/美元），表格数字的币种/量级从行表头+列表头+表题继承（`_infer_scale_from_header`，R4-4 修复）；中文口语量词（X成/X折/X分之X/翻倍/翻一番/翻两番/减半）由正则单独抽取；带〔示意〕/〔假设〕/〔估计〕标记或引用块的行标 exempt；脚注 `[^id]` 就近关联并解析为 evidence:/model:/prov:/f: 目标。

**第 2 步 标注（启发式）**：指标名由数字前的最近子句启发式截取（`_extract_metric_from_context`，通用修饰词"同比"会与前句主语拼成"广告收入 同比"）；`label_hint`（consensus/guidance/assumption/estimate/derived/reported）**按整行文本**判定（`_infer_label_hint(scan_line)`）。设计中的 LLM 标注器 `maybe_label_prose_figures_with_llm`（`audit.label_figures`，可补指标/期间/中文写法）**没有任何调用方**（见 M2）。

**第 3 步 匹配（代码筛候选，`match.py::match_figures`）**：顺序为——exempt 直接过；目标价/IRR/三情景收益只认模型单元格；consensus 标签的数字只认一致预期来源（estimates:/yf_analysis/street_estimate），否则 consensus_confusion；有脚注走 Order 0–3（facts 台账 f: → evidence: → model: → prov:）；无脚注先查 facts 台账（指标+期间+数值），再 Order 4 自动搜索 evidence → model → prov。数值比较一律换算后进行（`values_within_tolerance`：半末位容差、pct 0.05pp、跨单位换算；同位数但量级差 10 的幂 → unit_mismatch）；来源候选需指标兼容（`metrics_match`，含增速/利润率方向不匹配即拒）+ 期间相符或未注明。Order 5 对 derived 数字用邻近已核实数字重算（如 40.0% = 24.3/60.8）。

**第 4 步 LLM 判断（仅发布路径，`audit.py::aaudit_draft`，`use_llm_judge=True`）**：对确定性未匹配、且非硬规则冲突（目标价缺模型格、CONTRADICTED_REASONS）的数字，取最多 5 条候选（`retrieve_candidate_sources` 按脚注/指标/期间打分），调 `assist_json("audit.judge")` → `dalton_complete`（准入、预留结算、调用日志、按内容+模型缓存）。草稿阶段 `check_draft` 工具不开 LLM（只写 sidecar 反馈，不阻止）。

**第 5 步 代码复核（`verify_llm_judge_verdict`）**：`supported` 必须四要素齐全（matched_source_id/quote/source_value/source_unit），quote 逐字出现在来源文本、数值换算在容差内、quote 本身无冲突单位，否则降为 unverified/contradicted；`contradicted` 与 `exempt` **直接采信，不做任何复核**（见 M1）；assist 失败/超时/解析失败 → uncertain。

**第 6 步 汇总（`_build_audit_result` → 四类结论）**：
| 结论 | 判定来源 | 发布时处理 |
|---|---|---|
| 已核实 | 确定性 matched（含 exempt/derived）或 LLM supported 且通过代码复核 | 通过 |
| 有矛盾 | reason ∈ {source_conflict, period_mismatch, unit_mismatch, consensus_confusion, consensus_needs_provenance}（确定性产生，或 LLM contradicted/复核降级） | **阻止**（audit_failed，写 .audit.md/.annotated.md） |
| 无来源 | 其余未匹配（unverified；含 LLM 判 unverified、supported 但复核要素缺失）；分析师须补脚注或标〔估计/假设〕（exempt 标记直通） | **阻止** |
| 未能判断 | assist 调用失败/超时/解析失败（uncertain） | **不阻止**，逐条进 PM 审批卡 |

`AuditResult.passed = (contradicted + unverified) == 0`，uncertain 不计入。`run_publish` 状态机：auditing（上述核验）→ auditing 失败即 audit_failed；通过 → reviewing（跨家族独立审稿，经 `dalton_complete`）→ revise/unavailable 阻止，pass → awaiting_pm（交互线程发 interrupt 审批卡，自动任务写 agenda pm_handoff）→ PM 批准（consume_approval 幂等执行一次）→ publishing（不可变归档 + thesis.official）。阻止发布的只有：有矛盾、无来源、审稿不通过/不可用（另加基础设施错误与 rejected/expired/superseded 治理态）——未发现第四类内容性阻止。
