对比「研究总监（Home）」和「工作区分析师」的上下文边界，帮你在发起研究前选对对话入口。

**跨工作区、临时快问、或者需要同时协调多家公司/同事工作区时，找研究总监**；**围绕某家具体公司或专题持续深挖、建模、改文件或跑长流程技能时，直接进对应工作区找分析师**。

## 一眼分清：决策对照表

| 场景特征 | 选「研究总监（Home）」 | 选「公司 / 专题工作区分析师」 |
| :--- | :--- | :--- |
| 只是问一个不落盘的快问题（例如查某条宏观数据或某次电话会要点） | **首选** | 也可，但没必要为此新建工作区 |
| 横向对比 3–5 家不同工作区里的公司结论 | **首选**（统筹全局与团队记忆） | 视野局限于当前工作区 |
| 对单个标的做首次覆盖、财报深拆、搭三表/DCF 模型 | 研究总监会再转派给分析师，多一层交接 | **首选**（直接读写该标的档案与模型） |
| 修改工作区内的 Markdown 报告、HTML 看板或 Excel 文件 | 可通过研究总监派发，或由你切过去改 | **首选**（文件预览面板就在右手边，所见即所得） |
| 让同事的工作区帮你查证一个问题（已开研究总监共享） | **首选**（直接让研究总监点名派给同事工作区） | 仅当对方开了「网页可读写」时才能直接进对方工作区对话 |

## 常见误区与建议

1. **误区：把单家公司的全部深度对话都留在 Home 里**
   - **问题**：Home 没有绑定单一股票代码和公司知识档案（Knowledge/Agenda），跑出来的报告和文件散落在 Home 目录中，后续做该公司的财报跟踪或复盘时很难自动接续。
   - **建议**：长期跟进的标的务必建立独立公司工作区，在对应工作区里沉淀档案与报告。
2. **误区：已经知道目标公司，却每次都先找研究总监“传话”**
   - **建议**：如果是单一标的多轮追问（例如反复调整估值假设、逐段审校草稿），直接进入该公司工作区对话效率最高，还能在右侧实时点开生成的文件与表格。
3. **配合方式**：
   - 当你需要在早会前同时让三家公司更新财报前瞻时，在「研究总监」里一句话派出去最省力；等各家分析师在后台跑完回报后，再点进各自工作区的「查看汇报」细节微调（如果你看不到向同事派活的相关入口，请联系管理员）。
