这页帮你对比「研究总监（Home）」和「工作区分析师」的分工与上下文边界，提问前一眼选对入口。

**跨工作区、临时快问，或者要同时协调多家公司和同事工作区时，找研究总监**。**围绕某家公司或某个专题持续深挖、建模、改文件或跑长流程技能时，直接进对应工作区找分析师**。

## 一眼分清：决策对照表

| 场景特征 | 选「研究总监（Home）」 | 选「公司 / 专题工作区分析师」 |
| :--- | :--- | :--- |
| 只问一个不落盘的快问题（比如查一条宏观数或某次电话会要点） | **首选** | 能用，日常快问找研究总监更轻便 |
| 横向对比 3–5 家不同工作区里的公司结论 | **首选**（能统筹全局和团队记忆） | 视野只落在当前这一个工作区 |
| 对单只标的做首次覆盖、财报深拆、搭三表或 DCF 模型 | 研究总监还得转派给分析师，多一层交接 | **首选**（直接读写这只标的的档案和模型） |
| 修改工作区里的 Markdown 报告、HTML 看板或 Excel | 可以让研究总监派发，或者切过去自己改 | **首选**（文件预览面板就在右手边，改完立刻看到） |
| 让同事的工作区帮你查一个问题（已开研究总监共享） | **首选**（直接让研究总监点名派给同事工作区） | 只有对方开了「网页可读写」时，才能直接进对方工作区对话 |

## 常见误区与建议

1. **误区：把单家公司的全部深度对话都留在 Home 里**
   - **问题**：Home 没有绑定单只股票代码和公司知识档案与研究议程，跑出来的报告和文件会散在 Home 目录里，后面跟财报或复盘时接不上。
   - **建议**：长期跟进的标的要建独立公司工作区，把档案和报告都沉淀在里面。
2. **误区：已经知道是哪家公司，每次还先找研究总监“传话”**
   - **建议**：如果是单一标的多轮追问（比如反复调估值假设、逐段审校草稿），直接进目标公司工作区效率最高，右侧还能实时点开生成的文件和表格。
3. **配合方式**：
   - 早会前想同时让三家公司更新财报前瞻，在「研究总监」里一句话派出去最省力。等各家分析师在后台跑完回报后，再点进各自工作区的「查看汇报」微调细节。如果页面上找不到向同事派活的入口，请联系管理员。
