这页帮你分清 Everflow 里**技能（Skill）**、**插件（Plugin）**和**研究数据源（Research Data）**各自管什么，实操时怎么搭配。

**数据源**提供原材料（研报、财报、专家摘录、行情）。**插件**是把数据源或外部工具接进系统的扩展包。**技能**则是教助手按什么步骤、什么格式、走哪几步核验，把原材料加工成成品报告的操作手册。

## 三层关系对照

| 概念 | 在投研流程里的角色 | 类比理解 | 典型例子 |
| :--- | :--- | :--- | :--- |
| **研究数据源** | 原材料仓库 | 彭博终端、Wind、SEC EDGAR、内部研报库 | AlphaEngine、Guidepoint、SEC XBRL（`dalton_sec`）、`estimates`、雪球 |
| **插件（Plugin）** | 连接仓库和工具箱的适配器 | 装进工作台的接口模块包 | `dalton-data`（内置 `researchdata` 和 `dalton_sec`）、`price_data` 行情服务 |
| **技能（Skill）** | 标准化投研流程与质量模板 | 团队内部《首次覆盖写作指南与核验清单》 | `/initial-coverage`、`/dalton-earnings-preview`、`/dalton-stock-move`、`/dalton-publish` |

## 实操里怎么搭配用

1. **只想查单点事实 → 直接点名数据源**
   - 比如：*“帮我查一下 `alphaengine` 里最近两周关于台积电 CoWoS 产能的卖方纪要，再对比 `dalton_sec` 里的资本开支数字。”*
   - 这时助手只跑一段短小的沙箱代码直连对应数据源，省去整套覆盖流程的耗时。
2. **要出整套研究交付物 → 触发对应技能**
   - 比如：*“运行 `/dalton-earnings-preview` 准备这家公司的三季报前瞻。”* 或者 *“帮我用首次覆盖流程跑一份完整初稿。”*
   - 技能会自动派子代理并发扫 `alphaengine`、`guidepoint`、`transcript`、`sec` 和 `estimates`，最后按团队约定结构落盘并做数字核验。
3. **想改报告模板或加专用检查 → 调整技能或工作区指南**
   - 数据源和插件负责把数据准确取回来。如果你有自己偏好的对比口径或固定排版，把规则写进自定义技能或工作区指南就行。
