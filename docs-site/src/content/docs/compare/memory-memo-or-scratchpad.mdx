这页帮你对比**长期记忆（Memory）**、**个人资料（Memo）**、**团队知识库**、**团队对话归档**和**草稿本（Scratchpad）**，选对材料该放哪里。

想让助手长期记住你的习惯或对某只股票的基本假设，用**长期记忆**。有一批参考文档要跨对话反复翻，传到**资料（Memo）**。要把一手纪要或卖方观点沉淀给全队共享检索，明确要求入库到**公司 Wiki / 销售纪要**。至于**草稿本（Scratchpad）**，当前部署已经关闭，过程稿直接存成工作区普通文件就行。

## 快速决策表

| 你想存什么 | 选哪种方式 | 谁能看到 | 存放在哪与关键限制 |
| :--- | :--- | :--- | :--- |
| 个人偏好、分析口径、某只标的的长期关注点 | **长期记忆（Memory）** | 你自己（按用户或工作区层级） | 随对话自动或按要求更新，每轮注入运行时基线 |
| 方法论 PDF、个人研究模板、多对话共用的参考文件 | **个人资料（Memo）** | 你自己（助手只读，支持 `⌘K` 全文搜） | 右侧「备忘录」面板上传，原文件 ≤ **5 MiB**，抽取正文 ≤ **1 MiB** |
| 管理层或专家一手纪要、团队调研笔记 | **归档至公司 Wiki** | 内部成员和管理员 | 对话里明确要求归档；单文件 ≤ **20 MB**，每人每小时 ≤ **30 次** |
| 卖方研报、券商电话会、销售推票纪要 | **归档至销售纪要** | 内部成员和管理员 | 同上，通过统一入库按「谁在说」自动分流 |
| 本次研究做的中间表格、初稿报告、代码输出 | **工作区普通文件** | 工作区主人和已获授权的同事 | 存在工作区目录里持久保留（右侧文件面板可见） |
| 过去团队对话里讨论过的判断、目标和待办 | **团队历史研究记录（只读归档）** | 内部成员和管理员（需在设置开启） | 截至 2026-11-18 的历史讨论只读知识卡片归档（不再每日新增抽取） |
| 单条对话的临时草稿本（Scratchpad） | **当前已关闭** | — | 当前部署已关闭该功能，请直接用工作区 `.md` 文件 |

## 三条选型原则

1. **分清“个人参考”和“团队资产”**：
   - 只给自己看、不想进团队公共库或受入库去重规则限制的材料，放进**工作区文件**或 **Memo**。
   - 对全团队有复用价值的一手纪要或卖方观点，明确要求归档到 **公司 Wiki** 或 **销售纪要**；也可以打开工作区顶部的「自动入库」，让分析师批量分流。
2. **卖方观点归进销售纪要**：
   - 公司 Wiki 沉淀一手访谈、管理层原话、公告和内部笔记；卖方观点和销售路演进销售纪要。用统一入库入口时，系统会按「谁在说」自动分流。
3. **大文件和超长文本放工作区文件**：
   - 备忘录面板单文件原始体积上限 **5 MiB**，抽取出的纯文本正文上限 **1 MiB**（纯文本过密时建议放进工作区文件）。几十兆的财报 PDF 或原始数据包，请直接拖进**聊天输入框（≤ 200 MiB）**或右侧**工作区文件面板**。
