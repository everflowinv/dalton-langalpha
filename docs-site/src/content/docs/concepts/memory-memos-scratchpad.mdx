分清 Everflow 中**长期记忆（Memory）**、**个人资料（Memo）**、**公司 Wiki / 销售纪要**、**团队对话归档**与 **草稿本（Scratchpad）** 的定位和权限边界。

在当前 Dalton 部署中，**长期记忆**存放助手自动记录的偏好与背景，**Memo** 存放你手动上传的只读参考材料，**公司 Wiki / 销售纪要**用于沉淀全团队共享的正式研究资料，**团队对话归档**记录过去讨论过的研究卡片；而上游的**草稿本（Scratchpad）**功能目前处于**关闭状态**。

## 五种信息载体一览

| 载体 | 谁写入 | 谁可读 | 典型用途 | 当前状态 |
| :--- | :--- | :--- | :--- | :--- |
| **长期记忆（Memory）** | 助手根据对话自动沉淀或按你要求记录 | 当前用户 / 当前工作区 | 记录你的分析口径偏好、标的长期假设、常用格式 | **开启** |
| **个人资料（Memo）** | 你在右侧 Memo 面板主动上传（单文件原始 ≤ **5 MB**、抽取正文 ≤ **1 MiB**） | 你自己的助手只读读取；`⌘K` 可搜索正文 | 长期需要参考的行业框架、个人笔记模板、历史纪要 | **开启** |
| **公司 Wiki / 销售纪要** | 你在对话中明确指示归档入库（或工作区开启「自动入库」） | 内部成员与管理员可用；外部成员不可写入 | 团队共享的一手调研、专家访谈（进 Wiki）或卖方研报/销售路演（进销售纪要） | **开启（限内部+管理员）** |
| **团队对话归档** | 系统后台定时抽取并脱敏归纳对话中的观点、事实与待办卡片 | 通过 `conversation_search` 工具供研究总监和助手检索 | 回溯“之前对某家公司怎么看”、对比不同时期的判断演变 | **开启（研究总监可在设置中开关）** |
| **草稿本（Scratchpad）** | — | — | 上游用于单条对话的临时过程笔记 | **已关闭**（`features.scratchpad.enabled: false`） |

## 重点能力说明

### 1. 资料入库：按“谁在说”自动分流

以前公司 Wiki 在系统里只能读不能写，现在你可以在「研究总监（Home）」或任意公司工作区让分析师把资料正式归档进团队知识库：

1. **自动分流规则**：
   - **销售纪要（Sales Notes）**：主要是券商分析师或销售的判断（如券商深度报告、业绩点评、卖方电话会纪要、销售推票观点、券商撰写的路演总结）。
   - **公司 Wiki**：主要是公司管理层交流、专家访谈（包括券商组织但由公司高管或行业专家本人发言的一手纪要）、公司公告、买方同业交流或团队自己写的研究笔记。
   - 如果单靠标题和正文分不清“谁在说”，分析师会先向你确认再入库，不会乱猜。
2. **两步确认 vs 工作区「自动入库」**：
   - 默认情况下（「自动入库：关闭」），分析师会先生成一份归档预览，等你确认后再正式写入并去重。
   - 开启工作区顶部的**「自动入库」**按钮后，调用统一入库且分类明确、无重复时，会省去等待确认直接写入并返回入库回执；遇到疑似重复或分类不清时，仍会停下来问你。
3. **A 股 / 港股公司别名自助登记**：用中文名或股票代码入公司 Wiki 时，如果系统还没有对应登记，可当场核对或指定英文目录名，并顺手把中文简称和股票代码登记为别名（单次最多 **10 个**）。
4. **体积、格式与频率限制**：
   - 单个文件最大 **20 MB**；
   - 仅支持 `docx`（新版 Word，不含旧版 `doc`）、`pdf`、`md`、`txt`，以及 `png`、`jpg`、`webp` 图片（不含 `jpeg`）；
   - 公司 Wiki 与销售纪要各自限制每人每小时最多正式写入 **30 次**。

:::caution[知识库安全红线]
卖方研报与销售材料按合规与分流规范必须进入**销售纪要**，不要强制归入公司 Wiki。外部成员不可使用公司 Wiki 与销售纪要入库功能，也不可检索团队对话归档。
:::

### 2. 草稿本（Scratchpad）为什么关闭

在当前 `config.dalton.yaml` 配置中，`features.scratchpad.enabled` 设为 `false`。因此界面和助手提示中不会启用临时的对话级草稿笔记目录；研究过程中的中间文档建议直接保存为工作区正式文件（如 `.md` 笔记），由工作区持久化管理。
