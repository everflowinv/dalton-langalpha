这页帮你分清 Everflow 里五种信息载体的定位和权限边界：**长期记忆（Memory）**、**个人资料（Memo）**、**公司 Wiki / 销售纪要**、**团队对话归档**和**草稿本（Scratchpad）**。

简单来说：**长期记忆**自动记你的偏好和背景，**Memo** 放你自己传的只读参考文档，**公司 Wiki / 销售纪要**沉淀全队共享的正式研究资料，**团队对话归档**留着历史研究卡片；**草稿本（Scratchpad）**在当前部署里处于**关闭状态**。

## 五种信息载体一览

| 载体 | 谁来写 | 谁能读 | 常见用途 | 当前状态 |
| :--- | :--- | :--- | :--- | :--- |
| **长期记忆（Memory）** | 助手按对话自动沉淀，或按你要求记下 | 当前用户 / 当前工作区 | 记你的分析口径偏好、标的长期假设、常用格式 | **开启** |
| **个人资料（Memo）** | 你在右侧 Memo 面板主动上传（原文件 ≤ **5 MB**、抽取正文 ≤ **1 MiB**） | 你自己的助手只读；`⌘K` 可搜正文 | 长期要翻的行业框架、个人笔记模板、历史纪要 | **开启** |
| **公司 Wiki / 销售纪要** | 你在对话里明确要求入库（或打开工作区「自动入库」） | 内部成员和管理员可用；外部成员不能写 | 团队共享的一手调研、专家访谈（进 Wiki）或卖方研报、销售路演（进销售纪要） | **开启（限内部+管理员）** |
| **团队对话归档** | 系统后台定时抽取并脱敏整理对话里的观点、事实和待办卡片 | 研究总监和助手通过 `conversation_search` 检索 | 回查“以前对某家公司怎么看”、对比不同时期的判断变化 | **开启（研究总监可在设置里开关）** |
| **草稿本（Scratchpad）** | — | — | 上游用来存单条对话的临时过程笔记 | **已关闭**（`features.scratchpad.enabled: false`） |

## 重点能力说明

### 1. 资料入库：按“谁在说”自动分流

你可以在「研究总监（Home）」或任意公司工作区里，让分析师把资料归档进团队知识库（早期公司 Wiki 只支持只读检索，现在也能写入）：

1. **自动分流规则**：
   - **销售纪要（Sales Notes）**：主要是券商分析师或销售的观点，比如券商深度报告、业绩点评、卖方电话会纪要、销售推票、券商写的路演总结。
   - **公司 Wiki**：主要是管理层交流、专家访谈（包括券商组织、由高管或专家本人发言的一手纪要）、公司公告、买方同业交流或团队自己写的研究笔记。
   - 只靠标题和正文看不清“谁在说”时，分析师会先问你确认，不会擅自乱分。
2. **两步确认 vs 工作区「自动入库」**：
   - 默认状态下（「自动入库：关闭」），分析师先出归档预览，等你点头再写入并去重。
   - 打开工作区顶部的**「自动入库」**开关后，只要分类明确又不重复，调统一入库入口会直接写入并回执。遇到疑似重复或分类拿不准时，还是会停下来问你。
3. **A 股 / 港股公司别名自助登记**：用中文名或股票代码往公司 Wiki 入库时，如果库里还没登记，可以当场核对或指定英文目录名，顺便登记中文简称和股票代码别名（单次最多 **10 个**）。
4. **大小、格式和频率限制**：
   - 单文件最大 **20 MB**；
   - 只支持 `docx`（新版 Word，不含旧版 `doc`）、`pdf`、`md`、`txt`，以及 `png`、`jpg`、`webp` 图片（不含 `jpeg`）；
   - 公司 Wiki 和销售纪要各自限制每人每小时最多写入 **30 次**。

:::caution[知识库合规边界]
卖方研报和销售材料按合规分流规则必须进**销售纪要**，不要硬塞进公司 Wiki。外部成员既不能往公司 Wiki 和销售纪要入库，也不能搜团队对话归档。
:::

### 2. 草稿本（Scratchpad）当前状态

在 `config.dalton.yaml` 里，`features.scratchpad.enabled` 设为 `false`，界面和提示里都关掉了临时的对话级草稿目录。研究过程中产生的中间文档，建议直接存成工作区正式文件（比如 `.md` 笔记），由工作区持久保存。
