这页讲清 Everflow 的三类后台任务：**自动化任务（Automations）**、**唤醒（Wakeups）**和**后台命令（Background Commands）**。

日常的定时研究和个股异动监控，统一在左侧导航的 **自动化（`/automations`）** 里配。对话里跑超 5 分钟的长脚本，会自动转成**后台命令**并在跑完后汇报。至于对话内自定唤醒（`schedule_wakeup`）和内置目标价（`watch_market`），在当前 Dalton 部署里保持**关闭状态**。

## 1. 自动化任务（Automations）

打开左侧主导航的 **自动化（`/automations`）**，就能新建和管理个人与团队任务，触发方式有三种：

| 触发方式 | 界面标签 | 适用场景 | 关键规则 |
| :--- | :--- | :--- | :--- |
| **按计划（Cron）** | `按计划` | 每日盘前晨报、每周行业扫描、定期公司巡检 | 自选执行频率和时区（默认跟随 Home 时区） |
| **一次性（Once）** | `一次性` | 约好未来某个时间点跑一次研究或检查 | 到点跑完一次后自动归进「已完成」分组 |
| **价格触线时（Price）** | `价格触线时` | 盯某只股票冲破目标价，或单日/相对基准涨跌幅达标 | 填上股票代码和触发条件（金额或百分比基准）就行 |

### 可靠性与管理能力

- **前置预检（Preflight）**：平台托管的自动巡检启动前，会先跑一次零消耗预检，看有没有新事件或达到触发条件。常规任务预检超时 **45 秒**，数据健康任务 `dalton-data-health` 超时 **600 秒**，没达条件就直接跳过。公司跟踪、行业巡检和数据健康任务在预检超时后也会跳过，省掉多余开销；日历和研究总监日报、周报这类汇总任务预检超时后，仍会保守唤醒分析。用户自己新建的普通自动化任务直接按设定触发，不走这套预检。
- **团队公共任务与版本回滚**：内部成员和管理员能在自动化页看到团队公共任务（比如定期研报扫描、公司近况巡检）的运行记录和修改历史，还能一键回滚版本。删掉的任务会进 **30 天回收站**，误删随时能找回。
- **指定模型与通知路线**：在高级选项里，可以给单条任务指定模型（留空就用账户默认模型）。列表页和详情页还能勾选个人或飞书团队群推送目标，详情见 [定时报告与投递](/help/everflow/scheduled-reports-and-delivery/)。
- **后台续跑保持投递**：自动化任务派生出后台命令或子代理时，执行记录会一直等它彻底跑完（当前默认最长上限 **6 小时**，由系统工作流超时和至少 3 小时保底共同决定），确保最终报告不会漏发。

### 跟踪议程（Agenda）的到期规则

在公司工作区的议程里记待验证事项时，如果只填了日期（比如 `2026-11-18`）没写具体时间，系统会按**这只股票所属交易所当地时间 18:00** 判定到期：

- A 股按上海时间 18:00，港股按香港时间 18:00，美股按纽约时间 18:00（顺带覆盖收盘后业绩电话会）。
- 往议程里加或改到期时间，只认标准日期（`YYYY-MM-DD`）或带时区的完整 ISO 时间，写模糊文字会被拒绝。

## 2. 唤醒（Wakeups）与内置盯盘目标价

在 `config.dalton.yaml` 里，`features.wakeups.enabled` 和 `features.market_watch.enabled` 都设成了 `false`：

- 助手不会在对话里私自注册后台定时器（`schedule_wakeup`）或内置价格触发器（`watch_market`），免得无人看管时悄悄耗掉预算。
- 所有定时追踪或盯盘需求，都请在 [自动化（`/automations`）](/help/explore/price-move-watch/) 里明明白白配好开关和条件。

## 3. 后台命令（Background Commands）

分析师在沙箱里用 Bash 或 `execute_code` 跑耗时任务（比如批量回测、长音视频转写后处理、大规模数据清洗）时，后台会这样接管：

1. **超时自动转后台**：单次调用默认等 **5 分钟**（Bash 最长可设 **10 分钟**，助手也能一开始就设成后台跑）。超时的命令会自动转到后台继续跑，日志写进 `.agents/threads/<thread8>/commands/<command_id>.log`。
2. **随时看进度与停止**：聊天框底部状态栏会显示**「N 个命令运行中」**，对应的步骤行上有实时状态和**停止**按钮，不想等随时能掐掉。
3. **跑完自动汇报**：命令结束时，如果这一轮对话还在跑，结果直接并进当前回复；如果这一轮已经结束，系统会自动开新一轮把结果交给你。
4. **预算撞顶也不丢结果**：命令跑完时正好碰到每日预算耗尽，结果会先安全存好。等你调整好预算，回到原对话发一句话就能取出完整输出。
5. **休眠停机规则**：在闲置会自动休眠的计算机上，后台命令会在所在对话最后一轮回答结束 **1 小时**后自动停止。

:::note[后台命令一直跑不完？]
点步骤行上的**停止**按钮，再让分析师查查日志报错，或者缩小范围重跑一次。
:::
