这页讲清 Everflow 的三类后台任务：**自动化任务（Automations）**、**唤醒（Wakeups）**和**后台命令（Background Commands）**。

日常的定时研究、预约执行和个股异动盯盘，统一在左侧导航的 **自动化（`/automations`）** 里配；对话里跑超 5 分钟的长脚本，会自动转成**后台命令**并在跑完后汇报。

## 1. 自动化任务（Automations）

打开左侧主导航的 **自动化（`/automations`）**，就能新建和管理个人与团队任务，触发方式有三种：

| 触发方式 | 界面标签 | 适用场景 | 关键规则 |
| :--- | :--- | :--- | :--- |
| **按计划（Cron）** | `按计划` | 每日盘前晨报、每周行业扫描、定期公司巡检 | 自选执行频率和时区（更新任务时保留原任务时区） |
| **一次性（Once）** | `一次性` | 约好未来某个时间点跑一次研究或检查 | 到点跑完一次后自动归进「已结束」分组 |
| **价格触线时（Price）** | `价格触线时` | 盯某只股票冲破目标价，或单日/相对基准涨跌幅达标 | 填上股票代码和触发条件（金额或百分比基准）就行 |

### 可靠性与管理能力

- **前置预检（Preflight）**：平台托管的自动巡检启动前，会先跑一次零消耗预检，看有没有新事件或达到触发条件。常规任务预检超时 **45 秒**，数据健康体检超时 **600 秒**，没达条件就直接跳过。公司跟踪、行业巡检和数据健康任务在预检超时后也会跳过，省掉多余开销；日历和研究总监日报、周报这类汇总任务预检超时后，仍会保守唤醒分析。用户自己新建的普通自动化任务直接按设定触发，不走这套预检。
- **团队公共任务与版本回滚**：内部成员和管理员能在自动化页看到**公司公共任务**（比如定期研报扫描、公司近况巡检）的运行记录和修改历史，还能一键回滚版本。删掉的任务会进 **30 天回收站**，误删随时能找回。
- **指定模型、思考强度与订阅备用切换**：
  - 在任务设置里可以单独指定**模型**和**思考强度**（可设具体档位或「跟随默认」；选 Antigravity 系列模型时同样可在系列选择器中切换该系列的可用档位，未改档时按系列默认强度运行）。自动任务新建的对话以及后续续跑、重试都会沿用该任务选定的模型与思考强度。
  - 自动任务的主订阅模型不可用时，系统会按你的个人备用模型列表依次切换；未设置个人备用列表时，按平台默认 6 档备用链依次尝试，并在执行结果中注明改用了哪个模型（手动对话则直接弹出提示，由你按需切换模型，详情见 [模型与额度](/help/concepts/models-and-budgets/)）。
- **推送路线与执行历史投递状态**：
  - 列表页和详情页可以开关单任务推送并选择个人或飞书团队群推送目标，详见 [定时报告与投递](/help/everflow/scheduled-reports-and-delivery/)。
  - 执行历史里会直接显示每次运行的投递结果：**「已完成」**、**「已完成 · 投递中」**、**「已完成 · 投递失败」**、**「已完成 · 部分投递失败」**，点开可看各目标的具体原因（包括「投递状态未确认」）。按计算机筛选执行历史时，同时覆盖任务本身或其对话落在该计算机上的记录。
- **后台续跑保持投递**：自动化任务派生出后台命令或子代理时，执行记录会一直等它彻底跑完（当前默认最长上限 **6 小时**，由系统工作流超时和至少 3 小时保底共同决定），确保最终报告完整发出。

### 跟踪议程（Agenda）的到期规则

在公司工作区的议程里记待验证事项时，如果只填了日期（比如 `2026-11-18`）没写具体时间，系统会按**这只股票所属交易所当地时间 18:00** 判定到期：

- A 股按上海时间 18:00，港股按香港时间 18:00，美股按纽约时间 18:00（顺带覆盖收盘后业绩电话会）。
- 往议程里加或改到期时间，只认标准日期（`YYYY-MM-DD`）或带时区的完整时间格式，写模糊文字会被拒绝。

## 2. 定时与盯盘的统一入口

所有周期巡检、预约执行和股价盯盘都在 [自动化（`/automations`）](/help/explore/price-move-watch/) 里统一配置、显式开关和查看记录，确保预算清晰可控。

## 3. 后台命令（Background Commands）

分析师在沙箱里跑耗时脚本（比如批量回测、长音视频转写后处理、大规模数据清洗）时，后台会这样接管：

1. **超时自动转后台**：单次调用默认等 **5 分钟**（最长可设 **10 分钟**，助手也能一开始就设成后台跑）。超时的命令会自动转到后台继续跑并完整记录日志。
2. **随时看进度与停止**：聊天框底部状态栏会显示**「N 个命令运行中」**，对应的步骤行上有实时状态和**停止**按钮，不想等随时能掐掉。
3. **跑完自动汇报**：命令结束时，如果这一轮对话还在跑，结果直接并进当前回复；如果这一轮已经结束，系统会自动开新一轮把结果交给你。
4. **预算撞顶也不丢结果**：命令跑完时正好碰到每日预算耗尽，结果会先安全存好。等你调整好预算，回到原对话发一句话就能取出完整输出。
5. **休眠停机规则**：在闲置会自动休眠的计算机上，后台命令会在所在对话最后一轮回答结束 **1 小时**后自动停止。

:::note[后台命令一直跑不完？]
点步骤行上的**停止**按钮，再让分析师查查日志报错，或者缩小范围重跑一次。
:::
