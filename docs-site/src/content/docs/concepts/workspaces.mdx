这页讲清工作区（Workspace）和 `Home` 的分工，以及创建、自动跟踪、归档和迁移规则。

一个工作区对应一个研究对象，把它的对话、文件、长期记忆和自动跟踪任务收在一起。工作区默认建在你的主计算机沙箱上，同一台计算机上的工作区共用底层容器。**`Home` 工作区**专属于「研究总监」，永久归你个人所有，不会对外共享。

## 两种工作区：Home 与普通工作区

| 类型 | 对应助手 | 目录与用途 | 共享规则 |
| :--- | :--- | :--- | :--- |
| **Home 工作区** | 研究总监（Chief of Staff） | 放跨工作区协调对话，以及研究总监自己的临时或汇总文件 | 永久私有，不会出现在团队分组，别人看不了 |
| **公司 / 专题工作区** | 工作区分析师（Analyst） | 围绕某家公司（比如宁德时代、NVIDIA）或跨公司主题（比如算力供应链）做长期研究 | 内部成员可通过「共享设置」设为不可见、仅可读或可读写；研究总监跨区派活由设置总开关控制 |

## 创建与命名

1. 在左侧工作区总览或侧栏顶部点**新建工作区**，填个名字就行。
2. 你也可以在对话里直接让研究总监帮你建一个工作区。
3. **重名检查**：新建工作区时，系统会拦住重名，防止重复创建。
4. **重命名同步**：工作区改名后，底层计算机目录会在下次打开那台计算机时跟着同步。

## 自动跟踪与公司识别

- **有股票代码的公司工作区**：如果工作区围绕单家上市公司展开，分析师会自动读取工作区档案和核心论点里的股票代码（比如 `0700.HK`、`002271.SZ`），用来识别交易所时区、财报日历和行情接口。
- **跨公司主题工作区**：没有绑定单只股票的主题工作区，系统会自动隐藏「自动跟踪」开关，免得跑出无效巡检。
- **自动入库开关**：公司工作区顶部栏有**「自动入库：开启 / 关闭」**开关（默认关闭）。打开后，只要归档材料分类明确又不重复，分析师就能直接写入公司 Wiki 或销售纪要，不用再等你二次确认。

## 归档、删除与跨机迁移

- **归档工作区**：不再频繁跟进的标的可以归档，对话和文件都会留在历史记录里。工作区归档或取消权限后，之前通过同事派发发起过对话的人，还是能在自己页面里只读回看历史。
- **删除限制**：里面有**已发布正式研究报告**的工作区只能归档，不能直接删除，避免团队正在引用的报告丢掉。
- **多机迁移**：名下有多台计算机时，可以在工作区菜单里把普通工作区迁到另一台计算机。同一台计算机上的工作区共用一个 OS 用户和执行环境。

:::caution[安全与信任边界]
同一台计算机上的工作区共用同一个沙箱执行用户，工作区隔离主要用来区分研究上下文和权限路由。如果要和外部协作，外部成员的账户和工作区会跑在完全隔离的独立环境里，详情见 [分享与权限边界](/help/concepts/sharing/)。
:::
