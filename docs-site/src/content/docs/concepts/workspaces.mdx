说明**工作区（Workspace）**与 `Home` 的组织方式，以及命名、自动跟踪、归档和删除规则。

工作区是把**一个研究对象的对话、持久化文件、长期记忆与自动跟踪任务**绑定在一起的工作目录（默认建在你的主计算机沙箱上；同一计算机上的工作区共享底层容器环境）；其中 **`Home`** 工作区专属于「研究总监」，永久归你个人所有，绝不对外共享。

## 两种工作区：Home 与普通工作区

| 类型 | 对应助手 | 目录与用途 | 共享规则 |
| :--- | :--- | :--- | :--- |
| **Home 工作区** | 研究总监（Chief of Staff） | 存放跨工作区协调对话和研究总监自己的临时/汇总文件 | 永久私有，不可在团队分组展示，他人无法访问 |
| **公司 / 专题工作区** | 工作区分析师（Analyst） | 围绕某家公司（如宁德时代、NVIDIA）或某个跨公司主题（如算力供应链）开展长期深度研究 | 内部成员可通过工作区「共享设置」设为不可见 / 仅可读 / 可读写；研究总监跨工作区派活由设置页总开关控制 |

## 创建与命名

1. 在左侧工作区总览或侧边栏顶部点击**新建工作区**，输入名称即可。
2. 也可以在对话里直接让研究总监替你建一个工作区。
3. **重复名称保护**：创建工作区时，系统会检查避免同名的重复工作区误建。
4. **重命名同步**：重命名工作区后，底层计算机目录会在下次打开该计算机时跟随更新，无需手动迁移文件。

## 自动跟踪与公司识别

- **有股票代码的公司工作区**：如果工作区围绕单一上市公司展开，分析师会自动读取工作区档案与核心论点里的股票代码（例如 `0700.HK`、`002271.SZ`），据此识别交易所时区、财报日历与行情接口。
- **跨公司主题工作区**：对于没有绑定单一股票代码的主题研究工作区，系统会自动隐藏无意义的「自动跟踪」开关，避免产生无效巡检。
- **自动入库开关**：在公司工作区顶部栏提供**「自动入库：开启 / 关闭」**开关（默认关闭）。开启后，让分析师调用统一入库入口归档资料时，只要分类明确且不重复，可跳过二次确认直接写入公司 Wiki 或销售纪要。

## 归档、删除与跨机迁移

- **归档工作区**：不再频繁跟进的研究对象可以归档，对话与文件保留在历史记录中；归档或取消访问权限后，曾经通过同事派发在该工作区发起过对话的发起人，仍可在自己的页面以只读方式回看历史对话。
- **删除限制**：包含**已发布正式研究报告**的工作区禁止直接删除，只能归档，防止团队已引用的研报产物丢失。
- **同一计算机与迁移**：你名下的多台可用计算机可以在工作区菜单里进行普通工作区的迁移操作；位于同一台计算机上的工作区共享底层 OS 用户与执行环境。

:::caution[安全与信任边界]
同一台计算机上的工作区共享同一个沙箱执行用户。工作区隔离是面向研究上下文和权限路由的设计，而非跨工作区的安全边界。如果需要对外协作，外部成员的账户和工作区运行在完全隔离的独立环境中，详情见 [分享与权限边界](/help/concepts/sharing/)。
:::
