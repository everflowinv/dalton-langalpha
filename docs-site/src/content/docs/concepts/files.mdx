梳理工作区文件的持久化周期、上传大小限制、PDF/图片处理机制与飞书导出边界。

工作区里的常规文件（你上传的资料、助手下载的公告、生成的 Markdown/Excel/PDF/HTML 报告）在满足持久化体积上限与同步规则的前提下会自动保存，并在右侧**文件面板**实时展示；大文件请优先通过对话输入框直传（上限 **200 MiB**）或文件面板上传。

## 工作区文件与持久化

- **持久化目录与体积上限**：工作区根目录下的普通文件会在容器停止、重启或重建后从持久化存储恢复，但受当前部署的存储路径上限约束——未开启对象存储时单文件持久化上限为 **100 MiB**，走服务端中转的对象存储为 **256 MiB**，仅在启用沙箱直传对象存储时才不受单文件固定上限限制（仅受磁盘空间约束）；此外 `.git`、`__pycache__`、`.pyc` 等依赖/缓存目录与构建产物默认不纳入备份。
- **保存失败与超限提示**：如果助手生成或你放入工作区的文件超过上述备份上限（例如未开对象存储时生成了 150 MiB 文件）或路径过长，系统会在备份时跳过该文件而不覆盖已有记录，并在工作区备份状态中显示「`N 个未保存`」及具体原因（如「`文件过大，无法在此备份。请移动或拆分。`」或「`路径过长，无法备份。请缩短文件夹名称。`」）。遇到超限大文件请及时拆分或下载到本地保存。
- **特殊只读挂载路径**：系统内部使用的长期记忆（Memory）、个人资料（Memo）和历史索引由服务端直接托管，部分路径以只读方式供助手查阅，不可当作普通草稿随意覆盖。
- **上传时间戳保留**：通过文件面板或中转路径上传/恢复的文件会保留正确的当前时间戳，方便按修改时间排序查找最新成果。

## 上传方式与体积上限

| 上传位置 | 单文件上限 | 批量 / 整条消息上限 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **聊天输入框（直传工作区）** | **200 MiB** | **600 MiB** / 条消息 | 直接随提问发给分析师的大 PDF、数据压缩包、大型 Excel 模型 |
| **聊天输入框（无工作区内联回退）** | **30 MiB** | **60 MiB** / 条消息 | 仅在无工作区环境触发的轻量内联附件 |
| **右侧「文件面板」** | 视存储配置（默认持久化 **100 MiB**，对象存储中转最高 **256 MiB**） | 支持多文件拖拽排队依次上传，中途可继续拖入 | 把一批底稿、纪要、原始数据提前放进工作区 |
| **右侧「资料（Memo）面板」** | 原始 **5 MiB**（抽取正文上限 **1 MiB**，文本密集型超限会拒收） | 支持多文件排队上传，失败项单独列出 | 长期跨对话只读参考的个人背景文档 |

## PDF、图片与 Excel 的阅读体验

- **大 PDF 分片加载与分段读取**：
  - 在右侧文件面板预览大体积 PDF 时，系统首次优先请求前 **4 MiB** 并按翻页按需分段加载，减少等待时间。
  - **上传与直接读取上限区分**：通过聊天输入框可将最大 **200 MiB** 的 PDF 上传并存入工作区（右侧文件面板视存储配置支持 **100 MiB** 或 **256 MiB**）；当分析师使用 `Read` 工具直接把 PDF 源文件加载进上下文时，单份源文件读取上限为 **64 MiB**，系统会把文件路径和总页数交给分析师按每次 **20 页**分段读取重点内容（超过 **64 MiB** 的 PDF 仍可在工作区内通过 Python 脚本抽取文本；未落盘工作区的内联 PDF 受 **10 MiB** 限制）。
- **大图片自动压缩适配**：发给模型的图片超过 **5 MiB**、分辨率过大或方向旋转时，系统会自动缩放、转格式并摆正；单次传给模型的图片总预算为 **20 MiB**。
- **Excel / CSV 表格与图表预览**：点击工作区中的 `.xlsx` / `.csv` 文件可直接按工作表网格渲染（保留原生单元格样式与公式计算结果），点击右侧右上角**展开面板**即可全宽看大表。

## HTML 报告与飞书文档

1. **HTML 报告预览与发布**：
   - Dalton 生成的 HTML 研究报告或交互式看板，可在右侧面板顶部切换**查看页面 / 查看源代码**，或**在新标签页打开**。
   - 点击工具栏的**发布**按钮，即可将该网页或目录挂到 [监控面板](/help/everflow/monitors/) 供自己或团队查看。
2. **飞书文档读写边界（仅限内部成员与管理员）**：
   - **读取**：把飞书文档链接发给研究总监或分析师即可直接阅读并总结，也可查看飞书知识空间目录。
   - **写入**：**只有当你明确在对话里要求**“写成飞书文档”或“追加到飞书文档末尾”时，助手才会写入飞书（不会在没要求时擅自发到飞书）。
   - **图片上传**：带图表的 Markdown 报告写入飞书时，会自动上传工作区内的配图；新建文档会自动给内部团队跟踪群和你的公司邮箱开通完全权限。
   - **当前限制**：飞书写入目前**只支持新建文档和在已有文档末尾追加**，不支持覆盖原文、删除段落、移动位置或修改权限。外部成员无法新建或追加飞书文档，仅能读取管理员开放范围内的飞书知识空间文档。
