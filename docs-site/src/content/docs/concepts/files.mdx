这页讲清工作区文件的保存机制、上传上限、PDF 与图片怎么处理，以及飞书文档的读写边界。

工作区里的常规文件——包括你传的资料、助手下载的公告和生成的 Markdown、Excel、PDF、HTML 报告——都会按持久化规则自动保存，并在右侧**文件面板**实时显示。大文件优先从对话输入框直传（上限 **200 MiB**）或通过文件面板上传。

## 工作区文件与持久化

- **持久化目录与大小上限**：工作区根目录下的普通文件，在容器停机、重启或重建后都会从持久化存储恢复。单文件能存多大，看后台配了哪种存储路径：未开对象存储时是 **100 MiB**，服务端中转的对象存储是 **256 MiB**，沙箱直传对象存储时只受磁盘空间限制。`.git`、`__pycache__`、`.pyc` 这类缓存和构建目录默认不备份。
- **超限备份提醒**：如果文件超过备份上限（比如没开对象存储时生成了 150 MiB 文件）或路径太长，系统会在备份时跳过它并保住已有记录，同时在工作区备份状态里提示「`N 个未保存`」及具体原因。遇到这类大文件，记得及时拆分、缩短文件夹名或下载到本地。
- **只读挂载路径**：系统用的长期记忆（Memory）、个人备忘文档和历史索引由服务端直接托管，供助手只读查阅；需要调整长期记忆或备忘文档时，通过对话或右侧「备忘录」面板操作即可。
- **保留上传时间**：通过文件面板或中转路径上传、恢复的文件，都会保留准确的当前时间戳，方便按修改时间排序找最新文件。

## 上传方式与大小上限

| 上传位置 | 单文件上限 | 批量 / 单条消息上限 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **聊天输入框（直传工作区）** | **200 MiB** | 单条消息最多 **10 个附件**、合计 **600 MiB**（未发送大文件暂存上限每人 20 个 / 1000 MiB） | 随提问发给分析师的大 PDF、数据压缩包、大型 Excel 模型 |
| **聊天输入框（无工作区内联回退）** | **30 MiB** | **60 MiB** / 条消息 | 只在无工作区环境触发的轻量内联附件 |
| **右侧「文件面板」** | 看存储配置（默认持久化 **100 MiB**，对象存储中转最高 **256 MiB**） | 支持拖入多文件排队上传，中途也能继续加 | 提前把底稿、纪要和原始数据放进工作区 |
| **右侧「备忘录」面板（备忘文档）** | 原始 **5 MiB**（抽取正文上限 **1 MiB**，纯文本过密超限会被拒） | 支持多文件排队上传，失败项单独标出 | 长期跨对话只读参考的个人背景文档 |

## PDF、图片与 Excel 怎么看

- **大 PDF 分片加载与分段读取**：
  - 在右侧文件面板看大 PDF 时，页面会先请求前 **4 MiB**，翻页时再按需分段拉取，减少等待。
  - **上传上限与直接读取上限**：聊天输入框能传最大 **200 MiB** 的 PDF 到工作区（右侧文件面板支持 **100 MiB** 或 **256 MiB**）。分析师直接把 PDF 源文件读进上下文时，单文件上限是 **64 MiB**，每次按 **20 页**分段读取重点内容。超过 **64 MiB** 的 PDF 仍留在工作区里，用 Python 脚本就能抽文本。没有落盘工作区的内联 PDF 受 **10 MiB** 限制。
- **大图片自动压缩**：发给模型的图片超过 **5 MiB**、分辨率太高或方向倒了，系统会自动缩放、转格式并摆正。单次传给模型的图片总预算是 **20 MiB**。
- **Excel / CSV 在线预览**：点工作区里的 `.xlsx` 或 `.csv` 文件，直接按工作表网格渲染，保留原单元格样式和公式结果。点右上角**展开面板**就能全宽看大表。
- **会议录音转写与纪要整理（限内部成员与管理员）**：把 `.mp3`、`.wav`、`.m4a`、`.mp4` 等音视频放进工作区（转写任务单文件上限 **2 GiB**；通过网页上传进工作区需在上方聊天框 **200 MiB** / 文件面板 **100–256 MiB** 上限内，超大无损音频请先转码或压缩后再上传），在对话里告知语种（中文或英文）与会议背景（或使用 `/transcribe`），即可在后台转写并按“句对句”保真原则整理成投研纪要、核对数字量级与专名并按需归档入库。

## HTML 报告与飞书文档

1. **HTML 报告预览与发布**：
   - Dalton 做的 HTML 报告或交互看板，可以在右侧面板顶部切换**查看页面 / 查看源代码**，或者**在新标签页打开**。
   - 点工具栏上的**发布**，就能挂到 [监控面板](/help/everflow/monitors/) 给自己或团队看。
2. **飞书文档读写边界（限内部成员与管理员）**：
   - **读取**：把飞书文档链接发给研究总监或分析师，就能直接读正文并做摘要，还能浏览飞书知识空间目录。
   - **写入**：**只有你在对话里明确说**“写成飞书文档”或“追加到飞书文档末尾”时，助手才会动飞书；平时讨论只留在本地工作区。
   - **上传配图**：带图表的 Markdown 报告写进飞书时，会自动把工作区里的配图传上去。新建文档还会自动给内部团队跟踪群和你的公司邮箱开完全权限。
   - **适用范围**：飞书写入支持**新建文档**和**在已有文档末尾追加**；需要改写原段落、调整中间内容或修改全局权限时，直接在飞书里编辑即可。外部成员可只读查阅管理员开放的飞书知识空间文档。
