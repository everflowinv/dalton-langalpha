这页讲清内置投研**技能（Skills）**、Slash 快捷指令、**插件（Plugins）**和程序化工具调用（PTC）怎么配合工作。

**技能**是做好的投研方法论和标准流程，比如首次覆盖、财报前瞻、估值校验和数字核验。**插件**是打包好数据源和工具的扩展。你在对话里直接提需求，或者敲 `/` 指令，助手就能加载对应的技能。

## 内置投研技能体系

Everflow（Dalton）在上游能力的基础上，建了一整套贴合中文投研习惯的技能，覆盖从背景调研、财报跟踪到核验发布的完整流程：

### 核心研究与跟踪技能

- **公司初始化与档案管理**：`/dalton-init-company` 用来建公司知识档案；`/dalton-company-background` 梳理公司背景；日常对话中可直接要求更新核心论点、多空争论和待验证议程。
- **覆盖与深度报告**：
  - `/initial-coverage`（首次覆盖）：多轮编排，并发拉取研报、专家纪要和财报，写出结构化的首次覆盖报告。
  - `/full-coverage`（完整覆盖）：更深入、覆盖面更全的完整流程。
  - `/topic-research`（主题研究）：做跨公司的专题研究。
  - `/weekly-review`（周度复盘）：做周度复盘总结。
- **财报全周期**：
  - `/dalton-earnings-calendar`：跟踪财报日历和近期事件。
  - `/dalton-earnings-preview`：财报前瞻，梳理一致预期、核心看点和情景假设。
  - `/dalton-earnings-flash`：财报速评，财报一出来马上给出 Beat/Miss 和关键指引变化。
  - `/dalton-earnings-deep`：财报深度复盘，结合业绩电话会转写和管理层指引更新核心论点。
- **异动、观点与问答**：
  - `/dalton-stock-move`：个股异动归因分析。
  - `/dalton-thesis-delta`：拿新信息对比核心论点变化，给出五词标准结论（**论点不变、论点加强、论点削弱、论点失效、新论点**）并更新赔率评估。
  - `/bullbear`：多空推演分析。
  - `/dalton-call`：输出投资观点，带年化收益和赔率门槛校验。
  - `/pm-qa`：回答 PM 提问，给出经过核查的精准答复。
  - `/dalton-filing-review`：重点公告深度拆解。
  - `/dalton-financial-lenses`：多维度财务透视分析。
  - `/dalton-director`（研究总监工作区）：扫描覆盖池待办事项，按紧急程度在当天预算内向各公司分析师派活。
  - `/transcribe`（仅内部成员与管理员）：对工作区录音或音视频执行后台转写并整理成保真投研纪要。
- **专题筛选与策略技能**：包括机构 13F 持仓追踪、期权偏度分析、做空筛选、BDC 分析等（在对话中直接描述需求即可触发）。
- **质量护栏与发布**：研究规范、中文文字审校（自动随报告与日常笔记收尾触发，也可在对话中直接要求审查）与 `/dalton-publish`（数据核验、审校与正式发布流程）。

:::tip[不用死记指令名]
除了在输入框敲 `/` 挑指令，你也可以直接用大白话说“帮我写一份这家公司的财报前瞻”或“核一下刚那份草稿的数字”，助手会自动匹配并加载对应技能。
:::

## 插件与程序化工具调用（PTC）

点左侧主导航的 **插件（`/plugins`）**，可以看到现在有哪些可用数据源和扩展：

- **内置核心投研数据插件**：聚合了卖方研报与会议库、专家访谈库、业绩电话会转写、公司 Wiki、销售纪要、TMT 总结、独立研究、SEC 公告与 XBRL 归一化财务事实、一致预期、港 A 股与宏观指标。
- **实时行情服务**：提供美股、港股、A 股、指数，以及期权和宏观报价。
- **批量检索并汇总**：面对高密度研究数据源时，助手会在沙箱里编写 Python 脚本，一次批量查数、对齐口径、去掉重复来源，再把精确结果汇总给你。

## 自定义技能

如果你或团队有固定的分析框架、表格模板或检查清单，可以在工作区或引导对话里把流程沉淀成自定义技能（`SKILL.md`），以后直接复用。
