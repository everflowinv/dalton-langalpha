这页讲清工作区跑代码和存文件所用的托管沙箱配置、共享边界和休眠恢复规则。

在当前 Everflow 部署里，所有工作区都跑在**平台统一托管的云端容器沙箱**里（默认 **2.0 vCPU / 3 GB 内存**）。

## 平台托管沙箱里有什么

沙箱按**计算机**来隔离。新建工作区默认建在你的主计算机上，各自有独立的工作区目录。同一台计算机上的多个工作区共用同一个运行环境、数据连接和本地磁盘。把工作区放到不同的计算机上，才会有容器级隔离。

沙箱里已经提前装好了投研需要的运行环境：

- **Python 数据分析与画图环境**：预装数据处理、图表叠加标注（支持在行情图上画技术指标、趋势线等并导出截图）、美股申报分析，以及 Excel 和 PDF 处理工具。
- **中文 PDF 与音视频处理能力**：内置中文字体映射与音视频解析组件，保证中文研报 PDF 抽文本和会议录音解析正常。
- **内置研究数据通道**：沙箱内已接通授权好的研究数据接口，可直接调研报库、行情、SEC 财报、宏观数据和图表渲染。

## 休眠、恢复与数据持久

1. **自动停止与重建**：闲置的容器过一段时间会自动停机省资源。等你再打开工作区或跑起定时任务，系统会自动拉起容器并从持久化存储还原文件，同一台计算机上的所有工作区会一起恢复挂载。
2. **后台命令的休眠约束**：在闲置会自动休眠的计算机上，脱离对话在后台跑的命令行任务，会在所在对话最后一轮回答结束 **1 小时**后自动停掉。常开计算机没有这个限制。
3. **重计算独立隔离**：大报告的数据核验、超大网页抽正文和 PDF 解析这类重计算，会放进独立的受限通道执行，保持正常对话流畅响应。
4. **网页抓取隔离**：需要抓取动态网页时，会交给独立的受限抓取服务执行，保障对话主服务稳定。

## 运行环境统一托管说明

在当前部署里，全队通过浏览器访问网页版 Everflow，工作区统一运行在平台托管的云端容器沙箱中，网页抓取由后台独立受限服务完成，保持团队环境与安全边界一致。

:::note[如果你名下有多台托管计算机]
部分账号名下会有多台托管计算机。你可以在设置或工作区菜单里指定默认主计算机，或者把普通工作区从一台迁去另一台。
:::
