这页讲清工作区跑代码和存文件所用的托管沙箱配置、共享边界和休眠恢复规则。

在当前 Everflow（Dalton）部署里，所有工作区都跑在**平台统一托管的 Docker 容器沙箱**里（默认 **2.0 vCPU / 3 GB 内存**）。桌面客户端和个人 SSH 电脑目前都没有开放。

## 平台托管沙箱里有什么

沙箱按**计算机**来隔离。新建工作区默认建在你的主计算机上，各自有独立的工作区目录。同一台计算机上的多个工作区共用同一个 Linux 容器，也就是共用 OS 用户、运行依赖、数据连接和本地磁盘。把工作区放到不同的计算机上，才会有容器级隔离。

容器里已经提前装好了投研需要的运行环境：

- **Python 科学计算与投研库**：预装了 `pandas`、`numpy`、`chartkit`（在行情图上画技术指标、趋势线等叠加层并导出图表截图）、`edgartools`（跑 13F 等 SEC 申报分析），以及 Excel 和 PDF 处理工具。
- **中文 PDF 与文档处理能力**：内置了 `poppler-data`（带 Adobe-CNS1 中文字体映射）和 `ffmpeg` / `ffprobe`，保证中文研报 PDF 抽文本和音视频附件解析正常。
- **数据网关与工具封装**：容器里会自动注入授权好的数据桥接模块（`tools.*`）。`execute_code` 可以直接调研报库、行情、SEC XBRL、宏观数据和图表渲染。

## 休眠、恢复与数据持久

1. **自动停止与重建**：闲置的容器过一段时间会自动停机省资源。等你再打开工作区或跑起定时任务，系统会自动拉起容器并从持久化存储还原文件，同一台计算机上的所有工作区会一起恢复挂载。
2. **后台命令的休眠约束**：在闲置会自动休眠的计算机上，脱离对话在后台跑的命令行任务，会在所在对话最后一轮回答结束 **1 小时**后自动停掉。常开计算机没有这个限制。
3. **重计算独立隔离**：大报告的数字核验（Number Audit）、超大网页抽正文和 PDF 解析这类重计算，会放进后端独立受限的子进程跑（默认每个工作进程最多并发 **2** 个），不会卡住你的正常对话。
4. **网页抓取容器隔离**：要用无头浏览器抓动态网页时，会交给独立的受限爬虫容器（并发上限 **1**），保住后台稳定。

## 当前未开放的电脑类型

为了保证数据安全和团队运维一致，下面这些个人电脑和远程连接能力在当前部署里保持关闭：

- **个人电脑 SSH 接入与 SSH 网关**：`agent_config.dalton.yaml` 里的 `offered_providers` 留空，也没开 `SSH_GATEWAY_ADDRESS`。
- **桌面客户端下载与本机遥控**：目前不分发 Mac 或 Windows 桌面端，页面里也没有「控制本机 Mac」入口。
- **沙箱内 `la` 命令行令牌**：`computer_cli_tokens.enabled` 为 `false`，沙箱里不会下发 `la` CLI 访问令牌。

:::note[如果你名下有多台托管计算机]
部分账号名下会有多台托管计算机。你可以在设置或工作区菜单里指定默认主计算机，或者把普通工作区从一台迁去另一台。
:::
