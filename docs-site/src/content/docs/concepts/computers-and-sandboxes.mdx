说明工作区代码执行与文件存放所依赖的托管容器沙箱规格、多工作区共享边界及休眠恢复策略。

在当前 Everflow（Dalton）部署中，所有工作区均运行在**平台统一托管的隔离 Docker 容器沙箱**中（默认配置为 **2.0 vCPU / 3 GB 内存**）；**不开放**个人电脑桌面客户端接入、也不开放 SSH 远程电脑接入。

## 平台托管沙箱里有什么

沙箱的隔离单位是**计算机**而非单个工作区：每个新建工作区默认创建在你的主计算机上，拥有各自的工作区文件夹，但**同一台计算机上的多个工作区共享同一个隔离的 Linux 容器环境**（共用同一 OS 用户、运行依赖、数据连接与本地磁盘；只有放在不同计算机上的工作区才互相容器隔离）。容器内预装了投研所需的运行环境：

- **Python 科学计算与投研库**：预装 `pandas`、`numpy`、`chartkit`（用于在股票行情图上绘制技术指标、趋势线等叠加层并生成图表截图）、`edgartools`（用于 13F 等 SEC 申报分析）及 Excel/PDF 处理依赖。
- **中文 PDF 与文档处理能力**：内置 `poppler-data`（含 Adobe-CNS1 中文字体映射）与 `ffmpeg`/`ffprobe`，保障中文研报 PDF 文本抽取与附件解析稳定运行。
- **数据网关与工具封装**：容器内自动注入经过授权的数据桥接模块（`tools.*`），让 `execute_code` 能直接调用研究库、行情、SEC XBRL、宏观数据与图表渲染。

## 休眠、恢复与数据持久

1. **自动停止与重建**：为节约计算资源，闲置容器会在无活动后进入停止状态；当你再次打开工作区或触发定时任务时，系统会自动启动并从工作区持久化存储中还原文件，同一台计算机上的全部工作区会同步恢复挂载。
2. **后台命令的休眠约束**：在会因闲置而自动休眠的计算机上，如果后台命令行任务已脱离对话运行，系统会在该对话最后一轮回复结束 **1 小时**后自动停止该命令（常开计算机不受此限）。
3. **重度计算独立隔离**：大型报告的数字核验（Number Audit）、超大网页正文抽取和 PDF 解析等重计算，会在后端独立的受限子进程中执行（默认每工作进程并发上限为 **2**），避免阻塞你的正常对话流。
4. **网页抓取容器隔离**：需要调用无头浏览器抓取动态网页时，会由独立的受限爬虫容器（并发上限 **1**）执行，确保后台稳定性。

## 当前部署不提供的电脑类型

为保证数据安全与团队运维一致性，以下个人电脑与远程连接功能在当前部署中保持关闭：

- **不提供个人电脑 SSH 接入与 SSH 网关**：`agent_config.dalton.yaml` 中 `offered_providers` 置空，且未开启 `SSH_GATEWAY_ADDRESS`。
- **不提供桌面客户端下载与本机遥控**：不分发 Mac/Windows 桌面端，也不提供「控制本机 Mac」入口。
- **不启用沙箱内 `la` 命令行令牌**：`computer_cli_tokens.enabled` 为 `false`，沙箱内不会下发 `la` CLI 访问令牌。

:::note[如果你名下有多台托管计算机]
部分账号名下可能存在多台托管计算机，你可以在设置或工作区菜单中指定默认主计算机，或将普通工作区从一台计算机迁移到另一台计算机。
:::
