这页讲清主模型、备用链和后台专用模型怎么路由，以及每日美元预算和单任务上限怎么管。

在 Everflow 里，团队共享的模型凭据由管理员统一维护（`credentials.sharing: team`），普通成员不用自己配 API Key。你可以直接在「设置 → 个人设置 → 模型」挑主对话模型和星标模型，再去「用量与预算」看今天花了多少钱、调每日美元上限（没改过时系统默认 **$100/天**）。

## 模型怎么选：主模型、备用链与后台专用模型

在「设置 → 个人设置 → 模型」里，模型按用途分成三层：

1. **主对话模型与快捷切换（默认模型）**：
   - 对话输入框下面能随时切当前对话的模型；设置页里则可以定新对话的**默认模型**，以及轻量任务用的**后台模型**。
   - 改默认模型时，系统会问你只对新对话生效，还是顺便应用到还没锁定的现有对话。
   - **星标常用模型**：把常用的几个模型点亮星标，它们会排在对话模型选择器的最前面。
2. **备用模型链（Fallback）**：
   - 首选模型碰上限流或上游故障时，系统会按备用链顺序自动切去下一个可用模型，把回答接完。
   - **订阅限额例外**：如果你用的是个人第三方订阅（比如个人 Claude 登录）并且撞上套餐窗口限额（`plan_limited` / `plan_stopped`），系统会停下重试，直接弹出卡片写明重置时间。
3. **后台专用模型路由（点开「高级设置」可见）**：
   - 留空就全部用系统默认值，后台已经按中文投研各环节配好了性价比合适的模型。真要微调时，可以分别指定：
     - **数字核验模型 / 备用模型 / 单次核验超时**（`dalton_audit_model` 等）：跑报告数字核验。
     - **文字审校模型**（`dalton_language_model`）：留空时跟着核验模型走。
     - **独立复核候选模型**（`dalton_reviewer_models`）：用于深度覆盖和报告的多模型交叉复核。
     - **轻量后台任务模型**（`dalton_assist_model`）：跑 JSON 提取这类轻任务。
     - **研究记忆整理模型**（`dalton_extract_model`）：跑后台对话归档抽卡。

## 用量与每日美元预算（Budget）

打开「设置 → 个人设置 → 用量与预算」，就能随时看自己的开销：

- **今日费用概览**：列出今天已结算费用、跑着的任务预占多少，以及还剩多少可用额度。点「今日费用明细」能看到每一笔调用的状态（进行中 / 已结算 / 已退还）。
- **每日美元上限**：数据库里还没单独存过上限的账号，系统按 `dalton.yaml` 的默认值给 **$100 / 天**（时区 `Asia/Shanghai`），你可以自己调高或调低。
- **默认单任务上限与工作区覆盖**：
  - 可以设一个全局的默认单次任务上限，防止个别长流程跑飞。
  - 需要跑全套深度覆盖的重点公司工作区，还能单独设更高的单任务上限，随时也能删掉恢复默认。
- **预占与退还机制**：每个回合启动前，系统先看剩余额度够不够最低准入线（默认 `$0.25`），够的话按块预占 `$1.00`。任务跑完后按实际 token 消耗多退少补，取消或没用完的预占会自动退回来。

## 额度耗尽或模型报错怎么办

- **日预算用完**：下一轮准入时会直接拦下并提示已达每日预算。要是有后台命令正好在预算耗尽前刚跑完，输出会安全留在后台。等恢复或调高日预算后，回到原对话发一句话就能取出来。
- **按付费方提示错误**：用的是个人绑定登录或自有密钥时，错误卡片会原样写出上游返回的报错和账号名（比如余额不足 `402` 或限流窗口）。用的是平台共享额度时，卡片会给出替代建议，比如换模型、稍后再试或新开一条对话。
- **管理员看团队状态**：管理员可以在「设置 → 团队管理 → 模型与供应商」看团队共享凭据的健康度，还能检查或同步最新模型目录；同步完，新模型就会出现在所有人的模型选择器里。
