说明主模型、备用链与后台专用模型的路由规则，以及每日美元预算和单任务上限的控制机制。

Everflow 团队由管理员统一维护共享的模型接入凭据（`credentials.sharing: team`）；普通成员无需自己配 API Key，即可在「设置 → 个人设置 → 模型」挑选主对话模型与快速切换的星标模型，并在「用量与预算」查看今日花费与设置每日美元上限（系统未单独设置时的代码默认日上限为 **$100**）。

## 模型怎么选：主模型、备用链与后台专用模型

在「设置 → 个人设置 → 模型」中，模型按用途分为三层：

1. **主对话模型与快速切换（默认模型）**：
   - 你可以在对话输入框下方随时切换当前对话的模型，也可以在设置里设定新对话的**默认模型**与轻量任务使用的**后台模型**。
   - 变更默认模型时，系统会询问仅对新对话生效还是同时应用到未锁定的现有对话。
   - **星标常用模型**：把常用的几个模型标星后，它们会置顶显示在对话模型选择器的快捷列表中。
2. **备用模型链（Fallback）**：
   - 当首选模型遇到临时限流或上游异常时，系统会按备用链顺序自动切换到下一个可用模型继续回答。
   - **注意订阅限额例外**：对于使用个人第三方订阅（如 Claude 登录等）且触及套餐窗口限额（`plan_limited` / `plan_stopped`）的情况，系统会展示明确的窗口重置时间卡片，不再无意义重试三次。
3. **后台专用模型路由（展开「高级设置」可见）**：
   - 留空时全部自动跟随系统默认值（在后台配置中已针对中文投研各环节挑好高性价比模型）；如有特殊需要，可分别微调：
     - **数字核验模型 / 备用模型 / 单次核验超时**（`dalton_audit_model` 等）：用于报告数字核验。
     - **文字审校模型**（`dalton_language_model`）：留空则跟随核验模型。
     - **独立复核候选模型**（`dalton_reviewer_models`）：用于深度覆盖/报告的多模型交叉复核。
     - **轻量后台任务模型**（`dalton_assist_model`）：用于辅助 JSON 提取等轻任务。
     - **研究记忆整理模型**（`dalton_extract_model`）：用于后台对话归档抽卡。

## 用量与每日美元预算（Budget）

打开「设置 → 个人设置 → 用量与预算」，你可以随时掌握自己的模型开销：

- **今日费用概览**：展示今日已结算费用、当前进行中任务的预占金额以及剩余可用额度，点击「今日费用明细」可展开每一笔调用的实时状态（进行中 / 已结算 / 已退还）。
- **每日美元上限**：未在数据库单独保存过上限的用户，系统按 `dalton.yaml` 的默认配置给予 **$100 / 天**（时区 `Asia/Shanghai`）；你可以根据需要调高或调低。
- **默认单任务上限 & 工作区单任务覆盖**：
  - 你可以设置全局默认的单次任务费用上限，防止个别长流程跑飞；
  - 也可以为某些需要跑全套深度覆盖的特定公司工作区单独配置更高的单任务上限（随时可移除恢复默认）。
- **预占与退还机制**：每次回合启动前，系统会校验剩余可用额度是否达到最低准入线（默认 `$0.25`）并按块预占（`$1.00`）；任务实际结束后按真实 token 消耗多退少补，被取消或未消耗完的预占会自动退还。

## 额度耗尽或模型报错怎么办

- **日预算用完**：系统会在回合准入时拦截并提示已达每日预算；对于刚好在预算耗尽前已经跑完的后台命令，输出会保留在后台，等你恢复或调高日预算后回到对话即可读取。
- **按付费方提示错误**：若使用的是个人绑定登录/自有密钥，错误卡片会直接显示上游服务商返回的原文与账号名（例如余额不足 `402` 或限流窗口）；若使用的是平台共享额度，错误卡片会给出可执行的替代提示（如切换模型、稍后重试或新开对话）。
- **管理员查看团队状态**：团队管理员可在「设置 → 团队管理 → 模型与供应商」查看团队共享凭据健康度，并检查或同步最新模型目录（同步后新模型会自动出现在全体成员的模型选择器中）。
