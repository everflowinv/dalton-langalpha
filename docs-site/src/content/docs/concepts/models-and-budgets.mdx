这页讲清主模型、思考强度、备用模型链和后台专用模型怎么配合，以及每日美元预算和单任务上限怎么管。

在 Everflow 里，**团队共享的模型账号和密钥由管理员在「设置 → 团队管理 → 模型与供应商」统一连接和维护**，普通成员不用自己填密钥。你可以直接在「设置 → 个人设置 → 模型」挑自己的默认主模型、后台模型、思考强度和备用列表，再去「用量与预算」看今天花了多少钱、调每日美元上限（没改过时系统默认 **$100/天**）。

## 模型怎么选：主模型、思考强度、备用链与后台专用模型

在「设置 → 个人设置 → 模型」里，模型按用途分成四块：

1. **默认对话模型、后台模型与收藏的模型**：
   - 对话输入框下面能随时切当前对话的模型和**推理强度**；在你自己发起的对话中（本人工作区，或同事开放了「可读写」的工作区）也可以直接让 Dalton 切换当前对话的模型（切换内置订阅系列时一并说清思考强度，如“换成 Gemini 4 Neon 高强度”，从下一条消息起生效；组织共享工作区的对话请在输入框菜单按条选择）。设置页里则可以定新对话的**默认模型**，以及轻量任务用的**后台模型**（隐藏档位菜单，优先用低思考强度运行，低档不可用时自动取最低可用档；新用户引导默认推荐主模型 **Gemini 4 Neon**、后台模型 **Gemini 4 Hydrogen**）。
   - 改默认模型时，系统会问你只对新对话生效，还是顺便应用到还没锁定的现有对话。
   - **收藏的模型**：把常用的几个模型点亮收藏，它们会排在对话模型选择器的最前面。
2. **Antigravity 按系列合并与思考强度选择**：
   - Google Antigravity 渠道下的同系列模型（如 Gemini 4 Neon、Gemini 4 Hydrogen、Gemini 4 Carbon、Gemini 4 Argon、Claude Opus 5.5 等）在聊天、设置、子 Agent 和自动化选择器里都**合并为一行**，选定系列后在旁边的**思考强度 / 推理强度**菜单直接切档（低 / 中 / 高 / 超高；「后台模型」槽位隐藏档位菜单并优先取低档，低档不可选时使用该系列最低可用档）。
   - 首次新用户引导里只按系列展示，卡片上列出 5 档精选模型的**智能 / 速度 / 说人话**三项评分，选定后自动按系列默认强度保存（后台模型优先低档，低档不可选时使用该系列最低可用档）。
3. **高级模型设置 → 路由（含备用模型）**：
   - 点开**「高级模型设置」**后，最上方是**「路由」**（可配置「网页抓取模型」「上下文压缩模型」和**「备用模型」**）：
   - **手动对话**：主订阅模型遇到登录失效或额度耗尽时，会直接弹出明确提示（含重置时间或联系管理员重连），由你决定等待重置还是手动切换其他模型。
   - **自动任务**：后台运行的自动化任务遇到主订阅不可用时，按你在「备用模型」里保存的列表依次切换（保存空列表即关闭回退）。未自定义过备用列表时，系统自动按团队默认的 **6 档备用链**依次尝试（**Gemini 4 Neon → Claude Opus 5.5 → GPT-6.2 Sol → Grok 4.7 → Muse Wonder 1.0 → DeepSeek Flash**），并在执行摘要里注明改用了哪个模型。
4. **高级：后台任务使用的模型（位于「高级模型设置」下方的二级折叠块）**：
   - 内含**「账户默认值」**、**「按模型设置」**以及 8 项专用模型槽位；留空就全部沿用团队管理员设置或系统默认值。需要微调时，可以分别指定：
     - **数据核验模型 / 数据核验备用模型 / 单次核验超时（秒）**：发布正式报告前核对文中数字与引用来源。
     - **文字审校模型**：检查正式报告表达和术语问题（仅标注提醒），留空则与数据核验模型相同。
     - **独立复核候选模型**：用于深度覆盖和报告的跨模型家族独立复核。
     - **轻量后台任务模型 / 轻量后台任务备用模型**：用于消息预筛选、格式整理等轻量后台任务。
     - **研究记忆整理模型**：对话归档提炼研究结论与长期记忆。

## 用量与每日美元预算

打开「设置 → 个人设置 → 用量与预算」，就能随时看自己的开销：

- **今日费用概览**：顶部展示**「今日个人已用（现金渠道）」**（已合并已结算与未结算预占，对照每日总上限）与**「今日个人已用（订阅折算）」**；展开**「今日费用明细」**能看到每一笔调用的状态（`进行中 / 已结算 / 已退还`）。后台辅助调用按每次实际发出的上游请求据实计费（即使格式解析失败重发也会如实记账）。
- **每日总上限（USD）与日切重置时区**：还没单独改过上限的账号，系统默认给 **$100 / 天**（默认按北京时间 `Asia/Shanghai` 每日重置），你可以按需调高、调低或改日切时区。
- **单任务默认上限（USD，可选）与按工作区覆盖单任务上限**：
  - 可以设一个全局的单任务默认上限，防止个别长流程跑飞。
  - 需要跑全套深度覆盖的重点公司工作区，还能在「按工作区覆盖单任务上限」里单独设更高的上限，随时也能删掉恢复默认。
- **预占与退还机制**：每个回合启动前，系统先看剩余额度够不够最低准入线（默认 `$0.25`），够的话按块预占 `$1.00`。任务跑完后按实际消耗多退少补，取消或没用完的预占会自动退回来。

## 额度耗尽或模型报错怎么办

- **日预算用完**：下一轮准入时会直接拦下并提示已达每日预算。要是有后台命令正好在预算耗尽前刚跑完，输出会安全留在后台。等恢复或调高日预算后，回到原对话发一句话就能取出来。
- **同账号同厂商共享配额冷却**：同一 Google Antigravity 订阅账号下，同一上游厂商的模型共用配额冷却（例如任一 Gemini 模型额度耗尽后，同账号下其余 Gemini 模型也会直接提示“订阅额度耗尽”和重置时间，不再发出必然失败的请求；Claude、GPT 等其他厂商通道独立计算）。
- **按付费方提示错误**：提示卡片会写清是订阅登录失效、订阅额度窗口上限还是按量账户余额不足（402）。团队共用凭据过期时，联系管理员去「设置 → 团队管理 → 模型与供应商」重新连接即可。
- **管理员看团队状态**：管理员可以在「设置 → 团队管理 → 模型与供应商」看团队共享凭据的健康度，还能检查或同步最新模型目录；同步完，新模型就会出现在所有人的模型选择器里。
