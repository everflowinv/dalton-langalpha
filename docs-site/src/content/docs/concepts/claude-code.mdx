这页讲清 **Claude Code 模式**的概念、使用前提，以及在当前 Everflow 团队环境里使用 Claude 模型的方法。

在当前 Everflow 团队部署里，日常使用 Claude 系列模型，直接在模型选择器里选用团队共享目录中的 Claude 订阅模型即可（团队共用凭据由管理员在「设置 → 团队管理 → 模型与供应商」统一连接与维护）。

<span id="how-it-runs" aria-hidden="true"></span>
## 运行方式

在开启了 Claude Code 模式的部署环境中，对话会交给沙箱或指定主机里的命令行会话来跑：

- 每次回合会复用或交接一个对应工作区目录的会话，切换模型前后还会按需自动生成上下文交接摘要。

<span id="requirements" aria-hidden="true"></span>
## 使用前置条件

将来如果团队决定开启 Claude Code 模式，需要同时满足三个条件：

1. **平台已开启该功能并就绪对应运行环境**；
2. **计算机规格达标**：云端容器沙箱需要达到中等（Medium）及以上规格（当前托管沙箱默认为 `2.0 vCPU / 3 GB`）；
3. **有效认证令牌**：需要绑定设置令牌（Setup Token）并通过可用性校验。

<span id="where-it-runs-and-when-it-can-run" aria-hidden="true"></span>
## 运行位置与何时可运行

开启该模式时，一般有两种运行位置：

- **云端容器托管模式**：把设置令牌安全托管后，在规格达标的云端沙箱里运行。
- **自有电脑模式**：在绑定的个人 Mac（桌面端远程控制）或 SSH 电脑在线唤醒状态下运行。

<span id="set-it-up" aria-hidden="true"></span>
## 如何配置

在当前版本里，使用 Claude 系列模型按下面操作即可：

1. 点左下角头像，进「设置 → 个人设置 → 模型」。
2. **使用团队共享 Claude 模型**：在默认模型下拉框或聊天输入框的模型菜单里直接选择团队配好的 Claude 模型（如 Claude Opus 5.5）。
3. **团队共用凭据管理**：团队共用凭据模式下，账号连接、重连与断开由管理员在「设置 → 团队管理 → 模型与供应商」操作；普通成员看到“请重新连接”时联系管理员即可。（当部署关闭团队共用凭据时，由个人在「设置 → 个人设置 → 模型」自行绑定账号。）
4. 以后如果管理员通知团队开启了 Claude Code 模式，再到同一页面按通知绑定令牌。

<span id="moving-from-the-claude-sign-in" aria-hidden="true"></span>
## 从 Claude 账号登录迁移

在开启 Claude Code 模式的环境里，旧版 Claude 登录方式通常会被标记为旧版并提示迁移到设置令牌。

在当前 **Everflow** 团队部署里，主力 Claude 模型通过标准 Claude 订阅通道稳定运行，团队继续沿用现有的 Claude 订阅登录方式即可；管理员随时可以在「设置 → 团队管理 → 模型与供应商」检查连接状态或重新授权。
