这页讲清对话（Thread）和回合（Turn）的生命周期，包括流式重连、上下文压缩、草稿和大附件处理。

一个工作区里可以同时留着多条**对话**，互相不干扰。你在对话里每发一条消息，或者自动化任务触发一次执行，就开启一个新的**回合**。每个回合都会独立记下推理设置、重连缓冲和上下文压缩状态。

## 对话（Thread）与回合（Turn）

- **对话（Thread）**：对应侧边栏里的一条会话记录，收着同一条脉络下的连续追问、产物卡片和引用来源。单次回复的溯源归档最多能记 **10,000 条**，多轮对话会跨回合累计。
- **回合（Turn）**：从你点发送（或后台任务/命令回报唤醒）开始，到助手想完、调完工具并给出最终回复，算一个完整回合。
- **断线与打断保护**：
  - 所有流式事件都会在服务端缓存在 Redis 并写入检查点。刷新页面或网络闪断后，页面会从断点接着重放，保留正在生成的内容。
  - 如果你在大模型刚准备输出时打断对话，下一句还是会用原来选好的模型继续，不会因为格式中断被迫切去备用模型。

## 单条对话的独立推理设置

- 聊天输入框下面调的**推理强度**（高、中、低）和**速度**，只对**当前这条对话**有效，并随这条对话一直保存，换电脑或刷新都不会变。
- 想改所有**新对话**的默认配置，去「设置 → 个人设置 → 模型」调就行。
- 在「设置 → 个人设置 → 对话与助手」里，还能单独设置四项显示偏好：
  - **实时显示推理**（开 / 关）
  - **回答显示方式**（连续显示 / 按段落）
  - **工具调用**（逐行 / 状态行）
  - **回复结束时**（停留在末尾 / 显示回复开头）

## 长对话上下文压缩

一条对话积累了大量工具返回和多轮分析、快接近模型上下文上限时，Everflow 会自动触发**上下文压缩**：

1. **按 token 预算保留近期内容**：系统按 token 预算完整留住最近几轮对话，默认约 **2 万 token**，Claude 模型约 **3.2 万 token**（上限不超过压缩触发阈值的三分之一），保证最近的细节完整可用。
2. **清理早期大附件**：早期回合里占空间的图片和旧内联附件会被清掉，只保留结构化结论，免得后面的追问超时或报错。
3. **跨模型切换交接**：长对话中途换了另一家模型，而历史里有旧模型专用的加密思维摘要时，系统会先让原模型转成通用文字摘要，再交给新模型。
4. **冷启动压缩保持关闭**：在当前 Dalton 部署里，回合开头的冷压缩（`cold_compact_tokens`）设为 `0`，日常长对话只在达到阈值时触发常规压缩。

## 输入框草稿与消息附件

- **自动保存草稿**：在输入框打完字还没发出去，哪怕切到别的工作区或刷新页面，草稿也会保存在当前浏览器里（保留 **7 天**，单条上限 **100 KB**，不同账号互相隔离）。等服务端确认收到消息，草稿就会清掉。注意：**草稿只存文字，不存待发附件**。
- **附件上传方式与上限**：
  - 从聊天输入框加附件时，文件会立刻分段上传，实时显示大小和进度，失败可以单文件重试。
  - **工作区直传上限**：单文件最大 **200 MiB**，单条消息全部附件合计最大 **600 MiB**。文件直接存进工作区 `work/uploads/` 目录，代码沙箱随时能读。
  - **内联回退上限**：当工作区不可用或直传通道没开时，走内联通道的上限是单文件 **30 MiB**、单条消息合计 **60 MiB**。
  - **图片自动适配**：发给模型的单张图片超过 **5 MiB** 或尺寸、方向异常时，系统会自动缩放转码并摆正。单次传给模型的图片总预算是 **20 MiB**，超出时优先保留最新图片，早期的改成传工作区文件路径。
