介绍三类成员身份的权限边界、工作区协同共享、研究总监共享开关以及对外分享时的安全隔离规则。

Everflow 将用户分为**管理员（PM）**、**内部成员**和**外部成员**三类。内部成员之间可以通过「研究总监共享」互相派活，或按工作区开放「只读 / 可读写」网页访问；**外部成员的工作区默认对所有人（包括管理员）不可见，且与研究总监通道完全双向隔离**。`Home` 工作区永远只属于你自己，绝不共享。

## 三类成员的权限边界

| 能力 | 管理员（Admin / PM） | 内部成员（Internal） | 外部成员（External） |
| :--- | :--- | :--- | :--- |
| **自己的工作区与全部数据源** | 可用 | 可用 | 可用（仅限自己工作区） |
| **内部工作区协同与研究总监派活** | 可用 | 可用 | **不可用**（双向严格隔离） |
| **读写飞书文档** | 读写（新建与文末追加） | 读写（新建与文末追加） | **仅可读**管理员开放的指定飞书知识空间 |
| **归档公司 Wiki / 销售纪要** | 可用 | 可用 | **不可用** |
| **检索团队对话归档（`conversation_search`）** | 可用 | 可用 | **不可用** |
| **发布公开对话 / 公开监控面板链接** | 可用 | **不可创建或开启公开链接**（监控面板最高「全公司」） | **不可公开**（监控面板仅「仅自己」） |
| **团队管理（同步模型 / 成员邀请 / 飞书范围）** | 完整管理权限 | 仅部分内部运维查看/受限邀请（视配置） | 不可见 |

## 内部成员的两种共享机制

### 1. 账户级「研究总监共享」总开关

位于「设置 → 个人设置 → 对话与助手 → 工作区协同共享」（**内部成员默认开启**；外部成员设置页不显示此开关）：

- 开启后，内部同事可以在他们自己的「研究总监（Home）」里向你名下除 `Home` 以外的全部工作区派发研究任务或发起提问（如果你在页面上看不到相关入口，请联系管理员）。
- 你随时可以在设置里关闭该开关，关闭后新的派发和追问立即被拦截，正在运行中的任务会正常收尾。

### 2. 工作区级「共享设置」三档网页访问

在某个具体公司工作区右上角打开「共享设置」弹窗，可以单独调整**别人的网页界面**权限（**对所有人默认「不可见」**）：

- **不可见**：同事的左侧栏「团队」分组里看不到这个工作区。
- **仅可读**：同事可以在「团队」分组里打开这个工作区，浏览对话记录和右侧文件，但不能上传文件或发消息。
- **可读写**：同事可以在「团队」分组里进入这个工作区上传/修改文件，并直接新建对话提问。

:::caution[开启共享前必读：整机信任与费用归属]
1. **整机环境信任**：一旦允许内部同事的研究总监访问你的工作区，或把某个工作区网页设为「可读写」，代表对方发起的任务会在**你的计算机环境**中执行（共用同一机的数据连接、第三方数据源配额与磁盘环境）；因此只建议向完全信任的内部同事开放。
2. **费用与入库归属**：同事向你工作区派发任务时，**模型调用费用计入派发人（提问人）自己的每日预算**；如在任务中执行资料入库，入库记录也记在派发人名下。
3. **Home 永不共享**：`Home` 工作区永远只属于你个人，他人不可见、不可派发。
:::

## 外部成员的特殊规则

- **研究总监通道完全隔离**：外部成员的「研究总监」看不到任何内部成员或管理员的工作区；反过来，内部成员和管理员的「研究总监」也永远访问不到外部成员的工作区。
- **网页通道默认全隐藏**：外部成员工作区的网页访问对所有人（**包括管理员**）默认不可见，且别人（含管理员）不能替外部成员修改共享设置。外部成员自己将其调整为「仅可读」或「可读写」后，内部成员与管理员才可按对应的网页权限档位访问或写入（仍不可通过研究总监派活）；其他外部成员之间始终互不可见。
- **禁止外部公开分享**：外部成员不能创建或开启对话公开分享链接，发布监控面板时也只能选择「仅自己」可见（若已存在历史公开链接，关闭撤销仍然允许）。

## 对话与监控面板分享

- **对话分享**：在对话菜单里点击「分享…」，可生成分享链接（仅管理员可创建/启用面向外部的公开访问链接）。
- **监控面板分享**：支持「仅自己 / 指定同事 / 全公司 / 任何人（公开链接，仅管理员）」四档可见范围，详情见 [监控面板](/help/everflow/monitors/)。
