这页讲清 Everflow 三类成员的权限边界、工作区怎么共享，以及对外分享时的隔离规则。

Everflow 把成员分成**管理员（PM）**、**内部成员**和**外部成员**三类。内部成员之间可以开「研究总监共享」互相派活，或者给单个工作区开「只读 / 可读写」网页访问。**外部成员的工作区默认对所有人（包括管理员）隐藏，研究总监通道也完全双向隔离**。`Home` 工作区永远归你个人，绝不共享。

## 三类成员的权限边界

| 能力 | 管理员（Admin / PM） | 内部成员（Internal） | 外部成员（External） |
| :--- | :--- | :--- | :--- |
| **自己的工作区与全部数据源** | 可用 | 可用 | 可用（限自己的工作区） |
| **内部工作区协同与研究总监派活** | 可用 | 可用 | **不可用**（双向隔离） |
| **读写飞书文档** | 读写（新建和文末追加） | 读写（新建和文末追加） | **仅可读**管理员开放的指定飞书知识空间 |
| **归档公司 Wiki / 销售纪要** | 可用 | 可用 | **不可用** |
| **检索团队对话归档（`conversation_search`）** | 可用 | 可用 | **不可用** |
| **发布公开对话 / 公开监控面板链接** | 可用 | **不能建或开公开链接**（监控面板最高「全公司」） | **不能公开**（监控面板仅「仅自己」） |
| **团队管理（同步模型 / 成员邀请 / 飞书范围）** | 完整管理权限 | 仅部分内部运维查看和受限邀请（看配置） | 不可见 |

## 内部成员的两种共享机制

### 1. 账户级「研究总监共享」总开关

这个开关在「设置 → 个人设置 → 对话与助手 → 工作区协同共享」，**内部成员默认打开**，外部成员的设置页里没有这一项：

- 打开后，内部同事可以在他们自己的「研究总监（Home）」里，向你名下除了 `Home` 以外的所有工作区派任务或提问。如果页面上找不到对应入口，请联系管理员。
- 你随时可以关掉这个开关。关掉后，新的派发和追问会立刻被拦住，正在跑的任务会正常收尾。

### 2. 工作区级「共享设置」三档网页访问

在某个公司工作区右上角点开「共享设置」弹窗，可以单独设**别人网页界面**的权限，**对所有人默认「不可见」**：

- **不可见**：同事左侧栏的「团队」分组里看不到这个工作区。
- **仅可读**：同事能在「团队」分组里打开看对话记录和右侧文件，但不能传文件或发消息。
- **可读写**：同事能在「团队」分组里进来上传或改文件，也能直接开新对话提问。

:::caution[开启共享前必读：整机信任与费用归属]
1. **整机环境信任**：只要允许同事的研究总监访问你的工作区，或者把工作区网页设成「可读写」，对方派来的任务就会跑在**你的计算机环境**里，共用同一台机的数据连接、第三方配额和磁盘。只建议向完全信任的内部同事开放。
2. **费用与入库归属**：同事往你的工作区派任务时，**模型调用费算进派发人（提问人）自己的每日预算**。任务里顺便做了资料入库，记录也记在派发人名下。
3. **Home 永不共享**：`Home` 工作区永远只属于你个人，别人看不见，也派不了任务。
:::

## 外部成员的特殊规则

- **研究总监通道完全隔离**：外部成员的「研究总监」看不到任何内部成员或管理员的工作区。反过来，内部成员和管理员的「研究总监」也永远进不去外部成员的工作区。
- **网页通道默认全隐藏**：外部成员工作区的网页访问对所有人（**包括管理员**）默认不可见，而且别人（包括管理员）无权替外部成员改共享设置。只有外部成员自己把它调成「仅可读」或「可读写」后，内部成员和管理员才能按对应档位访问或写入（仍不能走研究总监派活）。外部成员之间始终互相看不见。
- **公开分享范围限制**：外部成员的对话不能生成或打开公开分享链接，发监控面板时可见范围只有「仅自己」一档（已有的历史公开链接仍可关掉撤销）。

## 对话与监控面板分享

- **对话分享**：在对话菜单里点「分享…」，就能生成分享链接。面向外部的公开访问链接只有管理员能创建和开启。
- **监控面板分享**：支持「仅自己 / 指定同事 / 全公司 / 任何人（公开链接，仅管理员）」四档可见范围，详情见 [监控面板](/help/everflow/monitors/)。
