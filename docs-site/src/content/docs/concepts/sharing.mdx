## 内部成员的两种共享机制

### 1. 账户级「工作区协同共享」总开关

这个开关在「设置 → 个人设置 → 对话与助手 → 工作区协同共享」，**内部成员默认打开**：

- 打开后，内部同事可以在他们自己的「研究总监（Home）」里，向你名下除了 `Home` 以外的所有工作区派任务或提问。如果页面上找不到对应入口，请联系管理员。
- 关闭该开关后，正在跑的任务会正常收尾，此后同事的研究总监将停止发起新的派发和追问。

### 2. 工作区级「共享设置」三档网页访问

在某个公司工作区右上角点开「共享设置」弹窗，可以单独设**别人网页界面**的权限，**对所有人默认「不可见」**：

- **不可见**：隐藏侧边栏「团队」分组里的工作区入口；此前同事已在该工作区发起的对话，发起人仍可通过网页只读回看自己的历史对话记录。
- **仅可读**：同事能在「团队」分组里打开查看对话记录和右侧文件。
- **可读写**：同事能在「团队」分组里进来上传或改文件，也能直接开新对话提问。

:::caution[开启共享前必读：整机信任、历史记录与费用归属]
1. **整机环境与同机文件范围**：允许同事的研究总监访问你的工作区，或者把工作区网页设成「可读写」后，对方派来的任务会跑在**你的计算机环境**里，共用同一台机的数据连接、第三方配额和磁盘，并可能访问同一台计算机上的其他工作区及 `Home` 目录文件。建议只向完全信任的内部同事开放。
2. **按入口分别收回**：网页访问看工作区的网页共享档位，研究总监派活看账户的协同开关，两者分开生效。要收回网页上的访问，把工作区网页改回「不可见」；之后同事仍可只读回看自己在你工作区发起过的那条对话。
3. **费用与入库归属**：同事往你的工作区派任务时，**模型调用费算进派发人（提问人）自己的每日预算**。任务里顺便做了资料入库，记录也记在派发人名下。
4. **Home 保持个人私有**：`Home` 工作区始终只属于你个人，在侧边栏和跨人协同中均为个人专属。
:::

## 外部成员的隔离与共享规则

- **研究总监通道隔离**：外部成员的「研究总监」仅访问自己名下的工作区，内部成员和管理员的「研究总监」也仅访问内部工作区。
- **网页通道由本人决定**：外部成员的工作区默认对其他人（包括管理员）不可见，由本人全权管理共享设置。本人开启「仅可读」或「可读写」网页共享后，内部成员和管理员按对应档位查看或协作（工作区跟踪设置仍仅由本人修改）。外部成员之间保持互相隔离。
- **分享范围**：外部成员发布监控面板时使用「仅自己」一档（已有历史公开链接可随时撤销）。

## 对话与监控面板分享

三种对外分享的权限分别如下：

- **纯对话公开链接**：在对话菜单里点「分享…」，管理员与内部成员在拥有该对话及所属工作区、且部署策略允许公开链接时，可以分享仅包含对话正文的链接。
- **附带工作区文件或允许下载的对话分享**：在满足上述所有权与策略前提下，由管理员发起。
- **公开监控面板**：面向外部免登录访问的「任何人（公开链接）」由管理员发布和开启；内部成员可按「仅自己 / 指定同事 / 全公司」分享，详情见 {/* DALTON_DOC:everflow */}[监控面板](/help/everflow/monitors/){/* DALTON_DOC_ELSE */}[做监控面板与图表](/help/explore/dashboards-and-charts/){/* /DALTON_DOC */}。
