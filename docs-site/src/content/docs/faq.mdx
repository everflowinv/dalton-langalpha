这页汇总日常投研里最常碰到的七类问题，帮你按步骤快速定位原因。

遇到异常时，先看三个地方：去「设置 → 用量与预算」看今天还剩多少额度，去「设置 → 消息与渠道」核对推送总开关和账号绑定状态，再看面板或对话卡片上的提示文字。

## 1. 额度与预算问题

### 问：发消息时提示超出每日预算或单任务上限怎么办？

- **原因**：你的个人每日美元花销快到上限了（没单独改过时默认 **$100/天**），或者当前工作区撞上了设好的「单任务上限」。
- **处理方法**：
  1. 打开「设置 → 个人设置 → 用量与预算」，看今天已结算费用、跑着的任务预占多少，以及还剩多少可用余额。
  2. 按需调高每日美元上限；如果某家公司要跑深度覆盖，可以给那个工作区单独设更高的「单任务上限」。
  3. 要是后台命令刚跑完正好撞上上限，结果已经安全留在后台。把预算调高后回到原对话发一句话，就能把结果取出来。

### 问：为什么模型突然报错（比如 402 或限流窗口）？

系统会按付费方区分错误卡片：

- **用个人绑定订阅（比如个人 Claude 登录）或自有密钥**：卡片会原样写出上游服务商返回的报错和账号名，比如额度已满加重置时间，或者账户余额不足 402。照着提示等重置或换个模型就行。
- **用平台共享额度**：卡片会给出可操作建议，比如换模型、稍后再试或新开一条对话。

## 2. 监控面板打不开或提示“无权查看”

### 问：别人发给我的监控面板链接，点开提示“无权查看此监控面板”？

- **原因**：监控面板分四档可见范围，每档的边界很清楚：
  - `仅自己`：只有发布者本人能看；
  - `指定同事`：只有发布者在面板设置里勾过的公司内部成员能看；
  - `全公司`：所有内部成员和管理员都能看，**外部成员看不了**；
  - `任何人（公开链接）`：只有管理员能设，链接格式是 `/m/<slug>`。
- **处理方法**：请面板所有者在对应面板或原工作区的「发布」弹窗里，把你加进「指定同事」，或者调高可见范围。注意：外部成员账号默认打不开「全公司」面板。

## 3. 监控面板显示“数据未更新”或“最近一次更新失败”

### 问：看板顶部写着「数据未更新（上次成功：…）」是什么意思？图表还能看吗？

- **含义**：看板此刻**保留了上次成功拉到的有效数据**。刚才那一轮采集里，某一路外部行情或统计接口超时或报错，系统把受影响的数据源标成 `stale`，并在顶部挂出横幅提醒你数字停在上次成功的时间点。
- **排查**：看横幅里写的异常数据源和原因，先分清是交易所休市还是接口临时抖动。非休市时段一直没恢复，就找团队管理员检查。

### 问：面板卡片出现黄色「最近一次更新失败」警示？

- **含义**：你给面板开了自动更新（工作区文件一改就自动发，或数据任务定时重建），最近一次切新版本失败了。**现在页面上挂着的还是上一个完整可用的版本**，照常能看。如果是自己发的工作区网页，点顶部**前往源文件**回工作区查查那个 HTML 文件有没有报错。

## 4. 定时报告没收到

### 问：自动化任务在「自动化」列表里明明跑完了，为什么飞书 / Discord / 微信没收到？

按下面 4 步排查：

1. **查个人全局总开关**：去「设置 → 个人设置 → 消息与渠道 → 消息推送与接收账号」，看顶部的**全局推送总开关是不是开着**，下面至少勾了一个「已绑定」的个人接收账号。
2. **查单任务推送开关和路线**：在「自动化」列表里，确认这条任务自己的推送开关是开着的，**推送目标**也没被设成空路线。
3. **核对机器人和群绑定**：
   - 个人飞书或 Discord 必须**私聊 Dalton 机器人发 `/bind <绑定码>`**，发在群里没用。
   - 发往飞书团队群时，确认管理员已经把 Dalton 机器人拉进群，并在「团队管理 → 团队渠道与运维 → 飞书团队群绑定」点过一次测试发送。
4. **看有没有收到失败告警**：网关重试 3 次还是失败的话，系统会另发一条**投递失败告警**提醒你排查。

## 5. 数据过期或搜不到刚发的研报 / 财报

### 问：公司刚发了财报或最新卖方快评，为什么助手说 AlphaEngine 还没搜到？

- **原因**：为了替团队省额度和提速，AlphaEngine 搜索在宿主机侧开了团队缓存。之前如果正好有人搜过同一家公司（默认当天有结果缓存 **2 小时**、空结果缓存 **30 分钟**），系统会直接吐出缓存快照。
- **处理方法**：在对话里直接告诉助手：
  > 这家公司刚刚发了最新财报/快评，请传 `fresh=true` 绕过缓存重新检索一次 AlphaEngine。
- **补充**：如果要找业绩会转写，让助手直接走 `transcript` 路由。`all` 跨库初筛里带不出 `transcript`，得单独点名。

## 6. 助手答非所问、卡在半路或找不到工作区对话

### 问：长任务跑到一半断了怎么办？说“继续”会重头再跑吗？

- **从断点接续**：首次覆盖、完整覆盖这种长流程半路停下来后，直接回一句 **“继续”**，系统会先看工作区里已经写出的文件进度，从断点接着跑。只有在你明确说“重新开始跑一次”时，才会从头再来。
- **后台长命令**：看到状态栏亮着「N 个命令运行中」又等得太久，点开步骤行上的**停止**按钮，再让助手换小一点的范围重跑。

### 问：为什么助手没查到某个同事的工作区，或者我在别人的对话里发不了消息？

- **内部研究总监共享**：去「设置 → 个人设置 → 对话与助手」，让对方确认已经打开「工作区协同共享」。
- **同事发起的对话只读**：标着「由某某派发」的对话，只有发起人本人能继续追问，工作区主人和其他同事点进去都是只读。这样大家能看到过程和结论，又不会打乱原对话的推理上下文。
- **外部成员隔离**：外部成员和内部成员的研究总监通道双向隔离，谁也穿不到对方的工作区。

## 7. 文件上传与飞书写作报错

### 问：文件上传被拒或提示超大小限制怎么办？

- **聊天输入框**：走工作区直传，单文件最高 **200 MiB**、单条消息最高 **600 MiB**。PDF 传上去后，助手按每次 **20 页**分段读取（`Read` 工具直接打开 PDF 源文件的上限是 **64 MiB**，再大的 PDF 用工作区 Python 脚本抽内容就行）。
- **右侧「文件面板」**：单文件上限看后台存储配置，未开对象存储时是 **100 MiB**，开对象存储中转时是 **256 MiB**。
- **右侧「Memo 面板」**：单文件原始上限 **5 MiB**，抽出来的纯文本正文上限 **1 MiB**（纯文本太密集超过 1 MiB 会被拒收）。更大的参考资料请放到工作区「文件面板」或直接拖进聊天框。
- **归档进公司 Wiki / 销售纪要**：单文件上限 **20 MB**，每人每小时最多入库 **30 次**，只认 `docx`、`pdf`、`md`、`txt` 和 `png`/`jpg`/`webp`（不支持旧版 `doc` 和 `jpeg`）。
