这页汇总日常投研里最常碰到的七类问题，帮你按步骤快速定位原因。

遇到异常时，先看{/* DALTON_DOC:everflow */}三个地方：去「设置 → 个人设置 → 用量与预算」看今天还剩多少额度，去「设置 → 个人设置 → 消息与渠道」核对推送总开关和账号绑定状态，再看面板或对话卡片上的提示文字。{/* DALTON_DOC_ELSE */}两个地方：去「设置 → 个人设置 → 用量与预算」看今天还剩多少额度，再看面板或对话卡片上的提示文字。{/* /DALTON_DOC */}

## 1. 额度与预算问题

### 问：发消息时提示超出每日预算或单任务上限怎么办？

- **原因**：你的个人每日美元花销快到上限了（没单独改过时默认 **$100/天**），或者当前工作区撞上了设好的「单任务上限」。
- **处理方法**：
  1. 打开「设置 → 个人设置 → 用量与预算」，查看**「今日个人已用（现金渠道）」**（含进行中预占 / 每日总上限）与**「今日个人已用（订阅折算）」**，展开**「今日费用明细」**可查每笔 `进行中 / 已结算 / 已退还` 状态。
  2. 按需调高每日美元上限；如果某家公司要跑深度覆盖，可以给那个工作区单独设更高的「单任务上限」。
  3. 要是后台命令刚跑完正好撞上上限，结果已经安全留在后台。把预算调高后回到原对话发一句话，就能把结果取出来。

### 问：为什么模型突然报错（比如 402 或限流窗口），或者提示“订阅额度耗尽”？

系统会按付费方和场景给出明确提示：

- **手动对话遇订阅异常时直接提示**：无论是团队共享订阅还是个人绑定订阅，碰到额度耗尽、限流窗口或登录失效，对话里会直接弹出提示卡片（写明重置时间或联系管理员重连），由你决定等待重置还是手动换其他模型。
- **同一 Antigravity 账号下同厂商模型共用冷却**：例如任一 Gemini 模型额度耗尽后，同一账号下的其他 Gemini 模型也会直接提示额度耗尽与重置时间，不再反复发无效请求；换到其他厂商模型（如 Claude、GPT、Grok）不受影响。
- **自动任务会自动走备用链**：后台运行的自动任务碰到主订阅不可用时，会按你保存的备用模型列表（未自定义时按平台默认 6 档备用链）依次切换，并在结果摘要里注明改用了哪个模型。
- **按量计费账户余额不足（402）**：卡片会标明对应账号或服务商，按提示补额、换模型或联系管理员即可。

## 2. 监控面板打不开或提示“无权查看”

### 问：别人发给我的监控面板链接，点开提示“无权查看此监控面板”？

- **原因**：监控面板分四档可见范围，每档的边界很清楚：
  - `仅自己`：只有发布者本人能看；
  - `指定同事`：只有发布者在面板设置里勾过的公司内部成员能看；
  - `全公司`：所有内部成员和管理员都能看；
  - `任何人（公开链接）`：由管理员设置，链接格式是 `/m/<slug>`。
- **处理方法**：公司成员请面板所有者在对应面板或原工作区的「发布」弹窗里，把你加进「指定同事」，或者调高可见范围；外部成员通过已经公开的链接查看，或请管理员从自己的工作区另行发布公开面板。

## 3. 监控面板显示“数据未更新”或“最近一次更新失败”

### 问：看板顶部写着「数据未更新（上次成功：…）」是什么意思？图表还能看吗？

- **含义**：看板此刻**保留了上次成功更新的数据**。刚才那一轮采集里，某一路外部行情或统计接口超时或报错，系统把受影响的数据源标成**未更新**，并在顶部挂出横幅提醒你数字停在上次成功的时间点。
- **排查**：看横幅里写的异常数据源和原因，先分清是交易所休市还是接口临时抖动。非休市时段一直没恢复，就找团队管理员检查。

### 问：面板卡片出现黄色「最近一次更新失败」警示？

- **含义**：你给面板开了自动更新（工作区文件一改就自动发，或{/* DALTON_DOC:everflow */}数据任务{/* DALTON_DOC_ELSE */}自动化任务{/* /DALTON_DOC */}定时重建），最近一次切新版本失败了。**现在页面上挂着的还是上一个完整可用的版本**，照常能看。如果是自己发的工作区网页，点顶部**前往源文件**回工作区查查那个 HTML 文件有没有报错。

{/* DALTON_DOC:everflow */}## 4. 定时报告没收到

### 问：自动化任务在「自动化」列表里明明跑完了，为什么飞书或 Discord 没收到？

按发送目标类型依次排查（注：个人微信绑定用于微信私聊提问及通用会话消息，自动化报告推往飞书或 Discord）：

1. **查个人全局总开关**：去「设置 → 个人设置 → 消息与渠道 → 自动推送与接收账号」，确认顶部的**自动推送总开关**已打开；若要接收个人私信推送，普通任务要发个人私信时，确认下方勾了「已绑定」的飞书或 Discord 个人接收账号（只发飞书群时，任务本身选中目标群即可；带报告模板的定时报告按它自己的投递配置发送）。
2. **查单任务推送开关和路线**：普通任务在「自动化」列表里确认这条任务的推送开关已打开，且**推送目标**已选中接收账号或飞书团队群；带报告模板的定时报告使用独立的投递配置，直接让 Dalton 查看这条任务的报告投递目标。
3. **核对机器人和群绑定**：
   - 个人飞书或 Discord 需要**私聊 Dalton 机器人发 `/bind <绑定码>`**完成绑定。
   - 发往飞书团队群时，确认管理员已经把 Dalton 机器人拉进群，并在「团队管理 → 团队渠道与运维 → 飞书团队群绑定」点过一次测试发送。
4. **看执行历史的投递状态和失败告警**：在「自动化」的执行历史里，「已完成」表示任务执行结束，具体送达情况以展开后的各目标明细及投递状态（「已完成 · 投递中」「已完成 · 投递失败」「已完成 · 部分投递失败」「投递状态未确认」）为准。投递通常最多尝试 **3 次（含首次发送）**；使用固定报告模板的定时报告在确定失败且已配置有效告警目标时，系统会另发一条**投递失败告警**提醒你排查。

## 5. 数据过期或搜不到刚发的研报 / 财报

### 问：公司刚发了财报或最新卖方快评，为什么助手说 AlphaEngine 还没搜到？

- **原因**：为了替团队省额度和提速，AlphaEngine 搜索开了团队级缓存。之前如果正好有人搜过同一家公司（默认当天有结果缓存 **2 小时**、空结果缓存 **30 分钟**），系统会直接返回缓存快照；上游遇到临时限流或超时时，也会优先返回 7 天保留期内的旧缓存并标注抓取时间。
- **处理方法**：在对话里直接告诉助手：
  > 这家公司刚刚发了最新财报/快评，请跳过缓存，帮我重新检索一次 AlphaEngine 上的最新研报。
- **补充**：如果要找业绩电话会原话，请在对话里直接要求查**业绩电话会转写**（常规跨库初筛需单独点名检索业绩会转写）。{/* DALTON_DOC_ELSE */}## 4. 自动化任务未触发或结果异常

### 问：自动化任务到了计划时间或股价达标，为什么没有生成新报告？

按以下顺序排查：

1. **核对任务开关与条件**：在左侧「自动化」列表确认该任务处于开启状态，检查触发时间、时区设置以及股票代码与阈值条件是否填写准确。
2. **检查每日预算与单任务上限**：打开「设置 → 个人设置 → 用量与预算」，确认当日预算与该工作区的单任务上限有充足余额。
3. **查看执行历史详情**：展开「自动化」中的执行历史条目，查看具体状态、采用的模型以及错误摘要，必要时在详情页直接手动重试。

## 5. 如何第一时间获取刚发布的财报与公告

### 问：公司刚发布季报或最新公告，如何让助手优先拉取最新原文？

- **处理方法**：在对话里直接说明刚发业绩，要求实时抓取最新法定申报与全网新闻，例如：
  > 这家公司刚刚发了最新季报，请实时拉取最新 SEC 公告与公开新闻，帮我做一份速评拆解。
- **补充**：如果要找业绩电话会原话，请在对话里直接要求查**业绩电话会转写**（常规跨库初筛需单独点名检索业绩会转写）。{/* /DALTON_DOC */}

## 6. 助手答非所问、卡在半路或找不到工作区对话

### 问：长任务跑到一半断了怎么办？说“继续”会重头再跑吗？

- **从断点接续**：首次覆盖、完整覆盖这种长流程半路停下来后，直接回一句 **“继续”**，系统会先看工作区里已经写出的文件进度，从断点接着跑。只有在你明确说“重新开始跑一次”时，才会从头再来。
- **后台长命令**：看到状态栏亮着「N 个命令运行中」又等得太久，点开步骤行上的**停止**按钮，再让助手换小一点的范围重跑。

### 问：为什么助手没查到某个同事的工作区，或者我在别人的对话里发不了消息？

- **内部研究总监共享**：去「设置 → 个人设置 → 对话与助手」，让对方确认已经打开「工作区协同共享」。
- **同事发起的对话只读**：标着「由某某派发」的对话，由发起人本人继续追问，工作区主人和其他同事点进去以只读方式查看过程与结论，保持原对话的推理上下文完整清晰。
- **研究总监调度范围**：研究总监仅在各自范围内调度——外部成员的研究总监仅管理本人名下工作区，内部成员与管理员的研究总监仅调度内部工作区。

## 7. 文件上传{/* DALTON_DOC:everflow */}与飞书写作{/* /DALTON_DOC */}报错

### 问：文件上传被拒或提示超大小限制怎么办？

- **聊天输入框**：走工作区直传，单文件最高 **200 MiB**、单条消息最多 **10 个附件**且合计最高 **600 MiB**。PDF 传上去后，助手直接读进上下文时按每次 **20 页**分段读取（直接读取的源文件上限是 **64 MiB**，再大的 PDF 用工作区 Python 脚本抽内容就行）。
- **右侧「文件面板」**：单文件上限看后台存储配置，未开对象存储时是 **100 MiB**，开对象存储中转时是 **256 MiB**。
- **右侧「备忘录」面板（备忘文档）**：单文件原始上限 **5 MiB**，抽出来的纯文本正文上限 **1 MiB**。更大的参考资料请放到工作区「文件面板」或直接拖进聊天框。{/* DALTON_DOC:everflow */}
- **归档进公司 Wiki / 销售纪要**：单文件上限 **20 MB**，每人每小时最多入库 **30 次**，支持 `docx`、`pdf`、`md`、`txt` 以及 `png`/`jpg`/`webp` 图片格式（旧版 `.doc` 请另存为 `.docx`，`.jpeg` 后缀改为 `.jpg` 后入库）。{/* /DALTON_DOC */}
