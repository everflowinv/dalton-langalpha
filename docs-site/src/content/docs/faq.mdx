汇总日常投研中最常遇到的七类故障与排查路径，方便快速定位问题根因。

遇到异常时先检查三处状态：**「设置 → 用量与预算」确认今日额度是否触顶**、**「设置 → 消息与渠道」确认总开关与账号绑定正常**，以及面板或对话卡片上的状态提示说明。

## 1. 额度与预算问题

### 问：对话发送时提示超出每日预算或单任务上限怎么办？

- **原因**：你的个人每日美元消耗已接近或达到上限（未单独设置时系统默认 **$100/天**），或者当前工作区触发了设置的「单任务上限」。
- **处理方法**：
  1. 前往「设置 → 个人设置 → 用量与预算」查看今日已结算费用、进行中预占与可用余额；
  2. 根据需要适当上调每日美元上限，或为跑深度覆盖的特定公司工作区单独配置更高的工作区单任务上限；
  3. 如果是后台命令行刚刚跑完时恰好撞上预算上限，你的命令结果已在后台安全保留——调整预算后回到原对话发一句话即可直接取出。

### 问：为什么模型突然报错（如 402 或限流窗口）？

- 系统已按付费方区分错误卡片：
  - **使用个人绑定订阅（如个人 Claude 登录）或自有密钥**：卡片会直接显示上游服务商返回的原文与账号名（例如额度已满并给出重置时间，或账户余额不足 402）。请按提示等待重置或更换模型；
  - **使用平台共享额度**：卡片会提示具体的可操作建议（切换模型、稍后重试或新开对话）。

## 2. 监控面板打不开或提示“无权查看”

### 问：别人发给我的监控面板链接打开提示“无权查看此监控面板”？

- **原因**：监控面板有四档可见范围，各自边界不同：
  - `仅自己`：只有发布者本人可见；
  - `指定同事`：只有发布者在面板设置里勾选的公司内部成员可见；
  - `全公司`：所有内部成员与管理员可见，**外部成员不可见**；
  - `任何人（公开链接）`：仅管理员可设，链接格式为 `/m/<slug>`。
- **处理方法**：请面板所有者在对应的监控面板或原工作区「发布」弹窗中将你加入「指定同事」或调高可见范围（注意：外部成员账号默认无法访问「全公司」面板）。

## 3. 监控面板显示“数据未更新”或“最近一次更新失败”

### 问：看板顶部提示「数据未更新（上次成功：…）」是什么意思？图表还能看吗？

- **含义**：看板展示的并非空白或错误数字，而是**保留了上一次成功采集的有效数据**，只是最近一轮采集周期中某一路外部行情或统计接口超时/异常，因此系统把受影响的数据源标为 `stale` 并亮起横幅提醒你“当前数字尚未更新到这一分钟”。
- **排查**：看横幅里列出的异常数据源名称与原因，区分是交易所休市间隙还是外部接口临时波动；若非休市原因持续未恢复，可联系团队管理员检查。

### 问：面板卡片显示黄色「最近一次更新失败」警示？

- **含义**：面板开启了自动更新（工作区文件变更自动发布或数据任务重建），最近一次切新版本失败了，但**当前展示的线上版本仍是上一个完整可用的稳定版本**，不会破坏现有页面。如果是自己发布的工作区网页，可点顶部**前往源文件**回工作区检查该 HTML 文件是否存在错误。

## 4. 定时报告没收到

### 问：自动化任务明明在「自动化」里显示运行完了，为什么飞书 / Discord / 微信没收到消息？

请按下面 4 步逐一检查：

1. **检查个人全局总开关**：前往「设置 → 个人设置 → 消息与渠道 → 消息推送与接收账号」，确认顶部的**全局推送总开关已打开**，且已勾选至少一个处于「已绑定」状态的个人接收账号。
2. **检查单任务推送开关与路线**：在「自动化」列表里，确认该任务本身的推送开关已打开，且**推送目标**没有被显式设为空路线。
3. **验证机器人与群绑定**：
   - 个人飞书/Discord 必须通过**私聊发送 `/bind <绑定码>`** 给 Dalton 机器人（发在群里无效）；
   - 发往飞书团队群时，确认管理员已把 Dalton 机器人拉入该群，并在「团队管理 → 团队渠道与运维 → 飞书团队群绑定」点击一次测试发送验证连通。
4. **查看是否触发了失败告警**：如果网关发送重试 3 次均失败，系统会另外发送一条**投递失败告警**提醒。

## 5. 数据过期或搜不到刚发的研报 / 财报

### 问：公司刚刚发了财报或最新卖方快评，为什么助手说 AlphaEngine 还没搜到？

- **原因**：为了节省团队额度并提速，AlphaEngine 搜索启用了宿主侧团队缓存。如果之前正好有人检索过同一家公司（默认当天有结果缓存 **2 小时**、空结果缓存 **30 分钟**），系统会直接返回缓存快照。
- **处理方法**：在对话里明确告诉助手：
  > 这家公司刚刚发了最新财报/快评，请传 `fresh=true` 绕过缓存重新检索一次 AlphaEngine。
- **补充**：如果检索业绩会转写，请提醒助手直接查 `transcript` 路由（不要依赖 `all` 跨库初筛，因为 `all` 不包含 `transcript`）。

## 6. 助手答非所问、卡在半路或找不到工作区对话

### 问：长任务跑到一半断了怎么办？说“继续”会重头再跑一遍吗？

- **不会重头跑**：首次覆盖、完整覆盖等长流程中途中断后，直接回复 **“继续”**，系统会检查已生成的工作区文件进度并从断点接续；只有明确说“重新开始跑一次”才会从头启动。
- **后台长命令**：如果看到状态栏显示「N 个命令运行中」但等太久，可以点步骤行上的**停止**按钮再让助手换更小范围测试。

### 问：为什么助手没查到某个同事的工作区，或者我在别人的对话里发不了消息？

- **内部研究总监共享**：在「设置 → 个人设置 → 对话与助手」确认对方没有关闭「工作区协同共享」。
- **同事发起的对话只读**：标有「由某某派发」的对话只有发起人本人可以继续追问，工作区主人和其他同事打开均为只读状态，这是为了避免打乱对方的推理上下文。
- **外部成员隔离**：外部成员与内部成员的研究总监通道完全隔离，互相无法通过研究总监访问对方工作区。

## 7. 文件上传与飞书写作报错

### 问：文件上传被拒绝或超出大小限制怎么办？

- **聊天输入框**：使用工作区直传支持单文件最高 **200 MiB**、单条消息 **600 MiB**；PDF 上传后由助手按每次 **20 页**分段读取（`Read` 工具直接加载 PDF 源文件的上限为 **64 MiB**，更大的 PDF 可通过工作区 Python 脚本提取内容）。
- **右侧「文件面板」**：单文件上限视存储配置为 **100 MiB**（未开对象存储）或 **256 MiB**（对象存储中转）。
- **右侧「Memo 面板」**：单文件原始上限为 **5 MiB**，且抽取后的纯文本正文上限为 **1 MiB**（纯文本密集文件超过 1 MiB 会被拒收）；更大的参考资料请改传到工作区「文件面板」或直接拖进聊天框。
- **归档进公司 Wiki / 销售纪要**：单文件上限 **20 MB**，每人每小时最多入库 **30 次**，仅支持 `docx`、`pdf`、`md`、`txt` 及 `png`/`jpg`/`webp`（不支持旧版 `doc` 与 `jpeg`）。
