这页教你围绕财报季，把**财报前瞻 → 公布速评 → 电话会深度复盘 → 核心论点更新**串成闭环。

在对应的公司工作区里，财报前用 **`/dalton-earnings-preview`** 对齐一致预期和关键看点。财报一发出来，用 **`/dalton-earnings-flash`** 出 Beat/Miss 速评。电话会转写进库后，再跑 **`/dalton-earnings-deep`** 做深度复盘，顺便更新核心论点和议程。

## 财报前准备（Earnings Preview）

1. **确认议程与预期**：
   - 提前在工作区跑 `/dalton-earnings-calendar`，看清近期的财报窗口。
   - 如果工作区里记了财报期待验证事项，到期时间要写成标准日期（`YYYY-MM-DD`）。系统会按**这只股票所属交易所当地时间 18:00** 判到期，并在巡检时汇总。
2. **生成财报前瞻**：
   - 运行 `/dalton-earnings-preview`，或者直接跟分析师说：*“帮我做一份本季度财报前瞻，重点对比市场一致预期和最近两周销售纪要里的市场预期差（whisper）。”*
   - 分析师会列出核心财务指标一致预期表、本季要盯的 3–5 个关键业务指标、指引敏感性，以及不同业绩落点下的情景推演。

## 财报发布后：速评与深度复盘

### 1. 第一时间出速评（`/dalton-earnings-flash`）

财报刚落地时，很多机构研报还没出全，这时记得**跳过缓存拿最新数据**：

> 本公司刚发完最新季报，请跳过搜索缓存拉取最新公告与全网新闻，跑一次 `/dalton-earnings-flash`，按营收、利润率、现金流和最新指引做 Beat/Miss 拆解。

分析师会在工作区优先拉最新的美股 SEC 公告（`8-K` / `10-Q`）或港 A 股法定公告，再结合全网搜索和市场一致预期写出结构化速评。

### 2. 电话会后做深度复盘（`/dalton-earnings-deep`）

业绩电话会转写进系统后，运行 `/dalton-earnings-deep`：

- 技能会专门检索**业绩电话会转写库**（常规跨库初筛需单独点名检索业绩会转写），以获取管理层原话和 Q&A。
- 要是中英文公司名在转写库里没配全，分析师会自动组合中英文名，或者拉宽日期范围重试。
- 跑完后，工作区的历史财务表、核心论点状态（`/dalton-thesis-delta` 五词结论：论点不变、论点加强、论点削弱、论点失效、新论点）和赔率评估会一并更新，同时把已验证的旧议程勾完、建好下季的新验证项。

:::tip[一次跟踪多家公司]
财报周经常一天有好几家标的发业绩。你可以直接在「研究总监（Home）」里同时给多个公司工作区派速评任务，让各工作区分析师并发跑完，再回来汇总给你。
:::
