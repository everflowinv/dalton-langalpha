这页教你让 Dalton 在沙箱里搭出可审计的 **Excel 估值模型**，并在右侧表格预览器里逐格核对。

工作区分析师会在沙箱里调用**美股 SEC 归一化财务数据**或历史报表数据，用 Python 写出带完整动态公式（比如 `SUM`、`NPV`、WACC 敏感性矩阵）的 `.xlsx` 工作簿，还会做公式重算检查，确认每个单元格都没算错。

## 操作步骤

### 1. 说清口径和输入假设

进目标公司的独立工作区，提问时把建模范围和关键假设一次说清楚：

> 请从美股 SEC 财报拉取公司过去 5 年及近 4 个季度的营收、毛利、营业利润、资本开支与自由现金流（明确标出最新重述口径与申报号），在工作区生成 `model_valuation.xlsx`。包含三张表：`Historical`（历史财务）、`DCF`（未来 5 年预测与 WACC/永续增长率敏感性矩阵）、`Comps`（可比公司倍数）。所有汇总、折现和敏感性表格全部使用动态 Excel 公式计算。

### 2. 手头已经有团队旧模型底稿

1. 把原来的 `.xlsx` 模型拖进聊天输入框或右侧**文件面板**（比如 `base_model.xlsx`）。
2. 让分析师先检查原有工作表结构、命名区域和公式引用，再只往最新历史列补进本季实际数并顺延预测期，保住团队原有的格式和配色。

### 3. 在右侧电子表格面板检查结果

文件生成后，在对话卡片或右侧文件树点开那个 `.xlsx` 文件：

- {/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 会按真实的浅色电子表格网格渲染每个 Sheet，留住背景填充、边框和字体颜色。
- 点右上角**展开面板**，可以把大宽表铺满主区看。
- 哪一行预测逻辑想微调，直接在左侧对话说出 Sheet 名和行项，比如“把 `DCF` 表 2027 年研发费用率假设从 18% 调成 16.5%”。分析师会就地改好工作簿，并自动检查有没有 `#REF!`、`#DIV/0!`、`#VALUE!` 这类公式错误。

:::tip[美股公司与非美股公司的取数差异]
- **美股公司**：要求拉取 SEC 归一化季度、年度、YTD 和推导 Q4 财务数据，保证和 SEC 原表（`10-K` / `10-Q`）对齐。
- **A 股 / 港股公司**：结合港 A 股财务数据与上传的年报 PDF 抽历史明细；如果要回算历史市值和 PE，记得要求取**不复权**历史股价配历史股本。
:::
