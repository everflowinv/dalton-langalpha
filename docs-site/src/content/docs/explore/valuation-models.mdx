让 Dalton 在工作区沙箱里构建和迭代可审计的 **Excel 估值模型**，并在右侧表格预览器中逐格核对公式。

不要让大模型直接在聊天框里“口算”估值，而是让工作区分析师在沙箱里调用 **`dalton_sec`（美股归一化 XBRL）** 或历史报表数据，用 Python 写出带有完整 Excel 动态公式（如 `SUM`、`NPV`、WACC 敏感性矩阵）的 `.xlsx` 工作簿，并通过公式重算检查确保零报错。

## 操作步骤

### 1. 准备口径与输入假设

进入目标公司的独立工作区，在提问时把建模范围和关键假设说清楚：

> 请用 `dalton_sec` 拉取公司过去 5 年及近 4 个季度的营收、毛利、营业利润、资本开支与自由现金流（明确标出重述口径 `latest` 与申报号），在工作区生成 `model_valuation.xlsx`。包含三张表：`Historical`（历史财务）、`DCF`（未来 5 年预测与 WACC/永续增长率敏感性矩阵）、`Comps`（可比公司倍数）。所有汇总、折现和敏感性表格必须使用 Excel 公式，不能写死计算结果。

### 2. 如果你已经有团队旧模型底稿

1. 把已有的 `.xlsx` 模型拖进聊天输入框或右侧**文件面板**（例如 `base_model.xlsx`）。
2. 让分析师先检查原有工作表结构、命名区域和公式引用关系，再只往最新历史列补充本季度实际数并顺延预测期，避免破坏团队习惯的格式与颜色编码。

### 3. 在右侧电子表格面板检查成果

文件生成后，在对话卡片或右侧文件树中点击该 `.xlsx` 文件：

- Everflow 会按真实浅色电子表格网格渲染每个 Sheet，保留背景填充、边框与字体颜色。
- 点击右上角**展开面板**可以把大宽表铺满主区查看。
- 发现某行预测逻辑需要微调时，直接在左侧对话里说明要调整的 Sheet 与行项（例如“把 `DCF` 表 2027 年研发费用率假设从 18% 调成 16.5%”），分析师会就地更新工作簿并自动核验无公式错误（如 `#REF!`、`#DIV/0!`、`#VALUE!`）。

:::tip[核验美股公司与非美股公司的差异]
- **美股公司**：优先明确要求使用 `dalton_sec` 的 `get_company_facts` 获取归一化季度、年度、YTD 与推导 Q4 数据，确保与 SEC 原表（10-K/10-Q）对齐。
- **A 股 / 港股公司**：结合 `cn-hk` 财务工具与上传的年报 PDF 提取历史明细，同时可指定历史股价取**不复权**口径配合历史股本回算历史市值与 PE。
:::
