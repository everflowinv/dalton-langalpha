这页教你给重点持仓股配自动盯盘：股价突破目标价或单日涨跌幅达标时，自动查清原因并推送简报。

盯个股异动请在左侧导航 **自动化（`/automations`）→ 新建 → 价格触线时** 里创建（对话内定时唤醒与内置目标价在当前部署里保持关闭）。触发时配合工作区档案和 `/dalton-stock-move`，几分钟内就能拿到带证据的异动归因。

## 配置步骤

### 第一步：选定目标工作区

把监控任务绑到**这只股票对应的公司工作区**。任务触发时，分析师就能直接读你以前写好的核心论点，判断这次涨跌有没有动摇原有逻辑。

### 第二步：在「自动化」新建股价触发任务

1. 点左侧导航的 **自动化（`/automations`）**，点新建自动化。
2. 触发方式选 **价格触线时**。
3. 填好触发条件：
   - **代码**：选或输入目标代码，比如 `NVDA`、`0700.HK`；
   - **条件**：选高于或低于某个具体价格，或者涨跌幅达到某个百分比及**参考基准**（比如相对前收盘价）；
   - **数值**：比如单日波动到 `5%`，或者跌破目标买点价格。
4. 点开 **更多选项** 调整触发频率与模型：
   - **重复触发**：新建价格触线任务默认**「单次触发」**（触发一次后即结束）；要持续盯盘请切到**「循环」**。冷却时间留空时每个交易日触发一次，自定义冷却时间最短为 **240 分钟**。
   - **模型与思考强度**：按需指定这条任务使用的模型和思考强度（留空则跟随默认）。
5. 写好执行指令，建议直接要求按异动归因规范排查：
   > 当触发条件达成时，请用 `/dalton-stock-move` 排查今日异动原因（核查突发新闻、X 社媒发酵、卖方研报与销售纪要中的最新催化），并与工作区核心论点对比：论点是否发生变化？当前赔率如何变化？请给出简洁的中文结论。

### 第三步：设置推送渠道

1. 在任务行或详情里打开推送开关，再在**推送目标**下拉菜单选你要收消息的已绑定个人账号（飞书或 Discord）或飞书团队群。
2. 确认自己在「设置 → 个人设置 → 消息与渠道 → 自动推送与接收账号」已经打开**自动推送总开关**；若只发飞书群，确认任务已选中对应飞书群，若要同时收个人推送，确认下方已勾选「已绑定」的飞书或 Discord 个人账号。

:::tip[控制触发频率与预算]
- 怕股价在阈值线附近来回震荡导致频繁重跑，记得把百分比阈值设合理，并在「设置 → 个人设置 → 用量与预算」里给这个工作区设好单任务费用上限。
- 遇上某天大盘剧烈波动想先歇一天，去「自动化」列表一键暂停这条任务就行。
:::
