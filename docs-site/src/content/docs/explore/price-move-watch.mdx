设置重点持仓股的自动盯盘：当标的突破目标价或单日涨跌幅达到阈值时，自动归因异动原因并投递简报。

盯个股异动请在左侧主导航 **自动化（`/automations`）→ 新建 → 价格触线时** 中创建（不要在对话里要求设“唤醒闹钟”，因为 `wakeups` 与 `market_watch` 在当前 Dalton 中已关闭）。触发时配合工作区档案与 `/dalton-stock-move`，能在几分钟内给出带证据的异动归因。

## 配置步骤

### 第一步：选定目标工作区

建议把监控任务绑定到**该股票对应的公司工作区**，这样任务触发时分析师可以直接读取你过去积累的核心论点，判断这次涨跌有没有打破原有逻辑（而不需要每次重新查背景）。

### 第二步：在「自动化」新建股价触发任务

1. 点击左侧导航栏的 **自动化（`/automations`）**，点击新建自动化。
2. 在触发方式中选择 **价格触线时（Price）**。
3. 填写触发条件：
   - **股票代码**：在输入框中选择或输入目标代码（如 `NVDA`、`0700.HK` 等）；
   - **触发条件**：选择高于/低于某个具体价格（`$`），或涨跌幅达到某个百分比（`%`）及对应的参考基准（如相对前收盘价）；
   - **目标数值**：例如设定单日波动达到 `5%` 或跌破目标买点价格。
4. 编写执行指令（Prompt），建议直接要求按异动归因规范排查：
   > 当触发条件达成时，请调用 `dalton-stock-move` 排查今日异动原因（核查 `web_search` 突发新闻、`x_search` 社媒发酵、`alphaengine` 与 `sales-notes` 最新催化），并与工作区核心论点对比：论点是否发生变化？当前赔率如何变化？请给出简洁的中文结论。

### 第三步：设置推送渠道

1. 在该任务行或详情里开启推送开关，并在**推送目标**下拉菜单中选择你要接收通知的个人账号（飞书 / Discord / 微信）或飞书团队群。
2. 确保你在「设置 → 个人设置 → 消息与渠道」已打开**全局推送总开关**且绑定账号处于「已绑定」状态。

:::tip[控制触发频次与预算]
- 为避免股价在临界线反复震荡导致频繁重跑耗费预算，合理设定百分比阈值与单任务费用上限（可在「设置 → 个人设置 → 用量与预算」中配置工作区单任务上限）。
- 如发现某天市场剧烈波动无需继续重跑，可随时在「自动化」列表里一键暂停该任务。
:::
