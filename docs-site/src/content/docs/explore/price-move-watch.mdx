这页教你给重点持仓股配自动盯盘：股价突破目标价或单日涨跌幅达标时，自动查清原因并推送简报。

盯个股异动请在左侧导航 **自动化（`/automations`）→ 新建 → 价格触线时** 里创建（`wakeups` 和 `market_watch` 在当前 Dalton 部署里保持关闭）。触发时配合工作区档案和 `/dalton-stock-move`，几分钟内就能拿到带证据的异动归因。

## 配置步骤

### 第一步：选定目标工作区

把监控任务绑到**这只股票对应的公司工作区**。任务触发时，分析师就能直接读你以前写好的核心论点，判断这次涨跌有没有动摇原有逻辑。

### 第二步：在「自动化」新建股价触发任务

1. 点左侧导航的 **自动化（`/automations`）**，点新建自动化。
2. 触发方式选 **价格触线时（Price）**。
3. 填好触发条件：
   - **股票代码**：选或输入目标代码，比如 `NVDA`、`0700.HK`；
   - **触发条件**：选高于或低于某个具体价格（`$`），或者涨跌幅达到某个百分比（`%`）及参考基准（比如相对前收盘价）；
   - **目标数值**：比如单日波动到 `5%`，或者跌破目标买点价格。
4. 写好执行指令（Prompt），建议直接要求按异动归因规范排查：
   > 当触发条件达成时，请调用 `dalton-stock-move` 排查今日异动原因（核查 `web_search` 突发新闻、`x_search` 社媒发酵、`alphaengine` 与 `sales-notes` 最新催化），并与工作区核心论点对比：论点是否发生变化？当前赔率如何变化？请给出简洁的中文结论。

### 第三步：设置推送渠道

1. 在任务行或详情里打开推送开关，再在**推送目标**下拉菜单选你要收消息的个人账号（飞书 / Discord / 微信）或飞书团队群。
2. 确认自己在「设置 → 个人设置 → 消息与渠道」已经打开**全局推送总开关**，而且绑定账号显示「已绑定」。

:::tip[控制触发频率与预算]
- 怕股价在阈值线附近来回震荡导致频繁重跑，记得把百分比阈值设合理，并在「设置 → 个人设置 → 用量与预算」里给这个工作区设好单任务费用上限。
- 遇上某天大盘剧烈波动想先歇一天，去「自动化」列表一键暂停这条任务就行。
:::
