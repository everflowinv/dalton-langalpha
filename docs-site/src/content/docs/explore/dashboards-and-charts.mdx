用 Everflow 把研究数据转化为**可发布的团队监控看板**和**行情图表叠加标注**，区分独立 HTML 看板页面与 `chartkit` K 线叠加层的适用场景。

- **制作独立 HTML 报告或交互式多图看板**（用于发布到 [监控面板](/help/everflow/monitors/)）：在工作区里向分析师描述指标、图表和交互需求，分析师会生成独立的**看板页面**或**交互式 HTML 报告**（如 `overview_dashboard.html` 或 `dashboard/index.html`），你在右侧预览满意后点**发布**即可挂成团队面板。
- **在股票行情图上画技术叠加层与事件标注**（`chartkit`）：`chartkit` 是用于股票 K 线行情图的叠加层绘制与截图校验库（支持均线、通道、箱体、斐波那契、预测目标与事件标注），发布后直接叠加显示在应用内的股票行情图上（或在对话中以图表卡片呈现），**不用于生成独立的多图 HTML 网页看板**。

## 场景一：制作交互式看板并发布到「监控面板」

### 第一步：让分析师生成看板页面或交互式 HTML 报告

你可以在公司或专题工作区直接向分析师提出网页看板需求：

> 请从 `dalton_sec` 与行情数据提取这家公司过去 12 个季度的营收增速、Non-GAAP 营业利润率与估值指标，绘制双轴对比图、归因图与指标汇总表，输出成一个结构清晰的中文**交互式看板** HTML 页面 `overview_dashboard.html`。

如果你需要把多张统计图表、核心指标卡片和可排序筛选的数据表排在一页上，可以直接说：

> 请把上述图表和最新指标汇总表整合成单页**看板页面** `dashboard/index.html`，支持深浅色适配与清晰的鼠标悬停提示。

### 第二步：在右侧预览与微调

1. 对话结束后，点击工作区生成的 `overview_dashboard.html`（或 `dashboard/index.html`）在右侧面板实时渲染查看效果。
2. 需要查看或修改源码结构时，点击面板顶部的**查看页面 / 查看源代码**切换按钮；想在更大屏幕检查交互，点击**在新标签页打开**。
3. 如果布局太挤、文字重叠或想补充指标对比，直接在左侧对话继续提修改意见，分析师会就地重写并刷新预览。

### 第三步：发布到「监控面板」

1. 在右侧面板顶部工具栏点击**发布**（如果你看不到「发布」入口，请联系管理员）。
2. 填写：
   - **面板标题**：例如“消费电子重点标的估值跟踪”；
   - **所属分类**：选择对应的市场或分类（如 `美股`、`A 股`、`港股`、`个股`、`组合` 等）；
   - **谁能看**：按需要选择 `仅自己`、`指定同事` 或 `全公司`（管理员可设为 `任何人（公开链接）`）。
3. **开启自动更新（推荐）**：打开**「文件更新后自动更新」**开关。以后你配合[自动化定时任务](/help/concepts/automations-wakeups-commands/)每周或每天让分析师刷新一次数据并重写这个 HTML 文件，监控面板就会自动切出新版本（`v2`、`v3`……），团队同事打开同一个固定链接永远看到最新一期。

:::tip[区分静态报告和实时监控]
- 一次性阅读的**交互式 HTML 报告**也支持这样发布，不开启自动更新即可作为固定版本留存；
- 需要每天随工作区数据任务滚动刷新的**看板页面**，开启「文件更新后自动更新」后可在面板顶部版本下拉框随时回溯历史各期版本。
:::

## 场景二：使用 `chartkit` 在股票行情图上画叠加层

当你希望把技术指标、支撑/压力位、交易区间、财报发布日竖线或价格预测目标直接画在股票行情 K 线图上时，可让分析师调用沙箱预装的内置金融图表库（在代码里以 `chartkit` 导入）：

> 请拉取这家公司近 60 个交易日的日线行情，用 `chartkit` 标出区间上下沿、20 日均线与近两次财报日竖线并附带原因说明，先截图核验排版后再发布图层。

分析师会在后台用 `chartkit` 生成叠加层并先通过无头浏览器截图检查标签是否遮挡，确认无误后再调用 `publish()` 将图层写入并展示为对话里的图表卡片（或叠加在实时行情图上）。
