这页教你把研究数据做成两类可视化成果：发布给团队看的 **HTML 监控看板**，以及画在行情图上的**K 线叠加标注**。

- **独立 HTML 报告或交互式多图看板**（发布到 [监控面板](/help/everflow/monitors/)）：在工作区里把指标、图表和交互需求告诉分析师，它会生成独立的**看板页面**或**交互式 HTML 报告**（比如 `overview_dashboard.html` 或 `dashboard/index.html`）。你在右侧预览满意后点**发布**，就能挂成团队面板。
- **股票行情图上的技术叠加层与事件标注**：专门用来在 K 线图上画均线、通道、箱体、斐波那契、预测目标和事件标注，并截图校验排版。发布后直接叠在应用内的股票行情图上，或在对话里显示成图表卡片。要做独立的多图 HTML 网页看板，就用上面那种 HTML 看板做法。

## 场景一：做交互式看板并发布到「监控面板」

### 第一步：让分析师生成看板页面或 HTML 报告

在公司或专题工作区里，直接向分析师提出网页看板需求：

> 请从美股 SEC 财报与行情数据提取这家公司过去 12 个季度的营收增速、Non-GAAP 营业利润率与估值指标，绘制双轴对比图、归因图与指标汇总表，输出成一个结构清晰的中文**交互式看板** HTML 页面 `overview_dashboard.html`。

如果要把多张统计图、核心指标卡片和可排序筛选的数据表排进同一页，可以这样说：

> 请把上述图表和最新指标汇总表整合成单页**看板页面** `dashboard/index.html`，支持深浅色适配与清晰的鼠标悬停提示。

### 第二步：在右侧预览与微调

1. 对话跑完后，点开工作区里的 `overview_dashboard.html`（或 `dashboard/index.html`），在右侧面板看渲染效果。
2. 想看或改源码结构，点面板顶部的**查看页面 / 查看源代码**切换；想在大屏上看交互，点**在新标签页打开**。
3. 觉得布局太挤、文字重叠或者想加一组对比指标，直接在左侧对话提修改意见，分析师会就地重写并刷新预览。

### 第三步：发布到「监控面板」

1. 点右侧面板顶部工具栏的**发布**按钮（看不到入口请联系管理员）。
2. 填好这几项：
   - **面板标题**：比如“消费电子重点标的估值跟踪”；
   - **所属分类**：选对应的市场或分类，比如 `美股`、`A 股`、`港股`、`个股`、`组合` 等；
   - **谁能看**：按需要选 `仅自己`、`指定同事` 或 `全公司`（管理员还能选 `任何人（公开链接）`）。
3. **打开自动更新（推荐）**：勾上**「文件更新后自动更新」**。以后配合 [自动化定时任务](/help/concepts/automations-wakeups-commands/)，每天或每周让分析师刷新数据并重写这个 HTML 文件，面板就会自动切出新版本（`v2`、`v3`……），同事点开同一个固定链接就能看到最新一期。

:::tip[分清静态报告和滚动看板]
- 一次性的**交互式 HTML 报告**也可以这样发布，不勾选自动更新就行，留成固定版本。
- 每天随工作区数据任务刷新的**看板页面**，打开「文件更新后自动更新」后，还能在顶部版本下拉框随时回看历史每一期。
:::

## 场景二：在股票行情图上叠加指标与事件标注

想把技术指标、支撑压力位、交易区间、财报日竖线或预测目标直接画在 K 线图上时，直接在对话里提出叠加需求：

> 请拉取这家公司近 60 个交易日的日线行情，在 K 线图上标出区间上下沿、20 日均线与近两次财报日竖线并附带原因说明，先截图核验排版后再发布图层。

分析师会在后台生成行情图叠加图层，先截图检查标签有没有遮挡，确认没问题再发布并展示为图表卡片（或叠在实时行情图上）。
