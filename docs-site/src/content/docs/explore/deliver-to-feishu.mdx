介绍将 Everflow 成果同步到飞书的两种方式：由自动化任务推送到飞书群或私聊，以及在对话中新建或追加为飞书云文档。

**发消息到飞书群**通过在「自动化」里为任务选择已绑定机器人的飞书群来实现（需内部成员以上身份）；**生成飞书云文档**则需在对话里明确说“写成飞书文档”或“追加到飞书文档”，助手绝不会在未获指令时擅自创建飞书文档。

## 场景一：把定时报告推送到飞书群（或个人私聊）

### 前提准备

1. **发往飞书团队群**：管理员需先将 Dalton 机器人拉入目标飞书群。之后内部成员和管理员可在「设置 → 团队管理 → 团队渠道与运维 → **飞书团队群绑定**」看到该群，并可点击测试推送按钮验证机器人是否具备发消息权限。
2. **同时发往你个人飞书私聊**：前往「设置 → 个人设置 → 消息与渠道 → **飞书与 Discord 账号绑定**」生成绑定码，私聊发 `/bind <绑定码>` 给 Dalton 机器人（切勿发在群聊），并在上方「消息推送与接收账号」打开总开关、勾选你的飞书账号。

### 配置单任务群推送

1. 打开左侧导航 **自动化（`/automations`）**，找到你创建的定时或价格触线任务（如每日行业扫描或个股异动）。
2. 开启该任务的推送开关。
3. 点击任务旁的**推送目标选择器**，在列表中勾选一个或多个目标**飞书群**（也可与个人接收账号同时勾选）。
4. 任务按计划或触发条件跑完后，频道网关会自动把结构化卡片或纯文本摘要推到指定飞书群。

:::note[为什么有时候会收到投递失败告警？]
如果某个飞书群把机器人踢出、群配置变更或网关发送重试 3 次仍确认失败，系统会自动触发一条投递失败告警通知你及时检查，防止你以为消息发出去了而实际漏发。
:::

## 场景二：把工作区报告写成飞书云文档

如果你要把一份较长的研报、会议纪要或专题复盘写进飞书云文档（限内部成员与管理员）：

1. **新建飞书文档**：在对话里明确要求：
   > 请把工作区里的 `report.md` 写成一篇新的飞书文档（如果里面有图表，请一并上传）。
   - 系统会先完成内容与图片转换再创建文档，不会因为正文失败留下空白文档；
   - 如果 Markdown 里包含工作区内的图表或图片，系统会自动上传并内嵌到飞书文档对应段落；
   - 新建完成后，系统会自动给内部团队跟踪群以及你绑定的飞书账号（公司邮箱 / `open_id`）开通编辑权限；若因为账号状态未能自动加权，直接对助手说“帮我给刚才这篇飞书文档补发一下我的编辑权限”即可。
2. **追加到已有飞书文档末尾**：
   > 请把今天更新的这三段结论追加到这篇飞书文档末尾：`https://...`
   - 若追加遇到网络异常，系统会明确区分“原文档未改变（可放心重试）”与“结果未知（请先打开文档看一眼再决定是否重跑，以免重复追加）”。

:::caution[当前飞书云文档写入边界]
飞书云文档写入工具目前**仅支持新建文档和在文末追加**，不支持覆盖已有正文、删除段落、移动位置或修改全局权限；外部成员不可创建或追加飞书文档，仅可读取管理员授权开放的飞书知识空间。
:::
