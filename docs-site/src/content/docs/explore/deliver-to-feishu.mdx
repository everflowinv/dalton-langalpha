这页讲两种把 Everflow 结果发去飞书的做法：定时推消息到飞书群或私聊，以及在对话里新建或追加飞书云文档。

**发消息到飞书群**要去「自动化」里选已经绑了机器人的飞书群（限内部成员及以上）。**生成飞书云文档**要在对话里明说“写成飞书文档”或“追加到飞书文档”，助手只有收到明确指令才会写入飞书。

## 场景一：把定时报告推到飞书群（或个人私聊）

### 前提准备

1. **发往飞书团队群**：管理员要先拉 Dalton 机器人进目标飞书群。之后内部成员和管理员能在「设置 → 团队管理 → 团队渠道与运维 → **飞书团队群绑定**」看到这个群，还能点测试推送检查机器人能不能发消息。
2. **同时发你个人飞书私聊**：去「设置 → 个人设置 → 消息与渠道 → **飞书与 Discord 账号绑定**」生成绑定码，私聊发 `/bind <绑定码>` 给 Dalton 机器人（一定发私聊，发群里无效）。然后在上方「消息推送与接收账号」打开总开关并勾上你的飞书账号。

### 配置单任务群推送

1. 打开左侧导航 **自动化（`/automations`）**，找到你建的定时或价格触线任务，比如每日行业扫描或个股异动。
2. 打开这条任务的推送开关。
3. 点任务旁边的**推送目标选择器**，在列表里勾一个或多个**飞书群**，也能同时勾上个人接收账号。
4. 任务跑完后，频道网关会自动把结构化卡片或纯文本摘要发进指定飞书群。

:::note[为什么偶尔会收到投递失败告警？]
如果某个飞书群把机器人踢了、改了群权限，或者网关重试 3 次还是没发出去，系统会给你发一条投递失败告警。这样消息没送达时你马上就能知道，不会以为已经发出去了。
:::

## 场景二：把工作区报告写成飞书云文档

想把长研报、会议纪要或专题复盘写进飞书云文档时（限内部成员和管理员），按下面两种指令来：

1. **新建飞书文档**：在对话里说清楚：
   > 请把工作区里的 `report.md` 写成一篇新的飞书文档（如果里面有图表，请一并上传）。
   - 系统会先把正文和图片转好再创建文档，保证建出来内容完整，没有空壳。
   - Markdown 里带了工作区图表或图片时，会自动传上去并插进对应段落。
   - 建完后，系统会自动给内部团队跟踪群和你的飞书账号（公司邮箱 / `open_id`）开编辑权限。万一因为账号状态没加上权限，直接跟助手说“帮我给刚才这篇飞书文档补发一下我的编辑权限”就行。
2. **追加到已有飞书文档末尾**：
   > 请把今天更新的这三段结论追加到这篇飞书文档末尾：`https://...`
   - 追加碰到网络异常时，系统会分清“原文档没动过（放心重试）”和“结果不明（先打开文档看一眼再决定要不要重跑，免得重复追加）”。

:::caution[当前飞书云文档写入边界]
飞书云文档写入工具现在**只支持新建文档和在文末追加**。要改已有段落、删内容、调顺序或改全局权限，请直接在飞书里编辑。外部成员只能读管理员授权的飞书知识空间，不能新建或追加飞书文档。
:::
