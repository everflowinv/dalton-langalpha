这页讲两种把 Everflow 结果发去飞书的做法：定时推消息到飞书群或私聊，以及在对话里新建或追加飞书云文档。

**发消息到飞书群**要去「自动化」里选已经绑了机器人的飞书群（限内部成员及以上）。**生成飞书云文档**要在对话里明说“写成飞书文档”或“追加到飞书文档”，助手只有收到明确指令才会写入飞书。

## 场景一：把定时报告推到飞书群（或个人私聊）

### 前提准备

1. **发往飞书团队群**：管理员先拉 Dalton 机器人进目标飞书群。之后内部成员和管理员能在「设置 → 团队管理 → 团队渠道与运维 → **飞书团队群绑定**」看到这个群，还能点测试推送确认机器人连通正常。
2. **同时发你个人飞书私聊**：去「设置 → 个人设置 → 消息与渠道 → **飞书与 Discord 账号绑定**」生成绑定码，私聊发 `/bind <绑定码>` 给 Dalton 机器人完成绑定。然后在上方**「自动推送与接收账号」**打开**「自动推送总开关」**并勾上你的飞书账号。

### 配置推送目标（普通自动化 vs 定时报告）

- **普通自动化任务**：
  1. 打开左侧导航 **自动化（`/automations`）**，找到你建的定时或价格触线任务，比如每日行业扫描或个股异动。
  2. 打开这条任务的推送开关。
  3. 点任务旁边的**推送目标选择器**，在列表里勾一个或多个**飞书群**，也能同时勾上已绑定的飞书或 Discord 个人接收账号。
- **使用固定报告模板的定时报告**：
  - 内部成员也可以直接在对话里让 Dalton 查看、设置或撤销这类定时报告的推送目标；经对话设置飞书群或 Discord 频道时，需你明确确认才会生效：内部成员可添加本人所在且已获授权的飞书群，群若绑定了工作区，任务所有者需对该工作区有写权限；Discord 频道由管理员配置。此类报告的富文本卡片发往飞书，Discord 接收纯文本。
- 任务跑完后，频道网关会自动把结构化卡片（超大飞书卡片自动拆分发送）或纯文本摘要发进指定飞书群。你可以在执行历史里查看各目标明细及「已完成 · 投递中」「已完成 · 投递失败」「已完成 · 部分投递失败」等投递状态。

:::note[排查送达状态与失败告警]
普通自动化任务的送达情况直接在「自动化」执行历史中查看各目标明细。使用固定报告模板的定时报告确认最终送达失败（通常是含首次发送在内 **3 次**尝试后）、且已配置有效告警目标时，系统会另发一条投递失败告警提醒你及时排查（如机器人被移出群或群权限调整）。
:::

## 场景二：把工作区报告写成飞书云文档

想把长研报、会议纪要或专题复盘写进飞书云文档时（限内部成员和管理员），按下面两种指令来：

1. **新建飞书文档**：在对话里说清楚：
   > 请把工作区里的 `report.md` 写成一篇新的飞书文档（如果里面有图表，请一并上传）。
   - 系统会先把正文和图片转好再创建文档，保证建出来内容完整，没有空壳。
   - Markdown 里带了工作区图表或图片时，会自动传上去并插进对应段落。
   - 建完后，系统会自动给内部团队跟踪群和你已绑定的飞书账号（或登记的公司邮箱）开编辑权限。万一因为账号状态没加上权限，直接跟助手说“帮我给刚才这篇飞书文档补发一下我的编辑权限”就行。
2. **追加到已有飞书文档末尾**：
   > 请把今天更新的这三段结论追加到这篇飞书文档末尾：`https://...`
   - 追加碰到网络异常时，系统会分清“原文档没动过（放心重试）”和“结果不明（先打开文档看一眼再决定要不要重跑，免得重复追加）”。

:::caution[飞书云文档写入适用范围]
飞书云文档写入支持**新建文档**和**在文末追加**；需要修改已有段落、调整顺序或更改全局权限时，直接在飞书里编辑即可。外部成员可只读查阅管理员授权的飞书知识空间。
:::
