在周末、月末或调仓节点，将分散在各公司工作区的动态、论点变化与过往决策记录汇总为完整的**组合复盘**。

组合复盘最顺手的入口是 **研究总监（Home）** 或一个专门的 **「组合复盘」专题工作区**；通过研究总监向各持仓公司工作区并行查证最新状态，再结合 **`conversation_search`（团队对话归档）** 对比几周前团队做决定时的原始假设，可以快速发现论点漂移和赔率变化。

## 两种常见复盘做法

### 做法一：在「研究总监（Home）」做跨公司一周汇总

适合持仓标的大多已有各自独立公司工作区的场景：

1. 进入左侧的 **研究总监**，直接列出你要复盘的持仓或核心覆盖清单：
   > 请帮我复盘本周以下 6 个核心持仓工作区：A、B、C、D、E、F。分别汇总本周股价表现、已到期的跟踪议程结果、核心论点是否有变化（五词结论：论点不变、论点加强、论点削弱、论点失效、新论点）以及最新赔率变化，最后按“需要重点重估”排序输出一张总表。
2. 如果你已在「设置 → 对话与助手」开启「交给分析师前不再询问」，研究总监会并发从各工作区拉取最新记录（或向需要深查的工作区派活），跑完后汇总成统一视角的组合综述。
3. 若你还开启了「共享团队历史研究记录」，研究总监还能顺带调用 `conversation_search` 检索团队过去对这些标的讨论过的预期、目标价与待办卡片，帮你对照“当初买入逻辑 vs 当前现实进度”。

### 做法二：在「组合专题工作区」上传持仓表做定量归因

适合需要结合真实权重、盈亏贡献或做图表的深度月度/季度复盘：

1. 新建一个专门的专题工作区（如“组合月度复盘”），把持仓权重/收益明细 `.xlsx` 或 `.csv` 拖进对话或文件面板。
2. 对分析师说明复盘需求，例如：
   > 请读取上传的持仓明细表，用 Python 计算分行业与分个股的收益贡献和回撤贡献，绘制归因瀑布图和持仓集中度图表，并针对贡献最大和拖累最大的前 3 只标的检索近期外部催化与市场状态拥挤度（`market-regime`），输出一份可预览的交互式 HTML 复盘报告。
3. 如果想每周自动出一次例行回顾，还可以在工作区使用 `/weekly-review` 技能，或将其配置为每周五/周日的定时**自动化任务**。

## 复盘输出怎么沉淀

- **给团队分享全景**：把生成的 HTML 组合复盘页面发布到 [监控面板](/help/everflow/monitors/) 的「组合」分类，设为「指定同事」或「全公司」可见。
- **更新核心论点**：发现某只股票赔率明显收窄或假设被证伪时，点进该公司工作区跑一次 `/dalton-thesis-delta`，把更新后的结论和下一阶段跟踪议程写入档案。
