这页教你周末、月末或调仓时，把散在各个公司工作区里的动态、论点变化和历史判断收拢成一份**组合复盘**。

做组合复盘最顺手的入口是 **研究总监（Home）**，或者单开一个 **「组合复盘」专题工作区**。用研究总监并行向各持仓工作区核对最新状态，再配合**团队历史研究记录（只读归档）**翻出以前团队做决定时的假设，很快就能看清论点有没有漂移、赔率怎么变。

## 两种常见复盘做法

### 做法一：在「研究总监（Home）」做跨公司一周汇总

适合持仓标的各自已经有独立公司工作区的情况：

1. 点左侧的 **研究总监**，把要复盘的持仓或核心覆盖清单列出来：
   > 请帮我复盘本周以下 6 个核心持仓工作区：A、B、C、D、E、F。分别汇总本周股价表现、已到期的跟踪议程结果、核心论点是否有变化（五词结论：论点不变、论点加强、论点削弱、论点失效、新论点）以及最新赔率变化，最后按“需要重点重估”排序输出一张总表。
2. 在「设置 → 个人设置 → 对话与助手」开启「交给分析师前不再询问」（新账号默认开启）时，研究总监会并发去各工作区拉最新记录（需要深查的还会派活过去），跑完汇总成统一视角的组合综述。
3. 在「设置 → 个人设置 → 对话与助手」打开了「共享团队历史研究记录」的话，研究总监还能顺手检索历史团队讨论归档，查出团队以前对这些股票讨论过的预期、目标价和待办卡片，帮你把“当初为什么买”和“现在走成什么样”放到一起比。

### 做法二：在「组合专题工作区」传持仓表做定量归因

适合要算真实权重、盈亏贡献或画图的月度、季度复盘：

1. 新建一个专题工作区（比如“组合月度复盘”），把持仓权重和收益明细 `.xlsx` 或 `.csv` 拖进对话或文件面板。
2. 把复盘要求说给分析师听，比如：
   > 请读取上传的持仓明细表，用 Python 计算分行业与分个股的收益贡献和回撤贡献，绘制归因瀑布图和持仓集中度图表，并针对贡献最大和拖累最大的前 3 只标的检索近期外部催化与市场状态拥挤度，输出一份可预览的交互式 HTML 复盘报告。
3. 想每周自动跑一次例行回顾，可以在工作区用 `/weekly-review` 技能，或者配成每周五、周日定时跑的**自动化任务**。

## 复盘输出怎么沉淀

- **分享给团队看**：把生成的 HTML 组合复盘页发布到 [监控面板](/help/everflow/monitors/) 的「组合」分类，设成「指定同事」或「全公司」可见。
- **更新核心论点**：发现某只股票赔率变窄或假设落空，点进那家公司的工作区跑一次 `/dalton-thesis-delta`，把新结论和下一阶段跟踪议程写进档案。
