这页带你从登录账号开始，一路走到选好默认模型、新建第一个工作区、发出提问并打开结果文件。

第一次进 Everflow，只要走完“登录 → 首次引导选默认模型与投资画像 → 建或选工作区 → 提问 → 在右侧看文件”这五步就能开始干活。左侧栏底部的「快速上手」清单会帮你记着完成了哪几步。

## 第一步：登录系统

Everflow 面向团队内部使用，登录页采用**邮箱或用户名 + 密码**的方式进入：

1. **公司邮箱登录**：管理员把你的公司邮箱加进白名单后，输入**邮箱和密码**就能登录。第一次还没设密码，或者以后忘了密码，点密码框旁边的**「忘记密码？」**，收一封重置邮件就能重设。
2. **一次性邀请链接注册（用户名 + 密码）**：拿到内部成员或管理员发给你的一条邀请链接后，点开直接设好**用户名**和**密码**就能进系统。之后在登录页填**用户名或邮箱**加密码都可以。

:::note[邀请链接有效期]
每条邀请链接有效期为 **7 天**，限用 **1 次**。链接过期或失效时，请找团队管理员或内部成员在「设置 → 团队管理 → 成员与权限」重新生成。
:::

## 第二步：完成首次引导（选默认模型与投资画像）

首次登录后，引导向导会带你完成两步配置：

1. **选择默认模型**：
   - 团队共享模型已由管理员配好，你直接看到**「团队已配置好模型」**即可进入默认模型选择。如果团队尚未配置推荐模型，页面会提示联系管理员，并提供**「重试」**按钮刷新最新模型列表。
   - 选模型页面按固定顺序列出最多 5 档精选模型（**Gemini 4 Neon**、**Gemini 4 Carbon**、**Claude Opus 5.5**、**GPT-6.2 Astra**、**GPT-6.2 Sol**），每张卡片带有**智能**、**速度**和**说人话**三项评分，帮助你按习惯挑选：
     - 主对话模型默认推荐 **Gemini 4 Neon**；
     - 后台模型默认推荐 **Gemini 4 Hydrogen**（低思考强度）；
     - 保持默认备用设置时，后台**自动任务**在主订阅不可用时会按系统默认 6 档备用链依次切换；**手动对话**碰到订阅不可用时直接弹窗提醒，由你决定等待重置或手动换模型。
2. **填写投资画像与显示偏好**：
   - 引导完成后会进入首次访谈，帮你记下关注市场、研究风格和常用研究深度；以后想改，点左下角头像进「设置 → 个人设置 → 投资画像」。
   - 新账号默认使用简体中文界面；个人显示时区在网页首次登录时自动采用当前浏览器时区（未传或未识别时兜底为香港时区 `Asia/Hong_Kong`，每日预算结算默认按北京时间 `Asia/Shanghai`）；想调整语言、时区、主题或卡片样式，去「设置 → 个人设置 → 通用与外观」。

## 第三步：创建或选择工作区

在 Everflow 里，建议按**“一只重点公司 = 一个工作区”**或**“一个跨公司专题 = 一个工作区”**来整理研究：

1. 如果只是先问个临时问题，直接在左侧点 **研究总监** 就能开聊。
2. 打算持续跟某家公司（比如宁德时代或某只美股），点左侧栏的**新建工作区**，起个简短的名字就行。
3. 你也可以直接对研究总监说：*“帮我新建一个 NVIDIA 的工作区”*，它会帮你把目录建好。
4. **重复公司提醒**：新建公司工作区时，系统会自动比对已有工作区和覆盖单元（外部成员只检查自己的工作区）。如果发现是同一家公司（比如 `700.HK` 和 `0700.HK` 或中英文别名），会先弹出已有工作区供你直接复用，避免重复建区。

:::tip[命名建议]
工作区名字支持中文或英文代码。如果你跟的 A 股或港股还没有别名，后面把材料归档进公司 Wiki 时可以自己登记中文简称和股票代码别名（一次最多 10 个），方便全队直接搜到。
:::

## 第四步：发出第一条提问并上传资料

1. 选中目标工作区（或研究总监），在底部输入框打字提问，比如：
   > 请帮我梳理这家公司最近三个季度的营收增速与毛利率变化，并对比市场一致预期。
2. 手头有路演纪要、PDF 财报或 Excel 表格，直接把文件拖进输入框（单文件上限 **200 MiB**，单条消息最多 **10 个附件**、合计上限 **600 MiB**），或者拖到右侧的 **文件** 面板。
3. 发送后，你可以实时看见 Dalton 正在调哪些工具和数据源。嫌页面太长，可以去「设置 → 个人设置 → 对话与助手 → 工具调用」切到「状态行」，过程会折成一行动态提示。
4. 还没发出去的文字草稿会自动存在当前浏览器里（保留 **7 天**、单条上限 **100 KB**，只存文字不含待发附件）。等服务端收到消息后，草稿会自动清掉。

## 第五步：在右侧面板看结果文件

Dalton 做出 Markdown 笔记、HTML 交互看板、图表或 Excel 表格后，你可以这样查看：

- 对话气泡里会贴出文件卡片，点一下就在右侧**文件**面板打开预览。
- 看长报告、宽表格或 PDF 时，点文件面板右上角的**展开面板**就能铺满主区域；想回到对话再点**显示对话**。
- 打开 HTML 网页报告时，顶部栏可以切换**查看页面 / 查看源代码**、**在新标签页打开**，也能一键点**发布**并在发布时选择可见范围（新面板默认**「仅自己」**），挂成 [监控面板](/help/everflow/monitors/)。
