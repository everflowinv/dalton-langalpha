从账号登录、配置研究偏好到创建首个公司工作区并打开产出文件的完整上手步骤。

第一次进入系统后，按顺序完成“登录 → 完善投资偏好 → 新建或进入工作区 → 提问 → 在右侧查看文件”五步即可开展日常投研；左侧栏底部的「快速上手」清单会同步跟踪完成进度。

## 第一步：登录系统

Everflow 面向团队内部使用，登录页采用**邮箱或用户名 + 密码**认证，常见进入方式如下：

1. **公司邮箱登录**：管理员将你的公司邮箱加入白名单后，需输入**邮箱和密码**登录。如果是首次使用还未设置密码，或后续忘记密码，可点击登录页密码框旁的**「忘记密码？」**，输入公司邮箱接收重置邮件并完成密码设置。
2. **一次性邀请链接注册（用户名 + 密码）**：如果你收到管理员发出的一次性邀请链接，打开链接后直接设置**用户名**和**密码**即可进入系统；以后在登录页输入**用户名或邮箱**与密码都能登录。

:::note[邀请链接有效期]
每条邀请链接有效期为 **7 天**，仅可使用 **1 次**。如链接已过期或失效，请联系团队管理员在「设置 → 团队管理 → 成员与权限」重新生成。
:::

## 第二步：配置个人偏好与投资画像

首次登录后，系统会引导你填写**投资画像**（关注市场、研究风格、常用研究深度等）。这些偏好会自动注入你后续的研究对话中：

- 你随时可以在左下角点击头像打开「设置 → 个人设置 → 投资画像」修改或重置这些选项。
- 如希望查看和调整语言（简体中文 / English）、个人显示时区（首次同步自动采用浏览器检测到的时区；每日预算结算时区默认 `Asia/Shanghai`）或卡片样式，可前往「设置 → 个人设置 → 通用与外观」。

## 第三步：创建或选择工作区

在 Everflow 中，建议按**“一只主要覆盖公司 = 一个工作区”**或**“一个跨公司专题 = 一个工作区”**的方式组织工作：

1. 如果只是想先问一个临时问题，可以直接在左侧选择 **研究总监** 发起对话。
2. 如果准备持续跟踪某家公司（例如宁德时代或某只美股标的），点击左侧栏的**新建工作区**，输入简洁的工作区名称即可。
3. 也可以直接对研究总监说：*“帮我新建一个 NVIDIA 的工作区”*，它会替你建好目录结构。

:::tip[命名建议]
工作区名称支持中文或英文代码；如果你覆盖的 A 股或港股尚未登记别名，后续把材料归档进公司 Wiki 时还可以自助登记中文简称和股票代码别名（单次最多 10 个），方便全团队直接检索。
:::

## 第四步：发起第一次对话并上传资料

1. 选中目标工作区（或研究总监），在底部输入框输入你的研究问题，例如：
   > 请帮我梳理该公司最近三个季度的营收增速与毛利率变化，并对比市场一致预期。
2. 如手头有路演纪要、PDF 财报或 Excel 表格，可以直接把文件拖拽进聊天输入框（单文件上限 **200 MiB**，单条消息合计上限 **600 MiB**），或拖到右侧的 **文件面板**。
3. 发送后，你可以实时看到 Dalton 正在调用哪些工具与数据源；如果在「设置 → 个人设置 → 对话与助手 → 工具调用」里切换为「状态行」，步骤会折叠成一行动态提示，画面更清爽。
4. 在你等待或切换页面时，输入框里还没发出去的文字草稿会自动保存在当前浏览器中（保留 **7 天**、单条上限 **100 KB**，仅保存文字不含待发附件），只有等服务端确认收到消息后才会清除。

## 第五步：在右侧面板查看结果文件

当 Dalton 生成了 Markdown 笔记、HTML 交互看板、图表或 Excel 表格时：

- 对话气泡里会出现对应的文件卡片，点击即可在右侧**文件面板**中打开预览。
- 浏览长报告、宽表格或 PDF 时，可以点击文件面板右上角的**展开面板**铺满主区域；需要回到对话时点**显示对话**即可。
- 浏览 HTML 网页报告时，顶部栏提供**查看页面 / 查看源代码**切换、**在新标签页打开**，以及将其发布为团队可见的 [监控面板](/help/everflow/monitors/) 入口。
