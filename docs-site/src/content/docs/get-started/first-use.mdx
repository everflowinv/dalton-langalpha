这页带你从登录账号开始，一路走到新建第一个工作区、发出提问并打开结果文件。

第一次进 Everflow，只要走完“登录 → 填投资画像 → 建或选工作区 → 提问 → 在右侧看文件”这五步就能开始干活。左侧栏底部的「快速上手」清单会帮你记着完成了哪几步。

## 第一步：登录系统

Everflow 面向团队内部使用，登录页采用**邮箱或用户名 + 密码**的方式进入：

1. **公司邮箱登录**：管理员把你的公司邮箱加进白名单后，输入**邮箱和密码**就能登录。第一次还没设密码，或者以后忘了密码，点密码框旁边的**「忘记密码？」**，收一封重置邮件就能重设。
2. **一次性邀请链接注册（用户名 + 密码）**：如果管理员发给你一条邀请链接，点开后直接设好**用户名**和**密码**就能进系统。之后在登录页填**用户名或邮箱**加密码都可以。

:::note[邀请链接有效期]
每条邀请链接有效期为 **7 天**，只能用 **1 次**。链接过期或失效时，请找团队管理员在「设置 → 团队管理 → 成员与权限」重新生成。
:::

## 第二步：配好个人偏好与投资画像

首次登录后，系统会引导你填**投资画像**，包括关注市场、研究风格和常用研究深度。这些偏好会自动带进你后面的每一轮研究对话：

- 想改或重填时，点左下角头像，进「设置 → 个人设置 → 投资画像」就行。
- 要切换界面语言（简体中文 / English）、个人显示时区（首次登录自动用浏览器时区；每日预算结算默认用 `Asia/Shanghai`）或卡片样式，去「设置 → 个人设置 → 通用与外观」。

## 第三步：创建或选择工作区

在 Everflow 里，建议按**“一只重点公司 = 一个工作区”**或**“一个跨公司专题 = 一个工作区”**来整理研究：

1. 如果只是先问个临时问题，直接在左侧点 **研究总监** 就能开聊。
2. 打算持续跟某家公司（比如宁德时代或某只美股），点左侧栏的**新建工作区**，起个简短的名字就行。
3. 你也可以直接对研究总监说：*“帮我新建一个 NVIDIA 的工作区”*，它会帮你把目录建好。

:::tip[命名建议]
工作区名字支持中文或英文代码。如果你跟的 A 股或港股还没有别名，后面把材料归档进公司 Wiki 时可以自己登记中文简称和股票代码别名（一次最多 10 个），方便全队直接搜到。
:::

## 第四步：发出第一条提问并上传资料

1. 选中目标工作区（或研究总监），在底部输入框打字提问，比如：
   > 请帮我梳理这家公司最近三个季度的营收增速与毛利率变化，并对比市场一致预期。
2. 手头有路演纪要、PDF 财报或 Excel 表格，直接把文件拖进输入框（单文件上限 **200 MiB**，单条消息合计上限 **600 MiB**），或者拖到右侧的 **文件面板**。
3. 发送后，你可以实时看见 Dalton 正在调哪些工具和数据源。嫌页面太长，可以去「设置 → 个人设置 → 对话与助手 → 工具调用」切到「状态行」，过程会折成一行动态提示。
4. 还没发出去的文字草稿会自动存在当前浏览器里（保留 **7 天**、单条上限 **100 KB**，只存文字不含待发附件）。等服务端收到消息后，草稿会自动清掉。

## 第五步：在右侧面板看结果文件

Dalton 做出 Markdown 笔记、HTML 交互看板、图表或 Excel 表格后，你可以这样查看：

- 对话气泡里会贴出文件卡片，点一下就在右侧**文件面板**打开预览。
- 看长报告、宽表格或 PDF 时，点文件面板右上角的**展开面板**就能铺满主区域；想回到对话再点**显示对话**。
- 打开 HTML 网页报告时，顶部栏可以切换**查看页面 / 查看源代码**、**在新标签页打开**，也能一键发布成团队可见的 [监控面板](/help/everflow/monitors/)。
