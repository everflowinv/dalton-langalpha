这页按屏幕从左到右的顺序，带你认全 {/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 网页版的布局、入口和常用快捷键。

{/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 网页版一共分四栏：最左边的**主导航轨道**、**工作区与对话列表**、中间的**主对话区**，以及右侧的**文件与图表预览区**。在任意页面按 **`⌘K`**（Windows 按 **`Ctrl+K`**），就能全局搜索历史对话、文件和个人资料（Memo）。

## 左侧主导航

最左侧的窄导航栏放着各模块入口（在手机端会落在底部标签栏）：

| 导航项 | 路径 | 用途 |
| :--- | :--- | :--- |
| **智能对话** | `/chat` | 主工作入口，里面有「研究总监」、你的工作区、同事共享的「团队」工作区和对话列表 |
| **自动化** | `/automations` | 管定时任务、一次性任务和价格触发任务，也能看**公司公共任务**、运行历史和回收站 |
| **监控面板** | `/monitors` | 集中看个人和团队发布的实时看板与研究网页，按市场或组合分类 |
| **插件** | `/plugins` | 看内置数据源插件（如研究库、SEC XBRL）和已配置扩展 |

:::note[界面裁剪说明]
在当前 {/* DALTON_DOC:everflow */}Everflow 企业{/* DALTON_DOC_ELSE */}Dalton {/* /DALTON_DOC */}部署里，个人看盘（行情中心 / 仪表盘）独立页和券商实盘订单页默认隐藏。日常查行情、一致预期和财报，直接在对话和监控面板里调取就行。
:::

## 工作区与对话列表栏

点开「智能对话」侧栏，从上到下分别是：

1. **搜索按钮**：点这里或按 `⌘K` / `Ctrl+K`，打开全局命令面板和搜索框。
2. **工作区总览**：用卡片视图看所有工作区，支持拖拽排序。最上面固定放着「研究总监」卡片和最近 3 条协调对话。
3. **研究总监（Home）**：全局统筹入口，点开就能发起跨工作区对话。
4. **我的工作区**：你名下的公司或专题工作区，以及历史对话列表。鼠标悬停可以置顶、重命名、分享、归档，或者在工作区菜单里迁移计算机。
5. **团队分组**：同事在「共享设置」里向你开放网页访问权（仅可读或可读写）的工作区，和你的工作区在同一个列表里往下滚就能看到。
6. **快速上手清单（左下角）**：新用户默认看到 **6 项**引导任务，可以折叠或关掉，帮你走完首次使用。
7. **个人头像菜单（最左下角）**：
   - **设置**：进入「个人设置」和「团队管理」。
   - **帮助**：展开后有**新功能**（`/help/whats-new/`）、**更新日志**（`/help/changelog/`）和**文档**（`/help/`）。
   - **退出登录**。

## 全局搜索（`⌘K` / `Ctrl+K`）

在任何页面按 **`⌘K`**（Windows / Linux 按 **`Ctrl+K`**），输入至少 **2 个字**，就能一次搜到：

- **历史对话记录**：按最新时间排序并高亮命中片段，点一下直接跳进那条对话。
- **工作区文件与个人 Memo**：能匹配文件名、路径和文档正文。

:::caution[搜索范围边界]
全局搜索只搜**你自己的工作区、对话和个人 Memo**。同事共享给你的工作区，要去左侧栏「团队」分组里翻。在 Windows Chrome / Edge 里，在页面内按 `Ctrl+K` 会直接打开全局搜索。
:::

## 主对话区与输入框

中间的主对话区展示当前对话的消息流、工具调用步骤和产物卡片：

- **消息时间与来源**：每条消息下面标着发送和完成时间，鼠标悬停能看完整日期和时区。同事派发或发起的对话会标「由某某派发」，对其他人显示只读保护。
- **输入框控制项**：
  - 切换当前对话用的**模型**（Google Antigravity 渠道下的同系列模型合并为一行显示）；在你自己发起的对话中（本人工作区，或同事开放了「可读写」的工作区）也可以直接让 Dalton 切换模型（切换内置订阅系列时一并说清思考强度，从下一条消息起生效）；
  - 单独调这一条对话的**推理强度**（如低 / 中 / 高 / 超高）和**速度**（在你自己发起的对话中——本人工作区，或同事开放了「可读写」的工作区，且该对话当前可写——随当前对话保存）；
  - 拖入或点击上传**附件**，上传进度和失败重试会直接显示在输入框上方的卡片里；
  - 开启**语音输入**（可在「设置 → 个人设置 → 对话与助手」打开开关）。
- **底部状态栏**：命令行脚本跑超过 5 分钟转到后台后，状态栏会显示**「N 个命令运行中」**。点开步骤行就能看日志或**停止**它。

## 右侧工作区面板（文件 / Memo / 图表）

对话右侧的面板用来看和管理工作区文件、个人 Memo 和工具画出的图表：

- **多标签与导航**：标签页左边有**后退 / 前进**按钮，右键点 `+` 号可以新建文件树或图表视图。
- **展开与收起**：看宽表格（Excel/CSV）、长 Markdown 研报或大 PDF 时，点右上角**展开面板**就能铺满主区，点**显示对话**立刻还原。
- **批量拖拽上传**：文件面板和 Memo 面板都支持一次拖多份文件排队上传，并实时显示进度（Memo 面板单文件原始体积上限 **5 MiB**、抽取正文上限 **1 MiB**）。
- **HTML 报告工具栏**：打开工作区生成的 HTML 文件时，顶部工具栏支持切换**查看页面 / 查看源代码**、**在新标签页打开**，还能点**发布**把它挂到 {/* DALTON_DOC:everflow */}[监控面板](/help/everflow/monitors/){/* DALTON_DOC_ELSE */}[监控面板](/help/explore/dashboards-and-charts/){/* /DALTON_DOC */}。
