按屏幕区域梳理 Everflow 网页版的布局结构、核心模块入口与常用全局快捷键。

Everflow 网页界面自左向右分为**主导航轨道、工作区与对话列表、主对话区、右侧文件与图表预览区**四栏；在任何页面按下 **`⌘K`**（Windows 按 **`Ctrl+K`**）都能直接全局搜索历史对话、文件与个人资料（Memo）。

## 左侧主导航

最左侧的窄导航栏提供进入各核心模块的入口（在手机端会显示在底部标签栏）：

| 导航项 | 路径 | 作用 |
| :--- | :--- | :--- |
| **智能对话** | `/chat` | 主工作入口，包含「研究总监」、自己的工作区列表、同事共享的「团队」工作区以及当前对话列表 |
| **自动化** | `/automations` | 创建和管理定时计划、一次性任务、价格触线时触发任务，查看**公司公共任务**与运行历史/回收站 |
| **监控面板** | `/monitors` | 集中浏览团队与个人发布的实时看板和研究网页，按市场/组合分类展示 |
| **插件** | `/plugins` | 查看系统内置的数据源插件（如研究库、SEC XBRL）及已配置扩展 |

:::note[界面裁剪说明]
在当前 Everflow 企业部署中，个人看盘（行情中心 / 仪表盘）独立导航页与券商实盘订单页默认隐藏；日常行情、一致预期与财报均可在对话与监控面板中直接调取。
:::

## 工作区与对话列表栏

展开「智能对话」侧栏后，从上到下依次包含：

1. **搜索按钮**：点击或按 `⌘K` / `Ctrl+K` 唤起全局命令面板与搜索框。
2. **工作区总览**：在卡片视图下浏览所有工作区，支持拖拽调整自定义排序，顶部置顶展示「研究总监」专属卡片与最近 3 条协调对话。
3. **研究总监（Home）**：全局统筹入口，点击即可新建跨工作区对话。
4. **我的工作区**：你名下的公司/专题工作区及其历史对话列表；鼠标悬停支持置顶、重命名、分享、归档与在工作区菜单中迁移计算机。
5. **团队分组**：同事通过「共享设置」向你开放了网页访问权（仅可读或可读写）的工作区，与你的工作区在同一滚动区内展示。
6. **快速上手清单（左下角）**：新用户默认展示 **6 项**引导任务（支持折叠或关闭），帮助你逐项完成首次使用。
7. **个人头像菜单（最左下角）**：
   - **设置**：进入「个人设置」与「团队管理」。
   - **帮助**：展开子菜单，包含**新功能**（`/help/whats-new/`）、**更新日志**（`/help/changelog/`）与**文档**（`/help/`）。
   - **退出登录**。

## 全局搜索（`⌘K` / `Ctrl+K`）

在任何页面按下 **`⌘K`**（Windows / Linux 按 **`Ctrl+K`**），输入至少 **2 个字**，即可一次搜索：

- **历史对话记录**：按最新时间排列并高亮命中片段，点击直接跳转到该条对话。
- **工作区文件与个人资料（Memo）**：支持匹配文件名、路径以及文档正文内容。

:::caution[搜索范围边界]
全局搜索只检索**你自己的工作区、对话和个人 Memo**，不会搜同事共享给你的工作区。在 Windows Chrome / Edge 中，`Ctrl+K` 原本是浏览器地址栏搜索快捷键，在 Everflow 页面内会被接管为打开全局搜索。
:::

## 主对话区与输入框

对话区中央显示当前回合的消息流、工具调用步骤与产物卡片：

- **消息时间与来源**：每条消息下方显示发送/完成时间（悬停看完整日期与时区）；由同事派发或发起的对话会标明「由某某派发」，对他人显示只读保护。
- **输入框控制项**：
  - 切换当前对话使用的**模型**；
  - 单独调节当前对话的**推理强度**与**速度**（保存于该条对话本身，不会影响其他对话的全局默认值）；
  - 拖入或点击上传**附件**，上传进度与失败重试均在输入框上方卡片直接显示；
  - 开启**语音输入**（可在「设置 → 对话与助手」开启开关）。
- **底部状态栏**：当有命令行脚本超过 5 分钟转入后台运行时，状态栏会显示**「N 个命令运行中」**，并可在步骤行点击查看日志或**停止**。

## 右侧工作区面板（文件 / Memo / 图表）

对话右侧的面板用于浏览和管理工作区文件、个人 Memo 以及工具生成的可视化图表：

- **多标签与导航**：标签页左侧提供**后退 / 前进**按钮，右键点击 `+` 号可快速新建文件树或图表视图。
- **展开与收起**：查看宽表格（Excel/CSV）、长篇 Markdown 研报或大体积 PDF 时，点击右上角**展开面板**即可铺满主区，点**显示对话**立刻复原。
- **批量拖拽上传**：文件面板与 Memo 面板均支持一次拖入多份文件排队上传，并实时显示进度百分比（注：Memo 面板单文件原始体积上限 **5 MB**、抽取正文上限 **1 MiB**）。
- **HTML 报告工具栏**：打开工作区生成的 HTML 文件时，顶部工具栏支持切换**查看页面 / 查看源代码**、**在新标签页打开**，以及点击**发布**将其挂到 [监控面板](/help/everflow/monitors/)。
