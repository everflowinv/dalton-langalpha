这页讲清 {/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 的架构、两个核心角色的分工，以及沙箱如何支撑深度投研。

{/* DALTON_DOC:everflow */}Everflow 是公司的投研工作台，里面的研究助手叫 **Dalton**。{/* DALTON_DOC_ELSE */}**Dalton** 是面向投研团队的 AI 研究工作台。{/* /DALTON_DOC */}每个研究对象对应一个工作区，资料、笔记、模型和报告都留在里面，下次接着用。

Dalton 在平台托管的独立沙箱（Linux 容器）里写并跑 Python 代码。它自己拉{/* DALTON_DOC:everflow */}行情、财报、研报库和专家摘录{/* DALTON_DOC_ELSE */}行情、财报、业绩电话会与公开市场数据{/* /DALTON_DOC */}，算完指标后画图或生成 Excel、HTML 文件，再把核对过的结论交给你。默认情况下，同一位用户的多个工作区共用一台主计算机沙箱，各自保留独立目录；需要容器级隔离时，可以把工作区建在另一台计算机上。

## 两个核心角色：研究总监与分析师

{/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 的每一轮对话，都会由下面两个角色之一接手：

| 角色 | 所在位置 | 适合解决什么问题 | 能看哪些文件与上下文 |
| :--- | :--- | :--- | :--- |
| **研究总监（Chief of Staff）** | 左侧「研究总监（Home）」入口 | 跨公司对比、日常快问、建新工作区、派活给多个分析师并汇总结果 | 拥有自己的 `Home` 目录，也能读你名下工作区和同事已授权共享的工作区 |
| **工作区分析师（Analyst）** | 具体的公司或专题工作区 | 深度覆盖、财报拆解、估值建模、改工作区笔记与档案、跑长流程技能 | 读写当前工作区目录，以及这只标的的长期记忆、资料（Memo）和本地文件 |

:::tip[第一次用怎么选]
还没定好放进哪个工作区、想一次比几家公司，或者只是问个快问题，直接找**研究总监**。要长期沉淀某只股票的知识档案、搭估值模型或写深度研报，就进对应的**公司工作区**找分析师。详细对比见 [研究总监还是分析师？](/help/compare/chief-of-staff-or-analyst/)。
:::

## 核心能力全景

- **程序化工具调用（PTC）**：遇到复杂数据时，Dalton 把拉数、清洗、统计和画图写进同一个沙箱脚本一次算清。这样口径统一，过程也能复查。
- {/* DALTON_DOC:everflow */}**内部与公开研究数据源**：在一个地方接通内部研报库（AlphaEngine）、专家访谈（Guidepoint）、业绩会转写（Transcript）、公司 Wiki、销售纪要、美股 SEC XBRL 原始财报、一致预期、港 A 股财务与公告，以及全网和社交媒体实时检索。详情见 [研究数据源](/help/everflow/research-data-sources/)。
- **沉淀成团队资产**：工作区里做的图表和 HTML 网页，可以一键发布成团队可见的 [监控面板](/help/everflow/monitors/)。研究结论和一手纪要也能归档进公司 Wiki 或销售纪要。[自动化任务](/help/concepts/automations-wakeups-commands/) 还能按计划或股价异动自动跑完，把报告发到你的飞书或 Discord（绑定个人微信还能直接私聊提问）。{/* DALTON_DOC_ELSE */}**多源金融与公开研究数据**：在一个地方接通美股 SEC XBRL 原始财报、业绩电话会转写、市场一致预期、港 A 股财务与公告，以及全网和社交媒体实时检索，并支持按需扩展插件。详情见 [技能与插件](/help/concepts/skills-and-plugins/)。
- **沉淀为团队研究成果**：工作区里做的图表和 HTML 网页，可以一键发布成团队可见的 [监控面板](/help/explore/dashboards-and-charts/)。研究结论与重要假设会持续沉淀在工作区档案和长期记忆中。[自动化任务](/help/concepts/automations-wakeups-commands/) 还能按计划或股价异动自动运行并输出定时报告。{/* /DALTON_DOC */}
- **团队协同与权限隔离**：平台分管理员、内部成员和外部协作成员三级身份。内部成员之间可以按账户开关或工作区三档权限协同，外部成员的工作区默认对他人隐藏，本人可按需向内部成员和管理员开启网页共享（研究总监通道保持隔离）。详情见 [分享与权限边界](/help/concepts/sharing/)。

## 和常见通用聊天助手有什么不同

1. **有状态的工作区文件夹**：你传的 PDF、模型 Excel、生成的图表和报告（在持久化体积上限内）都会存进工作区目录。下次回来可以直接接着改。
2. **后台长任务与子代理协同**：写深度覆盖、跑全套财报分析时，Dalton 会拆出多个子代理（Subagent）并发查库、交叉核对。跑得久的脚本会自动转到后台，跑完了主动向你汇报。
3. **内置投研质量护栏**：{/* DALTON_DOC:everflow */}Everflow{/* DALTON_DOC_ELSE */}Dalton{/* /DALTON_DOC */} 针对中文投研内置了数据核验和文字审校。每个数字都要能追到来源，口径保持一致，没核实的数字会明确标出来。
