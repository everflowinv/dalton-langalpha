管理员登录系统后，可在 **「设置 → 团队管理 → 集成凭据」**（直达路径 `/settings?tab=deploymentCredentials`）统一录入并校验部署级第三方集成凭据，供全团队成员在个人授权时共用。

## 一、网页配置与 `.env` 的职责边界

系统将部署配置分为两类，按职责分别管理：

| 配置类型 | 维护位置 | 典型示例 | 生效方式 |
|---|---|---|---|
| **基础设施与密码学根密钥** | 服务器 `.env` 与容器编排文件 | 数据库与缓存连接、`BYOK_ENCRYPTION_KEY`（数据库加密主密钥）、`PUBLIC_APP_URL`（公开访问根地址）、TLS（传输层安全协议）证书参数 | 修改 `.env` 后执行 `docker compose ... up -d <service>` 重建对应容器生效 |
| **部署级第三方集成凭据** | 网页「设置 → 团队管理 → 集成凭据」 | Google OAuth 2.0（开放授权协议）客户端凭据、飞书开放平台企业自建应用凭据及事件订阅验签密钥 | 单事务加密落库并自动热同步至全部后端工作进程，立即生效 |

:::note[管理员登录模式要求]
部署级集成凭据管理面板面向已启用管理员登录模式的实例开放（`DALTON_AUTH_MODE=local` 或 `supabase`）。本机回环试用模式（`DALTON_AUTH_MODE=oss`）打开「集成凭据」时会展示启用登录模式的引导提示；在服务器执行 `bash scripts/standalone/init.sh --domain <你的域名>` 并完成管理员自举后即可进入完整配置界面。
:::

## 二、配置 Google OAuth 2.0 客户端凭据

管理员可在本页预先登记授权回调地址并完成客户端凭据校验与保存；成员端 Google 个人日历与邮箱授权入口将随个人连接器模块上线。

### 前置条件：站点域名要求

Google OAuth 2.0 Web 客户端要求由 `PUBLIC_APP_URL` 拼接生成的 Redirect URI（授权回调地址）满足以下任一条件：

1. **公网可达的公共顶级域名后缀 HTTPS 地址**：具备 Public Suffix（公共顶级域名后缀，如 `.com`、`.org`、`.cn`）的 `https://` 域名（包括企业公网主域名下配置内网 DNS 解析的子域名，例如 `https://dalton.corp.example.com` 搭配 `--tls-mode internal` 或 `--tls-mode custom`），且成员浏览器可访问该回调地址、后端容器可出站访问 `oauth2.googleapis.com`。
2. **本机回环地址**：单机开启本地登录调试时，可使用 Google 允许的 `http://localhost` 或 `http://127.0.0.1`。

当部署使用裸局域网 IP 或 `.internal` / `.local` 等私有后缀时，页面顶部会展示具体原因横幅，指引管理员改用合规域名重跑 `init.sh` 更新 `PUBLIC_APP_URL`，同时置灰对应的 Google 连接器开关；模型对话与飞书自建应用连接器均可照常配置使用。

### 操作步骤

1. 打开 **「设置 → 团队管理 → 集成凭据」**，在 **Google OAuth 2.0 客户端凭据** 卡片中点击 **「复制」**，获取页面动态生成的 **Google 授权回调地址（Redirect URI）**。
2. 登录 [Google Cloud Console](https://console.cloud.google.com/)，进入 **APIs & Services → Credentials**，创建类型为 **Web application** 的 OAuth 2.0 Client ID，并将上一步复制的回调地址添加到 **Authorized redirect URIs**。
3. 回到「集成凭据」页面，成对填入 `DALTON_GOOGLE_OAUTH_CLIENT_ID`（客户端 ID）与 `DALTON_GOOGLE_OAUTH_CLIENT_SECRET`（客户端密钥）。页面逐字段展示「已设置 / 未设置」及生效来源，输入框保持空白以供新值录入。
4. 点击 **「测试连通性」**：后端会向 Google 官方令牌端点 `https://oauth2.googleapis.com/token` 发起带总时限保护的受控探测，并区分「网络连通性」、「探测超时」与「客户端凭据有效性」。确认通过后点击 **「保存该组凭据」**，凭据将经数据库加密保存并立即同步生效。

## 三、配置飞书开放平台应用与事件验签凭据

### 1. 复制页面回调地址

在 **飞书开放平台应用与事件验签凭据** 卡片中，直接点击 **「复制」** 获取两条由系统动态拼接的标准地址，供管理员预先在飞书开放平台登记（成员端个人飞书日历授权与事件回调将随个人连接器模块上线）：

- **飞书授权回调地址（Redirect URI）**：用于飞书开放平台后台「安全设置 → 重定向 URL」。
- **飞书事件订阅请求地址（Events URL）**：用于飞书开放平台后台「事件与回调 → 请求地址配置」。

### 2. 配置应用凭据（App ID / App Secret）

1. 登录飞书开放平台，创建企业自建应用并在「凭证与基础信息」页面获取 **App ID** 与 **App Secret**。
2. 在「集成凭据」页面成对填入 `DALTON_FEISHU_APP_ID` 与 `DALTON_FEISHU_APP_SECRET`。
3. 点击 **「测试连通性」**：后端调用官方接口 `tenant_access_token/internal` 核验应用凭据（验证通过后立即丢弃返回的临时令牌，仅保留校验结果；同时细分 `10003` 参数错误、`10014` 应用不可用与密钥错误）。
4. 确认通过后点击 **「保存该组凭据」** 立即生效。

:::tip[Everflow 现网飞书应用凭据说明（第 1 批只读保护）]
在 Everflow 现网环境中，飞书应用双键（`DALTON_FEISHU_APP_ID` 与 `DALTON_FEISHU_APP_SECRET`）在第 1 批继续以只读方式回退读取主管理员 Vault（加密凭据保险箱），页面展示琥珀色徽标 **「现网飞书机器人使用中（只读 · 第 3 批迁移后可在此修改）」** 并标明各字段的已设置状态与来源。如需在现网轮换飞书机器人密钥，可继续在主管理员 Vault 中更新后立即重启渠道网关，新进程会实时读取最新密钥；第 3 批完成 Vault 迁移后即可直接在本页修改。

下方的 **事件订阅验签凭据** 与应用凭据的只读状态相互独立，可在当前网页直接填写与轮换。
:::

### 3. 配置事件订阅验签凭据（Encrypt Key / Verification Token）

在卡片下方的 **事件订阅验签凭据** 区域，可按飞书开放平台「事件与回调 → 加密策略」中的配置，单独填写 `DALTON_FEISHU_VERIFICATION_TOKEN`（验证令牌），或与 `DALTON_FEISHU_ENCRYPT_KEY`（加密密钥）一同填写并点击 **「保存事件验签凭据」**。这两项密钥采用加密存储，与上方应用凭据的只读锁定相互独立。

## 四、凭据五态来源与连接器能力开关说明

### 五态来源徽标

页面为每组与每个字段展示配置状态与生效来源，遵循 **启动环境变量 > 网页数据库已保存值 > Vault 只读回退 > 默认 / 未配置** 的优先级：

| 徽标状态 | 含义与操作说明 |
|---|---|
| **由服务器环境变量提供（只读）** | 服务器启动环境或 `.env` 中已为该组任一键赋值，系统以环境变量为准并锁定网页编辑；如需调整，请在 `.env` 修改后重建容器。 |
| **已在网页配置** | 凭据已加密保存于数据库并热生效；页面展示已设置状态与来源，输入框保持空白，输入新值保存即可覆盖轮换，也可点击「清除已保存凭据」删行清空。 |
| **现网只读回退（`vault_readonly`）** | 第 1 批仅用于已绑定主管理员 Vault 的飞书应用双键，页面以只读状态展示已设置标识并支持连通性测试，待第 3 批迁移后开放网页修改。 |
| **Vault 读取异常（`vault_error`）** | 读取主管理员 Vault 时发生数据库或解密异常，系统自动锁定应用双键写入以保护既有绑定；排查数据库与 `BYOK_ENCRYPTION_KEY` 后刷新即可恢复。 |
| **默认 / 未配置** | 当前尚未配置该组凭据，可在网页直接录入并保存。 |

### 连接器能力开关与「即将推出」状态

个人日历与邮箱连接器模块上线前，开关区以 **「即将推出」** 展示待开放的连接器条目，供管理员预先完成上方凭据保存与连通性测试。当连接器注册了部署级能力开关后，开关提供三种明确状态：

- **开启**：向数据库写入显式开启值，按所配置凭据启用该能力；
- **关闭**：向数据库写入显式关闭值，优先级高于部署形态默认值；
- **恢复默认**：仅在网页保存过覆盖值时出现，点击后删除数据库覆盖行，恢复由部署形态默认值控制。

保存或恢复默认成功后，当前浏览器会立即刷新能力列表；其他在线成员在切换回浏览器标签页或缓存满 60 秒后会自动同步最新能力状态。
