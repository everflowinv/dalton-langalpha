这页按日期倒序记录 Everflow（Dalton）已合入的用户可见更新；想按专题看重点功能的用法，请看 [新功能](/help/whats-new/)。

- **2026-11-19**（正式版）：完成 OpenClaw 最终清理，删除只为旧系统服务的网页搜索通道、旧版消息转发与迁移工具代码，全面摆脱对本机 OpenClaw 目录的依赖，正式作为独立程序运行（`#395`）；生产共 151 个定时任务与 40/42 个数据任务（按配置在容器或服务器本机运行，含三个数据任务生成的「市场状态与板块强弱」「A股申万行业强弱与估值」收盘后更新面板与「A股盘中监测」「港股动量指数」盘中每分钟更新面板，以及覆盖 Codex、Claude 和 Antigravity 通道的每日模型可用性检查）均已在 Dalton 运行。
- **2026-11-19**（正式版）：生产已开启**录音转写与纪要整理**能力（`#175`–`#178`），支持把工作区音频（单文件上限 2 GiB）自动转写成保真投研纪要、核对数字与专名并按说话人分流入库（仅内部成员与管理员可用）。
- **2026-11-19**（正式版）：按 Google Cloud 计费目录价格在模型目录预接入 **Gemini 4 Neon**，订阅开放后由管理员核对档位并加入模型选择器（目前订阅里尚未列出）（`#394`），同时将 Antigravity（Gemini）通道纳入每日模型可用性检查。
