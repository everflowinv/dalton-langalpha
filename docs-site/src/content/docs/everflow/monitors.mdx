这页讲清怎么把工作区网页发布成监控面板，以及四档权限、刷新频率和异常提示怎么看。

**监控面板（`/monitors`）** 把工作区生成的 HTML 网页和后台定时数据看板收在同一个入口，支持**仅自己 / 指定同事 / 全公司 / 任何人（公开链接，仅管理员）**四档权限。底层数据源采集异常时，看板会保留上次成功的数据并提示**「数据未更新」**，页面和历史图表照样能看。

## 四档可见范围（谁能看）

发布或修改监控面板时，可以选下面四档可见范围，权限跟成员身份严格绑定：

| 可见范围 | 谁能查看 | 谁能设置 |
| :--- | :--- | :--- |
| **仅自己** | 只有发布人本人 | 所有用户（外部成员**只能**选这一档） |
| **指定同事** | 发布人加上勾选的内部成员，至少选 1 人；成员离职或失去内部权限时自动收回 | 内部成员、管理员 |
| **全公司** | 全体内部成员和管理员 | 内部成员、管理员 |
| **任何人（公开链接）** | 拿到 `/m/<slug>` 公开链接的任何人免登录就能看页面和实时数据 | **仅管理员**（发布前要二次弹窗确认） |

:::caution[公开链接权限提醒]
管理员拥有的面板由管理员负责修改；如果原发布者事后失去管理员身份，继续修改自己名下原为「任何人（公开链接）」的面板时，保存后可见范围会调整为「全公司」。外部成员发布面板时使用「仅自己」一档。
:::

## 怎么把工作区网页挂成监控面板

只要工作区里有一份交互式 HTML 报告，或者包含 `index.html` 的看板目录，都能一键挂成监控面板。如果页面里看不到「发布」或监控面板入口，请联系管理员。

1. 在工作区右侧**文件面板**打开那个 HTML 文件，或目录里的 `index.html`。
2. 点顶部工具栏的**发布**按钮。
3. 在弹窗里填好这四项：
   - **面板标题**：显示在列表和顶部栏的名字；
   - **所属分类**：`市场总览`、`美股`、`A 股`、`港股`、`日韩台`、`个股`、`组合` 或 `其他`；
   - **谁能看**：按需要选四档可见范围（选「指定同事」时勾出成员）；
   - **文件更新后自动更新**（可选）：勾上后，只要助手在同一个工作区结束一轮对话且这个文件有改动，系统就会自动发一个新版本。
4. 点发布，以后就能用固定链接 `/monitors/<slug>`（公开链接是 `/m/<slug>`）随时打开。

### 面板查看器常用操作

打开任意一个监控面板后，顶部栏有三个常用按钮：

- **切换版本（`v1` / `v2`…）**：工作区发布的面板可以在下拉框翻看历史版本，最多保留最近 100 个版本。
- **复制链接 / 新窗口打开**：一键复制对应权限的固定链接，或者在新标签页全屏看。
- **前往源文件**：面板所有者或有管理权限的人看工作区面板时，点一下就能直接跳回原工作区那个文件，方便继续让分析师改。

## 让 Dalton 帮你挂面板

除了自己在右侧文件面板点「发布」，你也可以在对话里直接让 Dalton 帮你挂上去：

- 在对话里说**“把这个页面挂到监控面板”**，Dalton 会默认按**「仅自己」**可见发布。
- 想给**指定同事**或**全公司**看，就在对话里明说范围，比如“挂到监控面板，给全公司看”或“挂到监控面板，只给某某看”。
- **公开链接（免登录访问）由管理员在面板设置里开启**。

## 面板来源与数据更新频率

监控面板分两类来源，更新节奏各不相同：

1. **工作区网页面板**：
   - 手动点重新发布时更新。
   - 打开了**「文件更新后自动更新」**时，只要分析师在工作区改了网页或附属文件并在回合结束时校验通过，系统就会自动切出新版本。
2. **团队定时数据看板**：
   - 由后台数据任务按计划刷新，主要分三类：
     - **市场情绪系列面板**（`市场情绪总览`、`美股市场情绪与监控`、`A股情绪、资金流与拥挤度`、`港股AH溢价与板块强弱`、`日韩台融资杠杆`、`美股与中国个股监控`）：工作日按定时计划重建并发布最新版本。
     - **日终板块与相对强弱面板**（`市场状态与板块强弱`、`A股申万行业强弱与估值`、`相对强弱看板（中概 / 美股金融 / ETF）`）：每个交易日收盘后更新。
     - **交易时段分钟级实时看板**（`A股盘中监测`、`港股动量指数`）：按交易所日历动态读取开休市和半日市收盘时间。A 股常规交易时段（09:30–11:30、13:00–15:00）和港股常规交易时段（09:30–12:00、13:00–16:00，半日市按日历提前收盘）内，每 **60 秒**推一次实时快照，午休和休市日自动跳过。收盘后写入当天最终值，休眠到下一个交易时段开盘。

## “数据未更新”与更新时间指标的含义

面板卡片和详情页上有两个不同的时间和两种异常提示，先分清它们的意思：

- **页面更新时间**：指面板 HTML 外壳最近一次重新发布版本的时间。
- **数据时间**：指底层行情或统计数据最近一次成功拉取落库的时间。一个实时看板可以页面框架好几天不动，但「数据时间」每分钟都在刷新。
- **「数据未更新（上次成功：…）」横幅**：
  - 交易时段实时采集器遇到某路外部数据源超时、限流或解析报错时，系统会**保留上次成功拿到的完整数据**继续展示，避免图表变空白。同时页面顶部或状态栏会亮出**「数据未更新」**横幅，写明上次成功时间和故障原因，提醒你注意数据时效。
- **「最近一次更新失败：…」警示**：
  - 后台自动更新任务或工作区自动发布没能生成新版本时，卡片和顶部栏会出现黄色警示（悬停可看详情）。此时页面上展示的仍是上一个稳定的已发布版本，团队成员还能照常看。
