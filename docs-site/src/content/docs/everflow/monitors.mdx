把工作区网页发布为团队可访问的实时看板，管理四档可见范围、自动刷新与异常状态提示。

**监控面板（`/monitors`）** 把工作区生成的可视化 HTML 页面和平台定时数据任务看板统一收口在一个入口，支持**仅自己 / 指定同事 / 全公司 / 任何人（公开链接，仅管理员）**四档权限；当底部数据源采集异常时，系统会保留最后一次成功的数据并提示**「数据未更新」**，而不是让图表白屏或报错。

## 四档可见范围（谁能看）

发布或修改一个监控面板时，可以设置以下四档可见范围（受成员身份严格约束）：

| 可见范围 | 代码标识 | 谁可以查看 | 谁可以设置 |
| :--- | :--- | :--- | :--- |
| **仅自己** | `own` | 仅发布人本人 | 所有用户（外部成员**仅能**选此档） |
| **指定同事** | `members` | 发布人及勾选的公司内部成员（至少选 1 人；若成员离职或失去内部权限，访问权自动收回） | 内部成员、管理员 |
| **全公司** | `company` | 全体公司内部成员与管理员（外部成员不可见） | 内部成员、管理员 |
| **任何人（公开链接）** | `public` | 互联网上任何持有 `/m/<slug>` 公开链接的人免登录即可查看页面与实时数据 | **仅管理员**（发布前需二次弹窗确认） |

:::caution[公开链接权限提醒]
非管理员在尝试修改管理员此前已设成「任何人（公开链接）」的面板时，系统会提示你没有公开权限，保存后可见范围会降级为「全公司」。外部成员发布面板时只能选择「仅自己」。
:::

## 如何把工作区网页挂成监控面板

只要工作区里有一份交互式 HTML 报告或包含 `index.html` 的看板页面目录（由分析师按你的需求生成），都可以一键挂成监控面板（如果你看不到「发布」或监控面板入口，请联系管理员）：

1. 在工作区右侧**文件面板**打开目标 HTML 文件（或目标目录的 `index.html`）。
2. 点击顶部工具栏的**发布**按钮。
3. 在弹出的发布窗口填写：
   - **面板标题**：显示在监控面板列表和顶部标题栏的名称；
   - **所属分类**：`市场总览`、`美股`、`A 股`、`港股`、`日韩台`、`个股`、`组合` 或 `其他`；
   - **谁能看**：按需要选择四档可见范围（选「指定同事」时在列表中勾选成员）；
   - **文件更新后自动更新**（可选）：勾选后，每当研究助手在同一工作区结束一轮对话并检测到该文件发生变更时，系统会自动生成并发布一个新版本。
4. 点击发布，即可通过固定链接 `/monitors/<slug>`（公开链接为 `/m/<slug>`）随时打开。

### 面板查看器常用操作

打开任意一个监控面板后，顶部栏提供以下功能：

- **切换版本（`v1` / `v2`…）**：对于工作区发布的面板，可在下拉框回看历史版本（最多保留最近 100 个版本记录）。
- **复制链接 / 新窗口打开**：一键复制对应权限的固定分享链接，或在浏览器新标签页全屏查看。
- **前往源文件**：若你是面板所有者或具备管理权限且来源为工作区，点击可直跳回原工作区对应的文件位置继续让分析师迭代修改。

## 让 Dalton 帮你挂面板

除了自己在右侧文件面板点「发布」，你也可以直接在对话里把工作区生成的页面交给 Dalton 挂到监控面板：

- 直接在对话里说**“把这个页面挂到监控面板”**，Dalton 会默认按**「仅自己」**可见为你发布。
- 如果你想分享给**指定同事**或**全公司**看，需要在对话里明确说出目标范围（例如“挂到监控面板，给全公司看”或“挂到监控面板，只给某某看”）。
- **公开链接（任何人可免登录访问）只能由管理员在面板设置里打开**，普通成员或对话指令不能直接设为公开。

## 面板来源与数据更新频率

监控面板支持两类来源，更新频率取决于来源类型：

1. **工作区网页面板（`workspace`）**：
   - 当你手动点击重新发布时更新；
   - 若开启了**「文件更新后自动更新」**，每当分析师在工作区修改了该网页或附属文件并在回合结束时校验通过，会自动切出新版本。
2. **团队定时数据任务看板（`data_job`）**：
   - 由后台确定性数据任务按计划刷新，例如：
     - **市场情绪系列面板**（`市场情绪总览`、`美股市场情绪与监控`、`A股情绪、资金流与拥挤度`、`港股AH溢价与板块强弱`、`日韩台融资杠杆`、`美股与中国个股监控`）：在工作日按定时计划重建并发布最新版本。
     - **交易时段分钟级实时看板**（如配置启用的 A 股盘中监测、港股动量指数）：按照交易所日历动态读取当日开休市与半日市收盘时间，在 A 股（常规交易日 09:30–11:30、13:00–15:00）与港股（常规交易日 09:30–12:00、13:00–16:00，半日市按交易所日历提前收盘）交易时段内每 **60 秒**轮询推送一次实时数据快照（自动跳过午休与休市日），并在盘后写入当日收盘最终值后休眠至下一交易时段开盘。

## “数据未更新”与更新时间指标的含义

在监控面板卡片和详情页里，你会看到两个不同的时间和两种异常提示，含义各不相同：

- **页面更新时间**：指面板 HTML 外壳/模板最近一次重新发布版本的时间。
- **数据时间（`data_as_of`）**：指看板展示的底层市场或统计数据最近一次成功拉取落库的时间。一个实时看板可以页面框架数天不变，而「数据时间」每分钟都在滚动刷新。
- **「数据未更新（上次成功：…）」横幅**：
  - 当交易时段实时采集器遇到某一路外部数据源超时、限流或解析异常时，系统会**保留最后一次成功获取的完整数据**继续展示，避免图表空白，同时在页面顶部或状态栏亮起**「数据未更新」**提示，写明上次成功时间与具体故障来源/原因，提醒你在看盘时留意数据时效。
- **「最近一次更新失败：…」警示**：
  - 当后台自动更新任务或工作区自动发布未能生成新版本时，列表卡片和顶部栏会显示黄色警示（悬停可看失败详情）。此时面板仍安全停留在上一个已发布的稳定版本（`published_seq`），不会把坏页面推给团队成员。
