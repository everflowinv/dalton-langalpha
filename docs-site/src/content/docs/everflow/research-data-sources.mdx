这页讲清 Everflow（Dalton）接了哪些研究和金融数据源，以及 AlphaEngine 缓存和 Guidepoint 专家库怎么用。

在 AlphaEngine 里，**每次调检索（`search_library`）都会消耗额度，哪怕参数一模一样；同一篇文档读过一次全文后，再翻页或重读不重复扣费**。为了替团队省额度，Everflow 在宿主机侧建了团队级 **AlphaEngine 检索缓存**，短时间内的重复检索直接走缓存。遇到财报刚发要看最新内容，让助手传 `params.fresh=true` 就能绕开缓存。

## 研究数据源全景路由

助手在工作区沙箱里通过 `researchdata`、`dalton_sec` 插件以及直连行情和搜索工具，调取下面这些数据源：

### 1. 内部研报、会议与公司库（`research` 路由）

| 路由 | 名称 | 提供什么内容与使用要点 |
| :--- | :--- | :--- |
| **`alphaengine`** | 卖方研报与机构/个人会议 | 卖方研报、机构会议、个人会议、录制状态和词典。先调 `search_library`，再按文档 ID 调 `get_document` 读正文（支持按 `content_field` 和字符分段翻页） |
| **`guidepoint`** | 专家访谈 | 供应链、渠道和竞品一线专家访谈摘录。只返回问答摘录，没有全文接口 |
| **`transcript`** | 业绩会转写 | 财报电话会和管理层回访原话（含指引与 Q&A）。注意 **`all` 跨库初筛里没有 `transcript`**，要单独点名检索 |
| **`company-wiki`** | 公司资料库 | 团队沉淀的公司笔记和行业档案。检索通道只读，要归档得走专门入库流程 |
| **`sales-notes`** | 销售邮件与纪要 | 交易台反馈、市场暗线预期（bogey/whisper）和早报催化。注意摘要转述和原件算同一条证据链 |
| **`tmtb`** | TMT 总结 | TMT 收盘总结和盘前盘后复盘。与原研报重复转述时，算同一条证据链 |
| **`funda-ai`** | FUNDA AI | 独立拆解和高频产业图表，适合跟踪 AI 算力和科技产业链 |
| **`all`** | 跨库初筛 | 并行查 `company-wiki + sales-notes + tmtb + funda-ai`，同时并发查 `alphaengine` 和 `guidepoint`；**不含 `transcript`** |

### 2. 财务、公告与宏观（`finance` / `macro` / `dalton_sec`）

- **美股 SEC 原始报表与 XBRL（`sec` & `dalton_sec`）**：覆盖 `10-K`、`10-Q`、`8-K`、`20-F`、`6-K` 和高管增减持 `Form 4` 原文。`dalton_sec` 提供按日历季、财季、年度、YTD、推导 Q4 和滚动窗口归一化的 XBRL 财务事实，并标明重述口径（`as_reported` vs `latest`）和申报号。
- **一致预期（`estimates`）**：拉取营收、EPS 等一致预期快照，用来做财报 Beat/Miss 对比和报告数字核验。
- **港 A 股财务与公告（`cn-hk`）**：包含法定公告（巨潮转载）、财务与估值问答（`ask`）和备用报价（`quote`）。港股大约有 **5%** 缺口（主要是纯英文公告和股东大会投票结果），助手需要原文时会改用全网搜索查 `site:hkexnews.hk`。
- **宏观与市场状态（`fred` / `treasury` / `market-regime`）**：提供美国通胀、就业、GDP 和利率序列（FRED），财政部 TGA 余额和联邦债务（Treasury），以及市场过热超卖、顶部底部、拥挤度和两融杠杆快照。

### 3. 实时行情、社区与公开网络

- **行情与 K 线**：Dalton 优先走免费行情链——美股免费行情、A 股日线和快照走 `tushare`、非美盘中和全市场免费回退走 `yfinance`，最后用 `fmp` 兜底来省每日配额。复牌日会自动核对近期日线防止假暴跌，也支持**不复权**历史股价。
- **社区与公开网络**：包含雪球讨论（`xueqiu`）、员工评论（`employee`）、跨平台社区情绪（`last30days`）、固定账号 X 时间线（`x-timeline`），以及全网搜索 `web_search`（Gemini Grounding）和 X 社媒检索 `x_search`（xAI）。

:::note[未直连的高频或另类数据]
暗池、期权异动流和高频另类数据（信用卡、卫星、海关等）目前没有直连。13F 持仓可以用 `dalton-13f-tracker` 技能，期权链用 `get_options_chain`，其余只能去 `alphaengine`、`funda-ai` 或 `guidepoint` 搜二手引述。期货和大宗商品行情大约有 **15 分钟延迟**。
:::

## AlphaEngine 额度计费与系统缓存机制

### 1. 额度到底扣在哪里

- **每次检索（`search_library`）都扣一次额度**：哪怕两次参数完全相同，只要打到上游 AlphaEngine，就会扣掉一次检索额度。
- **重读同一篇文档不扣额度**：用 `get_document` 读过一次全文后，同一篇文档再翻页或重读不会重复扣费。
- **省额度习惯**：让分析师**把同一家公司或同一个主题的关键词合并进一次 `search_library` 调用**（比如中英文公司名加代码一起传），别把一个问题拆成好几次搜。

### 2. 系统搜索缓存怎么工作

宿主机桥接层对 `alphaengine.search_library` 和 `transcript` 开了 **SQLite 团队级精确缓存**（第一期）：

1. **参数规范化**：查询词会做全半角和空白归一化，日期键和数组会统一排序。没填 `limit` 时默认按 **3 条**算。
2. **大条数命中截取**：缓存里如果已经有同一条件 `limit=20` 的结果，而这次只查 `limit=5`，系统直接截取前 5 条返回（不扣新额度），并附上说明*「结果由更大条数的缓存截取；需要更多结果请提高 limit 重新检索」*。
3. **动态缓存有效期（TTL，按北京时间对照查询结束日期计算）**：

| 查询结束日期（`end`）范围 | 缓存有效时长（TTL） |
| :--- | :--- |
| 未指定结束日期，或结束日期 ≥ 今天（北京时间） | 有结果缓存 **2 小时**；空结果缓存 **30 分钟** |
| 结束日期在过去 **7 天**内 | 缓存 **12 小时** |
| 结束日期早于 **7 天前**（历史查询） | 缓存 **7 天** |

### 3. 什么时候会绕过缓存（直连上游）

遇到下面四种情况，系统会**跳过共享缓存，直接请求 AlphaEngine 上游**（并算检索额度）：

1. **主动要最新结果**：调用时传了 `params.fresh=true`，比如财报刚发、突发公告或你在对话里要求“跳过缓存查最新进展”。
2. **翻页游标续查**：请求带了 `cursor` 翻页参数时，不走首屏缓存。
3. **个人会议范围（隐私隔离）**：只要涉及个人会议（如 `meeting_scope="personal"`、`own_reservations_only` 或 `personalmeeting` 分类和代码），**一律绕过团队缓存**，保证个人会议记录绝不会跨人共享。
4. **仅规划模式（`mode="plan"`）**：不触发真实检索和缓存。

:::tip[怎么让分析师强制刷新]
觉得某家公司刚出重磅卖方点评却没搜到，直接在对话里说：*“请加上 `fresh=true` 重新检索一次 AlphaEngine。”*
:::

## Guidepoint 专家库使用规则

- **只提供问答摘录**：Guidepoint 没有全文读取接口，也不能游标翻页。
- **条数与上限**：省略 `limit` 时默认返回 **3 条**，单次最多 **30 条**。哪怕返回满 30 条，也不能说明已经扫完了所有访谈。
- **关键词与排序偏好**：`params.keywords` 支持 1–10 个非空字符串（词组之间是 OR，单个词组内是 AND）。`params.recency_bias` 取值 1–100（偏好近期访谈一般从 30 起，只影响排序不截断日期）；`start` 和 `end` 按 UTC 日期硬过滤。
- **合规引用**：对外或报告里只能匿名写专家职务或身份，不能出现专家真名，而且原话直接摘录不能超过 **20 词**。
