这页讲清 Everflow（Dalton）接了哪些研究和金融数据源，以及 AlphaEngine 额度、缓存与 Guidepoint 专家库的使用规则。

在 AlphaEngine 里，**检索额度**和**新文档阅读额度**分开计算：检索按实际向上游请求的**页数**扣额度（命中团队短时缓存免扣），同一篇文档首次打开计一次阅读额度，之后翻页或重读免重复计次。遇到财报刚发要查最新内容时，直接让助手跳过缓存查最新结果即可（上游限流暂停期间，有可用旧结果会先显示原抓取时间，本地尚无缓存时提示稍后再试）。

## 研究数据源全景

助手在工作区沙箱里通过内置投研数据插件、美股公告财务接口以及实时行情和搜索工具，调取下面这些数据源：

### 1. 内部研报、会议与公司库

| 数据源 | 提供什么内容与使用要点 |
| :--- | :--- |
| **AlphaEngine（卖方研报与会议）** | 卖方研报、机构会议、个人会议、录制状态和词典。先检索研报列表，再按需打开选中文档的全文（支持按章节或字符分段翻页） |
| **Guidepoint（专家访谈）** | 供应链、渠道和竞品一线专家访谈的问答摘录 |
| **业绩电话会转写** | 财报电话会和管理层回访原话（含指引与 Q&A）。常规跨库初筛涵盖下方核心内部库，需要业绩会原话时请直接点名查“业绩会转写” |
| **公司 Wiki** | 团队沉淀的公司笔记和行业档案。常规检索只读，归档请直接让助手走入库流程 |
| **销售纪要** | 交易台反馈、市场暗线预期（bogey/whisper）和早报催化。摘要转述和原件算同一条证据链 |
| **TMT 总结** | TMT 收盘总结和盘前盘后复盘。与原研报重复转述时算同一条证据链 |
| **FUNDA AI** | 独立拆解和高频产业图表，适合跟踪 AI 算力和科技产业链 |
| **跨库初筛** | 一次并行查公司 Wiki、销售纪要、TMT 总结、FUNDA AI、AlphaEngine 和 Guidepoint（不含业绩电话会转写） |

### 2. 财务、公告与宏观

- **美股 SEC 原始报表与归一化财务事实**：覆盖 `10-K`、`10-Q`、`8-K`、`20-F`、`6-K` 和高管增减持 `Form 4` 原文，并提供按日历季、财季、年度、YTD、推导 Q4 和滚动窗口归一化的 XBRL 财务数据，同时标明初报口径与最新重述口径及申报号。
- **一致预期**：拉取营收、EPS 等一致预期快照，用来做财报 Beat/Miss 对比和报告数字核验。
- **港 A 股财务与公告**：包含法定公告（巨潮转载）、财务与估值问答和备用报价。针对少数仅英文版的港股公告和股东大会投票结果，助手会自动用全网搜索查港交所披露易原文。
- **宏观与市场状态**：提供美国通胀、就业、GDP 和利率序列（FRED），财政部 TGA 余额和联邦债务（Treasury），以及市场过热超卖、顶部底部、拥挤度和两融杠杆快照。

### 3. 实时行情、社区与公开网络

- **行情与 K 线**：优先使用美股免费行情、A 股日线与快照以及全市场免费行情链，必要时自动回退备用财务接口。复牌日会自动核对近期日线防止假暴跌，也支持**不复权**历史股价。
- **社区与公开网络**：包含雪球讨论、员工评论、跨平台社区情绪、固定账号 X 时间线（按实际取回的最早发帖时间判断时间窗是否完整覆盖，如可能漏帖会明确标注最早取到的时间），以及全网搜索、X 社媒检索与网页正文读取（直读失败时自动回退至备用网页抓取通道）。

:::note[13F、期权与大宗商品行情说明]
13F 持仓和期权链可直接在对话里调取；暗池、期权异动流与高频另类数据（信用卡、卫星、海关等）可通过卖方研报、独立研究或专家访谈检索二手引述。期货和大宗商品行情大约有 **15 分钟延迟**。
:::

## AlphaEngine 额度规则、缓存与软提醒

### 1. 双独立额度与省额度习惯

- **检索额度（按实际向上游请求的页数计算）**：命中团队短时缓存免扣额度；每次向上游请求一页至少按 20 条计（单次要求超过 20 条，或去重筛选后不足时会自动翻页，单次最多 5 页）。因此建议先请求 20 条以内，不够再翻页；查业绩会转写时把日期范围收窄到业绩会前后几天，避免跨度太宽连续翻页。
- **文档阅读额度**：首次打开一篇新文档扣一次阅读额度；同一篇文档再次打开或分段续读免重复扣额度。
- **单家公司一次检索**：检索一家公司时，把中英文公司名和股票代码用空格隔开写在同一次查询里，从返回列表挑选文档；已有结果先从现有列表筛选，不同公司或新主题照常各自检索。
- **会话级软提醒（只提醒、不拦截）**：
  - 同一对话 **30 分钟**内用相同查询词再次非翻页检索时，系统会提醒多久前已搜过及上次返回条数；
  - 同一对话 **30 分钟**内对同一家公司发起第 3 次及以上不同查询词检索时，系统会提醒并附带此前已返回的文档清单（最多 10 篇），方便直接复用已有结果；
  - 个人会议检索独立处理，既不计入重复历史也不记录文档清单。

### 2. 团队缓存、限流保护与旧缓存兜底

1. **参数规范化与大条数截取**：查询词会统一全半角、大小写和空白，筛选条件统一排序，减少无谓重复查询。缓存里如果已有同条件更大条数的结果（例如 20 条），当前只需更少条数（例如 5 条）时会直接截取返回，免消耗新额度。
2. **动态缓存有效期（按北京时间对照查询结束日期计算）**：

| 查询结束日期范围 | 缓存有效时长 |
| :--- | :--- |
| 未指定结束日期，或结束日期 ≥ 今天（北京时间） | 有结果缓存 **2 小时**；空结果缓存 **30 分钟** |
| 结束日期在过去 **7 天**内 | 缓存 **12 小时** |
| 结束日期早于 **7 天前**（历史查询） | 缓存 **7 天** |

3. **限流暂停保护与 7 天旧缓存兜底**：上游返回明确的限流或额度耗尽信号时，检索会自动暂停冷却（从 **60 秒**起指数退避，最高 **10 分钟**，成功一次即复位）。冷却期间、上游异常或请求即将超时前，如果本地有 **7 天**保留期内的历史缓存，系统会优先返回旧缓存并标明原抓取时间，保障研究流程顺畅；已读文档直连读取独立运行，保持可用。

### 3. 什么时候会跳过缓存直连上游

遇到下面三种情况，系统会**跳过共享缓存，直接请求 AlphaEngine 上游**，实际向上游请求时计检索额度：

1. **主动查最新结果**：你在对话里要求跳过缓存查最新进展（比如财报刚发或突发公告）时，常规时段直接向上游查最新结果；普通检索遇上游限流冷却期时，系统会先返回最近一次缓存结果（翻页和个人会议检索按下面两项直连）（本地尚无缓存时提示当前处于限流冷却期，稍后再试）。
2. **翻页续查**：继续翻下一页时直通上游。由于上游翻页游标仅在约 15 分钟内有效，每日增量跟踪跨天续采时按**日期边界**衔接，确保持续覆盖。
3. **个人会议范围（隐私隔离）**：涉及个人会议的检索全程独立直连上游，严格按本人隔离。

（此外，只制定检索方案的“仅规划模式”只输出查询建议，不发实际请求也不消耗额度。）

:::tip[怎么让分析师跳过缓存刷新最新研报]
觉得某家公司刚出重磅卖方点评却还没在缓存里，直接在对话里说：*“请跳过缓存，帮我重新检索一次这家公司在 AlphaEngine 上的最新研报。”*
:::

## Guidepoint 专家库使用规则

- **以问答摘录形式返回**：单次查询默认返回 **3 条**问答摘录，最多 **30 条**（返回满 30 条时可按关键词或日期分段继续细查）。
- **关键词与时间筛选**：支持同时提供 1–10 组关键词（词组之间为“或”关系，单组内为“且”关系），可按近期优先排序，也可指定起止日期（按 UTC 日期过滤）。
- **合规引用**：对外或报告里统一匿名标注专家职务或身份，单段原话直接摘录控制在 **20 词以内**。
