从个人通讯账号绑定到任务推送路线、团队公共任务差异与投递失败告警的完整配置说明。

Everflow 支持通过专用的**频道网关（Channel Gateway）**向**飞书（私聊及团队群）**、**Discord（私聊）**和**个人微信**投递定时研究报告；推送遵循**「个人总开关 → 个人接收账号 / 单任务路线覆盖」**两级规则，投递彻底失败时会自动向你发送**失败告警通知**，不会悄悄漏掉而不吭声。

## 第一步：绑定你的个人接收账号

前往左下角头像 → 「设置 → 个人设置 → 消息与渠道」：

### 1. 绑定飞书或 Discord

1. 在**「飞书与 Discord 账号绑定」**卡片中，点击**生成飞书绑定码**或**生成 Discord 绑定码**。
2. 复制生成的一次性绑定命令（例如 `/bind <绑定码>`）。
3. **私聊发送**该命令给平台内的 Dalton 机器人（**切勿发到群聊中**），绑定码在过期时间前有效。
4. 回到设置页点击刷新，状态显示为**已绑定**后即可用于接收个人推送。

### 2. 绑定个人微信

1. 在**「我的微信绑定」**卡片中点击**「生成个人微信绑定码」**。
2. 复制页面给出的绑定指令，用你的个人微信向团队 Dalton 机器人发送该指令，完成后回到设置页确认状态变为**已绑定**。
3. 绑定后，不仅能接收个人自动化推送，还可以直接通过微信私聊向 Dalton 提问。

:::note[团队微信机器人 vs 我的微信绑定]
普通成员只需在「个人设置 → 消息与渠道 → 我的微信绑定」生成绑定码并发指令绑定自己的微信；**「团队管理 → 团队渠道与运维 → 团队微信机器人」**仅用于管理员扫码登录、维护团队级的微信接入机器人本身。
:::

## 第二步：配置个人推送总开关与默认接收账号

在「设置 → 个人设置 → 消息与渠道 → **消息推送与接收账号**」卡片中：

1. **打开全局推送总开关**（默认关闭）：总开关关闭时，系统不会向你的任何个人账号推送自动化结果。
2. **勾选接收账号**：从已绑定的飞书、Discord 账号中勾选你希望接收推送的目标，还可点击发送测试消息验证连通性。

## 第三步：按任务配置投递路线（含飞书团队群）

打开左侧主导航的 **自动化（`/automations`）**，你可以为每个任务做更精细的投递控制：

- **单任务推送开关**：每条自动化行旁都有独立的推送开关。
- **单任务目标选择器**：点击行内或详情里的目标选择下拉框，可以覆盖全局默认设置，做到：
  - 只推给某几个已绑定个人账号；
  - 推给内部管理员已接入 Dalton 机器人的**飞书团队群**（可选 1 个或多个群）；
  - 或对某条测试中的任务显式设为空路线（不发给任何人）。

:::tip[查看已接入哪些飞书团队群]
内部成员和管理员可在「设置 → 团队管理 → 团队渠道与运维 → **飞书团队群绑定**」中查看所有已拉入 Dalton 机器人的飞书群聊列表，并支持单群测试推送（管理员可在该页面手动管理部分配置）。
:::

## 自动化投递与团队公共任务

在 Everflow 中，自动运行的任务分为两类：

1. **个人 / 团队自动化任务（Agent Turn）**：由助手按计划、一次性或股价异动触发执行，执行结束后先保存结构化报告记录，再通过频道网关投递为飞书富文本卡片或 Discord/微信消息（对于无固定卡片格式的普通任务，会生成规范化结果摘要卡片，点击可直接跳回对话详情）。
2. **团队公共与确定性数据任务（Data Jobs）**：如每日盘前/盘后自动巡检、市场情绪看板重建、新闻/研报增量扫描等。内部成员可在「设置 → 团队管理 → 团队渠道与运维 → **自动巡检与团队公共任务**」以只读方式查看最近运行状态与日志尾部（仅管理员可见主机与运维任务详情；启停与调度管理在「自动化 → **公司公共任务**」页签操作）。

## 投递可靠性：自动重试与失败告警

为了防止网络抖动导致报告漏发，也避免在状态不明时重复刷屏，后台采用了严格的状态机：

1. **确定失败才自动重试**：投递记录保存在数据库 `dalton_notify_deliveries`；对于明确失败或超过 **10 分钟**仍停留在待发状态的记录，后台扫描会自动重试（最多尝试 **3 次**）。
2. **状态未知时不盲目重发**：如果网关在发送瞬间重启或返回状态不确定（`delivery_uncertain` 等），系统会保持保守而不自动重复发第二遍相同的长报告卡片。
3. **投递失败告警（`automation_report_failure_alert`）**：当已生成的报告卡片或纯文本报告经重试确认彻底无法送达目标渠道时，系统会自动创建并发送一条**投递失败告警**通知相关负责人及时排查（若中途原报告成功补发，失败告警会自动取消）。
