这页教你绑定个人通讯账号、配好任务推送路线、查看团队公共任务，以及看懂投递失败告警。

Everflow 通过专用的**频道网关（Channel Gateway）**把定时研究报告推到**飞书（私聊和团队群）**、**Discord（私聊）**和**个人微信**。推送按**「个人总开关 → 个人接收账号 / 单任务路线覆盖」**两级规则走。如果确认送不出去，系统会给你发一条**失败告警通知**提醒排查。

## 第一步：绑定个人接收账号

点左下角头像，进「设置 → 个人设置 → 消息与渠道」：

### 1. 绑定飞书或 Discord

1. 在**「飞书与 Discord 账号绑定」**卡片里，点**生成飞书绑定码**或**生成 Discord 绑定码**。
2. 复制那条一次性绑定命令（格式为 `/bind <绑定码>`）。
3. **私聊发送**这条命令给平台里的 Dalton 机器人（记住要私聊发，发在群里没用），在过期前发出去就行。
4. 回到设置页点刷新，状态变成**已绑定**后就能收个人推送了。

### 2. 绑定个人微信

1. 在**「我的微信绑定」**卡片里点**「生成个人微信绑定码」**。
2. 复制页面给的绑定指令，用自己的微信发给团队 Dalton 机器人，再回设置页确认状态变成**已绑定**。
3. 绑好后不仅能收个人自动化推送，还能直接在微信里私聊问 Dalton 问题。

:::note[团队微信机器人 vs 我的微信绑定]
普通成员只要去「个人设置 → 消息与渠道 → 我的微信绑定」生成绑定码、发指令绑自己的微信就行。**「团队管理 → 团队渠道与运维 → 团队微信机器人」**是管理员用来扫码登录、维护团队微信机器人的，普通成员不用管。
:::

## 第二步：打开个人推送总开关与默认接收账号

打开「设置 → 个人设置 → 消息与渠道 → **消息推送与接收账号**」卡片：

1. **打开全局推送总开关**（默认关闭）：总开关关着时，系统不会往你的任何个人账号发自动化结果。
2. **勾选接收账号**：从已绑定的飞书、Discord 账号里勾出想收推送的账号，还可以点发送测试消息确认通不通。

## 第三步：按任务配置投递路线（含飞书团队群）

打开左侧主导航的 **自动化（`/automations`）**，就能按单个任务细调推送目标：

- **单任务推送开关**：每条自动化行旁边都有独立的推送开关。
- **单任务目标选择器**：点行内或详情里的目标下拉框，可以盖过全局默认设置，比如：
  - 只推给其中某几个已绑定个人账号；
  - 推给管理员已经拉入 Dalton 机器人的**飞书团队群**（可选 1 个或多个群）；
  - 给某条测试任务明确设成空路线，谁都不发。

:::tip[查看已经接入哪些飞书团队群]
内部成员和管理员可以在「设置 → 团队管理 → 团队渠道与运维 → **飞书团队群绑定**」看到所有已拉入 Dalton 机器人的飞书群，还能发单群测试消息；管理员也能在那里管理部分配置。
:::

## 自动化投递与团队公共任务

Everflow 里的自动任务分成两类：

1. **个人 / 团队自动化任务（Agent Turn）**：由助手按计划、一次性或股价异动触发。跑完后会先存结构化报告记录，再通过频道网关发成飞书富文本卡片或 Discord、微信消息。没有固定卡片格式的普通任务会生成标准摘要卡片，点一下直接跳回对话详情。
2. **团队公共与确定性数据任务（Data Jobs）**：比如每日盘前盘后巡检、市场情绪看板重建、新闻和研报增量扫描。内部成员能在「设置 → 团队管理 → 团队渠道与运维 → **自动巡检与团队公共任务**」只读查看最近运行状态和日志尾部（主机与运维任务详情只有管理员能看；启停和调度要去「自动化 → **公司公共任务**」页签操作）。

## 投递可靠性：自动重试与失败告警

既要防止网络抖动漏发报告，又要避免状态不明时重复刷屏，后台用了严格的状态机：

1. **确定失败才自动重试**：投递记录存在数据库 `dalton_notify_deliveries` 里。明确失败，或者超过 **10 分钟**还卡在待发状态的记录，后台扫描会自动重试，最多 **3 次**。
2. **状态不明时保持保守**：如果网关正好在发送瞬间重启，或者返回不确定状态（`delivery_uncertain` 等），系统会先保住记录状态、暂停重发，免得同一份长报告连发好几遍。
3. **投递失败告警（`automation_report_failure_alert`）**：报告卡片或纯文本报告重发 3 次仍然没送出去时，系统会自动发一条**投递失败告警**提醒相关负责人排查。如果中途原报告补发成功，失败告警会自动取消。
