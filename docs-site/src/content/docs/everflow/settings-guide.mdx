这页照着「设置（`/settings`）」左侧栏的顺序，带你逐栏看懂每一项配置和权限门槛。

Everflow 的设置页分**个人设置**和**团队管理**两大块：个人设置管你自己的账号和偏好，团队管理按管理员和内部成员身份显示对应栏目。上游的「交易」和「实验功能」入口在 Dalton 构建里保持隐藏。

## 第一组：个人设置（Personal）

### 1. 个人资料（`account`）

这里管当前登录账号的基本信息，包括**头像**、**显示名称**、**登录邮箱**（由管理员维护）和**退出登录**按钮。

### 2. 投资画像（`preferences`）

这里可以查看或修改你在首次引导时填过的投资偏好，比如关注市场、投研风格和常用研究维度。助手在对话里会自动参考这些偏好；想全部重填的话，点重置就行。

### 3. 通用与外观（`general`）

这里管界面显示和新手引导：

- **语言**：切换 `简体中文` 或 `English`。
- **时区**：设定个人显示时区（首次登录自动用浏览器时区，随时能改），影响日程显示、自动化默认时区和消息时间戳。每日预算结算时区固定默认按 `Asia/Shanghai` 算。
- **页面引导与快速上手**：可以重新播放各页的新手引导提示，或重置引导进度。
- **卡片样式**：在 **柔和**、**均衡**、**终端** 三种数据卡片样式里挑一个，Dalton 默认用**终端**样式。
- **主题模式**：切换**深色**、**浅色**或**跟随系统**。
- **字体大小**：按当前设备调界面文字的缩放比例。

### 4. 对话与助手（`chat`）

这里控制对话交互细节、工具行为和内部协同开关：

- **回复显示**：
  - **实时显示推理**：开 / 关；
  - **回答显示方式**：`连续显示` / `按段落`；
  - **工具调用**：`逐行`（展开每一步详情）/ `状态行`（折成一行简洁状态栏）；
  - **回复结束时**：`停留在末尾` / `显示回复开头`；
  - **语音输入**：打开或关掉输入框的语音录入按钮。
- **行为与输出格式**：
  - **输出格式优先级**：调整助手偏好的输出形态顺序；
  - **研究深度**与**主动联系**：设定默认分析深度，以及助手反问、主动推进的积极程度，也可以留给助手自己拿主意；
  - **子 Agent**：是否默认启用多子代理并发研究；
  - **免询问授权**：勾上**「交给分析师前不再询问」**和**「创建工作区前不再询问」**，研究总监派活时就不会老弹窗确认；
  - **网络搜索引擎**：配置公开网络检索方式。
- **文件评论（Artifact 评论默认设置）**：
  - **评论发送到**：设文件划词评论默认去哪一条对话（`文件旁的对话` / `生成它的对话` / `新对话`）；
  - **评论时**：设评论框按回车是加入待发送队列，还是立刻发送；
  - **Agent 在哪里回答**：设完整回答放在评论下面、对话里，还是跟着当前阅读位置走。
- **协作与团队记忆（按成员身份显示）**：
  - **工作区协同共享**（仅内部成员与管理员可见，默认打开）：允许内部同事的「研究总监」往你的工作区派任务或追问。
  - **共享团队历史研究记录**：允许你的「研究总监」跨工作区统筹时查阅团队过往的公开研究结论和对话归档。

### 5. 模型（`model`）

这里管可用模型、默认路由和后台专用模型：

- **模型接入**：查看已连接或可用的个人模型连接，比如个人 Claude 登录（`claude_oauth`）。
- **默认模型与快速切换**：设置新对话用的**默认主模型**、**轻量任务（Background）模型**和修改生效范围，也能把常用模型标星置顶。
- **高级设置**（点开后可见）：
  - **各模型参数调优**和**账户默认参数**；
  - **备用模型链（Fallback）**；
  - **Dalton 后台任务模型路由**：可以分别指定或留空跟随系统默认的 **数字核验模型**、**文字审校模型**、**核验备用模型**、**单次核验超时**、**轻量后台任务模型**、**独立复核候选模型**和**研究记忆整理模型**。

### 6. 用量与预算（`budget`）

这里管每天的模型开销上限，详情见 [模型与额度](/help/concepts/models-and-budgets/)：

- 看**今日已结算费用**、**当前预占**、**剩余额度**和**今日费用明细**；
- 设**每日美元上限**（未改过时默认 **$100**）和**默认单任务上限**；
- 给要跑深度长流程的特定公司工作区单独设或移除**工作区单任务上限**。

### 7. 消息与渠道（`integrations`）

这里配个人接收推送和绑定即时通讯账号，详情见 [定时报告与投递](/help/everflow/scheduled-reports-and-delivery/)：

- **消息推送与接收账号**：总开关加上勾选接收推送的已绑定个人账号；
- **飞书与 Discord 账号绑定**：生成一次性 `/bind` 绑定码，私聊发给机器人完成绑定；
- **我的微信绑定**：点「生成个人微信绑定码」，再用微信发给团队 Dalton 机器人。

### 8. 覆盖结构（`coverage`）

:::note[按开关显示]
只有当平台开启 `coverage_units` 覆盖单元特性开关时，这一栏才会出现，用来维护行业和独立公司覆盖单元并绑定工作区。没开这个开关时，系统会根据工作区档案和知识文档自动归类。
:::

## 第二组：团队管理（Team Management）

团队管理分组按账户身份（管理员 `admin` / 内部成员 `internal` / 外部成员 `external`）动态展示；外部成员看不到这一组。

### 9. 模型与供应商（`teamModels`，仅管理员）

- **团队模型接入**：统一管全团队共享的模型供应商 OAuth 和 API 凭据。
- **模型供应商与服务商状态**：看各供应商连通健康状态，以及各岗位当前用的默认模型。
- **模型目录同步**：拉取供应商最新模型列表、预览新增和建议下线的模型差异，一键把新模型同步或从目录里下线、恢复。同步完会自动出现在全团队成员的「设置 → 模型」里。

### 10. 成员与权限（`teamMembers`，内部成员及以上）

- **成员邀请与外部访问**：生成有效期 **7 天**、**1 次**有效的新成员注册邀请链接，设置成员角色，也能撤销还没用掉的旧链接。
- **飞书文档访问范围**（**仅管理员**）：勾选允许外部成员只读访问的飞书知识空间列表。管理员和内部成员默认拥有读写权限。

### 11. 团队渠道与运维（`teamChannels`，内部成员及以上）

- **团队微信机器人**（**仅管理员**）：用微信扫码登录团队公共微信机器人。
- **飞书团队群绑定**：查看已拉入 Dalton 机器人的飞书群聊和可推送状态，支持单群发测试消息。
- **自动巡检与团队公共任务**：只读查看知识库同步、研报增量扫描、公司近况巡检等团队任务的调度周期、最近运行时间和日志尾部。主机和运维任务只有管理员能看；启停和调度编辑都要去「自动化」页操作。
- **手动输入推送目标**（**仅管理员**）：管理员可以在这里补充或微调底层的接收目标 ID。
