按照「设置（`/settings`）」左侧导航的分组顺序，对照说明各项偏好配置与团队管理门槛。

Everflow 设置页分为**个人设置**（面向你自己的账号与偏好）和**团队管理**（按管理员 / 内部成员权限分栏显示）；上游的「交易」和「实验功能」入口在 Dalton 构建中已永久隐藏。

## 第一组：个人设置（Personal）

### 1. 个人资料（`account`）

管理当前登录账号的基本身份信息，包括**头像**、**显示名称**、**登录邮箱**（不可自助修改）以及**退出登录**操作。

### 2. 投资画像（`preferences`）

查看或重新编辑你在首次引导时填写的投资偏好（关注市场、投研风格、关注维度等），帮助助手在工作区对话中保持一致的分析视角；如想重新填写，可在此重置偏好。

### 3. 通用与外观（`general`）

管理界面显示与本地引导行为：

- **语言**：切换 `简体中文` 或 `English`。
- **时区**：设定个人显示时区（首次登录自动采用浏览器检测到的时区，可在此修改），影响日程显示、自动化默认时区和消息时间戳；每日预算结算时区默认按 `Asia/Shanghai` 计算。
- **页面引导与快速上手**：支持重新播放各页面的新手引导提示，或重置引导进度。
- **卡片样式**：在 **柔和**、**均衡**、**终端** 三种数据卡片视觉风格之间切换（Dalton 默认采用**终端**样式）。
- **主题模式**：切换**深色**、**浅色**或**跟随系统**。
- **字体大小**：按当前设备调整界面文字缩放比例。

### 4. 对话与助手（`chat`）

控制对话交互细节、工具行为与内部协同开关：

- **回复显示**：
  - **实时显示推理**：开 / 关；
  - **回答显示方式**：`连续显示` / `按段落`；
  - **工具调用**：`逐行`（展示每一步详情）/ `状态行`（折叠为简洁动态状态栏）；
  - **回复结束时**：`停留在末尾` / `显示回复开头`；
  - **语音输入**：开启或关闭输入框语音录入按钮。
- **行为与输出格式**：
  - **输出格式优先级**：调整助手偏好的输出形态排序；
  - **研究深度**与**主动联系**：设定默认分析深度与助手反问/主动推进的积极程度（也可保持由助手自决）；
  - **子 Agent**：是否默认启用多子代理并发研究；
  - **免询问授权**：勾选**「交给分析师前不再询问」**与**「创建工作区前不再询问」**可减少研究总监派活时的确认打断；
  - **网络搜索引擎**：配置公开网络检索方式。
- **文件评论（Artifact 评论默认设置）**：
  - **评论发送到**：设置文件划词评论的默认去向（`文件旁的对话` / `生成它的对话` / `新对话`）；
  - **评论时**：设置评论框按回车时执行的操作（加入待发送队列或立即发送）；
  - **Agent 在哪里回答**：设置完整回答默认放在评论下、对话中，还是跟随当前阅读位置。
- **协作与团队记忆（按成员身份显示）**：
  - **工作区协同共享**（仅内部成员与管理员可见，默认开启）：允许内部同事的「研究总监」向你的工作区派发研究任务或追问。
  - **共享团队历史研究记录**：允许你的「研究总监」在跨工作区统筹时查阅团队过往的公开研究结论与对话归档。

### 5. 模型（`model`）

管理可用模型、默认路由与后台专用模型：

- **模型接入**：查看已连接或可用的个人模型连接（如个人 Claude 登录 `claude_oauth`）。
- **默认模型与快速切换**：设置新对话使用的**默认主模型**、**轻量任务（Background）模型**及变更生效范围，并给常用模型标星置顶。
- **高级设置**（点击展开后可见）：
  - **各模型参数调优**与**账户默认参数**；
  - **备用模型链（Fallback）**；
  - **Dalton 后台任务模型路由**：可分别覆盖或留空跟随系统默认的 **数字核验模型**、**文字审校模型**、**核验备用模型**、**单次核验超时**、**轻量后台任务模型**、**独立复核候选模型**及 **研究记忆整理模型**。

### 6. 用量与预算（`budget`）

控制个人每天的模型消费额度（见 [模型与额度](/help/concepts/models-and-budgets/)）：

- 查看**今日已结算费用**、**当前预占**、**剩余额度**与**今日费用明细**；
- 设置**每日美元上限**（未设置时默认 **$100**）与**默认单任务上限**；
- 为需要跑深度长流程的特定工作区单独配置或移除**工作区单任务上限**。

### 7. 消息与渠道（`integrations`）

配置个人接收推送和绑定即时通讯软件（见 [定时报告与投递](/help/everflow/scheduled-reports-and-delivery/)）：

- **消息推送与接收账号**：总开关 + 勾选接收推送的已绑定个人账号；
- **飞书与 Discord 账号绑定**：生成一次性 `/bind` 绑定码用于私聊绑定机器人；
- **我的微信绑定**：点击「生成个人微信绑定码」并向团队 Dalton 机器人发送绑定指令完成绑定。

### 8. 覆盖结构（`coverage`）

:::note[按开关显示]
仅当平台开启 `coverage_units` 覆盖单元特性开关时显示该栏；用于维护行业与独立公司覆盖单元，并将工作区绑定到对应研究单元。未开启时系统会自动根据工作区档案与知识文档归类。
:::

## 第二组：团队管理（Team Management）

团队管理分组根据你的账户身份（管理员 `admin` / 内部成员 `internal` / 外部成员 `external`）动态展示；外部成员看不到此分组。

### 9. 模型与供应商（`teamModels`，仅管理员）

- **团队模型接入**：集中管理全团队共享的模型供应商 OAuth / API 凭据。
- **模型供应商与服务商状态**：查看各供应商连通健康状态、各岗位当前使用的默认模型。
- **模型目录同步**：检查供应商最新模型列表、预览新增与建议退役模型差异，一键将新模型同步或从目录中下线/恢复（同步后自动出现在全团队成员的「设置 → 模型」中）。

### 10. 成员与权限（`teamMembers`，内部成员及以上）

- **成员邀请与外部访问**：生成有效期 **7 天**、**1 次**有效的新成员注册邀请链接，配置成员角色并管理历史邀请（撤销未使用的链接）。
- **飞书文档访问范围**（**仅管理员**）：勾选允许外部成员只读访问的飞书知识空间列表（管理员与内部成员默认拥有读写权限）。

### 11. 团队渠道与运维（`teamChannels`，内部成员及以上）

- **团队微信机器人**（**仅管理员**）：使用微信扫码登录团队公共微信机器人。
- **飞书团队群绑定**：查看已拉入 Dalton 机器人的飞书群聊及可推送状态，支持发送单群测试消息。
- **自动巡检与团队公共任务**：只读查看知识库同步、研报增量扫描、公司近况巡检等团队任务的调度周期、最近运行时间与日志尾部（仅管理员同时可见主机与运维任务；启停和调度编辑在「自动化」页操作）。
- **手动输入推送目标**（**仅管理员**）：管理员可在此补充或调整底层接收目标 ID。
