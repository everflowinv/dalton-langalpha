这页照着「设置（`/settings`）」左侧栏的顺序，带你逐栏看懂每一项配置和权限门槛。

Everflow 的设置页分**个人设置**和**团队管理**两大块：个人设置管你自己的账号和偏好，团队管理按管理员和内部成员身份显示对应栏目。券商交易和实验功能入口保持隐藏。

## 第一组：个人设置

### 1. 个人资料

这里管当前登录账号的基本信息，包括**头像**、**显示名称**、**登录邮箱**（由管理员维护）和**退出登录**按钮。

### 2. 投资画像

这里可以查看或修改你在首次引导时填过的投资偏好，比如关注市场、投研风格和常用研究维度。助手在对话里会自动参考这些偏好；修改单项可直接点**「编辑投资画像」**保存，底部的**「重置偏好」**会一并清空投资画像回答、个人模型配置（默认模型、自定义模型与服务商、收藏模型、按模型设置）及仪表盘布局。

### 3. 通用与外观

这里管界面显示和新手引导：

- **语言**：切换 `简体中文` 或 `English`（新账号默认简体中文）。
- **时区**：设定个人显示时区（网页首次登录时自动采用当前浏览器时区，未传或未识别时兜底为香港时区 `Asia/Hong_Kong`，随时可改），影响日程显示、自动化默认时区和消息时间戳。每日预算结算时区默认按北京时间 `Asia/Shanghai` 算。
- **页面引导与快速上手**：可以重新播放各页的新手引导提示，或重置引导进度。
- **卡片样式**：在 **柔和**、**均衡**、**终端** 三种数据卡片样式里挑一个，默认用**终端**样式。
- **主题模式**：切换**深色**、**浅色**或**跟随系统**。
- **字体大小**：按当前设备调界面文字的缩放比例。

### 4. 对话与助手

这里控制对话交互细节、工具行为和内部协同开关：

- **回复显示**：
  - **实时显示推理**：开 / 关；
  - **回答显示方式**：`连续显示` / `按段落`；
  - **工具调用**：`逐行`（展开每一步详情）/ `状态行`（折成一行简洁状态栏）；
  - **回复结束时**：`停留在末尾` / `显示回复开头`；
  - **语音输入**：打开或关掉输入框的语音录入按钮。
- **行为与输出格式**：
  - **输出格式**：调整助手偏好的输出形态；
  - **研究深度**与**主动联系**：设定默认分析深度，以及助手反问、主动推进的积极程度，也可以留给助手自己拿主意；
  - **子 Agent**：是否默认启用多子代理并发研究；
  - **免询问授权**：**「交给分析师前不再询问」**新账号默认开启，**「创建工作区前不再询问」**默认关闭；按需勾选即可省去每次弹窗确认；
  - **网络搜索引擎**：配置公开网络检索方式。
- **文件评论**：
  - **评论发送到**：设文件划词评论默认去哪一条对话（`文件旁的对话` / `生成它的对话` / `新对话`）；
  - **评论时**：设评论框按回车是加入待发送队列，还是立刻发送；
  - **Agent 在哪里回答**：设完整回答放在评论下面、对话里，还是跟着当前阅读位置走。
- **协作与团队记忆（按成员身份显示）**：
  - **工作区协同共享**（仅内部成员与管理员可见，默认打开）：允许内部同事的「研究总监」往你的工作区派任务或追问。
  - **共享团队历史研究记录**（仅内部成员与管理员可见，默认关闭）：打开后，你的「研究总监」跨工作区统筹时可查阅团队截至 2026-11-18 沉淀的只读历史研究归档（公司工作区如需检索，可在各工作区设置里单独打开「团队记忆」）。

### 5. 模型

这里管默认模型、思考强度、备用模型链和后台专用模型：

- **个人模型接入**：在团队共用凭据模式下，所有共享模型账号均由管理员在「团队管理 → 模型与供应商」统一维护，普通成员此处显示只读提示。
- **默认模型、后台模型与收藏的模型**：设置新对话用的**默认模型**、**后台模型**（隐藏档位菜单，优先用低思考强度运行，低档不可用时自动取最低可用档）和修改生效范围，也能把常用模型加入**「收藏的模型」**置顶。Google Antigravity 同系列模型已合并为一行，选定系列后可直接选择**思考强度**。
- **高级模型设置**（点开后可见）：
  - **路由**：设置「网页抓取模型」「上下文压缩模型」与**「备用模型」**（用于**自动任务**在主订阅不可用时按顺序切换，留空未自定义时自动走团队默认 6 档备用链；手动对话遇订阅不可用时直接弹窗提醒，详见 [模型与额度](/help/concepts/models-and-budgets/)）；
  - **高级：后台任务使用的模型**（二级折叠块）：内含**「账户默认值」**、**「按模型设置」**，以及可分别指定或留空沿用默认值的 **数据核验模型**、**文字审校模型**、**数据核验备用模型**、**单次核验超时（秒）**、**轻量后台任务模型**、**轻量后台任务备用模型**、**独立复核候选模型**和**研究记忆整理模型**。

### 6. 用量与预算

这里管每天的模型开销上限，详情见 [模型与额度](/help/concepts/models-and-budgets/)：

- 查看**「今日个人已用（现金渠道）」**（含进行中预占 / 每日总上限）与**「今日个人已用（订阅折算）」**，展开**「今日费用明细」**查看每笔 `进行中 / 已结算 / 已退还` 状态；
- 调整**「每日总上限（USD）」**（未改过时默认 **$100**）、**「单任务默认上限（USD，可选）」**与**「日切重置时区」**；
- 在**「按工作区覆盖单任务上限」**里给要跑深度长流程的特定公司工作区单独设或移除上限。

### 7. 消息与渠道

这里配个人接收推送和绑定即时通讯账号，详情见 [定时报告与投递](/help/everflow/scheduled-reports-and-delivery/)：

- **自动推送与接收账号**：包含**「自动推送总开关」**和已绑定飞书、Discord 个人接收账号的勾选项；
- **飞书与 Discord 账号绑定**：生成一次性 `/bind` 绑定码，私聊发给机器人完成绑定；
- **我的微信绑定**：点「生成个人微信绑定码」，再用微信发给团队 Dalton 机器人，用于微信私聊提问及通用会话消息。

### 8. 覆盖结构

这里维护团队的**覆盖结构管理**（行业覆盖单元、独立公司覆盖单元与工作区绑定关系，以及整理未归类工作区）。内部成员和管理员新建工作区并确认公司或行业归类后，系统会尝试登记并绑定对应覆盖单元（遇到股票代码冲突等情况时工作区照常创建并提示登记未完成，可在此页补办绑定；跳过归类时归入「未归类工作区」）；外部成员仅维护个人工作区。

## 第二组：团队管理

团队管理分组按账户身份（管理员 / 内部成员）动态展示。

### 9. 模型与供应商（仅管理员）

- **团队共享模型凭据**：统一连接、更新和断开全团队共用的模型账号和 API 密钥。
- **模型供应商与服务商状态**：看各供应商连通健康状态，以及各岗位当前用的默认模型。
- **模型目录同步**：拉取供应商最新模型列表、预览新增和建议下线的模型差异，一键同步、下线或恢复。同步完会自动出现在全团队成员的「设置 → 个人设置 → 模型」里。

### 10. 成员与权限（内部成员及以上）

- **成员邀请与外部访问**：内部成员和管理员均可生成有效期 **7 天**、**1 次**有效的新成员注册邀请链接，并随时撤销未兑换的链接（内部成员最多同时持有 20 条有效链接，管理自己创建的邀请；受邀人身份按部署名单判定，名单外邮箱注册后归为外部成员）。
- **飞书文档访问范围**（**仅管理员**）：勾选允许外部成员只读访问的飞书知识空间列表。管理员和内部成员默认拥有读写权限。

### 11. 团队渠道与运维（内部成员及以上）

- **团队微信机器人**（**仅管理员**）：用微信扫码登录团队公共微信机器人。
- **飞书团队群绑定**：查看已拉入 Dalton 机器人的飞书群聊和可推送状态，支持单群发测试消息。
- **Discord 频道**（**仅管理员**）：登记可接收自动化群报告的 Discord 服务器文字频道。
- **自动巡检与团队公共任务**：只读查看知识库同步、研报增量扫描、公司近况巡检等团队任务的调度周期、最近运行时间和日志尾部。主机和运维任务只有管理员能看；启停和调度编辑都要去「自动化」页操作。
- **管理员手动添加推送目标**（**仅管理员**）：供管理员手动补充飞书私聊或 Discord 私信接收目标（飞书团队群和 Discord 频道在对应任务推送设置中选择）。

### 12. 集成凭据（仅管理员）

- **部署级应用与事件验签凭据**：统一配置 Google OAuth 2.0（开放授权协议）客户端凭据、飞书开放平台应用凭据及事件订阅验签双键（Encrypt Key 与 Verification Token），并支持一键复制标准回调地址与执行官方接口连通性测试。
- **第 1 批现网只读保护与职责分工**：Everflow 现网飞书应用双键在第 1 批由主管理员 Vault（加密凭据保险箱）只读提供（Vault 换钥后立即重启渠道网关实时生效），下方的事件验签双键可在网页直接填写与轮换；成员个人授权连接在个人设置中独立完成。完整配置步骤见 [集成凭据配置](/help/get-started/admin-integrations/)。
