# ANT 跟踪研究与写作规则

每轮先读 `references/common-rules.md`（始终适用），再读取脚本（`state.py rules-path` 或 `collect`）输出的 `rules_path` 对应的本公司规则，不要自行判断或选择规则路径。共用的工作底稿、新闻线索、X、待核实线索、卡片章节和语言步骤在共用规则里。下面是 Anthropic（ANT）专属的来源范围、关注重点和判断标准。

导入档案是 `research/tracker/imported-ant/thesis.md`（若存在则保持原字节）。

## 每轮必读的材料

### 第 3 条（AlphaEngine）

AlphaEngine 新文档先看摘要。只挑带新数字的，最多 2 篇读全文。新数字包括年化收入（ARR）里程碑、算力合约规模与承诺、应用程序接口（API）与订阅定价、首次公开募股（IPO）定价与解禁、盈利预测、估值倍数、买方调查。返回额度、`E_DESKTOP` 或 `E_UPSTREAM_API` 时停止读全文，只用摘要，并在本轮更新里注明。

### 第 4 条（SEC 新公告）

- 重点核查 `424B4`、`8-K`、`S-1`、`S-1/A`、`10-Q`、Form `4`（内部人持股变动表）。
- 8-K 先看条目号（item），`finance(route="sec", operation="eight-k", ticker="ANT", limit=2)`；有财报或重大公告时用 `finance(route="sec", operation="attachments", ticker="ANT", form="8-K")` 列出附件并读 99.1 新闻稿。
- 招股与上市文件（`424B4`、`S-1`、`S-1/A`）重点读发行定价、募资额、股份数量、锁定期与解禁时间表、客户集中度与算力承诺。
- `10-Q` 重点核查收入增速、算力成本与云厂商合作承诺、现金消耗与流动性、管理层口径变化。
- Form `4` 重点核查高管、联合创始人及主要机构股东的持股变动与减持节奏。

### 第 7 条（专家访谈）

专家访谈和管理层交流按已确认的合规范围使用。写法注明日期和自述身份，并说明与公司披露、第三方数据、其他专家是对得上还是有冲突。财报或重要披露出来后，把专家关于年化收入、算力供给、企业采用率与定价的说法逐条核对，更新「专家来源可靠性」。

## 新闻与 X

内部研究库查询路线为 `sales-notes`（卖方邮件）、`tmtb`（买方科技简报）、`funda-ai`（独立研究），关键词围绕 `Anthropic`、`ANT`、`Claude`。

本轮两条固定网页查询，以数据包里的记录为准：

- `Anthropic ANT Claude ARR revenue compute contract pricing IPO lockup news`
- `Anthropic Dario Amodei model release competition valuation analyst news`

X 重点跟踪 Anthropic 官方账号（如 `@AnthropicAI`）及管理层账号（如 `@DarioAmodei`）原话，以及基本面专业账号。账号池里，同时覆盖多家时可以写多家股票代码，适用范围保留 `ANT` 或 `ALL`。

## 是否重要

满足任一条就是 `material=yes`。共用的多空分歧（Debate）、买方仓位、催化剂、X 和股价条款在共用规则里。Anthropic 专属的几条是：

- 一致预期与行情：数据包自动触发项里有下一财年每股收益（EPS）、收入或平均目标价阈值触发（刚上市或数据稀疏阶段若指标标注「暂无」，只作记录，按其余事实与研究证据判断）。或者主流券商首次覆盖、调整评级、目标价变动 10% 以上、调整收入/ARR 或利润率预测，且改动幅度或理由是观点池里没有的。
- 公司事实与重点关注：
  - ARR 里程碑新披露或增速拐点；
  - 算力合约与云厂商合作条款变化（AWS、Google Cloud 等算力承诺、采购规模、独占或分成条款）；
  - API 与企业订阅定价调整、成本或推理毛利率新证据；
  - IPO 定价、超额配售、锁定期与解禁安排及 Form 4 大额减持；
  - 核心模型（Claude 系列）发布、性能与商业化竞争格局变化；
  - 管理层公开原话与重要 8-K、S-1/A、424B4、10-Q 披露。
- 关键经营指标（KPI）越过工作底稿里写的阈值。

## 盈利预测怎么拆

刚上市或覆盖初期，一致预期与行情若尚缺数据，在数据包和工作底稿里如实标注「暂无」，按三层拆解已有数字与边际变化：

1. 收入层：ARR 里程碑、API 调用与企业席位商业化、定价调整。
2. 成本与算力层：训练与推理算力合约支出、云基础设施分成、毛利率趋势。
3. 股本与资本层：IPO 定价与募资、解禁节奏、股本稀释与主要股东持股变动。

一致预期有变动时写明哪一层动了及隐含费用空间的变化；尚无一致预期或未动时如实写「暂无」或「一致预期未动」。
