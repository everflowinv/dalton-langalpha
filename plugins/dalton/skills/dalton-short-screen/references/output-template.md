# 做空风险初筛输出模板

完整报告保存至工作区：`drafts/<YYYY-MM-DD>-<TICKER>-short-screen.md`。

## 评级图例

- 🔴 **红旗**：发现明确会计激进处理、关键财务人员异常离任、监管/舞弊实质风险或强有力的做空证据链。
- 🟡 **黄旗**：存在结构性隐患或值得持续跟踪的边际恶化（如资本化加速、宽泛 Non-GAAP 激励、组织动荡或单源负面指控），尚不足以单独构成做空触发点。
- 🟢 **绿灯**：未发现明显异常，或已有充分透明的合理解释。

综合判断三档措辞：`值得深入做空研究` / `部分红旗需关注` / `暂无明显红旗`。
