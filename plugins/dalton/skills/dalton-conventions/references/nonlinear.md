# 非线性检查（Nonlinear Check）

本文件支撑 `dalton-conventions/SKILL.md` §1 决策链里的**非线性检查**一步：三情景价格算完之后、推导所需胜率之前，检查这笔投资里有哪些**不随价格线性变化的机会与风险**。首次覆盖、bullbear、财报深评、季度重估每次都要做；没有可承保的非线性机会时，明确写"本轮没有可承保的非线性机会"——这句话本身就是合法结论，不算缺项。

非线性检查的结论写入报告正文，并将关联的情景驱动、倍数切换机制（若估值倍数重估机制已在当期或近期现金流中实际兑现，则标 `thesis.underwriting.rerating_observed=true` 并附 `rerating_sources` 证据来源）、空头逼空压力情景（`underwriting.stress` 及借券成本 `underwriting.borrow_cost_annual`）与三层保护（`underwriting.protection`）同步体现在 `thesis.underwriting` 与 `drivers` 中（完整字段路径与样例见 `.agents/skills/dalton-knowledge/references/structured-write-example.md`）。

## 1. 四类检查表

逐类检查，每类写清**机制、最小计算或证据、证伪点**；某一类不适用就写"不适用"加一句原因，不得静默跳过。

### ① 倍数 regime 切换（市场给这类资产的定价规则整体切换）

- **机制**：市场换了给这家公司定价的规则。必须点名是**增长持续期、资本强度 / 现金转化、资本配置、尾部折价**四类中的哪一类变了，并给出可观测领先指标，不允许只写"估值会重估"。
- **最小计算**：同一份盈利预测下的新旧两个估值区间——EPS × 旧倍数区间 vs EPS × 新倍数区间——两者的差额就是纯倍数切换的贡献（价格影响与盈利影响分开列）。
- **证伪点**：什么可观测证据出现说明切换不会发生（例如资本回报率连续几个季度不改善，切换就应该撤掉）。

### ② 业务 driver（驱动变量）的非线性传导

- **机制**：收入或成本变量对利润不是线性传导——存在阈值、经营杠杆（固定成本放大利润波动）或 S 型放量。
- **最小计算**：关键变量至少**三个点**的利润 / FCF（自由现金流）敏感度（如产能利用率 70% / 85% / 95% 各对应多少利润率），或写明明确阈值（"付费用户过 X 之后单位经济转正"）。
- **证伪点**：**同向增加本身不能区分线性和非线性**（反例：利润 = x² 在 x > 0 时随 x 同向增加，但属于凸函数）。必须检查**斜率是否随变量增大而变化、曲率（弯曲程度）多大，或跨过阈值前后如何跳变**；实际表现偏离事先假设超过合理范围，即证伪该非线性假设。

### ③ 拥挤持仓 + 催化剂

- **机制**：一边倒的持仓遇到带日期的事件时，短期价格反应由资金流决定，不由基本面决定。
- **最小证据**：三件齐——持仓证据（sales color〔卖方销售台的盘面点评〕或拥挤度读数）、事前 bogey（买方预期门槛）、事件窗口。
- **纪律**：资金流造成的价格影响和长期价值**分开写**——挤压改变的是路径和入场价，不是终值。
- **证伪点**：事件落地后价格没有按持仓方向走，说明拥挤判断错误。

### ④ 反身性（股价反过来改变公司行为）

- **机制**：股价本身改变公司的资本、人才、客户、供应商条件。链路必须完整闭合：**股价 / 融资条件 → 资本、人才、客户、供应商行为 → 现金流 → 估值**，并给出传导量级（大约影响几个百分点的收入或成本）；哪一环接不上就写"不构成反身性"。
- **证伪点**：链路在哪一环断掉（例如融资条件改善了，但公司没有相应加大投入）。

## 2. 数学边界（防止把非线性说错）

- **高经营杠杆不等于凸性（非线性放大）**：固定成本高只说明利润对收入高度敏感（线性的放大），本身不算凸性；只有当**斜率随变量增大而加大**，或存在**阈值 / 期权性质**（小注、不对称结果）时，才叫凸性。
- **滞后、跳变、凸性是三回事，监控方式不同**：滞后（传导延后）要用前后两期数据对照验证；跳变（阈值触发）要盯住阈值变量本身；凸性（非线性放大）要做多点位敏感度。三者不得互相替代、不得混写。
- **EPS 和倍数同时变化时存在交互项**：对数分解没有交叉项，但简单百分比拆分会漏掉交互项；更重要的是**同一个原因不能在 EPS 和倍数里各算一次**——例如"提升利润率"若已计入 EPS 上修，就不得再当作倍数扩张的理由。

## 3. 示范：META 2022→2024 的事前推演

示范如何**只用当时可见的信息**做非线性判断（历史事实只采用当时已核实的三处公开披露）：

- 2023-02：全年费用指引从 940–1,000 亿美元下调到 890–950 亿美元；
- 2024-02：首次派发股息，并新增 500 亿美元回购授权；
- 2024-04：当年资本开支区间从 300–370 亿美元上调到 350–400 亿美元。

| 时点 | 当时可见的信息（事前口径） | 非线性判断 | 下一项证据改变什么 |
|---|---|---|---|
| 2022-11 | 当时可见的信息：当时的股价、一致预期与"支出失控"的市场叙事（不引用此后才发生的事） | 低倍数下真正的问题不是"还能跌多少"，而是**定价规则会不会换**：若支出叙事被打破，倍数与盈利会同向修复——凸性来自倍数 regime 切换，不是来自经营杠杆 | 下一份指引：费用指引下修改变**盈利**；指引维持则两者都不变 |
| 2023-02 | 费用指引下调至 890–950 亿美元（此前 940–1,000 亿美元） | **先确认费用下调对盈利的影响**（哪个财年的费用、对应多少利润与 EPS）；倍数切换只能写成**待验证的假说**——允许结论是维持旧倍数区间，同时另写支持切换的证据与证伪点（出现什么证据就承认切换不发生） | 资本配置证据（派息 / 回购 / 资本开支走向）：改变**倍数**（定价规则）或**盈利**（资本开支上行压缩利润） |
| 2024-02 | 首次派息 + 500 亿美元回购授权 | 反身性链路闭合检查：股价 / 融资条件 → 资本配置行为 → 每股现金流 → 估值；**回购授权本身不算托底，只认实际发生的股本缩减** | 资本开支指引：若上行，改变**盈利**（FCF 被压缩），并检查"叙事改善"是否被同时算进了 EPS 和倍数（重复计算） |
| 2024-04 | 资本开支区间上调至 350–400 亿美元（此前 300–370 亿美元） | **三类影响分开写、各注明期间**：① 当期 FCF（现金支出当期就减少自由现金流）；② 未来折旧与运营费用对 EPS 的影响（折旧在资产投运后分期进入利润——**不得把现金支出直接扣进 EPS，之后又重复计入折旧**）；③ 资本回报预期对倍数的影响（回报兑现与否改变定价规则）。三条不得混算，"AI 投资叙事"不得同时在 EPS 和倍数里各支撑一次 | 后续资本回报证据：回报兑现改变**倍数**，回报失约改变**盈利** |

**示范的纪律**：

- 每个时点只写当时可见的信息；**禁止用事后实现的利润，反过来证明当时就该高确信**——事后兑现不能倒推事前胜率。
- 每一步都写清"下一项证据会改变的是盈利、倍数，还是两者"——这是非线性检查与普通情景更新的分界线。
