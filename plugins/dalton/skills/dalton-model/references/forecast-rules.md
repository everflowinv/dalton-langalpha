# 财务预测建模规则与公式纪律（`forecast-rules.md`）

本文定义财务建模的期间跨度、共用期间映射、季度加总年计算规则、分部与经营指标勾稽、无循环利息与股本滚存、未预测项留空、四类单元格角色判定顺序、合法驱动假设公式以及汇总表规格。

---

## 1. 期间跨度、共用期间映射与季度加总年规则

### 1.1 期间跨度与知识层期间转换

- **逐季预测跨度**：覆盖本财年尚未披露的剩余季度以及下一完整财年的全部四个季度（例如最新已披露季为 `3Q26` 时，逐季预测覆盖 `4Q26E` 及 `1Q27E`–`4Q27E`）。
- **年度预测跨度**：至少覆盖本财年与下两个完整财年（如 `2026E`、`2027E`、`2028E`）。当公司处于新业务减亏爬坡期、市场主流采用 3 年后远期市盈率（`P/E`〔Price-to-Earnings Ratio〕）或多年期自由现金流折现（`DCF`〔Discounted Cash Flow〕）估值、或大型资本开支（`CapEx`〔Capital Expenditures〕）周期跨度超过 3 年时，可将年度预测延伸至增速与利润率进入稳态的财年。
- **历史单向保留**：完整保留历史年度（自 `FY2018` 或招股书最早完整财年起）与历史单季（至少自 `2024Q1` 起），只向后新增期间列。
- **列头沿用与知识层转换**：存量模型滚动维护时，列头直接沿用原模型的写法（如历史 `2025`、`3Q26`、`2026Q2`，预测 `2026E`、`4Q26E`、`2026Q3E`），非 12 月底结账的公司在表头旁或 `A2` 注明财年截止月（如 `3月底结账`）。调用 `knowledge_update(doc="models", ...)` 登记 `key_outputs` 时，调用 `model_style.normalize_period_for_knowledge` 将 `2026` / `2026E` / `2026F` 转为 `FY2026`、将 `4Q26E` / `2026Q4E` 转为 `4Q26`；复合年增长率（`CAGR`）等列省略非必填的 `period` 字段。

### 1.2 共用期间映射（`PeriodMap`）

`model_style.py` 与 `style_audit.py` 共用 `build_period_map(ws)` 解析主表头与表内子区块表头行：

1. **独立财季归属**：每个财年对应的四个财季由财年截止月、表头文本和期间轴对齐关系确定，独立于待检的求和公式。例如 3 月底结账公司，财年 `2027E` 绑定 `2Q26E`–`1Q27E` 四个财季列，跨自然年的财季求和属于标准同财年对应。
2. **重复列头身份保留**：同一表头行存在重复期间标签时（如连续两列均标 `2026E`），结合子标题或出现序位生成可跨插列识别的唯一列身份（`column_id`），在基线比对与加总核对中持续使用。
3. **实际与预测统一识别**：无后缀历史列（`2025`、`3Q26`）和带 `A` 后缀列（`2025A`、`FY25A`）识别为实际列；带 `E`、`F`、`P` 后缀列识别为预测列。
4. **`CAGR` 与差值列隔离**：表头含 `CAGR`、`YoY`（同比增速）、`QoQ`（环比增速）、`vs`、`Chg`、`Δ` 的列单独归为 `cagr_or_delta`，与预测期间列严格分离。

### 1.3 季度加总年五类行公式与行属性判定顺序

当某预测财年列在同表拥有 `PeriodMap` 绑定的四个财季列时，该年度列保持零驱动假设输入。行属性按 **期间列 → 公式结构（四季求和或四格相加、`=Q4`、两格相除）→ 行标签** 的顺序判定（三者对不上时列入待核对 `warn`）。五类行分别使用以下公式：

1. **流量金额行**（收入、成本、费用、营业利润、利息、所得税、净利润、经营现金流 `OCF`〔Operating Cash Flow〕、`CapEx`、自由现金流 `FCF`〔Free Cash Flow〕、分红与回购支出）：写对应四个财季的 `=SUM(Q1:Q4)`、四格相加 `=Q1+Q2+Q3+Q4`，或由同年度列分项汇总（如 `毛利 = 本年收入 - 本年成本`、`总收入 = 分部合计`）。
2. **时点余额行**（期末现金及短期投资、期末有息债务、资产负债表各时点科目、期末客户资产规模 `AUM`〔Assets Under Management〕、期末总股数）：写引用该财年第四季度的 `=Q4`（或由同年度列子项汇总）。
3. **加权股本行**：按公司财报披露口径写四季度均值 `=AVERAGE(Q1:Q4)` 或第四季度 `=Q4`。
4. **年度每股收益行（`EPS` / `EPADS`）**：「年度净利润（可含汇率折算）÷ 年度加权股数」与「四个财季 `EPS`/`EPADS` 之和（`SUM` 或四格相加）」两种写法均合规。**一致性规则仅约束同一指标行的跨期计算方法**：同一张工作表可以同时保留「年度利润 ÷ 年度股数」和「四季 `EPS` 之和」两行分别展示。
5. **衍生比率行**（`YoY`、毛利率、费用率、营业利润率 `OPM`〔Operating Profit Margin〕、净利率、货币化率 `Take rate`、分部占比）：统一用该年度列自身的金额单元格反算（或同类比率相减算百分点变动），设为斜体且无假设底色。

**未预测留空在加总年的豁免**：已在 `mapping.md`、`README & Changelog` 或 `model_lineage.json` 登记原因的未预测留空单元格，在季度加总年检查（`summed_year_violation`）与基线回归检查中同等豁免；必预测的财务结果格继续核查公式是否存在。

## 2. 存量结构继承、分部改口径与收入成本拆解

1. **沿用存量链路**：维护已有模型时，先梳理页签计算链路（如 `Peers` → `Key Metrics` → `Subs` → `Model` → `Valuation` / 分部加总估值 `SOTP`〔Sum-of-the-Parts〕）与工作簿命名区域，保留全部历史专题对比页。集团合并主结构未变时，新增业务在 `Subs` 页或主表下方增设子模型块并链回主表；涉及重大并表剥离、变更记账本位币或变更收入准则时，先列出新旧行映射清单交用户确认。
2. **分部改口径保留与可比期间对账**：公司调整分部披露口径时，在同一区域同时保留「旧披露口径区块」（填至最后一次披露期，后续留空）与「新披露口径区块」（自公司提供重述数据的最早期间起填入并向后预测）。在下方建立对账表（`Reconciliation`）：仅在同时有可比数据或可对齐集团总数的期间写出差额检验公式 `=新口径分部合计 + 未分配总部项 + 分部间抵销 - 集团合计`；缺少重述数据的不可比期间留空，并在最右侧红字备注列写明缺失项、原因与财报出处。
3. **关键经营指标（`KPI`〔Key Performance Indicator〕）挂钩收入与成本**：将披露的用户数、每用户平均收入（`ARPU`）、商品交易总额（`GMV`）、货币化率、订单量、客单价（`ASP`）、`AUM` 放在经营区，用公式将收入与直接变动成本挂钩上述指标。对股价与盈利弹性显著的关键驱动单独拆行或建子表预测（参考值：预计贡献未来两年集团增量收入或增量营业利润绝对值约 **20%** 以上，或稳态利润率与主业相差约 **10 个百分点**以上，可按公司结构调整）。历史披露不足时参考电话会定量线索、卖方拆法或高频数据估算，套用历史估算样式并在右侧红字备注列写明方法与来源。
4. **分部优先预测与成本费用拆分**：公司披露分部收入与分部营业利润（或经调整息税及摊销前利润 `EBITA`）时，优先在分部区块预测，集团主表营业利润直接汇总分部并加回未分配总部项与抵销项，保持单一利润计算源。法定定期报告持续披露股份支付费用（`SBC`〔Share-Based Compensation〕）、折旧与摊销（`D&A`）、履约物流等明细时，拆出独立行衔接公认会计准则（`GAAP`）与非公认会计准则（`Non-GAAP`）调节项。

## 3. 无循环利息滚存、股本滚存、资产负债表与现金流量表

1. **无循环期初计息**：当净现金储备或有息债务对利润和 `EPS` 有可见影响时（参考值：利息收支占税前利润 `EBT` 或 `Non-GAAP` 净利润绝对值约 **5%** 以上，或狭义净现金/总有息债占总市值约 **10%** 以上），将利息收支与现金及短期投资、有息债务余额建立公式关联，统一采用**无循环的期初余额计息**并保持迭代计算关闭（`iterate = False`）：
   - 预测单季列：`=期初生息现金（或期初有息债）× 假设年化利率 × 0.25`
   - 纯年度预测列：`=期初余额 × 假设年化利率`
   在历史期间用同口径公式反算隐含年化收益率与借款利率，作为预测利率合理带参照；债务笔数多且集中到期时（参考值：总有息债/`EBITDA` 约 **2.0 倍**以上），可拆建逐笔债务明细表。
2. **期末股数滚存与加权稀释股数分层**：
   - 股数滚存恒等式使用期末总股数：`期末股数 = 期初股数 + 本期股权激励增发股数 − 本期回购注销股数`，且 `本期回购注销股数 = 现金流量表股份回购现金支出（折算至交易币种）÷ 假设回购均价`，使回购同时扣减现金并缩减股数。拥有充裕存量净现金的公司动用账面净现金实施超过当期自由现金流的回购属于合理资本配置，在现金滚存中如实扣减并核对期末非受限现金充足即可。
   - `EPS` / `EPADS` 分母使用加权平均稀释股数（`=AVERAGE(期初股数, 期末股数) + 增量稀释股数`），发行美国存托凭证（`ADR`〔American Depositary Receipt〕）的公司用显式换算比绑定普通股与 `ADS`（美国存托股份）数量。
   - 跨期衔接要求：年度与季度分别保持各自独立的期初衔接上期期末链条；完整资产负债表中的期末现金与现金流量表期末现金保持相等。
3. **资产负债表建模范围**：常规非金融公司至少动态滚存期末现金及短期投资余额（有息债显著时同步滚存短期与长期有息债）；新建完整三表或原表已含完整资产负债表时，完整滚存各科目使每期 `总资产 = 总负债 + 股东权益`。资产负债表驱动型公司（银行、券商、保险、信贷科技、资管、`REITs` 及重资产租赁；参考值：净利息/投资收益/保费/融资融券收入占总收入约 **20%** 以上）完整预测生息资产与计息负债并与利润表逐项挂钩。
4. **现金流量表与未预测项留空**：
   - 所有模型至少预测 `OCF`、`CapEx` 与 `FCF = OCF − CapEx`，并扣减现金分红与回购支出滚存期末现金。
   - 营运资本变动（`ΔNWC`）在近 3–5 年呈现稳定规律时（参考值：`ΔNWC / 收入` 方向一致且标准差小于约 **3%**）按比例或周转天数建立预测公式；波动剧烈时选择不单独预测并留空，在右侧备注列写明原因。
   - **未预测项留空与显式零假设**：凡属未单独预测或已停用旧分部的预测期单元格一律保持空白（`Blank`），存量模型将原有公式转为未预测留空时在 `mapping.md`、`README & Changelog` 或 `model_lineage.json` 登记工作表、行项、期间与原因。仅当有明确一手证据表明该期发生额或假设值确实为零时，在套用假设样式的输入格中填入 `0`（或 `=0`）并在最右侧来源备注列写明证据来源；缺少备注的假设格 `0`/`=0` 会触发检查报警。

## 4. 四类单元格角色判定顺序、合法假设公式与常数识别

`model_style.py` 与 `style_audit.py` 严格按固定顺序判定单元格角色：**先由行项用途与所在期间列确定角色，再核对单元格样式是否匹配该角色**。涂成蓝字黄底假设样式的硬编码金额，只要处在财务结果行与预测期间列，仍判定为结果格硬编码（`forecast_amount_hardcode`）。

| 单元格角色 | 涵盖范围（先按行项与期间确定） | 允许内容与样式要求 |
|---|---|---|
| **1. 财务结果（`financial_output`）** | 存在量价/分部拆解的收入成本行、三表主表金额行、小计与合计行、现金/债务/股数滚存行、`EPS`/`EPADS`、估值输出格、**季度加总年的全部行**及衍生比率行。 | 预测期全部使用动态公式。同表公式黑字，跨表链接绿字（合计行加粗），衍生比率斜体（可与绿字同时生效），无假设底色。 |
| **2. 驱动假设（`driver_assumption`）** | 非加总预测列中的增速、`Take rate`、毛利率、费用率、有效税率、隐含利率、`CapEx` 占比、客单价等驱动参数行，以及历史估算值（`historical_estimate`）。 | 允许填入套用假设样式的数值常数（填 `0` 须在右侧备注列写明证据），也允许使用下述四类合法驱动假设公式。 |
| **3. 外部输入（`external_input`）** | `Inputs` 区或对照表中的可核验静态值：一致预期、附注披露的未来摊销表、董事会批准的回购预算、从外部插件抽离的基准股价/汇率/同行数据。 | 蓝字静态数值输入，最右侧备注列注明出处与日期，主表通过公式引用。 |
| **4. 不适用（`not_applicable`）** | 分节标题行、主副期间表头行、空白分隔行、最右侧红字备注列、已登记留空的未预测格与已停用分部空白格。 | 保留标题、备注或留空。 |

### 四类合法驱动假设（及历史估算）公式形态

先由行项用途与非加总期间列确定为 `driver_assumption`（或历史估算位置），并套用假设/估算样式，允许引用可比的历史反算指标、同期反算指标或其他驱动格：

1. 单期基准格加减常数增量：`=P272+0.05%`、`=R138+0.3%`
2. 单期基准格乘常数因子或 `(1 ± 常数增量)`：`=P40*(1+2%)`、`=P40*1.02`
3. 直接引用可比历史指标或同列子项：`=BE157`、`=N69`
4. 引用同期可比反算指标并加减固定差：`=P9-8%`（其中 `P9 =P8/P6`）

### 结果公式内业务常数识别与五类结构性换算放行

对所有 `financial_output` 公式检查全部业务常数（包括算术乘除加减常数及 `IF` 分支返回的固定金额常数如 `=IF(E5>0, 500, 0)` 中的 `500`），仅放行以下五类结构性常数：
1. 增减率与互补率基数 `1`（`A/B - 1`、`1 - 税率`）及条件守卫中的 `0`；
2. 期间折算与年化系数（`*4`、`/4`、`*0.25`、`*12`、`/12`、`*365`、`/365`、`*360`、`/360`）与 `CAGR` 幂指数 `^(1/N)`；
3. 十进制量纲与货币单位换算（`100`、`1000`、`10000`、`1000000`、`1e8`、`1e9`）；
4. 明确标识为 `ADS`/`EPADS`/`ADR` 行中的存托股换算倍率（如 `1 ADS = 8 普通股` 中的 `*8` 或 `/8`，推荐优先引用表头换算格）；
5. `Checks` 工作表中的容差比较阈值。

扫描原模型发现预测期财务结果行遗留手工硬编码金额时，改写为与同行逻辑一致的动态公式，并在交付说明中单列「原模型硬编码修复表」（记录工作表、行项、期间、原常数值、改后公式及数值影响）。

## 5. 汇总表规则

1. 每本工作簿均配备汇总表：单公司模型设于 `Summary` 页或 `Valuation` 页顶部总览区；行业多公司模型设于 `Peers` / `Global Comps` 或首页 `README & Changelog` 总览表，并保留各公司估值页。
2. 同时展示核心指标的**年度序列**（最近 1–2 个历史财年 + 全部预测财年）与**季度序列**（最近已披露季度 + 全部预测季度）。
3. **营业总收入（及同比增速）**与**稀释每股收益 `EPS` / `EPADS`（主流定价口径及同比增速）**为必备指标，再结合行业定价主线补充 3–6 项核心经营与盈利指标。
4. 汇总表全部历史与预测单元格通过公式直接指向底层主计算页的对应行与同一期间列。
