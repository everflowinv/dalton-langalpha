# 建模指引：版面、公式与各部分怎么预测

以下示例以电商公司说明；其他行业按公司自身的 KPI（关键经营指标）和报表口径替换。

## 1. 预测期

- **季度预测：本财年和下一财年逐季。** 例如当前在 2026 财年（FY26），季度预测做到 `4Q27E`（后缀 `E` 表示预测期 Estimate）。
- **年度预测：至少到下下个财年。** 同一例子里年度做到 `2028E`；无季度拆分的远期年份直接在年度列放驱动假设。市场按更远期利润定价的公司（高增长、利润尚未释放）可以继续往后延伸。
- **季度路径要有季节性**：看这家公司历史各季度占全年的比例和披露习惯，按同比增速或历史季度结构预测；业务本身没有季节性时才平均分配。
- **财年与自然年不同**（例如 3 月底结账）：按公司财年组织季度和年度，在 `A2` 单元格注明财年截止月（例如写 `FY ends Mar`〔财年截至 3 月底〕）。对比按自然年统计的数据时另做换算，模型本身保持公司口径。
- 历史期覆盖跨度参考 `.agents/skills/dalton-conventions/references/model-standards.md`；原模型已有的历史列全部保留。

## 2. 版面样板（一张公司主模型页，例如 `Model - PDD`）

列（从左到右）：

| 列 | 内容 |
|---|---|
| A–D | 标签。A 列：分节标题；B 列：合计行、一级行；C 列：明细；D 列：细项（D 列较宽） |
| 年度列 | `2018`…`2025`（历史）、`2026E`、`2027E`、`2028E` |
| 窄空列 | |
| CAGR（复合年增长率）列（可选） | 例如 `CAGR 25-28E`；维护原模型时仅在原模型已有该列时保留 |
| 窄空列 | |
| 季度列 | `1Q24`…`2Q26`（历史）、`3Q26E`…`4Q27E` |
| 备注列 | 最右，红字写来源和说明 |

行（从上到下，按公司调整）：

1. 第 1 行：期间表头；A1 写单位，例如 `(RMB MM)`（人民币百万元）。
2. **Income statement（利润表）**（A 列浅蓝分节条）
   - 收入分项 → 收入合计（加粗）→ 收入增速（斜体）
   - 营业成本 → 毛利（加粗）→ 毛利率（斜体）
   - 销售、管理、研发费用（必要时 SBC〔股权激励费用〕单列）→ 营业利润（加粗）→ 营业利润率（斜体）
   - 利息收入、利息支出、投资收益、其他 → 税前利润 → 所得税（有效税率）→ 少数股东损益 → 归母净利润（加粗）
   - 加权平均股数（基本、稀释）→ EPS（每股收益）/ EPADS（每份美国存托股收益）
3. **Non-GAAP measures（非公认会计准则指标）**（A 列棕色分节条）：SBC 等调整项 → Non-GAAP 营业利润、净利润、EPS。
4. **Segment Reporting（分部报告）**（棕色分节条）：各分部收入、营业利润、利润率。
5. **业务拆解区**（每个子业务一个桃色分节条，例如 `Temu`、`3P`〔第三方平台业务〕、`1P`〔自营业务〕）：KPI（GMV〔商品交易总额〕、订单量、用户数、ARPU〔单用户平均收入〕）→ take rate（货币化率）→ 收入；这里的收入被上面的收入分项引用。
6. **Cash flow statement（现金流量表）**（浅蓝分节条）：净利润、折旧摊销、SBC、营运资本变动 → 经营现金流；CapEx（资本开支）→ 自由现金流；分红、回购、借还款 → 现金净变动。
7. **Balance sheet（资产负债表）**（浅蓝分节条）：至少现金和有息债务；资产负债表驱动的公司做完整资产负债表。
8. 增速、利润率、占比小节紧跟在对应金额块下面，行标签斜体，做行分组。

多公司行业模型：前面放行业页（可比公司、行业数据），每家公司前放一个空白分隔页（例如 `PDD>>`），后面跟这家公司的 `Valuation - PDD`、`Key Metrics - PDD`、`Model - PDD` 等。

## 3. 常用公式写法

下面用列字母举例（`P = 2025`、`Q = 2026E`、`R = 2027E`、`S = 2028E` 年度列；`AW–AZ = 1Q26–4Q26` 季度列；`BA–BD = 1Q27E–4Q27E` 季度列）。

| 用途 | 写法 | 说明 |
|---|---|---|
| 收入 = 量 × 价 | `=BA20*BA21` | GMV × take rate；用户数 × ARPU |
| 同比增长 | `=AW15*(1+BA16)` | 去年同季 × (1 + 增速假设)，季节性强的业务首选 |
| 环比增长 | `=AZ15*(1+BA16)` | 上季 × (1 + 环比假设)，季节性弱时用 |
| 占收入比例 | `=BA10*BA31` | 费用 = 收入 × 费用率假设 |
| 分部加总 | `=SUM(BA40:BA44)` | 合计行引用明细 |
| 年度流量 | `=SUM(BA15:BD15)` | 2027E 年度收入 |
| 年度时点余额 | `=BD80` | 年末现金 = 第四季度期末现金 |
| 年度比率 | `=R15/Q15-1`、`=R25/R10` | 用本年度列的分子和分母重算 |
| 假设沿用 | `=AW21`、`=AZ21+0.3%` | 去年同季的 take rate、上季 + 0.3 个百分点（属于驱动假设，套驱动假设格式） |
| 跨表引用 | `='Key Metrics - PDD'!BA12` | 用绿字 |
| CAGR | `=(S10/P10)^(1/3)-1` | 2025→2028E 三年复合年增长率 |

## 4. 收入（重点）

1. **找到这家公司的关键驱动。** 读卖方报告和电话会，看市场在争论什么（例如 Temu 的 GMV 增速、主站 take rate、广告变现率）。影响大的驱动单独拆出来、单独给驱动假设；披露过少、缺乏拆分依据的，按卖方估算方式做简化拆分或保持合并预测，在最右备注列说明。
2. **KPI 与收入建立公式关系。** 公司披露的 KPI（GMV、订单量、用户数、ARPU、take rate、单车收入、在管资产等）尽量与收入用公式连起来。披露不全时，参照卖方的估算方式建一个合理的拆分，在最右备注列写来源（例如 `<GS 1117`，表示高盛 11 月 17 日报告），并套历史估算格式。
3. **检查历史关系是否还适用。** 会计处理（总额法 / 净额法）、业务组合或口径变化后，历史 take rate、ARPU 不一定可比；必要时分段处理并在最右备注列说明。
4. **有分部披露时按分部预测。** 集团营业利润 = 各分部营业利润之和 + 总部费用及分部间抵销（单列一行）。分部利润口径与集团不同、对不上时，把调整项单列，写明对不上的部分。
5. **分部口径变更**：在同一分部区上下保留旧口径块（填至最后披露期，后续留空）和新口径块（自最早重述期起填并向后预测）；在双方均有可比数据的期间增设口径对账（reconcile）行核对与集团合计的差额，不可比期间留空并在最右备注列写明原因。

## 5. 成本和费用

- 能拆则拆：营业成本可拆成履约 / 支付处理 / 带宽与服务器；费用拆成销售、管理、研发，SBC 单列；折旧与人工及其他分开。有原模型就沿用原模型的拆法。
- 缺乏持续披露依据的科目合并为一行，按占收入比例预测。
- 集团营业利润由分部加总得出时，集团层面的细分费用行只回填历史实际值，预测期留空（或由分部费用汇总）。

## 6. 营业利润到 EPS

- 依次：营业利润 → 利息收入 / 支出 → 投资收益和其他 → 税前利润 → 所得税 → 少数股东损益 → 归母净利润 → ÷ 加权平均稀释股数 → EPS。
- **所得税**：有效税率是驱动假设，参考历史和公司指引；现金税和会计税差别大时再拆。
- **投资收益、联营收益、少数股东**：有披露就单独一行并参考历史预测；未披露时沿用原模型，或留空并在最右备注列注明。
- **SBC**：利润表 SBC 费用与现金流量表 SBC 加回直接引用同一金额；股本滚存中的股权激励新增股数按同一套授予假设或历史稀释率配套测算。
- 营业利润趋势和 EPS 趋势不一致时（税率变化、大额投资收益、少数股东、一次性项目），把起主要作用的项目拆出来，区分经常性和一次性。
- 发行 ADS（美国存托股）的公司同时算 EPADS（`= EPS × 每份 ADS 对应普通股数`），与公司披露口径一致。

## 7. 净现金公司示例：现金、利息、回购、股本怎么联动

以一家有大量净现金、持续回购的公司为例（每个季度一列）：

1. **现金滚存**：`期末现金 = 期初现金 + 经营现金流 − CapEx − 分红 − 回购 + 借款净额 + 其他`。期初现金 = 上季期末现金。
2. **利息收入**：`= 期初生息资产 × 年化收益率 / 4`（用期初余额避免循环引用）。生息资产沿用原模型和公司披露：通常是现金及现金等价物加短期投资（定期存款、理财），受限资金一般不计息。收益率：用历史「利息收入 ÷ 平均生息资产」反算作参考，结合利率环境和资产配置变化设定驱动假设；预测期的收益率假设明显偏离历史隐含水平时，在最右备注列说明。
3. **回购**：金额按公司股东回报计划和历史节奏假设（例如每季 X 亿美元）；从现金流量表里扣除。
4. **股本**：`期末股数 = 期初股数 − 回购金额 ÷ 回购均价 + 股权激励新增股数`。回购均价可用当前股价或假设价格；股权激励新增参考历史年化增长（例如每年 1–2%）。
5. **EPS 用加权平均稀释股数**：季度可近似为（期初 + 期末）÷ 2 加上期权等稀释效应；与公司披露的稀释股数核对一次。
6. 金额不大的公司（现金少、无回购）可以简化：利息按固定金额或简单比例，股数按年化增长。

## 8. 资产负债表

- 至少：期末现金（来自现金流量表滚存）；债务影响大的同时预测有息债务（到期、利率、再融资假设，复杂的可以逐笔列）。
- 资产负债表驱动的业务（银行、券商、保险、融资租赁、金融科技）：预测完整资产负债表，并按 10-Q 等披露理清与收入成本的关系，例如 `利息收入 = 平均生息资产 × 收益率`、`佣金收入 = 客户资产 × 换手率 × 费率`。
- 做了完整资产负债表时核对：资产 = 负债 + 权益；资产负债表现金 = 现金流量表期末现金；下一期期初 = 上一期期末。

## 9. 现金流量表

- **至少预测到自由现金流**。各家算法不同（经营现金流 − CapEx，是否再扣 SBC、租赁），在表上写明本模型的口径，便于和卖方对照。
- **营运资本**：有规律时按周转天数或占收入比例预测（季节性强的业务参考同季历史）；波动大、找不到规律时，可以用合理区间的中值，或者只预测营运资本变动前的经营现金流（营运资本变动行预测期留空，并在经营现金流行标签或最右备注列写明「未含营运资本变动」）。
- **折旧**：CapEx 重要时，折旧 = 资产基数 × 折旧率或按 CapEx 滞后；不重要时按占收入比例。**摊销**：有重大并购时单独预测。
- **CapEx**：重资产业务按产能、门店、数据中心等拆；轻资产按占收入比例；有管理层指引时用指引金额作为输入。
- **分红和回购**：结合历史和最新股东回报计划；回购重大时勾稽到股本（见第 7 节）。
- 银行、券商等：现金流量表意义有限，重点看资本充足、流动性和可分配利润。

## 10. 多币种

- 外币业务的收入、成本按原模型的汇率假设或命名区域换算；报表币种和汇率假设写在假设旁边，汇率变化时只改一处。

## 11. 汇总表

- 放一张汇总表（例如 `Summary`，已有 `Key Metrics` 就沿用），列出年度和季度的收入、EPS，以及你判断重要的项目（分部收入、利润率、GMV、用户数、自由现金流等，参考卖方最关注的 KPI）。
- 汇总表的历史与预测单元格全部用公式引用主计算页的对应结果单元格。

## 12. 判断依据（遇到这些问题时怎么想）

- **什么是关键驱动？** 对估值和股价影响最大、市场分歧最大的那几个变量。读最近两三篇卖方报告的核心论点和电话会问答，被反复讨论的就是。
- **拆多细？** 拆到能解释主要的增长和利润变化、能回答市场在争论的问题为止；缺少披露支撑且影响微小的细项保持合并。
- **利息、债务是否值得建勾稽？** 利息或债务对净利润的影响达到能改变 EPS 判断的程度（例如净现金利息贡献利润的可观比例、或有大额到期债务）就建；其余情况用简单假设。
- **营运资本有没有规律？** 看过去 8–12 个季度的周转天数或占收入比例是否稳定或有清晰趋势；季节性看同季。
- **原模型的做法和这份指南不同？** 沿用原模型；若与四条核心要求冲突则按四条要求修正，并在变更记录说明。
- **数据缺失与零值**：能合理估算的填入估算值（套历史估算格式，最右备注列写依据）；无法估算的留空并在最右备注列写原因；仅在确认实际发生或预测为零时填 `0`。
