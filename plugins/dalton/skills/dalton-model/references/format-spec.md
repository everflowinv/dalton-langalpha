# 财务模型格式规范与存量样式画像（`format-spec.md`）

本文规定从零新建模型时的默认样式常量、存量模型样式画像提取规则、主题色还原方法与数字格式沿用边界。所有常量统一实现在 `.agents/skills/dalton-model/scripts/model_style.py`。

---

## 1. 默认样式常量表（新建模型与无参照新增元素使用）

### 标准数字格式常量

- 整数金额主力格式：`FMT_INT = "_(#,##0_);\\(#,##0\\);_(?\\-?_);@"`（负数加括号，零显示为 `-`）
- 1 位小数金额：`FMT_DEC1 = "_(#,##0.0_);\\(#,##0.0\\);_(?\\-?_);@"`
- 2 位小数（每股收益 `EPS`〔Earnings Per Share〕、`EPADS`、股价）：`FMT_DEC2 = "_(#,##0.00_);\\(#,##0.00\\);_(?\\-?_);@"`
- 百分比与精细货币化率：`FMT_PCT = "0.0%"`、`FMT_PCT2 = "0.00%"`
- 百分点（`pp`，percentage points）变动：`FMT_PP = '#,##0.0" pp"'`
- 估值倍数：`FMT_MULT = '#,##0.0" x"'`（存量模型兼容 `#,##0.0\x`）
- 月度跟踪日期：`FMT_YM = 'yy"年"m"月"'`

### 默认版面、列宽、大纲分组与冻结窗格

- **列排布与列宽区间**：`A–C` 窄缩进层级列（宽 `1.7–2.3`，默认 `2.0`）+ `D` 主行标签列（宽 `22–37`，默认 `28.0`）→ 左侧年度列 → 窄空隔列（宽 `0.7–1.8`，默认 `1.2`）→ 复合年增长率（`CAGR`〔Compound Annual Growth Rate〕）列 → 窄空隔列 → 右侧季度列 → 最右侧红字来源说明列；期间列宽设为 `7.2–9.2`（默认 `8.5`）。
- **网格线与大纲分组**：全表关闭网格线（`showGridLines = False`）。新建模型中，距今超过 3 年的早年年度列与超过 8 个季度的早年季度列设为列大纲分组并折叠隐藏（`outlineLevel = 1, hidden = True`）；`YoY`（同比增速）与利润率小节设置行大纲分组（`outlineLevel = 1`）。维护存量模型时沿用原表已有的行分组与列分组结构。
- **冻结窗格**：新建模型默认冻结第 2–3 行与最近几个季度列附近（如 `AZ3`）；存量模型保留各页原有的冻结行号，仅随新增季度列向右平移冻结列。
- **多公司工作簿页签组织**：行业总览页（`Global Comps`、`TAM`、`Monthly Tracking`、`Peers`）在前，之后每家公司可设一张分隔页 `{TICKER}>>`，同公司下属页签使用统一页签颜色（`tabColor`）。

## 2. 存量模型样式画像提取规则（`model_style.py profile`）

维护存量模型前，运行以下命令提取原模型契约：

```bash
python .agents/skills/dalton-model/scripts/model_style.py profile <原模型.xlsx> \
  --out research/<YYYY-MM-DD>-model-<动作>/style_profile.json
```

画像提取脚本按以下五条规则处理原工作簿：

1. **按实际内容识别工作表类型**：
   - 仅当可见工作表既无公式又无业务数值且非空单元格极少时，识别为空白分隔页（`blank_divider`）并在审计中跳过；
   - 名称以 `>>` 结尾但承载真实公式或估值测算的工作表（例如含多情景目标价公式且使用 11pt 字号的页签），识别为有效计算页（`calculation_sheet`）并建立单页独立样式画像；
   - 隐藏页（`hidden` 与 `veryHidden`）记录其可见状态及是否被可见页活动公式引用。
2. **主题色与色调精确还原**：读取工作簿压缩包内 `xl/theme/theme1.xml` 的 `<a:clrScheme>` 12 个主题色槽，结合单元格 `tint`（色调深浅浮点值）通过 HLS（色相-亮度-饱和度）变换换算为 6 位十六进制 `RGB`，避免仅按主题编号误判浅灰估算底色与深色标题底色。
3. **全工作簿完整采样**：遍历全部可见计算页的全部数据行，并调用共用函数 `build_period_map` 识别主表与表内子区块的表头行，完整覆盖位于数百行之后的分部与子模型块。
4. **先定角色再统计样式**：主表头与子区块期间表头行（如浅蓝底年份子表头）归入表头类，与估算底色分开；跨表链接按公式词元中指向其他工作表的 `RANGE` 操作数判定，跨表绿字与衍生比率斜体作为正交维度分别统计。
5. **两层配置与原表优先合并**：输出全局 `workbook_defaults` 与按页记录的 `sheet_overrides`（包含单页主字号、已观测字体与填充色、公式数字格式集合、是否存在 `General` 公式格式先例、冻结窗格坐标与大纲分组信息）。某角色样本达到 5 个且众数占比达到 60% 时锁定原表实测样式，同时保留单页合法变体（如 11pt 估值页与深红目标价单格）。

## 3. 存量数字格式沿用边界与外来模板防范

- **存量结果格沿用原区块数字格式**：在传入 `--baseline` 或 `--profile` 审核存量模型时，若原表某页或区块的计算公式已采用 `General` 格式（例如原有目标价测算页），该区块既有结果格允许沿用 `General`；仅对从零新建的模型，以及存量模型中缺少原区块 `General` 先例的新增结果格，强制执行严格数字格式检查（要求显式设置金额、百分比或倍数格式，且与同行历史期间格式一致）。
- **禁止混入外来模板样式**：新增与修改区域沿用原模型 `style_profile.json`（新建模型沿用第 1 节默认表）的配色与字号，保持与原书一致，避免引入 `1F4E79`、`D9E1F2`、`F2F2F2`、`BDD7EE` 等外来模板底色。
- **审计基准防自污染**：存量维护时，样式画像固定提取自修改前的基准原件，确保当次误写入的异常配色或字号能够被准确检出。
