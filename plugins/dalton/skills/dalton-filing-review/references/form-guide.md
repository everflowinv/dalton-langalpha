# SEC 各类公告审阅指南（Form Review Guide）

本文档定义 `dalton-filing-review` 在审阅不同类型 SEC 公告时的必查要点、取数工具与红旗信号。

---

## 一、10-Q / 10-K（及外国私人发行人 20-F）

季报与年报是最权威的一手财务披露（来源层级 Tier 1），审阅必须覆盖以下七项：

1. **核心财务与驱动指标更新（XBRL 事实提取）**：
   - 调用 `dalton_sec.get_company_facts(ticker=..., concepts=..., periods=..., forms=["10-Q", "10-K"])` 提取最新期数据；
   - **期间纪律**：单季指标只配约 90 天的 3 个月口径（`3M`）；Q4 单季由全年减前九个月（`FY - 9M`）推导并标 `derived_filing_actual`；
   - 核对与此前 8-K 业绩快报（EX-99.1）是否存在修正或重分类；
   - 将最新读数更新至知识层 `drivers`。
2. **MD&A（Item 2 in 10-Q / Item 7 in 10-K）措辞与归因变化**：
   - 与上一期 MD&A 对比：管理层对收入增速拆解（量 vs 价/ARPU vs 汇率）、毛利率与经营费用率变动原因的排序是否变化；
   - 流动性与资本资源（Liquidity and Capital Resources）：未来 12 个月 Capex 承诺、租赁承诺（尚未起租的 data center / 设施承诺金额）、自由现金流用途表述。
3. **风险因素（Item 1A Risk Factors）逐条 Diff（硬性要求）**：
   - 读取本期与上一期 10-Q/10-K 的 Item 1A；
   - 重点识别：**全新增加的风险段落**、**从假设性条件句（“if / may”）改为已发生陈述句（“we have experienced”）的措辞升级**、以及删减的条目；
   - 若确实无变化，明确写“风险因素无变化”；**若本轮未取到上一期 Item 1A 全文，必须写“本轮未取得上一期全文”，严禁写“无变化”**。
4. **分部报告与收入拆解附注（Segment Reporting & Disaggregated Revenue）**：
   - 检查各业务分部（如 Family of Apps vs Reality Labs、AWS vs North America/International）的收入、经营利润、资产及 Capex 拆分；
   - 检查是否存在分部重划分或费用分摊口径变更。
5. **重要会计政策与估计变更（Critical Accounting Estimates）**：
   - 服务器与网络设备折旧年限调整（对科技巨头 EPS 影响极大）、商誉减值测试假设、收入确认政策变更。
6. **承诺与或有事项附注（Commitments and Contingencies）**：
   - 反垄断调查、隐私诉讼、税务争议的最新进展；
   - 是否首次披露“合理可能损失区间（reasonably possible loss range）”或上调计提金额（accrual）。
7. **未完结合同义务（RPO / 递延收入）与股本回购**：
   - 剩余履约义务（Remaining Performance Obligations, RPO）总额及未来 12 个月内确认比例；
   - 季度内股票回购股数、均价、总额，期末剩余授权额度，以及封面页披露的**截至报告印发日前最新普通股股数**。

## 二、8-K（及外国私人发行人 6-K）

按触发的具体 Item 号逐项审阅：

| Item 号 | 事项名称 | 必查要点 |
|---|---|---|
| **Item 1.01** | 签署重大最终协议 | 交易对手、商业条款、总金额、期限、排他性或最低采购承诺、生效与先决条件 |
| **Item 1.02** | 终止重大最终协议 | 终止原因、违约金/分手费金额、对当期及未来收入/成本的直接影响 |
| **Item 2.01** | 完成资产收购或处置 | 最终对价（现金 vs 股票）、并表时间点、注入或剥离业务的收入与利润体量 |
| **Item 2.02** | 经营业绩与财务状况 | 若当日已跑 `/dalton-earnings-flash`，只核对 EX-99.1 数字与快讯是否一致；未跑则调用快讯流程 |
| **Item 2.03** | 新增直接财务义务或表外安排 | 债务工具类型、本金、利率、到期日、财务契约（covenants）限制 |
| **Item 2.05 / 2.06** | 退出/处置成本（重组）与重大减值 | 重组裁员规模、总费用区间、**现金支出 vs 非现金减值拆分**、预计年化成本节约及完成时间表 |
| **Item 3.02** | 未注册股权出售 | 发行对象、折价率、摊薄股数 |
| **Item 4.01** | 变更审计师 | 辞任还是解聘、过去两年是否存在会计分歧（disagreements）或保留意见 |
| **Item 4.02** | **历史财报不可依赖（Non-Reliance）** | **最高级别警报**：涉及哪些期间、哪项会计科目、预计重述幅度，立即评估是否触发 `THESIS_BROKEN` |
| **Item 5.02** | 董事或核心高管变动 | 谁离职/履新、是否立即生效、离职原因表述（是否有分歧）、继任安排及新签薪酬包 |
| **Item 7.01 / 8.01** | Reg FD 披露 / 其他重大事项 | 投资者日演示文稿关键新指引、股票回购新授权、重大诉讼裁决或监管和解 |

## 三、融资类公告（S-1 / S-3 / S-3ASR / 424B2 / 424B5）

1. **区分架上注册（Shelf Registration）与实际发行定价（Prospectus Supplement）**：
   - `S-3 / S-3ASR`：建立储架额度，检查总额度上限与登记证券类型；
   - `424B2 / 424B5`：实际发行定价补充招股书，必须提取精确数字。
2. **核心条款提取**：
   - **债券发行**：各档期限（tranches）、发行本金、票面利率（coupon）、发行折价、实际到期收益率、付息日、赎回条款；
   - **可转债（Convertible Notes）**：票息、初始转股价与转股溢价率、是否有 Capped Call 防稀释结构及上限价格；
   - **股权增发（Follow-on / ATM / 二次发售）**：是公司发行新股（Primary，产生摊薄但进现金）还是老股东减持（Secondary，无摊薄、资金不进公司）。
3. **资金用途（Use of Proceeds）与净现金重算**：
   - 核查募集资金是用于滚动到期债务、补充数据中心/AI Capex、并购还是回购；
   - 按 `.agents/skills/dalton-financial-lenses/SKILL.md` 的双口径公式，计算本次发债/融资本金与募集现金入账后的 **Pro-forma 基础净现金与严格净现金**。

## 四、DEF 14A（年度股东大会委托书 / Proxy Statement）

1. **高管薪酬考核指标（CD&A）**：
   - 短期年度奖金（STI）与长期股权激励（LTI / PSU）绑定的具体财务指标（如营业利润、FCF、ROIC、相对 TSR）及权重较上一年的变化（管理层考核什么，就会优先交付什么）。
2. **股权激励（SBC）与股东稀释**：
   - 股权激励计划剩余可用股数、申请新增授权股数、年化 Burn Rate 与 Overhang。
3. **公司治理与股东提案**：
   - 董事会独立性、双层股权投票权比例变化、重要股东提案及董事会反对/支持意见。

## 五、SC 13D / 13G 与 Form 4（大股东与内部人交易）

1. **SC 13D / 13D/A（主动大股东，持股 >5%）**：
   - 申报机构身份（是否知名激进投资基金 Activist）、持股比例与成本区间、Item 4（交易目的：是否要求董事会席位、分拆业务、加大回购或出售公司）。
2. **SC 13G / 13G/A（被动大股东）**：
   - 重要长期机构股东跨越 5% / 10% 门槛或清仓式减持。
3. **Form 4（内部人交易）**：
   - **交易代码**：重点看公开市场买入（Code `P`）与公开市场卖出（Code `S`），区分期权行权（`M`）或税款代扣（`F`）；
   - **是否 `10b5-1` 计划**：检查脚注是否注明交易按预先设立的 Rule 10b5-1 交易计划执行（以及该计划的设立日期）；**非 10b5-1 的高管主动公开市场买入（Code P）或大额非计划抛售信号最强**。
