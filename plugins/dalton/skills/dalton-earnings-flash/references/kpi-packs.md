# 行业核心经营 KPI 清单（`kpi-packs.md`）

本文件供 `dalton-earnings-flash`（Step 6）与 `dalton-earnings-deep`（第二节、第三节）按行业选取 **3–6 个关键经营 KPI**。

---

## 一、选表总则与可比性断点

1. **公司自身披露口径优先**：优先选用公司管理层在财报新闻稿、补充财务表（Financial Supplement）和指引中反复强调、以及卖方重点跟踪的 3–6 个经营指标，不机械照搬通用清单。
2. **必须包含三期对比**：每个入选 KPI 尽可能列出：**当季实际值、当季同比（YoY）、当季环比（QoQ）、上一季同比增速（Prior-Quarter YoY）**。
3. **显式标注可比性断点（Comparability Break）**：
   - 若公司在本季更改了 KPI 统计口径（如付费用户定义、ARR 口径、将某业务并入/移出某分部、并购并表或剥离出表、会计准则变更），必须在指标旁显式标注 `[口径变更/不可直接同比]` 并说明调整内容，严禁将不同口径的历史数据直接拼成连续增速。

## 二、分行业核心 KPI 清单（3–6 项）

### 1. 软件与 SaaS（Software / Cloud / SaaS）
- **ARR（Annual Recurring Revenue）** 与 **Net New ARR**（净新增 ARR）
- **NRR / NDR（Net Revenue Retention / 净金额留存率）** 与 Gross Retention（毛留存率）
- **cRPO（Current Remaining Performance Obligations，未来 12 个月履约义务）** 与总 **RPO**
- **Bookings / Calculated Billings（计算账单收入）**
- **大客户数与净增（Customers >$100k / >$1M ARR & Net Adds）**
- **Non-GAAP Operating Margin & FCF Margin（自由现金流利润率 / Rule of 40）**

### 2. 互联网、平台与广告/电商（Internet / Marketplaces / Ads / E-commerce）
- **GMV / GTV（商品交易总额 / 总交易额）** 与 **Take Rate（变现率 / 抽佣率）**
- **Orders / Transactions（订单量 / 交易笔数）** 与 **AOV（客单价）**
- **MAU / DAU / 活跃买家数（Active Buyers / Users）** 与用户时长/互动度（Engagement）
- **广告展示量（Ad Impressions）** 与 **单次广告均价（Average Price per Ad / CPM / CPC）**
- **云业务分部收入增速与营业利润率**（如 AWS、Azure、Google Cloud）
- **Capex（资本开支，特别是 AI 基础设施投入）** 与 **FCF（自由现金流）**

### 3. 半导体与硬件（Semiconductors / Hardware / Networking）
- **核心分部收入与占比**（如 Data Center vs Gaming/Client/Auto、Compute vs Networking、Custom ASIC vs Merchant）
- **出货量（Units / Shipments / Wafer Shipments）** 与 **ASP（平均售价）**
- **GAAP 与 Non-GAAP 毛利率（Gross Margin）**（受产品结构、先进制程爬坡 NPI、HBM/CoWoS 成本影响）
- **在手订单与出货比（Backlog / RPO / Book-to-Bill Ratio）**
- **产能与稼动率（Capacity / Utilization Rate / CoWoS 或先进节点占比）**
- **存货周转天数（Inventory Days / DOI）** 与渠道库存周数（Channel Inventory Weeks）

### 4. 消费与零售/餐饮/酒旅（Consumer / Retail / Restaurants / Travel）
- **同店销售额增速（Comparable Store Sales / Same-Store Sales Growth, SSSG）**
- **客流量/交易单数（Traffic / Transactions）** vs **客单价/件单价（Ticket / AOV / AUR）**
- **门店总数与净开店数（Store Count & Net New Stores）** 或 **间夜量（Room Nights）与 RevPAR（每间可售房收入，拆分为 ADR 房价 + Occupancy 入住率）**
- **活跃会员数 / 复购率（Active Loyalty Members / Repeat Rate）**
- **存货同比增速 vs 营收同比增速**（排查去库存或渠道压货风险）

### 5. 银行、支付与金融科技/资本市场（Banks / Cards / Fintech / Exchanges）
- **净息差（NIM, Net Interest Margin）** 与 **净利息收入（NII）**
- **贷款总额（Loans）与存款总额（Deposits）增速及成本**
- **总支付额 / 交易量（TPV / Purchase Volume / GMV / ADV 日均成交量）** 与 **Take Rate / 费率**
- **信贷质量指标**：逾期率（Delinquency Rate 30+/90+ dpd）、净核销率（NCO, Net Charge-Off Ratio）、拨备覆盖率（Reserve Ratio / Allowance to Loans）
- **资本充足率与股东回报**：CET1 Ratio、ROTCE（有形普通股股本回报率）、当季回购与分红金额

### 6. 工业、基建与公用事业/工程（Industrials / Infrastructure / Services）
- **内生收入增速（Organic Revenue Growth）**：拆分为 **量（Volume）** vs **价（Price / Mix）**
- **新签订单（New Orders / Bookings）** 与 **在手订单（Backlog）** 及 **Book-to-Bill**
- **分部营业利润率（Segment Operating Margin）** 与价格/成本差（Price/Cost Spread）
- **自由现金流转换率（FCF Conversion = FCF / Net Income）** 与营运资金周转

### 7. 医疗医药与器械（Healthcare / Biotech / MedTech）
- **核心商业化单品销售额**，拆分为 **处方量/手术量（Volume / Scripts / Procedures）** vs **净价（Net Price / Rebates）**
- **新患入组数 / 装机量（New Patient Starts / Installed Base）**
- **研发管线关键里程碑（Clinical Trial Readouts / FDA PDUFA 日期 / 适应症获批）**
- **现金跑道（Cash Runway）** 或商业化毛利率
