# 每晚 Thesis 增量重要性判定标准（Materiality Criteria）

本文档定义 `dalton-thesis-delta` 在每晚增量包（`packet.md`）采集完成后，如何区分“值得更新知识层并推送 PM 的重要变化（`material=yes`）”与“仅静默记账的常规噪音（`material=no`）”。

---

## 一、自动提示阈值（`auto_flags`）说明

`collect.py` 会读取工作区覆盖阈值 `research/tracker/thresholds.json`（若无则使用 `.agents/skills/dalton-thesis-delta/config/default-thresholds.json`）生成自动提示 `auto_flags`：

| 阈值键名 | 默认值 | 含义 |
|---|---|---|
| `eps_fy1_vs_last_pct` | `1.0` | 下一财年（`+1y`）或本财年（`0y`）一致预期 EPS 均值较上次运行变化 ≥ 1.0% |
| `eps_fy1_vs_7d_pct` | `2.0` | 下一财年（`+1y`）一致预期 EPS 均值较 7 天前变化 ≥ 2.0% |
| `rev_fy1_or_q1_vs_last_pct` | `0.7` | 下一财年（`+1y`）或下一季度（`+1q`）一致预期收入均值较上次运行变化 ≥ 0.7% |
| `target_price_vs_last_pct` | `2.0` | 卖方一致预期目标价均值较上次运行变化 ≥ 2.0% |
| `down_revisions_7d_min` | `5` | 过去 7 天内下一财年 EPS 下调分析师家数 ≥ 5 家 |
| `price_1d_pct` | `4.0` | 单日股价涨跌幅绝对值 ≥ 4.0% |
| `price_5d_pct` | `8.0` | 5 日股价涨跌幅绝对值 ≥ 8.0% |
| `any_new_sec_filing` | `true` | 窗口内出现任何未见过的 SEC filing |

> **注意**：`auto_flags` 只是机器筛出的定量线索，最终是否构成 `material=yes` 必须由分析师结合下列十条实质标准判断。

---

## 二、重要变化判定标准（命中任一条即 `material=yes`）

1. **一致预期实质修正**：
   - `auto_flags` 命中下一财年 EPS、下一财年/下一季收入或目标价均值变化阈值，且经核查并非单纯由于个别分析师加入/退出样本或一次性项目口径混淆所致。
2. **主流卖方动作或新预测**：
   - 主流覆盖券商（如 GS、MS、JPM、BofA、Citi、UBS、Barclays、Jefferies、Evercore、Bernstein 等）调整评级、目标价变动幅度 ≥ 10%，或调整下一财年 EPS / 经营费用 / Capex 核心预测，且其调整依据不在现有知识层的已知观点池中。
3. **公司一手事实变化**：
   - 发布财报、业绩预告或新指引；
   - 披露实质性 8-K / 6-K、股权或债券融资（S-3ASR、424B2/B5）、重大并购或重组；
   - 管理层在公开会议或访谈中对核心驱动变量（增长、利润率、Capex、新产品商业化）做出新表态；
   - 金额重大或改变业务时间表的法律诉讼、反垄断与监管进展。
4. **核心 Debate 倾向或置信度变化**：
   - 本轮新证据（含内部库专家访谈、渠道调研或同业财报交叉印证）使 `debate.md` 中某条争论的倾向（`my_view`）或置信度需要调整，或浮现知识层尚未记录的新核心分歧。
5. **KPI 越过 Thesis 阈值**：
   - 任何跟踪指标的最新读数越过 `data/thesis.json`（`thesis.md`）中设定的确认（confirm）、警告（warn）或证伪（falsify）阈值。
6. **买方预期（Bogey / Whisper）或仓位明显变化**：
   - 来自 `sales-notes` 或 `tmtb` 的证据表明买方一致门槛（bogey/whisper）、多空拥挤度或对冲基金持仓方向发生显著迁移。
7. **催化剂变更**：
   - 关键催化剂（产品发布、监管裁决、投资者日、财报日）新增、改期或取消。
8. **社交媒体（X）交叉印证的新论据**：
   - 至少两个互不相关的专业基本面账号提出已有观点池之外的同一个新论据/拆解；或专业帖披露的新数据点已被第二个独立来源核实。
9. **股价异动且有明确归因**：
   - 股价触发单日（≥4%）或 5 日（≥8%）阈值并找到背后的基本面或资金面原因。（若当天价格触发自动任务已运行过 `/dalton-stock-move` 并写入 `verdicts.md`，直接引用其结论，不重复归因；若纯属板块 beta 且无个股原因，按不重要处理。）
10. **财报 8-K（Item 2.02）首次出现**：
    - 财报发布当晚的 Item 2.02 总是判定为重要（若 `/dalton-earnings-flash` 已生成快讯，引用快讯结论并重点汇总盘后卖方预测修正与电话会增量）。

## 三、不属于重要变化的情形（判定为 `material=no`，不推送）

以下情形一律判为 `material=no`，只调用 `knowledge_append_verdict` 记录 `NO_CHANGE`（`progress="none"`）并执行 `commit --material no`：

1. **重复信息**：卖方日报、媒体或 TMTB 只是复述知识层已有观点或上一轮已记录的事件，无新数字、无新逻辑。
2. **孤立或低质社媒帖**：单条无第二来源验证的 X 帖、新闻搬运号转发、纯技术面看图或散户情绪帖。
3. **泛泛而谈的常规前瞻**：财报前没有新渠道数据、没有改动预测数字的例行预览评论。
4. **非主流机构微调**：单家小型券商对目标价或 EPS 做微幅调整（如 <5%），且无增量调研或新模型拆解。
5. **周末/节假日数据静止**：一致预期快照 `fetched_at` 未更新或仅有尾差，且无新文档与公告。
