# 支线 C：一手文件精读与三年指引可信度（`branch-c-primary.md`）

本支线输出 `research/<D>-fc/ec.md`，引用前缀为 `[C-1]`…`[C-n]`。重点服务 **Q1、Q2、Q3、Q4、Q5、Q9、Q10、Q12**（具体以 `research/<D>-fc/questions.md` 分工为准）。动手前必读 `references/branch-common.md` 与 `research/<D>-fc/facts.md`。

> **核心定位**：本支线的价值在于精读公司自己写下的法律文本与说过的原话，捕捉**措辞漂移、会计政策变化、风险因素异动与过去三年（12 个季度）管理层指引兑现记录**，而不是简单复述利润表数字（财务数字一律引用 `facts.md`）。

## 产出章节结构（C1–C7，按顺序撰写）

### C1. 最近 4 份定期报告精读与跨期 Diff（10-K/20-F 与 10-Q/6-K）
使用 `dalton_sec.list_filings`、`researchdata.finance(route="sec")`（`read-item`、`search-text`、`attachments`）及自带 `get_sec_filing` 逐期比对最近 4 份定期报告：
1. **MD&A 措辞漂移**：管理层对收入增长驱动、利润率变化、资本开支回报的解释口径在过去 4 个季度是否发生微妙变化（例如从强调“新增客户数”转向强调“存量大客户 ARPU”，或停止披露某个曾经高调宣传的运营指标）。
2. **Risk Factors（风险因素）逐条 Diff**：对比最新定期报告与上一期的 Risk Factors，**重点标出新增条目、删除条目、排序大幅前移或措辞从“可能（may）”升级为“已经（have experienced）”的条目**——这是最具前瞻信息量的法律披露。
3. **分部披露与口径变更**：分部划分、分部利润定义或成本分摊规则是否发生重述或合并，解释背后的经营意图。
4. **收入确认与关联交易附注**：核对递延收入/RPO 变化、大客户集中度、关联方交易、表外承诺与或有负债（Commitments & Contingencies）。
5. **Non-GAAP 调节表质量（“经常性的非经常性项目”）**：逐项检查公司在 Non-GAAP 中加回的项目（SBC、重组遣散费、诉讼和解、无形资产摊销、并购相关费用）是否年年出现、金额占比是否持续扩大。

### C2. 最近 4 次业绩电话会精读（Prepared Remarks & Q&A）
- **电话会信源回退链（严格遵守）**：
  1. 首选调用 `researchdata.research(route="transcript", ticker=T, limit=4)` 获取 `kind="company_call"` 的公司业绩会原文（忽略 `broker_callback` 券商回访）；
  2. 若无匹配，检索公司 IR 官网的 webcast transcript（`web_fetch`）；
  3. 仍无则查 8-K / 6-K 的 `Ex-99` 附件；
  4. 三条路径均未取得时，如实写 `电话会未覆盖（已尝试路径：…）`，**严禁用业绩新闻稿（Earnings Release）冒充电话会问答**。
- **必须提取的四项内容**：
  1. **四期指引措辞并排表**：将最近 4 期管理层的定量指引与定性语气（如从“strong visibility”变为“macro headwinds / prudent”）并排展示；
  2. **分析师高频提问计数**：统计哪几个问题在 Q&A 中被多位分析师反复追问（代表市场最担忧的焦点）；
  3. **管理层回避或答非所问的瞬间**：记录分析师问了什么具体问题、管理层如何绕开或拒绝给出定量口径；
  4. **2–4 个核心话题的四期原话漂移**：保留管理层原话语言（英文材料贴英文原句 + 中文解读，不把翻译当原话）。

### C3. 年报深度章节与招股书（S-1 / F-1）历史承诺对照
- 精读最新年报（10-K / 20-F）的 Item 1 Business、竞争格局、人力资本与高管薪酬激励考核指标（DEF 14A / 20-F 薪酬披露：管理层奖金和 PSU 到底挂钩收入、Non-GAAP EPS、FCF 还是股价？）。
- 若可取得上市招股书（S-1 / F-1）或早期年报，将**当时管理层对商业模式、远期利润率目标、TAM 与竞争壁垒的承诺**与今天的实际结果对照，评估管理层长期战略兑现度。

### C4. 三年指引可信度检查（12 个季度 Guidance vs. Actual 逐季表，核心必做）
这是评价 **Good People（管理层可信度）**、备忘录第七章以及 Excel 模型 `Guidance vs Actual` 页的直接依据，严禁省略（若公司历史不足 12 季或仅给年度指引，覆盖全部可得期次并写明指引频率）：

1. **输出 12 个季度的「指引 vs 实际」逐季对比表**：

| 季度（Period） | 指引指标（收入 / 营业利润 / EPS） | 指引区间与中点（Guidance Midpoint） | 实际结果（Actual） | 偏差幅度（Beat / Miss % or bps） | 结果判定（Beat / In-line / Miss） | 管理层当期事后解释与次季指引修正 |
|---|---|---|---|---|---|---|
| 1Q24 | | | | | | |
| 2Q24 | | | | | | |
| …（共 12 季） | | | | | | |

2. **归纳管理层指引风格（`guidance_style`，供写入 `management` 知识层）**：
   - **整体基调**：一贯保守（Beat-and-Raise）、中性精准（In-line）、还是激进常 Miss（Over-promise & Under-deliver）？
   - **指标差异**：收入指引和利润率/费用指引哪个更保守？
   - **年度指引修正节奏**：公司通常在哪一个季度（如 Q4 报或 Q1 报）给出全年初始指引，又通常在哪个季度（如 Q2 或 Q3）开始上修或下修全年区间？

### C5. 重大 8-K 事件、内部人交易与股权结构变化
- **8-K / 6-K 重大事项**：过去 12–24 个月的并购重组、大额发债/增发、核心高管/CFO/审计师变更、重大诉讼或监管调查。
- **内部人交易（Form 4 / 144）**：梳理高管与董事近一年的增减持方向、金额、均价，**必须区分属于预先设定的 10b5-1 自动交易计划还是非计划主动买卖（Open Market Purchase / Sale）**。
- **大股东与投票权结构（SC 13D/13G & Proxy）**：创始人投票权比例（AB 股双层架构）、主要机构股东进出。

### C6. 逐题证据小结与缺口
- 按 `references/branch-common.md` 第四节格式，汇总 Q1–Q5、Q9、Q10、Q12 的一手证据、最强反证与未决缺口。
