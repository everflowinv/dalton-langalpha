# 深度投资备忘录写作规范（`memo-writing.md`）

本文件定义 Dalton 买方完整覆盖投资备忘录（`drafts/<D>-memo.md`）的分析框架、12 问前置总纲与十章论证结构、章节映射、三段式写作流程及机械校验标准。动笔前必须先读 `.agents/skills/dalton-conventions/SKILL.md`、`research/<D>-fc/facts.md` 与 `research/<D>-fc/questions.md`。

---

## 一、核心原则：判断先行与分析链

1. **核心判断 ≤3 句说清立场**
   - 直接给出明确方向性评价（做多 / 做空 / 观察 / 暂无高 conviction），写清一句话差异化观点、核心 Thesis 支柱、主要风险、三情景风险收益比与仓位建议；若建议“观察”，必须回答正在等待什么可观测条件、为何值得等待。
   - **业务质量（Good Business）与股票吸引力（Good Price）必须分开判断**：好公司不等于现价好股票。
2. **章节与 12 问先给结论，再展开因果与证据**
   - 每个关键段落按 **「直接判断 → 关键证据与因果分析（带期间与 `[引用N]` 引用）→ 投资含义（对收入、利润、现金流或估值的影响）→ 必要的反方与改判条件」** 组织。
   - 把“不是 X / 不能当作 Y / 不等于 Z”这类防御性免责声明改写为正确的会计/业务口径及其投资含义；实质限制条件就近简述一次并说明影响，完整细节放入附录。
3. **完整买方分析链**
   - 全文沿着 **Revenue & Profit Driver Tree → 关键变量与行业框架 → 市场隐含假设（PIE） → 差异化观点（Variant Perception 三问） → 多/中/空三情景估值与回报 → 催化剂、高频跟踪与证伪条件** 严密推进。
4. **数字底表铁律**
   - 目标公司的所有历史财务、净现金、隐含资产、股东回报、盈利质量数字**只能来自 `research/<D>-fc/facts.md`**；未来预测、三情景估值、DCF 与敏感度数字**只能来自 `model/<TICKER>-model-v01.xlsx`**，严禁在正文中另行口算或临时拉数。

## 二、12 问前置投资总纲与章节映射规则

1. **前置位置硬约束（`research_structure.py` 强制校验）**
   - `## 零、12 个核心问题与投资判断` 必须作为二级标题，严格位于 `## 核心判断` 之后、`## 一、公司与业务` 之前（严禁放到文末或附录）。
   - Q1–Q12 必须按顺序全部使用三级标题 `### Q1. <题目>` 至 `### Q12. <题目>`，不得漏题、重复或改题号。
   - 只读 `## 核心判断` 和 `## 零、12 个核心问题与投资判断`，读者就应能完整复述投资逻辑、市场分歧、回报来源与改判条件；后面十章提供完整的数据、模型推导与证据展开。
2. **每题尾部固定两行（`来源：` 与 `详见：`）**
   每道题的回答正文之后，必须紧跟单独两行：
   ```markdown
   来源：一手 / 卖方 / 专家 / 场外 / 底表 —— [引用1][引用2]
   详见：第1章、第3章
   ```
   - 若某题确因客观原因存在材料缺口，允许写：`来源：缺口 —— 需要什么具体材料、已尝试的路径及对判断的影响`（说明文字不少于 8 个字）。
   - `详见：` 必须指向实际存在的第 1–10 章（写 `第1章` 或 `第一章` 均可）。
3. **重点题（必须深度展开）**
   - **Q1、Q2、Q3、Q4、Q5、Q7、Q8、Q12** 为重点题，审稿人会逐题核对回答是否足以支撑最终投资建议。
4. **问题与支线、论证章节映射表**

## 三、备忘录 11 部分章节标题与内容要求（标题逐字遵守）

`validate_memo.py` 与 `research_structure.py` 会严格校验以下二级标题名称与排列顺序（子节可使用三级标题自由展开，但二级标题名称必须逐字一致）：

```markdown
# {公司名}（{TICKER}）投资备忘录

## 基本信息
代码 / 日期 / 股价（日期） / 市值 / 30 日均成交额 / 当前建议

## 核心判断
一句话差异化观点 → Thesis 摘要 → 主要风险 → 风险收益 → 建议（≤3 句）

## 零、12 个核心问题与投资判断
### Q1. 这家公司靠什么赚钱？
……（Q1–Q12）

## 一、公司与业务
1.1 发展沿革与关键转折
1.2 产品、分部收入与利润池结构（区分收入规模最大业务与增量利润最高业务）
1.3 Revenue & Profit Driver Tree
1.4 历史财务分析（利润表最近 8 季、资产负债表关键科目、现金流与 FCF 转化，全部引用 `facts.md`）
1.5 盈利质量记分卡（Sloan 应计比率、CFO/NI、现金转换周期 CCC、Non-GAAP 调节项质量）
1.6 股东回报（R1/R2/R3 评分 `x.x/20`、两张六行表、回购性质与 SBC 稀释）

## 二、业务质量
2.1 Good Business（赚钱容易、赚钱多、赚钱久：毛利率、资产轻重、ROIC vs WACC、FCF Margin、护城河持续性、定价余量与变现克制）
2.2 Good People（长期导向、组织激励、资本配置纪律）
2.3 Good Price（现价要求公司做到什么，业务质量与股票吸引力分别评价）
2.4 综合评级与定性结论

## 三、行业与竞争
3.1 行业定义与 TAM（至少两种算法交叉验证）
3.2 竞争格局（5–8 家玩家份额趋势、同业现取财务表、上下游议价能力、壁垒形成或破坏及可证伪指标）
3.3 周期位置与景气度
3.4 全球对标（1–3 家可比公司坐标）
3.5 行业专用分析框架拆解

## 四、核心投资逻辑
4.1 差异化观点三问：
    - 市场认为：______（基于已覆盖卖方与市场样本）
    - 但实际上：______，因为 ______（核心证据与机制）
    - 错误定价为什么还存在：______（信息盲区 / 时间维度错配 / 叙事惯性 / 抱团 / 覆盖不足）
4.2 市场隐含预期（Price-Implied Expectations, PIE：现价反推隐含的未来收入增速、稳态利润率与资本开支要求）
4.3 Thesis 支柱逐条展开（3–5 条支柱，每条含：核心主张、因果传导链、支撑证据 `[引用N]`、市场未计入部分、确认/警告/证伪阈值；**注意：Thesis 小节中 ≥70% 的列表/表格行必须带 `[引用N]` 引用标记**）
4.4 与基金组合的关系（相关性、因子敞口、蓄水池或未定价隐含资产）

## 五、风险与反方证据
5.1 Risk Matrix（风险矩阵表：风险事项｜发生概率｜业绩与估值冲击｜反方证据 `[引用N]`｜领先观察指标；**注意：Risk Matrix 中 ≥70% 的数据行必须带 `[引用N]` 引用标记**）
5.2 Pre-mortem（事前验尸：**若一年后这笔投资亏损 30%，最可能怎样发生？** 按可能性从高到低写 3–5 条完整空方路径，必须写出空方最强的版本，严禁立稻草人）
5.3 我们自己的隐含假设（本稿结论最依赖但尚未被 100% 证实的 2–3 条脆弱假设）

## 六、风险收益
6.1 多/中/空三情景假设与估值结果（Bull / Base / Bear 关键驱动参数、目标市值与每股价值，**严格引用 Excel 模型 `Scenarios` 页**）
6.2 关键变量敏感度分析（引用模型 `Sensitivity Analysis` 页）
6.3 预期回报、上下行不对称比（Upside/Downside Ratio）、持有周期与股票流动性评估

## 七、管理层与股权
7.1 核心管理层履历、分工与历史战绩
7.2 三年指引可信度（完整嵌入 C4 支线的 **过去 12 个季度 Guidance vs. Actual 逐季对比表**，并总结指引风格）
7.3 高管薪酬考核机制（Proxy / DEF 14A）、持股比例变化、期权池与 SBC 年稀释率
7.4 内部人交易（区分 10b5-1 计划与主动买卖）与大股东结构（SC 13D/13G）

## 八、市场预期
8.1 过去 3 年历史估值、股价与盈利预期复盘（含 $\ln(P_1/P_0) = \ln(\text{EPS}_1/\text{EPS}_0) + \ln(\text{PE}_1/\text{PE}_0)$ 对数分解与关键重估事件）
8.2 卖方一致预期地图与过去 12 个月评级/目标价演进
8.3 **我们与卖方逐驱动对比（Street vs. House）**：与模型 `Street vs House` 页严格一致，逐项列出 `驱动变量｜卖方一致预期｜House Case（Base/Bull/Bear）｜差异幅度｜我们的核心依据 [引用N]`

## 九、估值
9.1 估值三角验证（DCF 估值、同业可比估值 Comps、历史估值区间三者交叉印证，说明各自权重与必要前提；DCF 净现金默认采用底表严格净现金口径）
9.2 可比公司估值表（与模型 `Comparable Companies` 页一致）
9.3 催化剂日历（未来 3 / 6 / 12 个月事件、验证指标與概率）
9.4 预期内部收益率（IRR）与目标价桥接（Target Price Bridge）

## 十、后续跟踪
10.1 高频跟踪指标（指标名称、当前值、更新频率、数据源）
10.2 关键验证日期与财报节点
10.3 结构化监控清单（表格：**监控指标｜确认阈值｜警告阈值｜证伪阈值（越线怎么办）｜数据来源｜验证时间窗**）

## 附录
- 财务报表摘要与模型假设明细
- 盈利质量计算明细與净现金/隐含资产拆分表
- 产品体验评分表（`toc`）或从业者一线信号表（`tob`）（来自 D7）
- 管理层/IR 访谈待提问清单（带背景、预期判据与追问）
- 信源覆盖与缺口说明

## 引用
- 文末统一合并为单一 `## 引用` 节（不再另设独立的来源章节），将正文中出现的每个 `[引用N]` 按 `[引用1]: f:F1 （数字底表｜research/<D>-fc/facts.md#F1）`、`[引用2]: evidence:E-20261023-01 （来源类型｜机构/作者｜标题｜日期｜文档 id / 链接）`、`[引用3]: model:model/<TICKER>-model-v01.xlsx!DCF!C12 （本方模型｜DCF 估值页核心假设）` 逐行映射到核验目标与可读来源说明，同时供 `validate_memo.py` 双向闭环检查与 `numbers.py` 数值核验。
```

## 四、三段式写作流程与 `validate_memo.py` 门禁

为保证每章分析深度并避免单次输出截断，`full-coverage` workflow 将备忘录分为三段顺序撰写，每段写完立即运行 `validate_memo.py`：

1. **第一段（Part 1）**：撰写标题、`## 基本信息`、`## 核心判断`、`## 零、12 个核心问题与投资判断`（Q1–Q12 完整回答）、`## 一、公司与业务`、`## 二、业务质量` 到 `drafts/<D>-memo.md`。
   - 写完运行：
     ```bash
     python .agents/skills/dalton-full-coverage/scripts/validate_memo.py drafts/<D>-memo.md --part 1
     ```
   - 确认 **0 FAIL** 后进入第二段。

2. **第二段（Part 2）**：先通读第一段已写内容与模型 `model/<TICKER>-model-v01.xlsx` 的情景输出，再向 `drafts/<D>-memo.md` 追加撰写 `## 三、行业与竞争`、`## 四、核心投资逻辑`、`## 五、风险与反方证据`、`## 六、风险收益`。
   - 写完运行：
     ```bash
     python .agents/skills/dalton-full-coverage/scripts/validate_memo.py drafts/<D>-memo.md --part 2
     ```
   - 确认 **0 FAIL**（含 Thesis 与 Risk Matrix 引用率 ≥70% 检查）后进入第三段。

3. **第三段（Part 3 / Full）**：先通读前两段确保文风与数字前后一致，再向 `drafts/<D>-memo.md` 追加撰写 `## 七、管理层与股权`、`## 八、市场预期`、`## 九、估值`、`## 十、后续跟踪`、`## 附录`、`## 引用`。
   - 写完运行：
     ```bash
     python .agents/skills/dalton-full-coverage/scripts/validate_memo.py drafts/<D>-memo.md --mode full \
       --facts research/<D>-fc/facts.md --questions research/<D>-fc/questions.md --research-dir research/<D>-fc
     ```
   - 修复全部 **FAIL**（0 FAIL）后，方可进入阶段 4 独立审稿。
   - **说明**：不设 700 行机械行数门槛（蓝图 §3.2），验收聚焦结构完整、12 问实质回答、引用双向闭环、Thesis/Risk Matrix 证据密度及与底表/模型数字一致。
