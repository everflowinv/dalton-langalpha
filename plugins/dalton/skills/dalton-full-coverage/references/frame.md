# 问题清单 Frame 规则（`frame.md`）

本文件定义 `full-coverage` workflow 阶段 0.8 产出的公司专属 12 问研究提纲（`research/<D>-fc/questions.md`）的生成、填写与机械校验规则。

---

## 一、作用与输入来源

在派发 A/B/C/D 四条取证支线之前，必须先把通用的“买方深度认知 12 问”转化为**这家公司专属的具体商业与估值问题**，避免取证支线泛泛搜集资料。

编写 `research/<D>-fc/questions.md` 时必须先读取：
1. **阶段 0 产出的 `research/<D>-fc/facts.md`**：掌握已读一手定期报告、电话会、财务镜头与盈利质量事实；
2. **工作区已有的初次覆盖稿（`drafts/*-initial-coverage.md`）与现有知识层（`thesis.md`、`debate.md`、`drivers.md`、`agenda.md`）**：继承初筛阶段留下的待验证问题与证据缺口；
3. **PM 的 `pm_brief` 与 `focus_questions`**：将 PM 关心的核心假设直接落入对应的 Q1–Q12 中。

---

## 二、结构硬约束（`research_structure.py validate-agenda` 校验项）

`research/<D>-fc/questions.md` 必须严格满足以下格式，否則 `research_structure.py validate-agenda` 会报错拦截：

1. **全文严禁残留“待填写”三字**：脚手架中所有的 `待填写` 必须替换为基于一手材料和初次覆盖认知的具体内容。
2. **头部必填三项**（位于 `# {公司名}（{TICKER}）12问研究提纲` 之后、`## Q1.` 之前，格式为 `字段名：内容`）：
   - `已读一手材料：` 列出阶段 0 已读的 10-K/20-F、10-Q/6-K、电话会期次、accession 及核心章节位置。
   - `关键驱动：` 写出本公司的 Revenue & Profit Driver Tree 核心公式与关键量价/利润率/现金流传导变量。
   - `关键矛盾：` 写出当前决定投资取舍的 1–3 个最核心的公司专属争议（结合初次覆盖 debate 与 PM 关注点）。
3. **按顺序包含唯一的 `## Q1. <标题>` 至 `## Q12. <标题>`**（二级标题，顺序与题号 1–12 严格一致）。
4. **每道题下必填五项字段**（格式为 `字段名：内容` 或 `- 字段名：内容`，冒号后必须有实质内容）：
   - `公司问题：` 把通用问题翻译成这家公司的具体问题（例如将 Q1“这家公司靠什么赚钱？”具化为“Meta 的 Family of Apps 广告曝光量与单价驱动结构如何，Reality Labs 每年约 160 亿美元亏损何时见顶？”）。
   - `关键假设：` 列出围绕该问题待检验的 1–3 条具体业务或估值假设（含 PM 提出的假设）。
   - `取证安排：` 明确指派给哪条支线（A/B/C/D 或建模）、具体去查什么信源与什么指标。
   - `论证章节：` 对应备忘录正文的第几章（如 `第1章、第2章`）。
   - `证据进展：` 汇总初次覆盖与阶段 0 已有的支持证据、最强反方证据，以及本次完整覆盖尚待补证的缺口。

---

## 三、标准问题与支线/章节默认映射表

可使用 `templates/questions.md` 或运行以下命令生成初始脚手架：

```bash
python .agents/skills/dalton-full-coverage/scripts/research_structure.py make-agenda \
  --name "<公司名>" --ticker "<TICKER>" --out research/<D>-fc/questions.md
```

默认映射关系如下（与 `scripts/research_structure.py` 的 `QUESTIONS` 完全一致）：

| 题号 | 通用问题 | 默认负责支线 | 默认论证章节 |
|---|---|---|---|
| Q1 | 这家公司靠什么赚钱？ | A、C | 第1章、第2章 |
| Q2 | 关键驱动变量是什么，趋势如何？ | A、C、D | 第1章、第3章、第8章 |
| Q3 | 市场预测里藏着哪些隐含假设？ | B、C | 第4章、第8章、第9章 |
| Q4 | 管理层和企业文化值得信任吗，股东如何受益？ | B、C、D | 第1章、第2章、第7章 |
| Q5 | 股价为什么在当前位置？ | B、C | 第8章 |
| Q6 | 哪些高频数据能帮助我们检验判断？ | A、D | 第10章 |
| Q7 | 市场共识、多方和空方分别怎么看？ | B、D | 第5章、第8章 |
| Q8 | 做多、做空还是观察，我们的差异化观点是什么？ | 主笔综合 A/B/C/D | 第2章、第4章、第6章、第9章 |
| Q9 | 催化剂如何使判断兑现？ | B、C | 第9章、第10章 |
| Q10 | 投资判断需要多长时间兑现？ | 主笔综合 B/C | 第6章、第9章、第10章 |
| Q11 | 需要对冲吗，应该对冲什么风险？ | 主笔综合 A/D | 第5章、第6章 |
| Q12 | 我们可能错在哪里，遗漏了什么风险？ | 主笔综合 A/B/C/D | 第5章、第10章 |

---

## 四、完成前必跑校验命令

填写完成后，必须运行以下命令确认 0 错误：

```bash
python .agents/skills/dalton-full-coverage/scripts/research_structure.py validate-agenda research/<D>-fc/questions.md
```
只有输出 `OK`（返回码 0）后，才能进入阶段 1 派发四条取证支线。
