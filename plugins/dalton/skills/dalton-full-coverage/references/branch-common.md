# 四条取证支线通用规则（`branch-common.md`）

本文件适用于 `full-coverage` workflow 阶段 1 的全部四条取证支线（A 行业与竞争、B 卖方与内部/专家、C 一手文件精读、D 场外信号）。各支线动手前必须先读 `.agents/skills/dalton-conventions/SKILL.md`、本文件及各自支线规则文件（`branch-{a,b,c,d}-*.md`）。

---

## 一、角色定位与问题归属

1. **只取证、不下最终投资结论**
   - 你的产出是供后续建模与主笔写稿使用的**高保真证据包**：一手事实、管理层/专家原话、结构化对比表、精确数字、来源身份与核验状态。
   - 保留正反两方面证据（尤其是挑战我们初步假设的反方证据），不在支线里代替主笔做最终仓位或评级拍板。
2. **围绕 `questions.md` 展开**
   - 先读 `research/<D>-fc/questions.md`，重点攻克分配给本支线的核心问题（Q1–Q12）。
   - **每条重要发现必须在段首或段末标明对应题号**（如 `【对应问题：Q2、Q8】`），并说明该证据是支持还是挑战 `questions.md` 中的哪个关键假设。

---

## 二、数字纪律（最硬红线）

1. **目标公司数字一律来自 `facts.md` 底表**
   - 目标公司自身的财务、市值、股本、净现金、股东回报、盈利质量数字，**全部引用阶段 0 产出的 `research/<D>-fc/facts.md`**。
   - 若发现某个必须使用的目标公司数字在 `facts.md` 中缺失，写 `底表缺 X（建议回补）`，**严禁在支线里自行从网页搜索或二手研报中抄录目标公司财务数字**。
2. **唯一例外：竞对与同业公司数字**
   - 竞争对手与可比公司的财务与估值数字由 A 支线使用实时工具（`dalton_sec`、`fundamentals`、`yfinance`）现取，**每个数字后必须紧跟 `（期间，来源）`**，例如 `毛利率 61.3%（2Q26，SEC 10-Q）`。
3. **每个数字必须带期间与单位**
   - 首次出现时写清 `FY2025`、`2Q26`、`1H26`、`过去 12 个月（至 YYYY-MM-DD）` 及货币单位。禁止裸写“收入增长 18%”。

---

## 三、引用编号与来源层级

1. **支线独立引用前缀**
   - 支线 A 使用 `[A-1]`、`[A-2]`…；
   - 支线 B 使用 `[B-1]`、`[B-2]`…；
   - 支线 C 使用 `[C-1]`、`[C-2]`…；
   - 支线 D 使用 `[D-1]`、`[D-2]`…。
   - 在本支线文件内从 1 开始连续编号。
2. **句末带来源身份，一句一源**
   - 格式：`……（UBS 2026-07-14 研报 [B-3]）。`、`……（CFO 在 2Q26 电话会上 [C-7]）。`、`……（某云计算渠道专家 2026-08 [B-11]）。`
   - 一句话只挂一个来源；同一来源被多渠道（如邮件、TMTB、FUNDA AI）转述只算一条来源链。
3. **来源优先级与禁用源**
   - 优先级：**SEC Filing > 交易所/公司官方公告 > 署名卖方研报 > 权威政府/协会统计 > 专家访谈（标身份不写姓名） > 一般新闻（仅作线索） > 社区讨论（仅作视角旁证）**。
   - **严禁使用百度百科**。非中文一手材料直接读原文，不用二手中文翻译。
4. **原文引用上限**
   - Guidepoint 专家原话直接引用 **不超过 20 个英文词**，并紧跟出处说明；其他来源原话引用不超过 3 句。

## 四、文件收尾固定格式（逐题小结 + 引用清单 + 完成标记）

每条支线输出文件（`research/<D>-fc/e{a,b,c,d}.md`）的末尾，必须包含以下三部分，且**文件最后一行固定写 `<!-- 完成 -->`**（`validate_memo.py` 会检查该完成标记）：

```markdown
## 逐题证据小结（按本支线负责的 Q 编号）

- **Q1**：
  - 已取得支持证据：…… [A-1][A-3]
  - 最强反方证据：…… [A-4]
  - 未决项与主笔需补材料：……
- **Q2**：
  - 已取得支持证据：……
  - 最强反方证据：……
  - 未决项与主笔需补材料：……

## 缺口记录（未取得项与原因）

- 区分三种状态：**无相关结果** / **渠道失败（含额度用尽、未登录）** / **未覆盖**。写明想查什么、尝试了哪条路径、为何未取得。

## 引用清单

- [A-1] 来源类型｜机构/作者｜日期｜标题｜可核对定位信息（doc_id / accession + item / URL）
- [A-2] ……

<!-- 完成 -->
```
