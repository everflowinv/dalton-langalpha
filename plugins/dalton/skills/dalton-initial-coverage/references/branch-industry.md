# 初次覆盖 B 支线规则：行业与竞争（`branch-industry.md`）

本文件定义 `initial-coverage` workflow 阶段 1B「行业支线」（输出 `research/<D>-ic/industry.md`）的 8 条取证与写作规则。执行前先读 `.agents/skills/dalton-conventions/SKILL.md` 及 `references/evidence-and-sources.md`。

---

## 1. 行业定义与 TAM（至少两种测算方法交叉）

- 先界定清晰的行业边界：包含哪些产品/服务、不包含哪些，统计口径是出货量、出厂收入还是终端交易额（GMV/TCV）。
- **至少采用两种方法测算 TAM**（能给三种更好）：
  1. **自上而下（Top-Down）**：引用权威第三方行业报告或官方统计口径；
  2. **自下而上（Bottom-Up）**：$\text{潜在客户/用户基数} \times \text{渗透率} \times \text{单客年化支出（ARPU/ASP）}$；
  3. **成熟市场类比（Benchmarking）**：对标海外或成熟市场在可比发展阶段的渗透率与集中度。
- 给出**过去 5 年实际复合增速（CAGR）**与**未来 3–5 年预测增速**，每个数字必须标明机构/来源、发布年份、口径期间与币种。不同机构口径存在显著差异时，并列写明差异原因，不得简单取算术平均。

## 2. 行业特性与周期性判定

- 明确判断该行业**是否具有周期性**（强周期 / 弱周期成长 / 非周期必选 / 存量博弈）。
- 若有周期性，指出**周期的核心驱动因子**：下游需求周期、行业产能投放/资本开支周期、产品价格/库存周期、信贷与利率周期、还是监管政策周期，并判断当前处于周期的哪个位置（底部出清 / 早期复苏 / 景气扩张 / 见顶回落）。
- 列出 **2–3 个可跟踪的高频行业指标**（写明指标名称、数据源、更新频率、领先/同步关系）。

## 3. 竞争格局与同业实时财务对比

- 选定 **5–8 家主要竞争对手**（若启动参数 `peers` 已指定则在此基础上增补；若未指定，由本支线自行确定并写明选取理由），给出各家市场份额及**最近 3 年份额趋势**（升 / 平 / 降），标明份额口径与年份。
- **同业现取财务表**（严禁使用网页搜索摘要里的过时数字，必须用 `dalton_sec`、`fundamentals` 或 `yfinance` 实时拉取）：
  - 字段：**公司/代码｜市值（USD 亿）｜最近一期收入及 YoY｜毛利率｜净利率（或营业利润率）｜主要估值倍数（Forward P/E、EV/Sales 或 EV/EBITDA）**。
  - 表内或注释中每个数字必须标明 `（期间，来源）`，如 `（2Q26，SEC 10-Q）`、`（2026-10-18，yfinance）`。

## 4. 竞争壁垒与“形成 vs 被破坏”判断

- 识别行业与目标公司的核心壁垒类型：**网络效应、规模经济、客户转换成本、品牌心智、监管牌照、核心技术/专利、专有数据、还是成本/供应链优势**。
- **必须给出明确方向性判断**：当前壁垒是**“正在形成/加固”**还是**“正在被破坏/侵蚀”**（例如技术范式迁移、新进入者补贴、渠道变迁或监管松绑），并说明商业机制。
- 给出 **至少 1 个可证伪的观察指标**（例如：新签客户获客成本 CAC 变化、头部客户流失率、竞品份额突破某阈值、或毛利率与同业剪刀差）。

## 5. 行业专用分析框架（按公司类型七选一）

根据目标公司商业模式，从以下七个专用框架中选出**最贴合的一个**展开定量拆解（不要生搬硬套无关框架）：

1. **互联网平台**：$\text{MAU/DAU} \times \text{单用户时长} \times \text{变现率（Ad Load / 付费率）} \times \text{Take Rate / CPM}$；留存率与双边网络效应证据。
2. **电商平台/零售**：$\text{GMV（活跃买家} \times \text{购买频次} \times \text{AOV）} \times \text{Monetization Take Rate（佣金 + 广告）} - \text{单均履约成本}$；品类渗透率与退货率。
3. **SaaS / 企业云软件**：$\text{ARR} = \text{存量 ARR} \times \text{NRR（净留存率）} + \text{New Logo ARR}$；$\text{Rule of 40（收入增速 + FCF Margin）}$；$\text{LTV / CAC}$ 与 Payback Period。
4. **半导体 / 硬件**：制程/架构代际优势 $\times$ 客户集中度与绑定深度 $\times$ $\text{ASP} \times \text{出货量}$；渠道库存周数；晶圆/封装产能利用率与良率。
5. **消费品牌**：品牌力（溢价与复购） $\times$ 渠道力（直营/经销结构、终端库销比、渠道利润率） $\times$ 产品力（大单品占比、新品成功率）。
6. **连锁服务 / 餐饮零售**：**单店模型（Unit Economics）**（成熟店日销、店均 EBITDA 利润率、单店 Capex、现金回本周期 Payback） $\times$ 开店空间与展店速度 $\times$ 同店销售增长（SSSG = 客流 $\times$ 客单价）。
7. **物流 / 供应链**：$\text{件量/货量} \times \text{单票收入（ASP）} - \text{单票分拣与运输成本}$；自动化率与干线装载率；规模效应拐点。

## 6. 长短期驱动因素拆分

- **短期驱动（未来 2–4 个季度）**：列出 2–4 个核心驱动变量（如新品发布、库存补库、提价落地、基数效应）。
- **长期驱动（未来 3–5 年）**：列出 2–4 个核心驱动变量（如渗透率提升、海外扩张、第二曲线商业化、行业集中度提升）。
- 每个驱动因素必须明确标注属于 **“结构变化（Structural）”** 还是 **“周期波动（Cyclical）”**。

## 7. 宏观敏感度与传导路径

- 从 **利率、汇率、居民消费景气、企业 IT/资本开支预算、贸易与产业政策** 中，识别出与本公司最相关的 **1–3 项宏观变量**。
- 写清具体的**业务传导路径**（例如：“联邦基金利率每上升 100bps → 下游中小客户融资成本上升 → 企业软件新签周期拉长 → 影响公司 New ARR 增速”），避免泛泛而谈“受宏观经济影响”。

## 8. 信源优先级与覆盖记录

- 按以下优先级检索并在文末附 `[B-ind-1]` 引用清单与信源覆盖说明：
  1. **基金内部行业认知（第一优先）**：`researchdata.research(route="company-wiki")` 检索公司页与所属行业目录（`params={sector: ...}` 或行业关键词）；
  2. **内部研究库与卖方行业深度**：`researchdata.research` 检索 `alphaengine`（行业深度报告 `foreign_report`）、`sales-notes`、`tmtb`、`funda-ai`；
  3. **Guidepoint 专家纪要**：用英文检索（`route="guidepoint", operation="search_library"`），了解行业竞争 win-loss、渠道真实返利与终端需求，原文直接引用 ≤20 个英文词并注明专家身份与日期；
  4. **官方统计、行业协会数据与公开检索（`web_search`）**。
- 数据接口若返回额度用尽或连接失败，必须如实写“额度用尽/渠道失败，本轮未覆盖”，严禁写成“无相关行业研究”。
