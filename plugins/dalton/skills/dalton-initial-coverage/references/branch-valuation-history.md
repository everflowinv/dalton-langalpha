## 1. 过去 3 年股价、远期估值倍数与远期 EPS 预期路径

- **时间跨度**：覆盖过去 3 个完整年度至今（上市不足 3 年则取上市以来全部历史）。
- **核心序列**：
  - 复权股价序列（默认使用 `yfinance` 的 `yf_price.get_stock_history`，统一基准日）；
  - 远期估值倍数序列（按行业特性选主倍数：盈利稳定/成长股用 **NTM P/E**，高增长未稳态盈利股用 **NTM EV/Sales**，重资产/周期股用 **NTM EV/EBITDA**；调用 `fundamentals.get_historical_valuation` 或 `yf_fundamentals.compare_valuations`）；
  - 远期 12 个月（NTM）EPS（或核心盈利指标）一致预期路径。
- **历史一致预期缺失时的近似规则**：
  - 首先检查工作区 `data/consensus/` 是否有历史一致预期快照；
  - 若无历史快照，从 `researchdata.research(route="alphaengine")` 检索各历史时点附近的外资行研报提取当时的 NTM EPS 预测点，或采用滚动后验实现的未来 4 季实际 EPS（或财报季当季年化 EPS）作为近似，**必须在正文与表注中显式标明所采用的近似方法与口径**。

## 2. “EPS 驱动还是倍数驱动”对数分解（核心必做）

为回答“历史上股价涨跌到底是由基本面盈利预期驱动，还是由估值倍数重估驱动”，必须按**自然年度**（如 2023、2024、2025、YTD）或**重大行情区间**（如见底反弹段、回撤段）执行对数恒等分解：

$$\ln\left(\frac{P_1}{P_0}\right) = \ln\left(\frac{\text{EPS}_1}{\text{EPS}_0}\right) + \ln\left(\frac{\text{PE}_1}{\text{PE}_0}\right)$$

- 其中 $P_t$ 为区间起止时点股价，$\text{EPS}_t$ 为当时的远期 12 个月（NTM）一致预期 EPS（或显式说明的同口径盈利指标），$\text{PE}_t = P_t / \text{EPS}_t$ 为当时的远期市盈率。
- **数学校验红线**：每一行中，`EPS 预期变化贡献（对数变动） + 倍数变化贡献（对数变动）` 必须严格等于 `股价对数总变化` $\ln(P_1/P_0)$（表中可同时展示普通百分比涨跌 $(P_1/P_0 - 1)$ 与对数分解贡献占比，确保两项贡献之和严格闭合）。
- **必须输出以下分解表**：

## 3. 当前股价与估值位置定位

- **自身历史分位**：当前主估值倍数（NTM P/E、EV/EBITDA 或 EV/Sales）处于过去 3 年（及 5 年，如有）历史区间的什么分位（给出当前值、3 年中位数、均值、±1 标准差区间、最高/最低值及对应日期）。
- **相对同业折溢价**：当前倍数相对于一档同业中位数的溢价/折价幅度（%），对比过去 3 年历史平均折溢价水平，判断当前相对估值处于高位还是低位。
- **交易位置**：当前股价比 52 周高点回撤多少（%）、比 52 周低点反弹多少（%）、30 日均成交额（USD 百万）。

## 4. 可比公司估值表（复用 `comps-analysis` 输出 `comps.xlsx`）

- 严格调用并遵循 `.agents/skills/comps-analysis/SKILL.md` 的方法（初次覆盖采用 **screen-grade** 精度即可，重在同口径横向可比与统计汇总）。
- **同业样本选择**：至少包含 **3 家以上一档直接可比公司（Tier-1 Peers）**（若有二档生态或跨市场可比公司可分档列示，并说明选取理由）。
- **输出要求**：
  1. 生成带动态公式与统计汇总行（Max、75th Percentile、Median、Mean、25th Percentile、Min）的工作簿 `research/<D>-ic/comps.xlsx`；
  2. 在 `research/<D>-ic/valuation.md` 中内嵌 Markdown 摘要表（包含：代码、市值、EV、未来两年收入增速、毛利率、EBITDA/营业利润率、NTM P/E、NTM EV/EBITDA、NTM EV/Sales、PEG），每个同业数字标明数据日期与来源。

## 5. 过去 3 年重要重估事件复盘

- 梳理过去 3 年内 **3–6 个让股价或估值中枢发生重大重估（单日/单周大涨大跌或趋势拐点）的标志性事件**（涵盖：关键财报 beat/miss、长期指引调整、重磅产品发布、竞争格局突变、监管政策或管理层变动）。
- 每个事件按以下结构写成一条或一行：
  - **事件与日期** → **期间股价与估值倍数变化** → **经营层面实际发生了什么（EPS 预期如何修）** vs **市场叙事/估值倍数发生了什么重估** → **对当前投资判断的启示**。
