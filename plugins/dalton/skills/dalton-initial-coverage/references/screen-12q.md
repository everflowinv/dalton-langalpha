# 12 问初筛写作规则（`screen-12q.md`）

本文件定义 Dalton 买方初次覆盖报告（`drafts/<D>-initial-coverage.md`）中「一、12 问初筛」的题目清单、重点题硬约束与逐题答题标准。题目源自 Dalton Playbook v1「深度认知 12 问」（与完整覆盖 `full-coverage` 的 12 问同源；题目表述以 `.agents/skills/dalton-conventions/SKILL.md` 及本文为准）。

---

## 一、初筛答题原则与重点题要求

1. **每题四要素结构**
   初次覆盖追求买方认知锐度与研究议程定位，不追求 50 页卖方式铺陈。每道题固定给出四项内容：
   - **当前判断**：开门见山给出有倾向的直接判断（1–3 句），不写空话套话；
   - **关键证据（带来源与期间）**：支撑判断的 2–4 个核心数据点或一手事实，句尾标明来源身份与 `[引用N]`；
   - **置信度**：高 / 中 / 低（并简述限制置信度的核心原因）；
   - **还缺什么（待验证缺口）**：当前初筛尚未解决的具体证据缺口，以及计划在后续跟踪或完整覆盖（Full Coverage）的哪条支线（A 行业 / B 卖方专家 / C 一手精读 / D 场外信号 / 模型）中补齐。

2. **重点题（必须实质展开，严禁略写）**
   - **重点题共 8 题：Q1、Q2、Q3、Q4、Q5、Q7、Q8、Q12**。
   - 这 8 道题必须基于阶段 1（A 背景、B 行业、C 财务镜头、D 估值历史）与阶段 2（bull/bear 快速版）的真实取证给出**实质判断与定量证据**，不得写“暂不展开”。
   - 若某条支线在运行中失败或数据缺失，在对应题目下如实写出“缺口：需要什么材料、已尝试路径及对当前判断的影响”。

3. **非重点题（Q6、Q9、Q10、Q11）的初筛弹性**
   - 若已有充分证据（如行业支线已给出高频指标 Q6、bull/bear 已给出催化剂 Q9），正常按四要素作答；
   - 若初筛阶段证据尚薄，允许简写为：`初筛暂不展开：当前缺 <具体数据/组合敞口输入>，计划在完整覆盖 <A/B/C/D 支线或模型> 中补齐`，并给出初步方向性线索。

## 二、12 个核心问题清单与初筛要点

### Q1. 这家公司靠什么赚钱？（重点题）
- **必答要点**：客户是谁、为什么付钱、收费模式（订阅/交易抽佣/按量/硬件买断/广告）、分部收入与利润贡献结构（区分规模最大的业务与真正贡献增量的高利润池）。
- **主要证据来源**：A 公司背景稿、B 行业支线。

### Q2. 关键驱动变量是什么，趋势如何？（重点题）
- **必答要点**：从收入与利润驱动树中挑出 2–4 个最核心的量/价/留存/利润率变量，判断未来 2–4 个季度与 3–5 年的方向（标明是结构变化还是周期波动），以及竞争壁垒是**正在形成还是正在被破坏**。
- **主要证据来源**：A 公司背景稿、B 行业支线（壁垒与行业专用框架）。

### Q3. 市场预测里藏着哪些隐含假设？（重点题）
- **必答要点**：当前一致预期（下一财年收入、EPS、隐含总费用空间与营业利润率）要求公司做到什么增速与利润率？卖方预测与公司指引之间最大的分歧落在哪个变量？
- **主要证据来源**：阶段 2 `bullbear-quick.md`（一致预期快照 + `implied_model.py`）、D 估值支线。

### Q4. 管理层和企业文化值得信任吗，股东如何受益？（重点题）
- **必答要点**：创始人/核心管理层背景与战略定力、指引一贯风格初判、资本配置纪律，以及 C 支线算出的**股东回报评分（R1/R2/R3，得分 x.x/20）、回购性质（真实回报 vs SBC 对冲）与净现金双口径**。
- **主要证据来源**：C 财务镜头（`lenses.json` / `drafts/<D>-lenses.md`）、A 公司背景稿。

### Q5. 股价为什么在当前位置？（重点题）
- **必答要点**：引用 D 支线的 **“EPS 驱动还是倍数驱动”对数分解表**（$\ln(P_1/P_0) = \ln(\text{EPS}_1/\text{EPS}_0) + \ln(\text{PE}_1/\text{PE}_0)$），说明过去 3 年股价主要由盈利预期变化还是估值重估驱动；当前估值在自身历史分位与同业可比中的位置，以及最近 1–2 次重估事件反映的市场担忧或期待。
- **主要证据来源**：D 估值历史与可比支线（`valuation.md`、`comps.xlsx`）。

### Q6. 哪些高频数据能帮助我们检验判断？（可精简）
- **必答要点**：列出 B 行业支线识别的 2–3 个可跟踪高频指标或季报核心 KPI、数据来源、更新频率，以及什么读数支持或削弱 thesis。
- **主要证据来源**：B 行业支线、阶段 2 `bullbear-quick.md`。

### Q7. 市场共识、多方和空方分别怎么看？（重点题）
- **必答要点**：当前股价 price in 了什么共识？估值之外真正的 2–4 个核心 Debate 是什么？多空双方最强的证据与反驳分别是什么？我们在每个 Debate 上的倾向。
- **主要证据来源**：阶段 2 `bullbear-quick.md`。

### Q8. 做多、做空还是观察，我们的差异化观点是什么？（重点题）
- **必答要点**：按差异化观点三问作答——“市场认为 ___”、“但实际上 ___，因为 ___”、“错误定价为什么仍存在（信息盲区 / 时间维度错配 / 叙事惯性）”，并结合隐含资产或未充分变现能力（underearning）给出初筛倾向（**关注 / 观察 / 暂不覆盖 / 建议完整覆盖**）。**若无足够预期差，直白写“暂无高 conviction”，并写明在等待什么条件或价格**。
- **主要证据来源**：主笔综合 A–D 与 `bullbear-quick.md`。

### Q9. 催化剂如何使判断兑现？（可精简）
- **必答要点**：未来 3–6 个月按时间排列的关键催化剂事件（财报、产品日、行业数据、政策节点）、检验哪条 Debate、对应的 bull/bear 阈值。
- **主要证据来源**：阶段 2 `bullbear-quick.md`。

### Q10. 投资判断需要多长时间兑现？（可精简）
- **必答要点**：初步判断经营拐点或差异化逻辑兑现需要几个季度，等待期间的机会成本或下行保护（如股东回报率、严格净现金占比）。
- **主要证据来源**：C 财务镜头、D 估值支线、`bullbear-quick.md`。

### Q11. 需要对冲吗，应该对冲什么风险？（可精简）
- **必答要点**：结合 B 支线识别的宏观敏感度（利率、汇率、大宗、板块 beta）与同业配对关系，说明主要非核心风险敞口；若初筛阶段尚无需设计具体对冲方案，写明完整覆盖阶段需验证的敞口。
- **主要证据来源**：B 行业支线（宏观敏感度）。

### Q12. 我们可能错在哪里，遗漏了什么风险？（重点题）
- **必答要点**：写出最强反方证据（Anti-thesis，不立稻草人）、我们自身判断依赖的最脆弱隐含假设、一旦出现即推翻初筛倾向的**可量化证伪指标（Falsifier）**，以及初筛尚未覆盖、必须在完整覆盖阶段深挖的决定性盲区。
- **主要证据来源**：主笔综合全部支线缺口与空方最强论据。
