# PM 问答回复模板（固定五段结构）

> 适用场景：公司分析师工作区或 Home 研究总监工作区回复 PM 提问。篇幅随问题复杂度伸缩，但**五段结构顺序与核心要素固定不变**。

---

## 标准五段回复模板（单公司 / 实时问题）

### 1. 直接回答
<第一句话直奔结论：明确回答“是/否/强化/削弱/维持不变”，并给出最关键的量化数字或核心原因，绝不寒暄绕圈。>

### 2. 依据
- **知识层既有定论**：<引用 `thesis v<N>（YYYY-MM-DD）`、`debate.md`、`drivers.md` 或模型 `<Sheet>!<Cell>` 中的本基金基准假设（House View） vs 卖方一致预期（Street Consensus）>
- **本次新核实证据**（若类型 b/c 涉及新查数据）：
  - <证据 1 + 具体数值 + 日期/所属期 + 来源 `[S1]`>【`事实` / `公司表态` / `一致预期` / `模型推导` / `判断` / `假设`】
  - <证据 2 + 具体数值 + 日期/所属期 + 来源 `[S2]`>【`标签`】

### 3. 和现有观点的关系
- **事件五词结论**：**`<NO_CHANGE / THESIS_STRENGTHENED / THESIS_WEAKENED / THESIS_BROKEN / NEW_THESIS>`**
- **受影响的支柱与驱动变量**：
  - 对 `<pillar_id>`（当前状态：`<intact/watch/impaired>`，确认阈值 `<...>` / 证伪阈值 `<...>`）：<说明本次信息使指标向哪个方向移动，是否触及阈值>。
  - 对 `<driver_id>`：<说明是否需要修正模型中的 House 预测值>。

### 4. 不确定性与改判条件
- **当前信息盲区**：<明确指出哪块数据目前仍缺失（`目前缺乏数据`）或仅依赖管理层单方表态>。
- **改判触发条件（What Would Change Our Mind）**：若在 `<YYYYQ# / 具体事件窗口>` 观察到 `<具体指标>` `<高于/低于>` `<量化阈值>`（来源：`<10-Q / 行业高频数据>`），我们将把判断从 `<当前立场>` 修正为 `<改判后立场>`。

### 5. 下一步
- **知识层与议程动作**：<例如：仅引用既有 `thesis v13`，无新证据不记 verdict；或已调用 `knowledge_append_verdict(trigger="pm_question")` 并将“<待跟踪问题>”记入 `agenda.md`（`origin="pm"`）>。
- **后续深挖建议**（如适用）：<例如：建议启动 `/topic-research` 专项拆解 `<议题>`；或在 Home 已通过 `delegate_to_analyst` 交办 `<TICKER>` 分析师更新模型>。
