# PM 问答回复模板（五项检查要素，可按需合并）

> 适用场景：公司分析师工作区或 Home 研究总监工作区回复 PM 提问。以下五项是**检查要素，可以按问题复杂度合并成段，不必每题各自单独成段**；只有会改变本题答案或行动的未知项才写，沿用的改判条件没有变化时不重抄。

## 标准回复要素（单公司 / 实时问题，简短追问可合并书写）

### 1. 直接回答
<第一句话直奔结论：明确回答“是/否/强化/削弱/维持不变”，并给出最关键的量化数字或核心原因，绝不寒暄绕圈。>

### 2. 依据
- **既有研究定论**：<说明既有基准假设（House View） vs 卖方一致预期（Street Consensus）的对比结论；模型单元格出处放文末 `## 引用`，不在正文写文件名或单元格号>
- **本次新核实证据**（若类型 b/c 涉及新查数据）：
  - <证据 1 + 具体数值 + 日期/所属期 + 来源 `[引用1]`>【`事实` / `公司表态` / `一致预期` / `模型推导` / `判断` / `假设`】

### 3. 和现有观点的关系
- **事件五词结论**：**<无变化 / 强化 / 削弱 / 证伪 / 新论点>**
- **受影响的支柱与驱动变量**：
  - 对「<用一句话写出受影响的支柱内容，不写编号>」（当前状态：<待验证 / 成立 / 强化 / 观察 / 受损 / 证伪 / 已变更 / 已退役>）：<说明本次信息使指标向哪个方向移动，是否触及阈值；既有阈值未变且前文已明示时不必整段重抄>。

### 4. 不确定性与改判条件（按需保留，无实质未知项或改判条件未变时可并入上段或省略）
- **影响本题结论或行动的未知项**（仅在存在会改变本题答案或行动的未知项时写；无则省略，不硬凑“目前缺乏数据”）：<指出具体缺哪项关键验证及其对本题判断的影响>。
- **决定行动的关键改判条件**（沿用的改判条件没有变化时不重抄，只写决定本题回答或行动的那一个关键条件）：若在 `<YYYYQ# / 具体事件窗口>` 观察到 `<具体指标>` `<高于/低于>` `<量化阈值>`（来源：`<10-Q / 行业高频数据>`），我们将把判断从 `<当前立场>` 修正为 `<改判后立场>`。

### 5. 下一步
- **观点与跟踪动作**：<例如：维持既有判断不变；或已记录本次事件结论并将“<待跟踪问题>”加入跟踪议程；无新增动作时可与上文合并一句收尾>。
- **后续深挖建议**（如适用）：<例如：建议围绕 `<议题>` 启动专题深挖；或已交办 `<TICKER>` 分析师更新财务模型>。
