# 股东回报支线规则（Bull / Bear Discussion 第一节与第九节）

本文件定义 `bullbear-doc` workflow 中「股东回报支线」的写作与排版规则。

> **计算与评分基准**：所有指标口径、R1/R2/R3 公式、政策可信度五档、持续性调整（-1 至 +2 分）及回购性质判定，一律以 `.agents/skills/dalton-financial-lenses/references/shareholder-return.md` 为准：
> - 分母与汇率锚点：直接读取准备阶段由 `.agents/skills/dalton-financial-lenses/scripts/anchors.py` 产出的 `anchors.json`（所有期间统一采用核定后的当前 USD 市值作为分母，不回溯历史市值）。
> - 评分复算：调用 `.agents/skills/dalton-financial-lenses/scripts/return_score.py` 计算，禁止手算或中间步骤提前四舍五入。
> - SBC 与股本参考：可参考准备阶段 `fincheck.md` 末尾的 SBC 费用与占收入比例，并结合 10-K/10-Q 现金流量表与股本附注核实。

---

## 一、引用与数字纪律

1. **独立引用序列**：支线使用 `[回报引用N]`（从 `[回报引用1]` 起连续编号），与主稿的 `[引用N]` 互不混用。
2. **句尾带身份**：格式为 `……（管理层 [回报引用2]）。`、`……（10-K [回报引用3]）。`，一句一个来源。
3. **每个数字带期间**：首次出现写清期间（如 `2Q26`、`FY2025`、`过去 12 个月（至 YYYY-MM-DD）`）；表格首列已标明期间的，单元格内不重复。
4. **只计实际执行**：只有实际支付的分红（按付款日归入窗口）和实际执行的回购才计入已实现回报；回购授权只作政策依据，不得计入已实现回购。

---

## 二、三份输出文件与行数硬约束

股东回报支线在运行目录 `${runDir}/` 下产出三个文件：`return.md`、`return_appendix.md`、`return_summary.md`。

### 2.1 `${runDir}/return.md`（第一节正文，≤40 行，机械检查上限 48 行）

第一节只放读者最核心的结论与两张表：**全部使用 bullet 或 Markdown 表格，禁止写长段落（单行非表格非 bullet 不超过 120 字）**。文件末行必须写 `<!-- 第一节完成 -->`。

小标题只写名字（如 `**回购性质与股本变化**`），不带括号条数备注：

```markdown

- 市值基准：USD {xxx} 百万（权益范围、来源与时点，股价 {price} {ccy}）；汇率 1 {报表币种} = {rate} USD（行情 [回报引用1]）
```

> **格式红线**：
> - 表 1「主要依据」列控制在 25 字以内，详细说明放第九节附录。
> - 各小节条数：`回购性质与股本变化` ≤3 条、`最新回购执行` 1–2 条、`管理层最新回报政策` 2–3 条、`未来 12 个月` 1 条。

### 2.2 `${runDir}/return_appendix.md`（第九节附录，≤30 行）

计算拆解、逐季回购明细、预测推导、评分拆解、口径差异与 `[回报引用N]` 清单全部放在本文件。文件末行必须写 `<!-- 完成 -->`。

```markdown
## 九、股东回报附录

- **回购性质拆分**：各年回购股数与员工计划新发/再发行股数、注销与库存股安排、两种口径（股数口径 vs SBC 费用口径）算出的真实回报比例、采用哪个及理由（10-K [回报引用2]）。
- **回购执行逐季**：最近 4–6 个季度逐季回购金额与买入均价；历史授权总额与执行率（10-Q [回报引用3]）。
- **未来 12 个月预测依据**：分红、回购、特别股息各一条，[假设] 项写清推导过程。
- **评分拆解**：R1 = x.xx%；R2 = x.xx%；R3 = x.xx% × 可信度 p% = x.xx%（可信度档位理由一句）；R = max(R1, R2, R3) = x.xx%；基础分 x.xx；持续性调整 ±x.x 分（加减项理由一句，不重复计）；最终得分 **x.x / 20**。
- **口径与未核实项**：外推假设、50% 混合拆分、现金流量表与逐季加总差异、卖方口径与公司口径差异。

**回报引用清单**
[回报引用1] 行情｜yfinance / anchors.json｜市值与汇率锚点｜YYYY-MM-DD｜anchors.json
[回报引用2] 公告｜SEC 10-K｜FY2025 年报现金流量表与股本附注｜YYYY-MM-DD｜accession ...
[回报引用3] 公告｜SEC 10-Q｜最近季度回购与股息披露｜YYYY-MM-DD｜accession ...
[回报引用4] 电话会｜管理层业绩会纪要｜资本配置与股东回报政策表态｜YYYY-MM-DD｜doc_id ...
<!-- 完成 -->
```

> **核对要求**：`return.md` 与 `return_appendix.md` 正文中出现的 `[回报引用N]` 集合，必须与 `**回报引用清单**` 下列出的 `[回报引用N]` 集合完全一致（`bb_check.py` 会强制校验）。合并后在报告末尾的 `## 引用` 一节逐行写出核验目标与括号内来源说明（形如 `[回报引用1]: evidence:E-20261023-04 （行情｜yfinance / anchors.json｜市值与汇率锚点｜YYYY-MM-DD｜anchors.json）`、`[引用1]: evidence:E-20261023-01 （行情｜Yahoo Finance｜价格与一致预期快照｜YYYY-MM-DD｜data/consensus/...）`）。

### 2.3 `${runDir}/return_summary.md`（供主稿引用的 5 条摘要）

主稿子任务只读这份 5 条摘要（不重算分红率与回购率，正文中用 `（见第一节股东回报）` 回指）：

```markdown
- R = x.xx%（由 R1/R2/R3 驱动），得分 x.x / 20；过去 12 个月已实现 x.xx%（分红 x.xx% + 回购 x.xx%），三年平均 x.xx%
- 回购性质：真实股东回报型 / SBC 对冲型 / 混合型（真实回报比例 x%，SBC 占收入 x%）
- 最新政策一句话：……
- 未来 12 个月：预计分红 x.xx% + 回购 x.xx% = x.xx%，政策可信度 p%
- 需要主稿注意的：……（如特别股息不可持续、SBC 稀释吃掉大部分回购、或净现金约束等）
```
