# Bull / Bear Discussion 成稿结构与写作规则（v4.2）

本文件定义 Dalton 个股 Bull / Bear Discussion 完整成稿（v4.2 格式）的章节结构、引用规范、检索方法与自检要求。写稿前请先读 `.agents/skills/dalton-conventions/SKILL.md`。

---

## 0. 核心原则：判断先行与数字纪律

1. **判断先行**
   - 开头第一段「核心判断」直接写当前立场、最重要依据和决定回报的主要变量；立场用中文写全：方向（看多 / 看空 / 中性 / 暂不表态）、确信度（高 / 中 / 低 / 无〔仅暂不表态〕），并在下一行写明**行动分类**（立即行动 / 等待买点〔附买点价带〕/ 等待证据〔附带期限的待验证事项内容〕/ 暂不参与）与**限制变量**（无〔仅"立即行动"〕/ 价格 / 关键证据待验证 / 催化剂时点 / 下行路径风险 / 交易执行条件）；对应枚举写入 `thesis.house_view`，正文不写 `stance`、`conviction` 等字段名或英文枚举值。
   - 紧接其后、`研究窗口` 行之前，单列一行写**投委会四问**（每问 1–2 句）：① 什么在改变客户行为和公司的经济性？② 为什么这个解释比竞争解释更可信？③ 市场在哪个环节判断错了？④ 看到什么我会认错（双向：看到什么减仓或回补、看到什么加仓或加空）？
   - 各 Debate 的「我的判断」先回答更支持哪一边（偏 Bull / 偏 Bear / 中性，置信度高 / 中 / 低），再用简短理由说明取舍。仅罗列限制却缺少判断的段落算审稿必改项。
   - 关键论点按「判断 → 证据 → 对收入、利润、现金或估值的影响 → 改判条件」组织。
   - 遇到“不是 / 不能 / 不代表 / 不等于”式提醒，先找它保护的事实，直接写正确口径及投资含义；实质限制就近简述一次并说明影响，完整口径、未取得材料放在股东回报附录或信源覆盖段。

2. **不编造、带期间、句末引用**
   - 正文里每个数字都要能回指本轮工具结果、任务指定的输入文件（一致预期快照、财务体检表、股东回报摘要）或知识层文件；查不到就标 `N/A` 或“本轮未取得”。
   - **每一句含事实数字的句子，句末带它的引用**：句末（句号或分号之前）标一组 `[引用N]`，该句数字共享这一组；同一来源再次被引用时沿用同一编号（发布前的数字核验按“同一句”绑定引用，跨句不认）。来源身份按需在句中自然写明：
     - 卖方：写机构名，如 `UBS 估计…… [引用9]`、`Morgan Stanley 下调…… [引用3]`
     - 管理层：写 `管理层在 2Q26 电话会上表示…… [引用5]`；能落到具体人写 `CFO 称……`
     - 专家：写身份不写姓名，如 `云计算渠道专家反馈…… [引用14]`
     - 社区：写平台加用户名，如 `X 用户 @xxx 提出…… [引用12]`
     - 公司披露、公告、行情：写 `10-Q 披露…… [引用6]`、`10-K [引用2]`、`行情 [引用1]`
   - **一条底表 / 模型引用只对应一个数字**：`f:<key>` 与 `model:…!<Sheet>!<Cell>` 各只核验一个数值，同句多个这类数字时句末并列多个编号；`evidence:` / `prov:` 可覆盖同句多个数字。同一份来源全文只占一个 `[引用N]` 序号。
   - **表格逐格标注；来源行只用于整表同源**：数字与 `[引用N]` 同格写（模型数字逐格各标各自单元格的引用，派生列不挂其他单元格的引用）；只有整表数字同源时才在表头分隔行之后、数据行之前加来源行（首格写 `来源`），且来源行只放能覆盖全表的引用。正文不写日期、文档 id、链接，这些全部放到文末 `## 引用`。
   - **期间写在句内**：含事实数字的句子在同句写明期间（季度 `2Q26`、`3Q25`，半年 `1H26`，年度 `FY2025`、`2025 年`，滚动 `过去 12 个月（至 YYYY-MM-DD）`）；同句多个数字同一期间只在第一个数字前写一次；期间或口径切换（换财季、季度↔年度、GAAP↔Non-GAAP）时重新标。表格在列头 / 行头标期间。禁止裸写“活跃客户 -2.8%、GMV -1.6%”。
   - **假设、阈值与情景数字按句或按格加豁免标记，且假设和事实数字不写在同一句里**：自己做的预测假设、兑现阈值和情景数字，必须在假设数字所在的那一句或那一个表格单元格里标注 `[假设]`（或 `[估计]` / `[示意]` / `[举例]` / `[阈值]`）；核验按句（句末标点或换行断开，见 `dalton-conventions` 的 `writing.md` 第 4 节）或按表格单元格豁免，标记不会传到下一句或相邻格子，段前或表前写一次不够，且假设和事实数字不写在同一句里，也不把假设标记与外部引用混写。
   - **分析师提问未确认数字**：电话会提问中出现但管理层未明确确认的数字，必须标为“分析师提问口径，管理层未确认”，不得作为管理层指引或已确认 KPI。
   - **股东回报回指**：股东回报支线的结论在主稿二至八节引用时写 `（见第一节股东回报）`，不占主稿 `[引用N]` 序号，不重新计算、不改口径。

## 2. 各节具体写作规则

### 第二节：市场共识（`## 二、市场共识：现在 price in 的是什么`）
- 固定三个父 bullet：`- **看多的人默认成立**：`、`- **看空的人默认成立**：`、`- **两边都不争的**：`。
- **父 bullet 冒号后不跟任何文字**，具体条目全部写成缩进子 bullet（`  - `）。
- 子 bullet 条数严格受检：`看多的人默认成立` 2–4 条、`看空的人默认成立` 2–4 条、`两边都不争的` 1–3 条。每条不超过 45 个汉字，句尾带来源。
- **不把价格走势当共识**：不写股价涨跌、不写技术位；估值倍数必须写成 **EPS × 倍数的情景桥**（这个倍数隐含了什么盈利、什么增长/利润率假设，对应哪档情景价格），不写裸倍数。三块之外不写额外段落。

### 第三节：Top N debates（`## 三、Top N debates：真正有分歧的地方`）
- N 为 2–3 条（最多 3 条，禁止硬凑）。每个 Debate 标题格式：`### Debate k：{可证伪问题}（{≤12 字短名}）`。
- 每个 Debate 固定包含以下五个一级 bullet（`- **块名**：`），全部用 bullet 组织，不写自然段：
  1. `- **分歧**：` 一句话把可证伪的分歧问清楚（不要“前景好不好”这种不可证伪问法）。
  2. `- **Bull 怎么看**：` 下挂 2–4 条子 bullet，每条一个论点加证据并标来源；最后一条固定写 `比共识乐观在哪：……`。
  3. `- **Bear 怎么看**：` 下挂 2–4 条子 bullet，最后一条固定写 `比共识悲观在哪：……`。
  4. `- **双方最强反驳**：` 下挂两条子 bullet：`Bull 对 Bear：……` 与 `Bear 对 Bull：……`，具体到数据或机制。
  5. `- **我的判断**：` 下挂三条子 bullet：
     - `立场与置信度：偏 Bull / 偏 Bear / 中性，高 / 中 / 低（和上一版比有变化就说原因）`
     - `依赖假设：[假设] ……（推导依据）`
     - `改判条件：……`（必须可观察、可量化）
- 固定写「我的判断」，**严禁出现「你的判断」**。

### 第四节：Earnings revision map（`## 四、Earnings revision map`）
- 直接引用准备阶段产出的一致预期快照（`consensus.md`）与 `implied_model.py` 结果，不重算：
  - **一致预期现状**：下一财年 EPS 与收入、7/30/90 天轨迹、近 30 天上调/下调家数、买方预期（whisper，来自 sales-notes / TMTB）。若当期 EPS low-high 区间异常宽或 90 天陡降，核对是否有分析师计入一次性项目（减值、和解、税项）。
  - **修正分层**：收入、费用/capex（或利润率）、一次性项目三层各自往哪边修，按对 EPS 影响大小排序。
  - **隐含费用对比**：`[假设] 卖方费用比一致预期隐含空间多 X，对应 EPS 少 Y（快照敏感度）`（此行不要含 `→` 符号）。
- **驱动变量回指规则**：Revenue、Margin、EPS 三组驱动各 ≤3 条。**凡含 `→` 的行，必须写成 `变量名 → Debate N 短名 → 敏感度（[假设] 变量变动 X 对应收入/EPS 变动 Y）`**（必须带 `Debate N`，不能只写短名）。EPS 驱动只列 revenue/margin 之外的税率、利息、股本、一次性项目。
- **赔率卡（本节末尾必附）**：三情景 EPS × 倍数 = 价格带（单个价带宽度 `(hi − lo) / mid`〔（上沿 − 下沿）÷ 中点〕≤ 25%，三档中点严格递增，主判定取价带中点）＋ 所需胜率与裁决；算法与写法按 `.agents/skills/dalton-conventions/references/risk-reward.md` §2 第 4 条（base〔基准情景〕测试权重固定 25% / 50% 两行，注明"测试权重，不是预测"；裁决用中文四选一——显著高于门槛 / 在门槛附近 / 低于门槛 / 无法判断——并写明方向、所用权重行与所依据分歧的具体内容，正文不写英文枚举值或 `D1` 编号）。

### 第五节：Catalyst & KPI（`## 五、Catalyst & KPI`）
- 按 **3 个月 / 6 个月 / 12 个月** 分组：列出 `事件｜日期或窗口｜检验哪个 debate（Debate N 短名）｜bull/bear 兑现阈值（[假设]）`。
- **KPI**：列 3–5 个核心高频/季报指标，写明当前值（带期间与来源）、bull 区间、bear 区间。
- **近期财报风险**：若 3 个月内有财报，写清财报日期、过去 4 次财报次日涨跌（来自一致预期快照）、买方持仓/拥挤度（来自 sales-notes / TMTB）、公司通常在哪次财报给下一年指引 → 给出本次财报风险方向与置信度。
- **三层保护与失效条件**：生存（资金链 / 融资需求）｜价值（机制与区间）｜路径（跌到价值区之间会发生什么），各写一句并写明失效条件；遵守 `dalton-conventions/references/risk-reward.md` §6 硬规则——不输出单一"底价"、回购授权不算托底（只认实际股本缩减）、EPS × 倍数后不得再加全部净现金、SBC（股票期权报酬）只算一次、历史低谷倍数须说明为何仍适用、融资需求写"未知"时不得宣称生存保护充分。
- **非线性检查**：按 `.agents/skills/dalton-conventions/references/nonlinear.md` 的四类检查表逐类核查（倍数 regime〔定价规则〕切换 / driver〔驱动变量〕非线性 / 拥挤持仓 + 催化剂 / 反身性），有信号写判断与证伪点；无信号时一行写明"本轮没有可承保的非线性机会"。

### 第六节：财务体检（`## 六、财务体检`）
- 只解读准备阶段生成的 `fincheck.md`，不重拉资产负债表和现金流。**结论先行，全节非空行 ≤12 行**：
  - `- **结论**：` 触发项数量、最关键的科目（加粗）及指向（经营性还是财务性，关联哪个 Debate 短名）。无触发时写 `资产负债表没有触发提示项`。
  - `- **核心项目**：` 1–2 项，格式 `**科目**：期间金额、占总资产比例、同比 → 机制解释一句话 → 关联 Debate N 短名（或与 debate 无关）`。
  - `- **其他触发项**：` 简要一行。不重复现金、有息债务、递延收入。
  - `- **Capex**：` 三年序列，固定写 **“Capex 相当于净利润的 x%”**（严禁写“占净利润的 x%”），并与**同一年份**的 D&A 对比。

### 第七节：Variant perception（`## 七、Variant perception`）
- 只写**一个**核心非共识观点：市场当前最可能低估或漏掉的是什么、为什么没看到（信息盲区 / 时间维度错配 / 叙事惯性）、体现在第四节哪个驱动变量上、何时验证。不重复第三节已展开的常规多空论点。

### 第八节：一句话（`## 八、一句话`）
- 固定句式：`The stock works if X; it breaks if Y; the key debate is Z.` 半角分号会断句，X、Y、Z 里的数字各自在本分句内带 `[假设]` 或 `[引用N]`。
- **严禁裸写 `Debate N`**（如禁止 `Debate 1 和 Debate 2 同时成立`）：每次提到 debate 都必须自带可证伪条件，写成 `具体可观察条件（debate N 短名）`。

### 第九节与文末 `## 引用`：股东回报附录与引用
- 若有 PM 要求的额外专题章节，放在第八节之后、`<!-- INSERT:return_appendix -->` 之前；全文最后依次是「股东回报附录」（`## 九、股东回报附录` 或顺延章节）、`## 附注`（写信源覆盖，必须有）、`## 引用`，`## 引用` 之后不得再有其他章节（不再另设独立的来源章节）。
- 在 `## 引用` 之前设 `## 附注`，写 **信源覆盖段**（内部研究库、卖方研报与点评、专家访谈纪要、SEC 文件等各来源是否找到材料、实际用了哪些，未取得的用一句人话写明原因；不写命中数之类的计数，附注里的数字同样要过发布核验）；`## 引用` 节只放引用行，每条一行，按序号排列，同时供 `bb_check.py` 与 `numbers.py` 解析（`## 引用` 里的其他文字会被当成正文核验数字）：
  ```markdown
  ## 附注

  **信源覆盖**：
  - 内部研究库：{是否找到相关材料、实际用了哪些；没找到或没取到的用一句人话写原因}
  - 卖方研报与点评：{同上}
  - 专家访谈纪要：{同上}
  - 一手披露（SEC 文件 / 电话会）：{覆盖了哪几期}

  ## 引用

  [引用1]: evidence:E-20261023-01 （行情｜Yahoo Finance｜价格与一致预期快照｜2026-10-18｜data/consensus/...）
  [引用2]: evidence:E-20261023-02 （公告｜SEC 10-Q｜2Q26 季报与指引｜2026-08-05｜accession 0001326801-...（超 3 个月））
  [引用3]: model:model/META-model-v01.xlsx!DCF!C12 （本方模型｜DCF 估值页核心假设｜2026-10-18｜model/META-model-v01.xlsx）
  [回报引用1]: evidence:E-20261023-04 （行情｜yfinance / anchors.json｜市值与汇率锚点｜2026-10-18｜anchors.json）
  ```
  超过 3 个月的材料在日期后标 `（超 3 个月）`；冒号后第一个词必须为 `evidence:`、`model:`、`prov:`、`f:` 之一。审稿必查：`## 引用` 表存在且每个 `[引用N]` / `[回报引用N]` 都能在表里找到。
