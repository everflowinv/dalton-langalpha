# 股东回报评分规范（Shareholder Return — R1 / R2 / R3）

本参考文件定义 Dalton 财务镜头之三：**股东回报分析与 R1/R2/R3 二十分制评分体系**。所有比率计算与 `scripts/return_score.py` 必须严格遵守本口径。

---

## 1. 统一市值基准与必算 7 项指标

### 1.1 市值基准硬规则
- **分母统一**：所有历史年度（FY-3、FY-2、FY-1）、过去 12 个月（TTM）和未来 12 个月（Forward）的分红率、回购率、总股东回报率，**一律使用 `anchors.py` 锁定的当前美元市值基准（Market Cap Basis）作为分母**，严禁回溯使用历史当时的市值。

### 1.2 必算 7 项核心指标
1. **过去 12 个月已实现分红率（TTM Dividend Yield %）** = 过去 12 个月实际支付（或已宣派且付款日在窗口内）的现金股息总额 / 当前美元市值基准
2. **过去 12 个月已实现回购率（TTM Buyback Yield %）** = 过去 12 个月实际执行的回购现金支出 / 当前美元市值基准
3. **过去 12 个月总股东回报率（TTM Total Return Rate %）** = 指标 1 + 指标 2
4. **最近三个完整财年（FY-3、FY-2、FY-1）每年的总股东回报率，以及三年算术平均（R2）**
5. **未来 12 个月预计分红率（Forward 12M Dividend Yield %）**
6. **未来 12 个月预计回购率（Forward 12M Buyback Yield %）**
7. **未来 12 个月预计总股东回报率（Forward 12M Total Return Rate %）** = 指标 5 + 指标 6

### 1.3 分红与回购口径细则
- **只认实际执行**：只有现金流量表或公告确认**实际已执行买回**的金额才计入已实现回购；董事会或股东大会批准的**回购授权额度（Authorization）本身不计入已实现回报**。
- **分红归属窗口**：按**实际付款日（Payment Date）**（或已宣告且付款日明确落在窗口内）归入对应期间；股票股利（Stock dividend）不计入现金分红。
- **特别股息（Special Dividends）**：
  - 历史期间：当年实际支付的特别股息计入当年分红总额。
  - 未来 12 个月预测：必须先核查近三年特别股息执行记录。**只有连续两年以上发放特别股息**的公司，才可按最近一次金额（或明确指引）计入未来 12 个月预测；否则未来特别股息记为 `0`，并在预测依据中写明。
- **美股一手取数线索**：
  - 现金流量表：`PaymentsForRepurchaseOfCommonStock`（回购现金支出）、`PaymentsOfDividends` 或 `PaymentsOfDividendsCommonStock`（分红现金支出）、`ShareBasedCompensation`（SBC 费用）；
  - 股本变化：资产负债表封面股数、股东权益变动表（发行新股、员工计划行权/RSU 归属、回购注销/库存股变动）；
  - 正文检索：10-K/10-Q 中检索 `"share repurchase"`、`"repurchase program"`、`"dividend"` 核查剩余授权额度与最新一季执行节奏。同一份 filing 内交叉核对单位。
- **港股与 A 股一手取数线索（`route="cn-hk"`）**：
  - **初值提取（`operation="ask"`，二手线索）**：按单一意图分别调用 `researchdata.finance(route="cn-hk", operation="ask", query=f"{code_or_name} 分红", limit=50)` 与 `researchdata.finance(route="cn-hk", operation="ask", query=f"{code_or_name} 回购", limit=50)` 获取分红送转汇总（`fhps` / `fhps_detail`）与股份回购记录（`repurchase`），并结合现金流量表（`query=f"{code_or_name} 现金流"` / `"{code_or_name} 港股现金流"`）中的“分配股利、利润或偿付利息支付的现金”与“回购股份支付的现金 / 支付其他与筹资活动有关的现金”提取初值。
  - **回法定公告原文核实（`operation="filings"` + 披露易退路，必做）**：平台汇总表属二手初值，必须调用 `researchdata.finance(route="cn-hk", operation="filings", ticker=code_5_or_6, start=..., end=..., limit=20)` 调取巨潮资讯（cninfo）的年报/中报附注（股本变动表、股息附注、股份支付 SBC 附注）、权益分派实施公告及回购进展/实施结果公告核实；港股若 `cn-hk filings` 未覆盖某份业绩公告或“翌日披露报表（Next Day Disclosure Return）”，必须用 `web_search` 查港交所披露易（`site:hkexnews.hk`）核对原文链接。
  - **A/H 回购、分红、币种与复权细则**：
    1. **实际执行 vs 方案授权**：A 股回购方案公告中的“拟回购资金总额上下限”属于授权额度，严禁计入已实现回报；只计回购进展/实施结果公告或现金流量表确认的**实际已支付回购总金额**。港股以财报附注或披露易“翌日披露报表”中实际在场内买回的累计金额为准。
    2. **回购用途与真实回报比例**：A 股公司回购常用于“员工持股计划或股权激励”（存放于回购专用证券账户未注销），该部分必须归入 `dilution_offset`，仅明确用于“注销并减少注册资本”的部分计入 `true_return`；港股场内回购通常注销（或在新规下转入库存股），须核对期初期末已发行股份总数及员工购股权/奖励股份（RSU）新发股数以计算 `true_return_share`。
    3. **币种折算与除权核对**：港股公司常以 `HKD` 宣派每股股息或披露场内回购金额，而财报以 `CNY` 列报。以 `HKD` 计价的回购/派息总额须按 `anchors.json` 的 `listing_fx.rate`（`HKD -> USD`）换算为美元，以 `CNY` 列报的现金流/附注总额按 `fx.rate`（`CNY -> USD`）换算为美元，统一除以 `anchors.py` 锁定的当前美元市值基准；同时核查区间内送转股、拆股/合股除权，避免股数基数失真。

## 2. 回购的经济性质与真实回报比例（True Return Share）

### 2.1 回购性质三选一
每家公司必须明确判定回购性质：
1. **真实股东回报型（`true_return`）**：回购股份注销或持续缩减总股本，真实提升每股权益。
2. **SBC 或员工激励稀释对冲型（`dilution_offset`）**：回购股份主要用于抵消员工股权激励（SBC / RSU / 期权行权）带来的股本稀释，总股本未实质下降。
3. **混合型（`mixed`）**：部分对冲员工激励稀释，部分实现净缩股。
（若无回购则标 `none`。）

### 2.2 真实回报比例（`true_return_share`，0 至 1）计算优先级
1. **首选：股数口径（Share Count Basis）**
   ```text
   真实回报比例 = clamp(1 − 用于员工计划新发或再发行的股数 / 同期回购总股数, 0, 1)
   ```
2. **次选：费用口径（Expense Basis，当股数拆分不可得时）**
   ```text
   真实回报比例 = clamp(1 − 同期 SBC 费用 / 同期实际回购金额, 0, 1)
   ```
   必须注明“按 SBC 费用/回购金额近似（费用口径）”。
3. **兜底：混合型默认 50%**
   当股数口径与费用口径均无法可靠拆分时，混合型按 `0.50`（50%）计入，并在备注中明确说明。

### 2.3 SBC 及员工计划年稀释比例（SBC Annual Dilution Ratio）
```text
SBC 年稀释比例 (%) = 当年因员工股权计划新发或再发行的股份数 / 期初总股本 × 100%
```
凡能从年报/季报算出，必须在回购分析与评分理由中列示最近三年的年稀释比例。

## 3. R1 / R2 / R3 二十分制评分公式

### 3.1 三个回报维度（R1、R2、R3）
- **R1（当前已实现真实回报率）**：
  ```text
  R1 = 过去 12 个月已实现分红率 (%) + 过去 12 个月已实现回购率 (%) × 真实回报比例 (true_return_share)
  ```
- **R2（三年历史均值）**：
  ```text
  R2 = (FY-3 总股东回报率 + FY-2 总股东回报率 + FY-1 总股东回报率) / 3
  ```
- **R3（经可信度折算的未来 12 个月回报率）**：
  ```text
  R3 = 未来 12 个月预计总股东回报率 (%) × (政策可信度档位 / 100)
  ```

### 3.2 政策可信度五档（Policy Credibility Tiers）

| 档位（`credibility`） | 判定条件 |
|---|---|
| **100%** | 管理层给出明确返还金额和时间表，或同一量化回报政策（如固定比例 FCF/净利返还）已连续两年兑现 |
| **90%** | 管理层有明确返还比例或金额政策，且当前已有实际执行记录支撑 |
| **75%** | 已宣布正式量化回报政策但尚未满一个执行周期，或近期有持续执行但未来 12 个月具体金额未明确指引 |
| **60%** | 仅有方向性口头表态（如“致力于回馈股东”），且历史实际执行较少或波动较大 |
| **50%** | 仅有董事会回购授权额度或泛泛表态，缺乏实际执行证据 |

### 3.3 基础分、持续性调整与最终分（只在最后一步四舍五入）
1. **主导回报率 `R`**：
   ```text
   R = max(R1, R2, R3)
   ```
   记录驱动项 `driver`（`"R1"`、`"R2"` 或 `"R3"`）。
2. **基础分（Base Score，满分 20）**：
   ```text
   基础分 = min(R, 20.0)
   ```
   （即 R = 7.5% 对应基础分 7.5 分；超过 20% 封顶 20 分。）
3. **持续性调整（Sustainability Adjustment，范围 −1.0 至 +2.0 分）**：
   - 加分项（如 +0.5、+1.0）：三年总回报率逐年稳步上升、股息连续上调、净股本持续显著缩减、极端逆境下仍坚持兑现回报承诺。
   - 减分项（如 −0.5、−1.0）：最近一季回购突然停摆、依赖一次性特别股息或举债分红、自由现金流无法覆盖回报支出、历史承诺多次未兑现。
   - 规则：同一因素不得重复加减；正负因素各自独立列明理由后相抵，总调整额夹逼在 `[−1.0, +2.0]` 之间：
     ```text
     调整分 (adj) = clamp(Σ 单项调整, −1.0, +2.0)
     ```
4. **最终分（Final Score，范围 0.0 至 20.0 分）**：
   ```text
   未四舍五入最终分 = clamp(基础分 + 调整分, 0.0, 20.0)
   最终分 (final_score) = round(未四舍五入最终分, 1)
   ```
   **铁律：中间过程（R1、R2、R3、R、基础分）保留完整浮点精度参与运算，只在计算 `final_score` 的最后一步四舍五入到一位小数**（例如 `14.61 × 0.90 = 13.149`，显示 `R3 = 13.15%`，但加 `0` 调整后最终分为 `13.1`，不能先四舍五入成 `13.15` 再进位成 `13.2`）。

## 4. 固定输出表格与披露要素

报告中必须包含以下两张固定六行表格（六行依次为：`FY-3`、`FY-2`、`FY-1`、`三年平均`、`过去 12 个月（至 YYYY-MM-DD）`、`未来 12 个月（预测）`）：

- **表 1（比率表，分母统一为当前美元市值）**：
  `| 期间 | 分红率 | 回购率 | 总股东回报率 | 主要依据（≤25字） |`
- **表 2（绝对金额表，单位 USD 百万）**：
  `| 期间 | 分红（USD M） | 回购（USD M） | 合计（USD M） | 备注 |`

表后必须逐项列出：
1. **回购性质与真实回报比例**（注明股数口径 / 费用口径 / 50% 默认口径）
2. **SBC 及员工计划年稀释比例**（近三年逐年）
3. **最新回购执行情况**（当前剩余授权额度、最近一季实际回购金额、执行节奏）
4. **管理层最新回报政策**（中文总结 + 原文出处与日期）
5. **未来 12 个月预测依据**（管理层指引 / 卖方预期 / 趋势外推，及特别股息处理说明）
6. **评分拆解**（直接粘贴 `return_score.py` 输出的 `rationale_zh`，含 R1、R2、R3、可信度档位及理由、R、基础分、每项调整与最终分）
