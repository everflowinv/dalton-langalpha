# 财报深度点评八节结构与证据标注规范（`eight-sections.md`）

本文件定义 `dalton-earnings-deep`（PS.9）的八节标准结构、新增的“前瞻对账”与“thesis 校准”章节、四类信息标注纪律以及一手证据层级契约。**报告的一级与二级标题必须逐字遵守下文结构。**

---

## 一、证据契约与四类信息标注（必守硬规则）

### 1. 一手证据优先级阶梯（Evidence Ladder）
报告中所有实际财务与经营数字必须按以下优先级从高到低采信，并在句末或表注给出可在 30 秒内定位的出处（文件 + 页码/表名/章节/电话会说话人）：
1. 已提交的当季 **`10-Q` / `10-K`**（外国私人发行人 **`6-K` / `20-F`**；港股与 A 股为通过 `researchdata.finance(route="cn-hk", operation="filings", ticker=CODE_5_OR_6, start=..., end=..., limit=20)` 获取的 **HKEX 披露易业绩公告/中报/年报与巨潮资讯法定定期报告**，港股若 `cn-hk filings` 未覆盖则用 `web_search` 查 `site:hkexnews.hk` 原文链接；`researchdata.finance(route="cn-hk", operation="ask", ...)` 平台财务表仅作二手初值线索，核心财务数字必须回法定公告原文核实）；
2. 披露当季业绩的 **`8-K EX-99.1`** 及其财务附表（Financial Supplement）；
3. 公司官方 **财报新闻稿（Earnings Release）**；
4. 公司官方 **业绩演示 PPT（Investor Presentation）与预备发言稿（Prepared Remarks）**；
5. **业绩电话会纪要（Transcript）**——仅作为定性机制、Q&A 和背景支撑，绝不单独作为已披露报表数字的首选来源。

- **口头指引标注**：仅在电话会口头提及、未写入新闻稿或归档表格的指引，必须在出现处显式标注 **`[电话会口头指引 / call-only guidance]`**。
- **Non-GAAP 配对纪律**：每个 Non-GAAP / Adjusted 指标首次出现或进入主表时，必须同时列出最接近的 GAAP 可比指标或说明两者的调节项（如 SBC、无形资产摊销、重组费用）。
- **缺失数据四词规范（严禁留空或裸写 `N/A`）**：
  - `未指引（not guided）`：公司拒绝或不提供该项指引；
  - `未披露（not disclosed）`：公司不对外公布该项历史指标；
  - `材料未含（not provided）`：指标存在但当前已获取材料中未包含；
  - `来源未获（source not found）`：已检索但未能核实（对应 `needs-source`）。

### 2. 严格区分四类信息标签

| 信息类别 | 定义与边界 | 正文呈现方式 |
|---|---|---|
| **事实** | 公司 10-Q/10-K/8-K/6-K、财报新闻稿、PPT、补充财务表中**已正式披露**的历史数据与既定事件 | 直接陈述并附一手来源定位；未经管理层确认的客户/订单传闻必须标 `[市场推测/管理层未确认]` |
| **管理层指引** | 新闻稿或电话会 Prepared Remarks / Q&A 中管理层对下季、全年或中长期给出的正式目标与定性口径 | 明确写“管理层指引/表示”，口头指引加标 `[call-only guidance]`；分析师提问中的数字未经确认严禁当指引 |
| **市场预期** | 卖方一致预期（注明快照日期）、买方 bogey、卖方研报观点及财报后股价隐含预期差 | 标明机构名称或一致预期快照出处 |
| **研究判断** | 分析师在事实、指引与预期对比基础上得出的独立推论与定性 | 集中放在各节的 **「点评」「综合判断」「关键观察」「值得关注的变化」「投资含义」** 小结中 |

#### 3.2 主要增长引擎（每个核心增长引擎独立成段）
对每个增长引擎依次拆解五项内容：
- **本季变化**：收入金额、同比/环比增速、占比变化、相对公司整体与同业的强弱；

### 六、市场观点与股价表现

- **财报后股价表现**（由 `scripts/price_reaction.py` 生成）：
  - 盘后（或盘前）、次日、一周（5 个交易日）的**绝对涨跌幅**与**相对基准（QQQ / SPY / 板块 ETF，硬件股加 SOX）超额涨跌幅**；
  - 截至最新收盘价在**真实 252 个交易日（52 周）高低区间**中的位置。
- **为什么动（归因分析）**：结合当季 beat 幅度、下季/全年指引上修幅度、财报前买方 bogey 预期差以及持仓拥挤度，解释股价反应的真实驱动。
- **多头核心逻辑（Bull Case）**：3–5 条（本季财报强化的证据）。
- **空头/担忧逻辑（Bear Case）**：3–5 条（本季财报暴露或未消除的隐患）。
- **卖方目标价与评级变化**：汇总财报后 3 个交易日内主流券商的评级调整、目标价修正区间与 FY0/FY1 盈利预测上修/下修幅度。

### 八、综合投资观点

- **评级倾向**：**积极 / 中性 / 谨慎**（给出清晰、克制的研究倾向，不写简单买卖指令，没有足够预期差可写“暂无高 conviction”）。
- **短期催化剂**：明确列出未来 1–2 个季度内的产品发布、行业大会、产能爬坡、监管节点或下次财报验证点。
- **估值参考**：给出当前股价对应的 **P/S、P/E、EV/EBITDA、EV/Sales**（硬件周期股加 mid-cycle P/E），并对比 **Bull / Base / Bear** 三情景下的目标倍数与隐含估值空间。
- **核心持有逻辑**：3–5 条精炼支柱。
- **破坏 Thesis 的条件（Falsifiers）**：明确写出哪些可观察数据或事件跌破何种阈值时会推翻当前判断。
