# 财报深度点评正文结构与证据标注规范（`eight-sections.md`）

本文件定义 `dalton-earnings-deep` 的正文结构（见 [`templates/deep.md`](../templates/deep.md)）、前瞻对账与论点校准的呈现边界（逐条表格留内部文件、正文只写结论），以及四类信息标注与一手证据层级契约。**报告的各级标题必须遵守 `templates/deep.md` 的结构（首个二级标题为 `## 摘要`），报告抬头只写发布日期和研究时点，不写内部取数状态。**

---

## 一、证据契约、四类信息标注与引用纪律（必守硬规则）

### 1. 一手证据优先级阶梯（Evidence Ladder）
报告中所有实际财务与经营数字必须按以下优先级从高到低采信，在句末或表格单元格内标注 `[引用N]`，并在文末 `## 引用` 给出可定位的出处（文件、页码/表名/章节或电话会说话人）：
1. 已提交的当季 **`10-Q` / `10-K`**（外国私人发行人 **`6-K` / `20-F`**；港股与 A 股为通过 `researchdata.finance(route="cn-hk", operation="filings", ticker=CODE_5_OR_6, start=..., end=..., limit=20)` 获取的 **HKEX 披露易业绩公告/中报/年报与巨潮资讯法定定期报告**，港股若 `cn-hk filings` 未覆盖则用 `web_search` 查 `site:hkexnews.hk` 原文链接；`researchdata.finance(route="cn-hk", operation="ask", ...)` 平台财务表仅作二手初值线索，核心财务数字必须回法定公告原文核实）；
2. 披露当季业绩的 **`8-K EX-99.1`** 及其财务附表（Financial Supplement）；
3. 公司官方 **财报新闻稿（Earnings Release）**；
4. 公司官方 **业绩演示 PPT（Investor Presentation）与预备发言稿（Prepared Remarks）**；
5. **业绩电话会纪要（Transcript）**——仅作为定性机制、问答（Q&A）和背景支撑，绝不单独作为已披露报表数字的首选来源。

- **电话会口头指引的自然表述**：仅在电话会上口头提及、未写入新闻稿或法定归档表格的指引，在正文用自然中文说明（例如“管理层在电话会上口头表示，未写入公告”），不在正文贴英文内部标签。
- **Non-GAAP（非公认会计准则）配对纪律**：每个 Non-GAAP / 调整后（Adjusted）指标首次出现或进入主表时，必须同时列出最接近的 GAAP（公认会计准则）可比指标或说明两者的调节项（如股权激励费用 SBC、无形资产摊销、重组费用；冗长调节明细放入文末 `## 附注`）。
- **缺失数据四词规范（严禁留空或裸写 `N/A`）**：
  - `未指引（not guided）`：公司拒绝或不提供该项指引；
  - `未披露（not disclosed）`：公司不对外公布该项历史指标；
  - `材料未含（not provided）`：指标存在但当前已获取材料中未包含；
  - `来源未获（source not found）`：已检索但未能核实（对应 `needs-source`）。

### 2. 严格区分四类信息标签

| 信息类别 | 定义与边界 | 正文呈现方式 |
|---|---|---|
| **事实** | 公司 10-Q/10-K/8-K/6-K、财报新闻稿、PPT、补充财务表中**已正式披露**的历史数据与既定事件 | 直接陈述并附一手来源定位；未经管理层确认的客户/订单传闻必须标 `[市场推测/管理层未确认]` |
| **管理层指引** | 新闻稿或电话会开场陈述（Prepared Remarks）/ 问答中管理层对下季、全年或中长期给出的正式目标与定性口径 | 明确写“管理层指引/表示”，仅口头提及的用自然语言注明未写入公告；分析师提问中的数字未经确认严禁当指引 |
| **市场预期** | 卖方一致预期、买方隐含预期门槛（bogey）、卖方研报观点及财报后股价隐含预期差 | 正文直接写“一致预期 [引用N]”或机构观点，具体快照或研报来源细节放在 `## 引用` |
| **研究判断** | 分析师在事实、指引与预期对比基础上得出的独立推论与定性 | 用连贯论证说明背后的业务与财务机制，与事实句子清晰区分 |

### 3. 正文可读性与数字引用硬规则
- **先给判断、再讲原因，控制句子数字密度与跨章节去重**：每个段落先用一句话给出清晰判断，再用两三句解释原因；每句事实数字不超过两个，不层层嵌套括号；细节数字放到表格或后续章节，影响判断的缺口在相关判断首次出现处用一句话写清影响，口径细节、Non-GAAP 调节明细与正文没有说明过的其余缺口、检索范围、失败原因集中放入文末 `## 附注`。成稿和每次修订后通读全文，同一缺口、同一限定、同一改判条件全文只保留最合适的一处。
- **正文不出现内部状态与代号**：正文给基金经理直接阅读，不写取数状态标签，不写 `P1`、`D1`、`V-001`、`Q-007` 等内部编号，不写 `reconcile.md`、`thesis-calibration.md`、`management-delta.md`、`predictions.json`、`lessons.md` 等内部文件名，不写英文枚举值，禁用数学公式符号；英文专业术语首次出现时附中文解释。
- **事实句与假设句严格分句、模型引用一数一格**：
  - 核验器按句（`。！？!?；;`）豁免：凡带 `[假设]` 的句子，整句数字都会跳过事实核验，因此**严禁把 `[假设]` 和事实数字写在同一句里**（中文逗号和括号不断句，必须拆成独立句子：事实一句标 `[引用N]`，假设一句标 `[假设]`）；
  - 表格中**每个含事实数字的格子都带自己的 `[引用N]`**（若整张表所有数字确系同一来源且该来源覆盖全表，可在表头分隔线下第一行用 `来源` 行统一标注）；
  - **一条 `model:` 引用只对应一个数字**：工作区有 Excel 模型时，每个由模型算出的数字必须各自使用独立的 `[引用N]`，并在 `## 引用` 中分别指向各自的**单个单元格**（如 `model:model/META-model-v01.xlsx!Scenarios!C12`、`Scenarios!D12`，严禁把多个不同数字指向同一个 `model:` 引用，也严禁引用单元格区域如 `B1:K45`）；只有未进模型、由分析师自己设定的情景假设与阈值才标 `[假设]`；
  - 同一处引用多个来源时紧挨着写成 **`[引用1][引用2]`**，**严禁在同一个方括号内用逗号合写多条引用**（发布核验器不认逗号分隔）。

|---|---|---|
| 一、核心判断 | `## 摘要` | 4 段连续论证 + 1 张最多 5 列（`指标 \| 本季 \| 一致预期 \| 差异 \| 含义`）、不超过 8 行的关键数字表（一格一个数字） |

| 三、业务结构拆解 | `## 业绩与指引`（`### 分部表现与主要增长引擎`） | 分部收入分布表 + 核心增长引擎分段论述（硬件股按 `hardware-overlay.md` 的 A–G 子模板展开）+ 非核心业务定位 |
| 四、三大财务报表关键变化 | `## 业绩与指引`（`### 整体业绩、盈利质量与三表关键变化`）+ `## 附注` | 正文写利润表费用杠杆、资产负债表净现金/存货/应收/递延收入/**商誉与无形资产**/**长期采购承诺**的重要变化、自由现金流（FCF）转换率 / 资本开支（Capex）强度 / SBC 相当于 FCF 的比例 / **并购现金支出** / **融资与偿债净额** / 实际回购与股本变化及三表对照；明细与 Non-GAAP 调节明细放 `## 附注` |
| 五、电话会议要点总结 | `## 业绩与指引`（`### 下一季与全年指引及电话会增量信息`） | 提炼管理层开场陈述 2–4 个增量要点、5–10 行高信息密度问答（Q&A）精选表及闭幕定调 |

| 前瞻对账、支柱校准、管理层兑现 | `## 投资逻辑的验证`（`### 核心支柱校准、前瞻对账与管理层兑现结论`） | **逐条表格留在 `reconcile.md`、`thesis-calibration.md`、`management-delta.md`**；正文对三项各用 1–2 句话写结论（含中文信号/状态词、事件五词中文终判、五种漂移排查结果、对账错因与管理层指引可信度） |

| 资料来源与核验映射 | `## 引用` | 文末单一 `## 引用` 节 |

## 三、分章节写作细则

### 1. `## 摘要`
- **4 段连续论证**（每段首句给判断，再用两三句解释原因；每句事实数字不超过两个，细节数字留给表格或后文）：
  1. **本季最重要的变化与投资判断**：首句直接给出本季财报定性与是否改变投资判断（事件五词中文：**强化 / 削弱 / 无变化 / 证伪 / 新论点**）；随后用两三句说明最核心的一两个预期差与下一季指引方向，并交代方向、确信度、行动分类与限制变量。
  2. **核心业务驱动与盈利成色**：首句判断本季业务增长与盈利改善是否扎实；随后用两三句说明核心拉动业务、利润率与自由现金流表现，以及表面 EPS 超预期是否受税率或非经常性损益放大。
  3. **指引、电话会增量与多空焦点**：首句概括管理层指引与电话会传递的边际变化；随后用两三句说明管理层对后续季度的关键定调（仅电话会口头提及的用自然语言注明未写入公告）及财报后一致预期修正方向与多空焦点。
  4. **赔率与决定行动的关键条件**：首句明确赔率与行动分类是否变化；随后用两三句结合当前估值与三情景空间说明原因，只写当前结论、决定行动的那一个条件与接下来盯哪一两件核心跟踪事项（不再附带下行风险清单；完整改判条件在 `## 跟踪` 节集中列一次，摘要不展开清单；若含分析师自设的情景假设或阈值，必须单独成句并标 `[假设]`，不得与事实数字同句）。
- **关键数字表（最多 5 列、不超过 8 行）**：列固定为 `指标 | 本季 | 一致预期 | 差异 | 含义`，一格只放一个数字；指引、同比、环比放到 `## 业绩与指引` 节的表格里。每个含事实数字的格子带 `[引用N]`（或整表同源时用 `来源` 行）。

### 2. `## 业绩与指引`
- **`### 整体业绩、盈利质量与三表关键变化`**：
  - 利润表：分析预期差最大的科目、研发/销售/管理费用率经营杠杆、股权激励费用（SBC）占比、有效税率及一次性非经营项目（重组、减值、公允价值变动、汇兑），拆解经常性 EPS（剔除有效税率、股票回购缩减股数与一次性非经营损益后的真实经营超预期幅度，事实数字与假设数字分句书写）；
  - 资产负债表：核查现金及短期投资、基础净现金与严格净现金（扣除受限现金、可转债、租赁负债等经营性类债务）、应收账款、存货及周转天数（DOI）、递延收入 / 当前剩余履约义务（cRPO）、有息负债，以及**商誉与无形资产**、**长期采购承诺**（重要变化写进本节正文与表格，明细放入 `## 附注`）；
  - 现金流量表：计算并点评 **自由现金流转换率（FCF / Non-GAAP 净利润）**、**资本开支强度（Capex / 营业收入）**、**SBC 相当于 FCF 的比例**、**并购现金支出**、**融资与偿债净额**，以及当季实际股票回购金额与扣除 SBC 后的实际股本变化（重要变化写进本节正文与表格，明细放入 `## 附注`）；
  - 行业核心经营指标：SaaS（软件即服务）/ 软件公司必加年度经常性收入（ARR）、净收入留存率（NRR）、大客户净增（Net Adds）、cRPO / 剩余履约义务（RPO）、新签订单额 / 开票额（Bookings / Billings）；消费 / 零售 / 平台公司必加同店增速（SSSG）、订单数（Orders）、客单价（AOV/AUR）、活跃/付费用户数；半导体 / 硬件公司按 [`hardware-overlay.md`](hardware-overlay.md) 叠加毛利结构、库存天数、晶圆/产品结构与新品爬坡成本。
- **`### 分部表现与主要增长引擎`**：
  - 列出分部或终端市场收入分布表；
  - 对每个主要增长引擎分段写清：首句给判断，随后交代本季变化、管理层指引（仅电话会口头提及的用自然语言注明未写入公告）、产品/技术进展、已确认客户或中标（未确认传闻标 `[市场推测/管理层未确认]`）及投资点评（硬件股按 `hardware-overlay.md` 的 A–G 子模板展开）；
  - 明确非核心业务定位（现金流底盘 / 周期底部企稳 / 战略收缩 / 早期期权）及对整体利润率的影响。
- **`### 下一季与全年指引及电话会增量信息`**：
  - 列出下一季与全年指引对比表（对比上次指引、本次更新与市场一致预期，写出隐含同比/环比增速）；
  - 提炼管理层开场陈述 2–4 个增量要点与闭幕定调（若无开场或闭幕陈述则如实注明），并附上 5–10 行高信息密度的问答（Q&A）精选表（含议题、提问者、管理层回答要点、投资含义）。

### 3. `## 投资逻辑的验证`
- **`### 股价反应与市场预期差`**：
  - 由 `scripts/price_reaction.py` 生成财报后股价表现：盘后/盘前、次日（T+1）、一周（5 个交易日）的绝对涨跌幅与相对基准（`QQQ` / `SPY` / 板块 ETF，硬件股加 `SOXX`/`SMH`）超额涨跌幅，以及最新收盘价在**真实 252 个交易日（52 周）高低区间**中的位置（引用指向 `price_reaction.py` 证据文件，不指向模型单元格）；
  - 股价反应归因：结合当季超预期成色、指引修正、买方隐含预期门槛与持仓拥挤度解释股价波动，严禁拿股价涨跌直接代替基本面验证信号；
  - 列出本季财报强化的**多头核心逻辑（3–5 条）**、暴露或未消除的**空头/担忧逻辑（3–5 条）**，以及财报发布至发布后 3 个交易日（T0 至 T+3）内主流卖方与独立研究（AlphaEngine / FUNDA AI / TMTB / 销售交易台笔记〔Sales Notes〕）的盈利预测与目标价修正。
- **`### 核心支柱校准、前瞻对账与管理层兑现结论`**：
  - **逐条对账表、支柱逐条校准表、历史指引逐条兑现表一律留在工作区 `research/<D>-deep-<quarter>/` 下的 `reconcile.md`、`thesis-calibration.md`、`management-delta.md` 内部文件中**；
  - 报告正文在此处**对三项各用一两句话写出结论**（不写 `P1`、`V-001` 等内部编号、英文枚举或内部文件名）：
