# 专题研究与事件笔记（`research/`）

本目录存放自由格式的研究过程文档、事件快评底稿、专家访谈深加工笔记与产业链交叉验证材料。

## 命名与使用约定

- **推荐命名**：`<YYYY-MM-DD>-<slug>.md`（例如 `2026-10-21-3q26-earnings-notes.md`、`2026-10-18-legacy-import.md`）。
- **与知识层的分工**：
  - `research/` 用于存放展开的论证过程、原始数据摘录与专项课题分析；
  - 凡是改变了核心 Thesis 支柱、多空分歧（Debate）、关键驱动读数（Drivers）、管理层评价、复盘教训（Lessons）或下阶段待验证议程（Agenda）的结论，必须同步调用 `knowledge_update` 或 `knowledge_append_verdict` 写入结构化知识层。
