# 设置位置与代改范围（Settings Map）

用户询问某项设置在哪里修改，或需要确认研究总监（Chief of Staff，简称 CoS）能否代改时，按本表回答。本表页面路径以当前前端界面为准。

## 一、系统、模型与账户设置

| 设置项 | 在哪里改（页面路径） | CoS 能否代改（用哪个工具） |
|---|---|---|
| 姓名、语言、时区、引导完成状态 | 设置 → 个人资料（姓名）；设置 → 通用与外观（语言、时区） | **能。** 编辑 `.agents/user/profile/user.json` |
| 投资画像、风险偏好、研究深度、输出格式、主动性、长期指示 | 设置 → 投资画像；设置 → 对话与助手 | **能。** 编辑 `.agents/user/profile/preference.json` |
| 自选股与持仓 | 侧栏「仪表盘」→「自选股」/「投资组合」卡片 | **能。** 编辑 `.agents/user/profile/` 下 `watchlist.json`、`portfolio.json` |
| 重置全部偏好（整组清空） | 设置 → 投资画像 → 重置偏好 | **不能整组重置。** 仅能清空资料文件开放的字段，整组重置请用户到上述页面操作 |
| 账户默认模型、更改默认模型时的适用范围、后台模型 | 设置 → 模型（默认模型、更改默认模型时） | **否。** 由用户在页面修改 |
| 收藏的模型（快捷列表）、账户默认值与按模型调参（思考强度、提示词详细程度、快速模式、压缩预设、闲置压缩） | 设置 → 模型（收藏的模型）；开启「高级模型设置」→ 展开「高级：后台任务使用的模型」内的「账户默认值」与「按模型设置」 | **否。** 由用户在页面修改 |
| 模型路由（网页抓取、上下文压缩、备用模型）与后台任务专用模型（数据核验、文字审校、核验备用、单次核验超时、轻量后台任务、独立复核候选、研究记忆整理） | 设置 → 模型 → 开启「高级模型设置」→「路由」与展开「高级：后台任务使用的模型」 | **否。** 由用户在页面修改 |
| 主助理搜索服务、搜索深度、子智能体（子 Agent）默认开关 | 设置 → 对话与助手（网络搜索引擎、搜索深度、子 Agent） | **否。** 账户级开关在页面修改；单个子智能体配置可编辑 `.agents/user/agents/<name>.md` |
| 自动批准派发分析、自动批准新建工作区 | 设置 → 对话与助手（交给分析师前不再询问、创建工作区前不再询问） | **否。** 授权开关由用户在页面修改 |
| 当前对话模型；单对话思考强度、快速模式、子智能体许可 | 当前对话模型、单对话思考强度、快速模式与子智能体（子 Agent）开关均可在对话输入区修改；账户默认模型在「设置 → 模型」修改 | **模型能，其余否。** 用户本轮明确要求切换当前对话模型时调用 `switch_thread_model`，从用户下一条消息起生效 |
| 交易权限（长期授权） | 当前版本不提供交易权限设置入口 | **否。** 当前版本不开放交易权限设置页 |
| 预算（每日总上限、单任务默认上限、日切重置时区、按工作区覆盖单任务上限） | 设置 → 用量与预算 → 个人每日美元预算（搜索名：每日预算与花费上限） | **否。** `dalton_coverage_board` 仅只读查看今日预算，修改请用户在页面操作 |

## 二、工作区、插件与工具设置

| 设置项 | 在哪里改（页面路径） | CoS 能否代改（用哪个工具） |
|---|---|---|
| 工作区迁移（更换计算机） | 在目标工作区菜单选择「迁移到其他计算机…」，并指定目标计算机 | **否。** 迁移须由所有者在界面操作 |
| 工作区自动入库（`dalton_auto_ingest`） | 在对应工作区的对话列表顶部切换「自动入库：开启 / 关闭」 | **否。** 开关随工作区生效，由用户在界面切换 |
| Discord 自动入库频道与发送者策略 | 对应自动化任务的任务指令（`instruction`）中配置频道 ID 与发送者策略；工作区是否启用自动入库在工作区对话列表顶部切换 | **部分能。** 个人自动化任务可在 `.agents/user/automations/*.json` 修改任务指令；公司公共任务与工作区自动入库开关由有权限的成员在界面修改 |
| 账户插件与连接器（MCP 服务）管理 | 侧栏「插件」页（插件、连接器、技能、密钥、子 Agent） | **否。** 账户级安装与启停在插件页管理 |
| 单个工作区的技能与 MCP（模型上下文协议）启停 | 对应工作区设置打开的 `Sandbox Settings` 面板（`MCP` / `Skills` 标签页） | **否。** 在该工作区的 `Sandbox Settings` 面板操作 |

## 三、自动化（定时任务）设置

| 设置项 | 在哪里改（页面路径） | CoS 能否代改（用哪个工具） |
|---|---|---|
| 个人任务的新建、编辑、暂停、恢复 | 侧栏「自动化」→「我的任务」 | **能。** 读写 `.agents/user/automations/*.json` |
| 受覆盖单元管理的财报任务、标准覆盖跟踪、公司公共数据任务 | 侧栏「自动化」→「研究跟踪」或「公司公共任务」；只读状态见「设置 → 团队管理 → 团队渠道与运维 → 自动巡检与团队公共任务」 | **部分能。** 财报排期用 `dalton_schedule_automation`，标准覆盖跟踪用 `dalton_coverage_tracking`，公司公共数据任务用 `dalton_system_jobs`（传 `data:<job_key>`）；运维任务只读；受管任务禁止直接改任务文件 |
| 自动化任务删除、回收站恢复与版本回退 | 恢复：侧栏「自动化」中「我的任务」「研究跟踪」「公司公共任务」每个分组底部各有独立「回收站」（普通任务删除超过 30 天会被清理）；版本回退：任务详情中的「修改历史」；立即运行：任务详情的立即运行按钮 | **个人任务可软删除，恢复与回退不能。** 个人任务通过文件设 `status: "deleted"` 或删除文件移入回收站并保留运行历史；受管任务不能经文件删除，可通过专用工具暂停 |
| 已有公司公共智能任务的编辑与管理 | 侧栏「自动化」→「公司公共任务」 | **否。** 个人任务不支持通过提交身份字段转换为公司公共任务，由有权限的成员在页面按版本编辑 |
| 普通结果投递、完成通知、定时报告投递 | 见本表第四节「自动推送总开关」及任务详情 | **能。** 普通结果填任务文件 `delivery`（先读 `.agents/user/channels/available.json`，传 `[]` 关闭）；完成通知用 `dalton_notify_settings`；定时报告（调用 `automation_report`）的卡片、文字与失败提醒用 `dalton_report_delivery`（群目标先请用户确认）；个人完成通知与报告投递均受属主的自动推送总开关限制 |
| 覆盖单元归属与个人覆盖名单 | 覆盖结构见「设置 → 覆盖结构」 | **能。** 团队覆盖单元用 `dalton_coverage_unit`，个人覆盖名单、分组和层级用 `dalton_coverage` |

## 四、通知、渠道、共享与团队记忆

| 设置项 | 在哪里改（页面路径） | CoS 能否代改（用哪个工具） |
|---|---|---|
| 自动推送总开关、默认个人收件人 | 设置 → 消息与渠道 → 自动推送与接收账号（搜索名：消息推送与接收账号，开启「自动推送总开关」） | **部分能。** `dalton_notify_settings(action="add_personal_target")` 可经确认添加个人飞书/Discord 目标；总开关及列表管理在页面操作 |
| 个人渠道绑定与解绑（飞书、Discord、个人微信） | 设置 → 消息与渠道（飞书与 Discord 账号绑定、我的微信绑定） | **否。** 绑定码验证与解绑在页面完成；已绑定渠道的默认工作区、首选聊天与默认投递可通过 `.agents/user/channels/channels.json` 修改（Dalton 支持飞书、Discord 和个人微信，个人微信仅支持普通私聊 `weixin:@me`） |
| 团队微信机器人、Discord 频道、飞书文档访问范围 | 团队微信机器人 / Discord 频道：设置 → 团队管理 → 团队渠道与运维；飞书文档访问范围：设置 → 团队管理 → 成员与权限 | **否（管理员专用）。** 仅管理员可在页面维护；CoS 仅可为有权限的任务选择已授权目标 |
| 飞书团队群绑定 | 设置 → 团队管理 → 团队渠道与运维 → 飞书团队群 | **否（内部成员及以上可见）。** 内部成员及以上可在页面查看群列表与测试发送；CoS 仅可为有权限的任务选择已授权群目标 |
| 工作区访问级别、账户协同共享开关、组织共享成员与角色 | 工作区访问级别：对应工作区对话列表顶部的「共享设置」弹窗；账户协同共享开关：设置 → 对话与助手 → 工作区协同共享；组织共享成员与角色：工作区的成员弹窗 | **否。** 共享授权由工作区所有者或管理者在页面操作 |
| 团队记忆（Home 与工作区） | Home 的团队记忆：设置 → 对话与助手 → 共享团队历史研究记录；工作区的团队记忆：对应工作区对话列表顶部的「共享设置」→ 团队记忆 | **否。** 开关由用户在页面切换；当前轮次是否可用以本轮运行时状态为准 |
| 共享工作区内的对话私有 / 共享状态 | 尚未共享的对话：对话输入区的隐私切换标签；已共享的对话：聊天顶部的隐私栏（有权改回私有的发起人可操作） | **否。** 由用户在页面切换 |
| 对话分享链接与工作区文件分享链接（受众、附件浏览与下载权限） | 对话右上角「分享对话」面板（受众「谁可以打开」与「允许浏览文件 / 允许下载文件」）；文件链接在工作区文件菜单管理 | **否。** 分享链接与附件权限由用户在界面管理 |

## 五、后台模型与入门模型说明

- **后台模型与默认推理强度**：生成标题等后台任务通常使用后台模型。使用后台默认模型且未指定推理强度（`reasoning_effort`）时，多档模型默认使用低档（`low`）；用户设置和调用显式指定的值优先。数据核验（数字核验）与文字审校（语言审查）使用各自独立配置（路径见第一节「高级：后台任务使用的模型」），不与通用后台模型混用。
- **入门模型候选与资料访谈**：入门模型页与资料访谈是两个独立步骤。入门模型页按顺序显示账户当前可用的推荐项：`Gemini 4 Neon`、`Gemini 4 Carbon`、`Claude Opus 5.5`、`GPT-6.2 Astra`、`GPT-6.2 Sol`。当 Claude Opus 首选不可用时，可显示其 `medium` 候选。若列表中没有可用推荐项，请用户联系管理员检查模型访问后点击重试。
